17.1 Describe the Need for and Purpose of Financial Statement Analysis
Need for Analysis
  • Need to calculate ratios
  • Need to compare periods
  • Need to compare to benchmarks
  • Need to identify trends
Purpose
  • Evaluate performance
  • Identify strengths and weaknesses
  • Make decisions
  • Communicate with stakeholders
  • Plan for future
17.2 Prepare Comparative Financial Statements
Comparative Statements
  • Show multiple periods side-by-side
  • Allow period-to-period comparison
  • Show changes in amounts and percentages
  • Identify trends
Format
17.3 Prepare Common-Size Financial Statements
Common-Size Statements
  • Express items as percentages
  • Income statement: % of revenue
  • Balance sheet: % of total assets
  • Allow comparison regardless of size
Income Statement Format
17.4 Compute and Interpret Financial Ratios
Types of Financial Ratios
Liquidity Ratios
  • Measures short-term liquidity
  • Higher is generally better
  • Should be > 1.0
  • Typical range: 1.5 - 3.0
  • Current Assets: €100,000
  • Current Liabilities: €50,000
17.5 Analyze and Interpret Return on Assets
Return on Assets (ROA)
  • How efficiently assets generate profit
  • Overall profitability
  • Asset utilization
Interpretation
  • Efficient use of assets
  • Good profitability
  • Effective management
  • Inefficient asset use
  • Low profitability
  • May need improvement
17.6 Appendix: Describe Other Measures Used to Analyze a Company
Other Measures
  • Measures value creation
  • Considers cost of capital
  • Advanced measure
  • Price-to-earnings (P/E)
  • Market-to-book
  • For public companies
Luxembourg Considerations
  • Focus on basic ratios
  • Compare to benchmarks
  • Use for decision-making
  • Less focus on market ratios

17.8 Luxembourg SME Performance Indicators
Key Indicators
  • Profitability ratios
  • Liquidity ratios
  • Efficiency ratios
  • Growth indicators
Typical Values
  • Gross margin: 30-50%
  • Net margin: 5-15%
  • Current ratio: >1.5
  • Gross margin: 40-60%
  • Net margin: 3-10%
  • Inventory turnover: 4-6 times
Key Terms
Common-Size Statement

Comparative Statement

Financial Ratio

Return on Assets (ROA)

Return on Equity (ROE)
