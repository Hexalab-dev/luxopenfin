# Supplementary Materials

This directory contains all supplementary materials for the Luxembourg SME Accounting Textbook, organized by category.

## Structure

### Instructor Resources
Materials for educators and trainers using this textbook:
- PowerPoint slides
- Test banks
- Assignment rubrics
- Teaching notes
- Solution manuals

### Student Resources
Materials for students and self-learners:
- Interactive tools
- Practice exercises
- Video tutorials
- Templates
- Study guides

### Interactive Tools
Web-based and downloadable tools:
- T-account simulator
- Journal entry practice tool
- PCN account lookup
- VAT calculator
- Financial statement generator

### Multilingual Support
Translation and localization resources:
- French translations
- German translations
- English version (base)
- Audio versions
- Video subtitles

## Development Status

These materials are being developed alongside the main textbook content. Check individual directories for current status.
