# Supplementary Reference Materials

This directory contains specialized reference materials that complement the main textbook volumes but are too specialized or structured differently to be integrated directly into the main content.

## Contents

### BTS_Curriculum_Structure.md
- **Purpose**: Course curriculum structure for BTS "Gestionnaire comptable et fiscal" program
- **Use**: Reference for course planning and organization
- **Content**: Module structure, ECTS credits, course descriptions

## Future Additions

Additional specialized materials may be added here, such as:
- Municipal/cameral accounting guides
- Sector-specific accounting methodologies (e.g., healthcare KTR)
- Advanced specialized topics

## Integration with Main Textbook

These materials are designed to:
- Support instructors in course planning
- Provide additional context for specialized topics
- Serve as reference for advanced or sector-specific applications

They complement but do not replace the comprehensive coverage in Volumes 1, 2, and 3.
