# Break-Even Calculator Tool - User Guide

## Overview

The Break-Even Calculator is an interactive web-based tool that calculates break-even points and performs sensitivity analysis. It helps businesses understand when they will start making a profit and how changes in costs and prices affect profitability.

## Features

### ✅ Core Functionality
- **Break-Even Calculation**: Calculate break-even units and sales
- **Contribution Margin**: Calculate contribution margin per unit and ratio
- **Target Profit Analysis**: Analyze profit at target sales levels
- **Sensitivity Analysis**: See how changes in variables affect break-even
- **Margin of Safety**: Calculate margin of safety percentage
- **Real-time Calculation**: Auto-calculates as you type

### 🎨 User Interface
- **Dark Mode Ready**: Modern dark theme
- **Responsive Design**: Works on desktop, tablet, and mobile
- **Visual Results**: Clear display of all calculations
- **Sensitivity Table**: Comprehensive what-if analysis

## Usage Instructions

### Basic Break-Even Calculation

1. **Enter Fixed Costs**: Total fixed costs (e.g., rent, salaries, insurance)
2. **Enter Variable Cost per Unit**: Cost that varies with production (e.g., materials, labor)
3. **Enter Selling Price per Unit**: Price at which you sell each unit
4. **Calculate**: Click "Calculate" or results update automatically

### Target Profit Analysis

1. **Enter Target Units**: Optional - enter desired sales volume
2. **View Results**: See revenue, costs, and profit at target level
3. **Margin of Safety**: See how far above break-even you are

### Sensitivity Analysis

After calculating, view the sensitivity table to see:
- How changes in selling price affect break-even
- How changes in variable costs affect break-even
- How changes in fixed costs affect break-even
- Percentage change in break-even for each scenario

## Break-Even Formulas

### Contribution Margin
```
Contribution Margin per Unit = Selling Price - Variable Cost per Unit
Contribution Margin Ratio = Contribution Margin ÷ Selling Price × 100%
```

### Break-Even Point
```
Break-Even Units = Fixed Costs ÷ Contribution Margin per Unit
Break-Even Sales = Break-Even Units × Selling Price per Unit
```

### Target Profit
```
Required Units = (Fixed Costs + Target Profit) ÷ Contribution Margin per Unit
```

### Margin of Safety
```
Margin of Safety = (Target Units - Break-Even Units) ÷ Target Units × 100%
```

## Example Calculation

### Example: Restaurant Break-Even

**Inputs:**
- Fixed Costs: €10,000/month (rent, salaries, utilities)
- Variable Cost per Meal: €8 (food, labor per meal)
- Selling Price per Meal: €20

**Calculations:**
- Contribution Margin: €20 - €8 = €12 per meal
- Contribution Margin Ratio: €12 ÷ €20 = 60%
- Break-Even Units: €10,000 ÷ €12 = 834 meals
- Break-Even Sales: 834 × €20 = €16,680

**Target Analysis (1,200 meals):**
- Total Revenue: 1,200 × €20 = €24,000
- Total Costs: €10,000 + (1,200 × €8) = €19,600
- Profit: €24,000 - €19,600 = €4,400
- Margin of Safety: (1,200 - 834) ÷ 1,200 = 30.5%

## Sensitivity Analysis

The sensitivity analysis shows how break-even changes when you vary:

### Selling Price Changes
- **+20%**: Lower break-even (need fewer units)
- **-20%**: Higher break-even (need more units)

### Variable Cost Changes
- **+20%**: Higher break-even (less contribution margin)
- **-20%**: Lower break-even (more contribution margin)

### Fixed Cost Changes
- **+20%**: Higher break-even (more costs to cover)
- **-20%**: Lower break-even (fewer costs to cover)

## Troubleshooting

### Issue: Break-Even Not Calculating
- **Solution**: Ensure variable cost is less than selling price
- Check that all required fields are filled
- Verify values are positive numbers

### Issue: Negative Margin of Safety
- **Solution**: Target units are below break-even
- Need to increase sales or reduce costs
- Business is operating at a loss

### Issue: Unrealistic Break-Even
- **Solution**: Review cost assumptions
- Verify fixed and variable cost classifications
- Check selling price is realistic
