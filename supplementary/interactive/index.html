Luxembourg SME Accounting - LuxOpenFin

About These Tools

These interactive tools are designed to enhance learning and practice with accounting concepts specific to Luxembourg SMEs. All tools are web-based, work offline, and require no installation. Simply open the HTML file in your browser.

✅ Available

VAT Calculator

Calculate VAT amounts for Luxembourg businesses with all four VAT rates (3%, 8%, 14%, 17%).

  • Net to gross and gross to net calculations
  • Multiple items support
  • VAT return worksheet
  • CSV export functionality

T-Account Simulator

Practice recording transactions in T-accounts with visual interface and automatic balance calculation.

  • Visual T-account interface
  • PCN account lookup and integration
  • Automatic balance calculation
  • Practice mode with hints
Open Tool Documentation

Journal Entry Practice

Practice creating journal entries with official PCN 2020 accounts, validation and step-by-step hints.

  • Journal entry form
  • Account lookup (PCN)
  • Debit/credit validation
  • Luxembourg transaction scenarios
Open Tool Documentation
✅ Available

PCN Account Lookup

Quick reference for selected Luxembourg PCN 2020 accounts (same list as the website's PCN Lookup) with search and browse functionality.

  • Search by account number or name
  • Browse by account class
  • Multilingual support (FR, DE, EN)
  • Export to CSV/Excel
Open Tool Documentation

Financial Statement Generator

Generate a simplified balance sheet and profit and loss account from a trial balance, classified by PCN 2020 class.

  • Input trial balance
  • Automatic statement generation
  • Balance sheet, profit and loss account, cash flow outline
  • Print / save as PDF
