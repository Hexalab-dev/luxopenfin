# Student Resources

## Overview

This directory contains resources designed for students and self-learners using the Luxembourg SME Accounting Textbook.

## Contents

### Interactive Tools
- T-account simulator
- Journal entry practice tool
- PCN account lookup tool
- VAT calculator
- Financial statement templates

### Practice Exercises
- Additional practice problems
- Self-assessment quizzes
- Chapter review questions
- Comprehensive practice sets

### Video Tutorials
- Chapter overviews
- Concept explanations
- Problem-solving walkthroughs
- Software demonstrations
- Luxembourg-specific tutorials

### Templates
- Excel templates for:
  - Journal entries
  - Financial statements
  - VAT calculations
  - Payroll calculations
  - Budget worksheets

### Study Guides
- Chapter summaries
- Key term flashcards
- Formula sheets
- Quick reference cards
- Exam preparation guides

## How to Use

### For Self-Study
1. Read chapter in textbook
2. Watch video overview
3. Complete practice exercises
4. Use interactive tools to reinforce concepts
5. Review study guides before exams

### For Classroom Learning
1. Use as supplementary materials
2. Complete exercises for homework
3. Use templates for assignments
4. Review study guides for exams

### For Professional Development
1. Focus on Luxembourg-specific content
2. Use templates for real business applications
3. Practice with interactive tools
4. Review case studies

## Interactive Tools

### T-Account Simulator
Practice recording transactions in T-accounts with instant feedback.

### Journal Entry Practice
Practice creating journal entries with validation and hints.

### PCN Account Lookup
Quick reference for Luxembourg PCN account numbers and descriptions.

### VAT Calculator
Calculate VAT amounts for different rates and scenarios.

### Financial Statement Generator
Generate financial statements from trial balance data.
