## Translation Pattern

### Figure Format (English)
```
**Figure X.Y:** Title

```
[Diagram/Table content]
```

*Alt text: Description of the visual element.*
```

### French Translation
```
**Figure X.Y :** Titre traduit

```
[Contenu du diagramme/tableau traduit]
```

*Texte alternatif : Description de l'élément visuel traduite.*
```

### German Translation
```
**Abbildung X.Y:** Überschrifter Titel

```
[Diagramm/Tabelleninhalt übersetzt]
```

*Alternativtext: Beschreibung des visuellen Elements übersetzt.*
```
