# Formatting Standards

This document defines formatting standards for the Luxembourg SME Accounting Textbook to ensure consistency and professional appearance.

## Purpose

Consistent formatting ensures:
- Professional appearance
- Easy navigation
- Clear structure
- Accessibility
- Print/web compatibility

## Heading Hierarchy

### Levels

**Level 1: Chapter Title**
```markdown
# Chapter X: [Chapter Title]
```

**Level 2: Major Sections**
```markdown
## X.Y [Section Title]
```

**Level 3: Subsections**
```markdown
### [Subsection Title]
```

**Level 4: Sub-subsections**
```markdown
#### [Sub-subsection Title]
```

**Level 5: Minor divisions**
```markdown
##### [Minor Division]
```

### Guidelines
- Use consistent numbering (X.Y format for sections)
- Don't skip heading levels
- Use descriptive headings
- Keep headings concise

## Text Formatting

### Emphasis

**Bold:**
- Use for key terms (first occurrence)
- Use for important concepts
- Use for account names in examples

*Italic:*
- Use for emphasis (sparingly)
- Use for foreign terms
- Use for book titles

### Lists

**Bulleted Lists:**
- Use for unordered items
- Use consistent bullet style
- Indent sub-items consistently

**Numbered Lists:**
- Use for ordered steps
- Use for sequential items
- Maintain numbering

### Code/Examples

**Journal Entries:**
- Use code blocks or tables
- Format consistently
- Include dates and references

**Calculations:**
- Show all steps
- Use proper formatting
- Highlight final answers

## Table Formatting

### Structure

**Headers:**
- Use proper header rows
- Bold header text
- Clear column labels

**Content:**
- Align consistently
- Use proper spacing
- Include units (€)

**PCN Tables:**
- Include account codes
- Include French names
- Include English translations

### Examples

**Financial Statement Tables:**
- Proper alignment
- Euro formatting
- Totals clearly marked
- Section subtotals

**Comparison Tables:**
- Clear comparison criteria
- Consistent formatting
- Luxembourg context column

## Visual Element Formatting

### Figures

**Captions:**
- Format: "**Figure X.Y:** [Description]"
- Descriptive, not just labels
- Include Luxembourg context when relevant

**Placement:**
- Immediately after introduction
- Or immediately before explanation
- Never isolated

### T-Accounts

**Format:**
- Consistent structure
- Clear labels
- Proper alignment
- PCN codes included

### Flowcharts

**Format:**
- Clear flow direction
- Proper labels
- Consistent styling
- Accessible format

## Example Formatting

### Journal Entries

**Format:**
```
Date: YYYY-MM-DD

Account Name (PCN Code)              €X,XXX.XX
Account Name (PCN Code)                      €X,XXX.XX
To record [description]
```

### Financial Statements

**Format:**
- Proper headers
- Company name
- Date/period
- PCN account codes
- Euro formatting
- Totals clearly marked

### Calculations

**Format:**
```
Step 1: [Description]
Calculation = Formula
Calculation = €X,XXX.XX

Step 2: [Description]
...
```

## Luxembourg-Specific Formatting

### PCN Account Codes
- Always include in parentheses
- Format: (XXXXXX)
- Include French name when first used

### Euro Formatting
- Use € symbol
- Format: €X,XXX.XX
- Consistent decimal places

### Dates
- Format: DD Month YYYY (e.g., 15 November 2024)
- Or: YYYY-MM-DD for journal entries
- Consistent throughout

### French Terms
- Include French terms for key concepts
- Format: English (French)
- Use consistently

## Accessibility Formatting

### Alt Text
- Required for all visuals
- Descriptive, not just labels
- Include key information

### Table Headers
- Proper header markup
- Screen reader friendly
- Logical structure

### Heading Hierarchy
- Proper levels
- Don't skip levels
- Logical structure
