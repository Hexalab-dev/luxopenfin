# Supplementary Materials

All companion assets live alongside the textbook inside this repository so instructors and learners never have to leave the site to understand what is available. Use the summaries below to jump into the right toolkit, then open the referenced paths in the repo (or your local checkout) to access the source files, HTML slide decks, and automation scripts.

## Instructor Resources

- **Solutions Manual** – `supplementary/instructor/solutions/` (Chapters 1–25: volumes 1 and 2). Each file mirrors the textbook structure with questions, problem sets, comprehensive cases, Luxembourg PCN references, and compliance notes.
- **Slides** – `supplementary/instructor/slides/` contains ready-to-present HTML decks plus Python generators for producing PPTX exports. Follow the README in `supplementary/instructor/slides/` for conversion steps.
- **Teaching Scripts** – `supplementary/instructor/scripts/` bundles CLI utilities (`generate_slides_html.py`, `generate_slides_enhanced.py`, etc.) with requirements files so you can regenerate assets after updating the chapters.

## Student & Interactive Resources

- **Interactive Tools** – hosted React widgets (T-account simulator, VAT calculator, payroll assistant, PCN lookup, break-even analyzer, and more) live under `supplementary/interactive/` and surface on the `/tools` page.
- **Student README** – `supplementary/student/README.md` explains how learners can access practice templates, study guides, and downloadable references to work offline.

## Multilingual & Reference Packs

- **Multilingual Starter** – `supplementary/multilingual/` tracks translation status, glossary exports, and guidance for FR/DE localization teams.
- **Appendix & Reference Mirror** – Additional quick-reference PDFs/markdown live under `supplementary/` with matching entries in the `appendices/` tree for easy cross-linking inside the textbook.

## How to Access

1. Clone or download this repository (`git clone https://github.com/Hexalab-dev/luxopenfin.git`).
2. Navigate to the relevant `supplementary/...` folder (see paths above).
3. Follow the README inside each folder for environment setup, slide generation, or distribution packaging.

Need something that is not listed here? Open an issue or discussion on GitHub and tag the module so we can wire it into the supplementary catalogue.
