# 10.7 Luxembourg PCN Class 3 Inventory Accounts

### PCN Class 3: Inventory

**Class 3** in PCN contains all inventory-related accounts.

**Account Ranges:**
- 30: Raw Materials (Matières Premières)
- 31: Work in Progress (En Cours de Fabrication)
- 32: Finished Goods (Produits Finis)
- 361: Merchandise (Marchandises)

### Main Inventory Accounts

#### 301: Raw Materials

**Use:**
- Materials to be used in production
- Ingredients for manufacturing
- Components to be assembled

**Example:** Manufacturing business
```
301    Raw Materials              €5,000
```

#### 311: Work in Progress

**Use:**
- Products partially completed
- Manufacturing in process
- Construction in progress

**Example:** Manufacturing business
```
311    Work in Progress           €3,000
```

#### 321: Finished Goods

**Use:**
- Completed products ready for sale
- Manufacturing businesses
- Products awaiting sale

**Example:** Manufacturing business
```
321    Finished Goods             €8,000
```

#### 361: Merchandise

**Use:**
- Goods purchased for resale
- Retail businesses
- Wholesale businesses
- Restaurants (retail items)

**Example:** Retail store
```
361    Merchandise                €15,000
```

### Inventory Sub-Accounts

**Can Create Sub-Accounts:**
- 3611: Merchandise - Category A
- 3612: Merchandise - Category B
- 3011: Raw Materials - Type X
- 3012: Raw Materials - Type Y

**Purpose:**
- Better tracking
- Multiple product types
- Different VAT rates
- Better management

### Cost of Goods Sold Accounts

**PCN Accounts:**
- **607**: Cost of Goods Sold (Coût des Marchandises Vendues)
- **601**: Cost of Raw Materials Used (Consommation de Matières)
- **607**: Cost of Finished Goods Sold (Coût des Produits Vendus)

**For Retail Businesses:**
- Use 607: Cost of Goods Sold

**For Manufacturing:**
- Use 601: Cost of Raw Materials
- Use 607: Cost of Finished Goods Sold

### Inventory Valuation Accounts

**Allowance Accounts:**
- **3619**: Allowance for Inventory Depreciation (Dépréciation des Stocks)

**Use:**
- When inventory value is below cost
- Write-downs to net realizable value
- Obsolete inventory

### Luxembourg Compliance Note

PCN Class 3 inventory accounts must:
- Be properly classified
- Use correct account numbers
- Support inventory values
- Enable proper cost of goods sold calculation
- Support financial statement presentation
- Comply with PCN requirements
