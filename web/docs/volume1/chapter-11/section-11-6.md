# 11.6 Luxembourg Fixed Assets Accounting (PCN Class 2 - Immobilisations)

### PCN Class 2: Immobilisations (Fixed Assets)

**Class 2** in PCN contains all long-term assets.

**Account Ranges:**
- 20–21: Intangible Assets (Immobilisations Incorporelles)
- 21: Intangible Assets (continued)
- 22: Tangible Assets (Immobilisations Corporelles)
- 22: Tangible Assets (continued)
- …9 sub-accounts: Accumulated Depreciation (Amortissements)
- …9 sub-accounts: Accumulated Amortization (Amortissements Incorporels)
- 23: Financial Assets (Immobilisations Financières)

### Intangible Assets (21)

**Main Accounts:**
- **211**: Research and Development Costs
- **212**: Concessions, Patents, Licenses
- **213**: Goodwill
- **21**: Other Intangible Assets

**Example:**
```
212    Patents                     €50,000
```

### Tangible Assets (22)

**Main Accounts:**
- **2211**: Land (Terrains)
- **2213**: Buildings (Constructions)
- **2221**: Technical Installations
- **222**: Equipment and Machinery (Matériel et Outillage)
- **2232**: Vehicles (Matériel de Transport)
- **2234**: Furniture and Fixtures (Mobilier)
- **2235**: Computer Equipment (Matériel Informatique)
- **2238**: Other Tangible Assets

**Example: Restaurant Equipment:**
```
222    Equipment                   €25,000
```

**Example: Vehicle:**
```
2232   Vehicles                    €30,000
```

### Accumulated Depreciation (…9 sub-accounts)

**Main Accounts:**
- **22139**: Accumulated Depreciation - Buildings
- **2229**: Accumulated Depreciation - Equipment
- **22329**: Accumulated Depreciation - Vehicles
- **22389**: Accumulated Depreciation - Other

**Example:**
```
2229   Accumulated Depreciation - Equipment €10,000
```

### Financial Assets (23)

**Main Accounts:**
- **231**: Investments in Subsidiaries
- **235**: Other Financial Investments
- **236**: Loans Granted

### Luxembourg Compliance Note

PCN Class 2 requirements:
- Must use proper account classifications
- Must maintain separate accounts for different asset types
- Must track accumulated depreciation separately
- Must comply with PCN structure
- Must support asset values
- Must enable proper financial statement presentation
