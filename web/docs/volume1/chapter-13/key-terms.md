# Key Terms

- **Bonds Payable**: Long-term debt securities
- **Effective-Interest Method**: Interest calculation based on carrying value
- **Face Value**: Amount to be repaid at maturity
- **Long-Term Liabilities**: Obligations due beyond one year
- **Present Value**: Current value considering time value of money
