# Chapter 33 – Solutions

## Multiple Choice Solutions

1. **b)** PCN compliance is mandatory and most important.

2. **b)** Sage BOB is Luxembourg-specific accounting software with PCN compliance.

3. **b)** Odoo community edition is free open-source software.

4. **b)** Excel may be suitable for very small businesses only, but has limitations.

5. **a)** Cloud software has lower upfront cost (subscription-based).

6. **b)** Data migration should be planned and tested thoroughly.

7. **b)** Bank integration allows automatic transaction import.

8. **b)** Backups should be done daily for active businesses.

9. **c)** Data must be retained for 10 years (Luxembourg requirement).

10. **c)** Software integration helps reduce costs, save time, and improve accuracy.
