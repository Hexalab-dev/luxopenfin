# Key Terms

- **Sage BOB**: Popular Luxembourg-specific accounting software
- **Odoo**: Open-source ERP system with Luxembourg localization
- **PCN Compliance**: Software support for Plan Comptable Normalisé
- **Cloud Software**: Software hosted online, accessed via internet
- **On-Premise Software**: Software installed on your own computers
- **Data Migration**: Process of transferring data from one system to another
- **Field Mapping**: Process of mapping source fields to destination fields
- **Bank Integration**: Connection between accounting software and bank
- **POS Integration**: Connection between accounting software and point-of-sale system
- **Payroll Integration**: Connection between accounting software and payroll system
- **Backup**: Copy of data for protection and recovery
- **Full Backup**: Complete data backup
- **Incremental Backup**: Backup of only changed data
- **Data Encryption**: Process of encoding data for security
- **Access Controls**: Security measures controlling data access
- **Disaster Recovery**: Procedures for recovering from data loss
- **Total Cost of Ownership (TCO)**: Total cost including purchase, implementation, support
- **Software License**: Right to use software (one-time or subscription)
- **API (Application Programming Interface)**: Interface for software integration
- **Data Validation**: Process of checking data accuracy and completeness
