# Key Terms

- **E-Invoice (Electronic Invoice)**: Invoice issued, transmitted, and received in electronic format
- **UBL (Universal Business Language)**: XML-based standard for business documents including invoices
- **Peppol (Pan-European Public Procurement On-Line)**: European network for e-invoicing with BIS format
- **Fiscal Cash Register**: Tamper-proof cash register system required for retail and hospitality
- **FAIA (Fichier d'Audit Informatisé AED)**: Luxembourg's standardized format for tax audit data
- **OECD SAF-T (Standard Audit File for Tax)**: International standard for tax audit files
- **CSV (Comma-Separated Values)**: Simple text format for storing tabular data
- **Excel**: Microsoft Excel file format for structured data
- **Digital Signature**: Electronic signature ensuring authenticity and integrity
- **Authenticity**: Invoice is from stated supplier and has not been altered
- **Integrity**: Invoice content is complete and has not been modified
- **Certified Equipment**: Fiscal cash registers certified by Luxembourg authorities
- **Data Export**: Process of exporting data from accounting software
- **Data Import**: Process of importing data into accounting software
- **Field Mapping**: Process of mapping source fields to destination fields during import
- **Integration**: Connection between different software systems
- **Compliance Best Practices**: Recommended practices for ensuring ongoing compliance
