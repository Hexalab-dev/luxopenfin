# Chapter 31 – Solutions

## Multiple Choice Solutions

1. **c)** E-invoices must ensure both authenticity and integrity.

2. **c)** Fiscal cash registers are mandatory for retail and hospitality sectors.

3. **a)** UBL stands for Universal Business Language.

4. **c)** FAIA format is based on OECD SAF-T (Standard Audit File for Tax).

5. **c)** E-invoices must be stored for 10 years.

6. **c)** Peppol is both a format (Peppol BIS) and a network.

7. **b)** Fiscal cash registers must be certified by Luxembourg authorities.

8. **b)** CSV format is text-based (comma-separated values).

9. **c)** Data export/import is essential for data migration, reporting, and analysis.

10. **c)** Software integration helps reduce errors, save time, and improve accuracy.
