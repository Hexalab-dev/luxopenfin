# LuxOpenFin <FeatureTag state="DEV" />

Welcome to LuxOpenFin, the open accounting textbook tailored for Luxembourg SMEs. This site is powered by Docusaurus and hosts multi-volume content, interactive tools, and supplementary resources.

- **Volume 1** – Financial Accounting for Luxembourg SMEs  
- **Volume 2** – Managerial Accounting for Luxembourg SMEs  
- **Volume 3** – Luxembourg-Specific Compliance and Practice  
- **Appendices** – PCN reference, VAT rates, tax calendar, and more.

The content migration from the existing markdown repository is in progress. During the build-out you will see placeholder sections that will be populated in later phases.
