# Schlüsselbegriffe

- **Budget** : Finanzplan für zukünftige Periode
- **Hauptbudget** : Vollständiges Budget einschließlich Betriebs- und Finanzkomponenten
- **Betriebsbudget** : Budget für Umsätze und Ausgaben
- **Finanzbudget** : Budget für Cashflows, Kapitalausgaben und Bilanz
- **Verkaufsbudget** : Prognose von Verkaufsvolumen und Umsatz
- **Produktionsbudget** : Plan für zu produzierende Einheiten
- **Cash-Budget** : Plan für Cash-Eingänge und -Ausgänge
- **Statisches Budget** : Budget basierend auf einem einzigen Aktivitätsniveau
- **Flexibles Budget** : Budget, das sich an tatsächliche Aktivitätsniveaus anpasst
- **Rollendes Budget** : Kontinuierlich aktualisiertes Budget (deckt immer festen Zeitraum)
- **Standardkosten** : Vorbestimmte Kosten basierend auf erwarteten Preisen und Mengen
- **Varianz** : Unterschied zwischen tatsächlichen und budgétierten/Standard-Beträgen
- **Varianzanalyse** : Vergleich tatsächlicher Ergebnisse mit Standards/Budget zur Identifizierung von Unterschieden
- **Günstige Varianz** : Tatsächliche Ergebnisse besser als Budget
- **Ungünstige Varianz** : Tatsächliche Ergebnisse schlechter als Budget
- **Materialpreisvarianz** : Unterschied aufgrund des für Materialien gezahlten Preises
- **Materialmengenvarianz** : Unterschied aufgrund der verwendeten Materialmenge
- **Arbeitslohnsatzvarianz** : Unterschied aufgrund des gezahlten Lohnsatzes
- **Arbeitseffizienzvarianz** : Unterschied aufgrund der geleisteten Arbeitsstunden
- **Budget-Slack** : Absichtliche Aufblähung von Budgets
- **Szenarioplanung** : Erstellung mehrerer Budgetversionen basierend auf verschiedenen Annahmen
- **Partizipative Budgétisation** : Budgétisationsprozess mit Beteiligung von Managern auf niedrigerer Ebene
