# 23.9 Luxemburgische Cashflow-Budgétisation für KMU

### Cashflow-Bedeutung

Cashflow-Budgétisation stellt sicher, dass das Unternehmen seine Verpflichtungen erfüllen, in Chancen investieren und Liquiditätskrisen vermeiden kann.

### Cashflow-Budget-Schritte

1. **Cash-Eingänge prognostizieren** :
   - Kundeneinzahlungen
   - Kredite und Investitionen
   - Sonstige Einnahmen (Zuschüsse, Rückerstattungen)

2. **Cash-Ausgänge prognostizieren** :
   - Inventar-/Materialeinkäufe
   - Gehälter und Löhne
   - Sozialabgaben (CCSS)
   - MwSt-Zahlungen (monatlich/vierteljährlich)
   - Miete und Nebenkosten
   - Schuldendienst (Zinsen, Tilgung)
   - Kapitalausgaben
   - Steuern

3. **Netto-Cashflow berechnen** :
   - Cash-Eingänge - Cash-Ausgänge

4. **End-Cash bestimmen** :
   - Anfangs-Cash + Netto-Cashflow

5. **Cash-Knappheiten identifizieren** :
   - Finanzierung planen oder Operationen anpassen

### MwSt-Überlegungen

- MwSt auf Verkäufen ist kein Umsatz ; muss an Behörden gezahlt werden
- MwSt auf Einkäufen kann erstattungsfähig sein, beeinflusst aber Cash-Timing
- Periodische MwSt-Zahlungen (monatlich bei über 620.000 € Umsatz, vierteljährlich zwischen 112.000 € und 620.000 €) erfordern Cash-Planung

### Sozialabgaben und Lohnsteuern

- Sozialabgaben (Arbeitgeberbeiträge) erhöhen die Bruttolohnsumme um etwa 12,6-15 % (CCSS-Sätze zum 1. Januar 2026; jedes Jahr auf ccss.lu prüfen)
- Müssen monatlich an CCSS gezahlt werden
- In Cash-Budget einbeziehen, um Strafen zu vermeiden

### Steuerzahlungen

- Körperschaftsteuer und Gemeindebetriebssteuer jährlich fällig (mit Vorauszahlungen)
- Steuervorauszahlungen in Cash-Budget einbeziehen

### Cashflow-Beispiel

**Monatliches Cash-Budget (vereinfacht) :**
- Anfangs-Cash : €25.000
- Eingänge :
  - Kundeneinzahlungen : €90.000
  - Kreditauszahlung : €10.000
  - **Gesamt Eingänge : €100.000**
- Ausgaben :
  - Inventar : €30.000
  - Gehälter : €20.000
  - Sozialabgaben : €5.000
  - Miete : €5.000
  - Nebenkosten : €2.000
  - MwSt-Zahlung : €12.000
  - Kredittilgung : €4.000
  - Capex : €8.000
  - Steuern : €3.000
  - **Gesamt Ausgaben : €89.000**
- Netto-Cashflow : €100.000 - €89.000 = €11.000
- End-Cash : €25.000 + €11.000 = €36.000
- Wenn Minimum Cash erforderlich : €30.000, Überschuss €6.000

### Cashflow-Management-Strategien

- Einzahlungen beschleunigen (Frühzahlungsanreize)
- Zahlungsbedingungen mit Lieferanten verwalten
- Kreditlinien für saisonale Bedürfnisse arrangieren
- Liquiditätskennzahlen wöchentlich/monatlich überwachen
- Rollende Cash-Prognosen verwenden (13-Wochen-Cashflow)

### Luxemburgische Compliance-Hinweis

Cash-Budgets stellen rechtzeitige Zahlung von MwSt, Sozialabgaben und Steuern sicher—kritisch, um Strafen zu vermeiden. Luxemburgische Banken fordern oft Cashflow-Prognosen für Kreditlinien. KMU mit grenzüberschreitenden Transaktionen müssen Währungs-Timing planen.
