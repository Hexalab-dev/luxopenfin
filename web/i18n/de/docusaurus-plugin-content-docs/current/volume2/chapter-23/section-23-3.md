# 23.3 Finanzbudgets vorbereiten

### Finanzbudgets

Finanzbudgets konzentrieren sich auf Cashflows, Kapitalausgaben und Bilanzprognosen. Sie stellen sicher, dass das Unternehmen Operationen und Investitionen finanzieren kann.

### Cash-Budget

*Alternativtext: Flowchart showing cash budget structure: Beginning Liquide Mittel Balance plus Liquide Mittel Inflows (collections from sales, loans received) minus Liquide Mittel Outflows (operating expenses, capital expenditures, taxes and debt payments) equals Net Liquide Mittel Flow, resulting in Ending Liquide Mittel Balance, with financing needs if the balance is negative, demonstrating how cash budgets track cash flow.*

Das Cash-Budget zeigt erwartete Cash-Eingänge, -Ausgänge und End-Cash-Salden.

**Struktur :**
1. Anfangs-Cash-Saldo
2. Cash-Eingänge (Einzahlungen, Kredite, Investitionen)
3. Cash-Ausgänge (Ausgaben, Kapitalausgaben, Steuern, Schuldentilgungen)
4. Netto-Cashflow (Eingänge - Ausgänge)
5. End-Cash-Saldo
6. Finanzierungsbedarf (wenn End-Cash < Minimum erforderlich)

**Detailliertes Cash-Budget-Format :**
```
Cash-Budget - [Periode]
─────────────────────────────────────────────────────
Anfangs-Cash-Saldo                    €XX.XXX

CASH-EINGÄNGE :
  Barverkäufe                              €XX.XXX
  Einzahlungen aus Kreditverkäufen            XX.XXX
  Sonstige Einnahmen                          X.XXX
  Kredite/Investitionen                       X.XXX
─────────────────────────────────────────────────────
Gesamt verfügbare Cash                      €XX.XXX

CASH-AUSGÄNGE :
  Inventareinkäufe                        €XX.XXX
  Gehälter und Löhne                        XX.XXX
  Sozialabgaben                              X.XXX
  Miete                                       X.XXX
  Nebenkosten                                 X.XXX
  MwSt-Zahlungen                              X.XXX
  Steuerzahlungen                             X.XXX
  Kredittilgungen (Tilgung)                   X.XXX
  Zinszahlungen                               X.XXX
  Kapitalausgaben                             X.XXX
  Sonstige Ausgaben                           X.XXX
─────────────────────────────────────────────────────
Gesamt Cash-Ausgaben                       €XX.XXX

Netto-Cashflow (Verfügbar - Ausgaben)      €XX.XXX
End-Cash-Saldo                            €XX.XXX

Minimum Cash erforderlich                  €XX.XXX
Überschuss (Defizit)                       €XX.XXX
Finanzierung erforderlich                 €XX.XXX
```

**Beispiel (Monatlich) :**
- Anfangs-Cash : €20.000
- Cash-Einzahlungen : €95.000
- Gesamt verfügbare Cash : €115.000
- Cash-Ausgaben :
  - Inventar : €35.000
  - Gehälter : €18.000
  - Sozialabgaben : €6.000
  - Miete : €5.000
  - Nebenkosten : €2.000
  - MwSt-Zahlung : €10.000
  - Steuern : €4.000
  - Kapitalausgabe (Ausrüstung) : €8.000
  - **Gesamt Ausgaben : €88.000**
- Netto-Cashflow : €115.000 - €88.000 = €27.000
- End-Cash : €20.000 + €27.000 = €47.000

**Wenn Minimum Cash €30.000 ist :**
- End-Cash : €47.000
- Minimum erforderlich : €30.000
- Überschuss : €17.000 (kein Kredit erforderlich)

**Wenn End-Cash €25.000 wäre :**
- End-Cash : €25.000
- Minimum erforderlich : €30.000
- Defizit : €5.000
- **Müssen €5.000 leihen, um Minimum zu erreichen**

### Kapitalausgaben-Budget

Plant den Kauf langfristiger Vermögenswerte.

**Beispiel :**
- Küchenausrüstungs-Upgrade : €15.000 im März
- Lieferwagen : €20.000 im Juni
- Softwarelizenz : €5.000 im Januar

### Budgétierte Bilanz

Projiziert die finanzielle Lage des Unternehmens am Ende der Budgetperiode.

**Komponenten :**
- Vermögenswerte : Cash, Inventar, Forderungen, Anlagevermögen
- Verbindlichkeiten : Verbindlichkeiten, Kredite, Steuern
- Eigenkapital : Kapital, Gewinnrücklagen

### Cashflow-Management (Luxemburg)

**Wichtige Überlegungen :**
- MwSt-Zahlungen (monatlich/vierteljährlich) reduzieren Cash
- Sozialabgaben und Lohnsteuern monatlich fällig
- Einkommensteuern und Gemeindesteuern jährlich fällig
- Lieferanten können kürzere Zahlungsbedingungen verlangen
- Banken bewerten Cash-Budgets bei Kreditbewertung

### Flexible Budgets

Flexible Budgets passen sich an tatsächliche Aktivitätsniveaus an. Nützlich für Leistungsbewertung.

**Formel :**
**Flexibles Budget = Budgétierte Fixkosten + (Budgétierte variable Kosten pro Einheit × Tatsächliche Einheiten)**

**Beispiel :**
- Budgétierte Fixkosten : €20.000
- Variable Kosten pro Einheit : €5
- Tatsächlicher Output : 4.000 Einheiten
- Flexibles Budget : €20.000 + (4.000 × €5) = €40.000

### Rollende Budgets

Rollende (kontinuierliche) Budgets decken immer einen festen Zeitraum (z. B. 12 Monate). Wenn ein Monat endet, wird ein weiterer hinzugefügt. Hält Budgets aktuell.

### Szenarioplanung

Szenarioplanung erstellt mehrere Budgets basierend auf verschiedenen Annahmen (Best Case, Base Case, Worst Case).

**Beispiel :**
- Best Case : Verkäufe +15%
- Base Case : Verkäufe unverändert
- Worst Case : Verkäufe -10%

### Luxemburgische Compliance-Hinweis

Finanzbudgets in Luxemburg müssen MwSt, Sozialabgaben und Steuerfristen berücksichtigen. KMU verwenden oft Cash-Budgets, um monatliche oder vierteljährliche MwSt-Zahlungen (je nach Umsatz) und jährliche Steuerzahlungen zu planen. Rollende Budgets sind in volatilen Märkten nützlich (z. B. Tourismus, Finanzdienstleistungen).
