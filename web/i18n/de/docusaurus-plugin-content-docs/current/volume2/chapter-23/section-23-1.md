# 23.1 Beschreiben, wie und warum Manager Budgets verwenden

### Die Rolle von Budgets

Budgets sind Management-Tools mit mehreren Zwecken :

- **Planung** : Budgets definieren, was die Organisation zu erreichen beabsichtigt
- **Ressourcenzuteilung** : Budgets bestimmen, wo Ressourcen verwendet werden
- **Koordination** : Budgets richten verschiedene Teile der Organisation aus
- **Kommunikation** : Budgets kommunizieren Prioritäten und Erwartungen
- **Motivation** : Budgets können Mitarbeiter über Leistungsziele motivieren
- **Kontrolle** : Budgets bieten Benchmarks zur Bewertung tatsächlicher Ergebnisse

- **Strategisches Budget** : Langfristiger Finanzplan, der mit Strategie verknüpft ist
- **Betriebsbudget** : Kurzfristiger Plan für Umsätze und Ausgaben
- **Finanzbudget** : Fokussiert auf Cashflow, Kapitalausgaben, Bilanz
- **Statisches Budget** : Basierend auf einem einzigen Aktivitätsniveau
- **Flexibles Budget** : Passt sich an verschiedene Aktivitätsniveaus an
- **Rollendes Budget** : Kontinuierlich aktualisiert (z. B. Monat hinzufügen, wenn einer endet)

### Budgétisationsprozess

1. **Ziele festlegen** : Ziele definieren
2. **Informationen sammeln** : Verkaufsprognosen, Kostenschätzungen, historische Daten
3. **Budget entwickeln** : Umsatz-, Ausgaben-, Kapital- und Cash-Budgets erstellen
4. **Budget genehmigen** : Management prüft und genehmigt
5. **Budget kommunizieren** : Mit verantwortlichen Teams teilen
6. **Budget umsetzen** : Operationen gemäß Plan ausführen
7. **Überwachen und kontrollieren** : Tatsächliche Ergebnisse mit Budget vergleichen
8. **Anpassen und bewerten** : Budgets basierend auf Leistung und Änderungen aktualisieren

### Budgetverantwortung

**Budgetverantwortung** bedeutet, dass jeder Manager für die Budgetposten verantwortlich ist, die er kontrolliert. Budgets sollten mit der Organisationsstruktur übereinstimmen, damit Manager für Ergebnisse verantwortlich sein können, die sie beeinflussen.

### Beteiligung an der Budgétisation

- **Top-Down-Budgétisation** : Oberes Management setzt Budgets
  - Vorteile : Schnell, mit Strategie ausgerichtet
  - Nachteile : Weniger Unterstützung, kann lokale Erkenntnisse ignorieren

- **Bottom-Up-Budgétisation** : Manager auf niedrigerer Ebene bereiten Budgets vor
  - Vorteile : Genauer, bessere Unterstützung
  - Nachteile : Zeitaufwändig, kann Verhandlung erfordern

- **Partizipative Budgétisation** : Kombiniert beide Ansätze
  - Ausgewogene Beteiligung und strategische Ausrichtung

### Verhaltensüberlegungen

Budgets beeinflussen Verhalten :
- **Zielkongruenz** : Budgetziele mit Unternehmenszielen ausrichten
- **Motivation vs. Druck** : Ziele sollten herausfordernd, aber erreichbar sein
- **Budget-Slack** : Manager können Budgets aufblähen (Slack aufbauen), um sicherzustellen, dass sie Ziele erreichen ; muss durch Überprüfung und Anreize verwaltet werden

### Budgétisationsethik

Budgetvorbereitung und -bewertung sollten ethischen Richtlinien folgen :
- Ehrlichkeit in Schätzungen
- Transparenz in Annahmen
- Manipulation zu persönlichem Vorteil vermeiden
- Ethische Behandlung von Mitarbeitern bezüglich Ziele
- Einhaltung rechtlicher Anforderungen

### Luxemburgische Compliance-Hinweis

In Luxemburg unterstützen Budgets die Einhaltung von Finanzberichterstattung und Steuerverpflichtungen. Banken benötigen oft Budgets bei der Bewertung von KMU-Krediten. Partizipative Budgétisation kann in mehrsprachigen Teams wesentlich sein, um Verständnis und Unterstützung sicherzustellen.
