# 25.5 Nicht-Zeitwert-basierte Methoden und Zeitwert-basierte Methoden vergleichen und gegenüberstellen

### Nicht-Zeitwert-basierte Methoden

1. **Payback-Periode**
   - Fokus : Liquidität
   - Vorteile : Einfach, hebt Risiko hervor
   - Nachteile : Ignoriert Zeitwert und Cashflows nach Payback

2. **Abgezinste Payback-Periode** (Hybrid)
   - Berücksichtigt Zeitwert, ignoriert aber immer noch Post-Payback-Cashflows

3. **Accounting Rate of Return (ARR)**
   - Fokus : Buchrentabilität
   - Vorteile : Verwendet vertraute Buchhaltungsdaten
   - Nachteile : Ignoriert Zeitwert, verwendet Buchgewinn nicht Cashflow

### Zeitwert-basierte Methoden

1. **Net Present Value (NPV)**
   - Fokus : Wertschöpfung
   - Vorteile : Berücksichtigt Zeitwert, Cashflows, Risiko
   - Nachteile : Erfordert genauen Diskontierungssatz

2. **Internal Rate of Return (IRR)**
   - Fokus : Rendite
   - Vorteile : Intuitiv, berücksichtigt Zeitwert
   - Nachteile : Mehrere IRRs möglich, Reinvestitionsannahme

3. **Profitability Index (PI)**
   - Fokus : Wert pro Einheit Investition
   - Vorteile : Nützlich für Kapitalrationierung
   - Nachteile : Kann mit NPV bei Vergleich gegenseitig ausschließender Projekte in Konflikt stehen

4. **Abgezinste Payback**
   - Fokus : Liquidität mit Zeitwert
   - Vorteile : Berücksichtigt Risiko und Zeitwert
   - Nachteile : Ignoriert Cashflows nach Payback

### Vergleichstabelle

| Methode | Zeitwert | Cashflow-Fokus | Entscheidungsmetrik | Beste Verwendung |
|---------|----------|----------------|---------------------|-------------------|
| Payback | Nein | Cash-Eingänge | Jahre bis Rückgewinnung | Schnelle Risikobewertung |
| Abgezinste Payback | Ja | Cash-Eingänge | Jahre bis Rückgewinnung (abgezinst) | Liquidität mit Risiko |
| ARR | Nein | Buchgewinn | Prozentuale Rendite | Einfache Leistungsmaßnahme |
| NPV | Ja | Cashflows | Geldwert | Primäre Entscheidungsmetrik |
| IRR | Ja | Cashflows | Rendite | Ergänzung zu NPV |
| PI | Ja | Cashflows | Verhältnis (Nutzen/Kosten) | Kapitalrationierung |

### Entscheidungsframework

- Payback/ARR für schnelles Screening verwenden
- NPV/IRR/PI für endgültige Entscheidungen verwenden
- Abgezinste Payback zur Risiko-/Liquiditätsbewertung verwenden
- Qualitative Faktoren durchgehend berücksichtigen

### Luxemburg-Compliance-Hinweis

In Luxemburg beginnen KMU oft mit einfachen Methoden (Payback, ARR), aber Banken und Investoren werden NPV- und IRR-Analyse für Finanzierungsentscheidungen erwarten. Investitionsbudgetierungsanalyse sollte auch Sensitivitäts- und Szenariotests angesichts der Marktvolatilität umfassen.
