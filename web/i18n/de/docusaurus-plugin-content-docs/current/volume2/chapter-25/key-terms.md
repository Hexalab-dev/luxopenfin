# Schlüsselbegriffe

- **Investitionsbudgetierung** : Prozess der Bewertung langfristiger Investitionen
- **Payback-Periode** : Zeit bis zur Rückgewinnung der Anfangsinvestition
- **Abgezinste Payback** : Payback unter Berücksichtigung des Zeitwerts des Geldes
- **Accounting Rate of Return (ARR)** : Durchschnittlicher Buchgewinn ÷ Investition
- **Zeitwert des Geldes (TVM)** : Konzept, dass Geld heute mehr wert ist als zukünftiges Geld
- **Net Present Value (NPV)** : Barwert der Cashflows minus Anfangsinvestition
- **Internal Rate of Return (IRR)** : Diskontierungssatz, der NPV = 0 macht
- **Profitability Index (PI)** : PV der Eingänge ÷ Anfangsinvestition
- **Diskontierungssatz** : Erforderliche Rendite, oft WACC
- **Abschreibung Steuerschutz** : Steuerersparnisse aus Abschreibung
- **Working Capital** : Umlaufvermögen minus kurzfristige Verbindlichkeiten
- **Terminal Cashflow** : Finaler Cash-Eingang am Projektende
- **Sensitivitätsanalyse** : Annahmen variieren, um Auswirkungen auf NPV/IRR zu sehen
- **Szenarioanalyse** : Verschiedene Fälle bewerten (bester, Basis, schlechtester)
- **Kapitalkosten** : Erforderliche Rendite von Investoren und Kreditgebern
- **Staatliche Beihilfe** : Staatliche Zuschüsse oder Subventionen für Investitionen
