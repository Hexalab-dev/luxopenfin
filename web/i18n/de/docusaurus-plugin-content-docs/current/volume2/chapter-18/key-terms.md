# Schlüsselbegriffe

- **Kostenrechnung** : Prozess der Identifizierung, Messung, Analyse, Interpretation und Kommunikation von Finanzinformationen an Manager für Planung, Entscheidungsfindung und Kontrolle
- **Planung** : Setzen von Zielen und Entwicklung von Strategien, um sie zu erreichen
- **Kontrolle** : Überwachung der tatsächlichen Leistung und Vergleich mit geplanter Leistung, dann Korrekturmaßnahmen ergreifen
- **Entscheidungsfindung** : Wahl zwischen alternativen Handlungsoptionen
- **Finanzbuchhaltung** : Buchhaltung, die sich auf externe Nutzer, historische Berichterstattung und Compliance konzentriert
- **Strategische Planung** : Langfristige Planung (3-5 Jahre oder mehr)
- **Taktische Planung** : Mittelfristige Planung (1-3 Jahre)
- **Operative Planung** : Kurzfristige Planung (täglich, wöchentlich, monatlich, jährlich)
- **Abweichung** : Unterschied zwischen tatsächlicher und geplanter Leistung
- **Kostenrechnung** : Prozess der Verfolgung, Aufzeichnung und Analyse von Kosten
- **Budget** : Finanzplan für eine zukünftige Periode
- **Prognose** : Vorhersage zukünftiger Finanzleistung
- **Leistungsmessung** : Prozess der Bewertung, wie gut Ziele erreicht werden
- **Schlüsselleistungsindikator (KPI)** : Metrik zur Erfolgsbewertung
- **Break-Even-Analyse** : Analyse zur Bestimmung des Punktes, an dem Umsatz Kosten entspricht
- **Kosten-Nutzen-Analyse** : Vergleich von Kosten und Nutzen von Alternativen
- **Institute of Management Accountants (IMA)** : Globale Vereinigung für Kostenrechner
- **Certified Management Accountant (CMA)** : Berufszertifizierung für Kostenrechner
- **Ethik** : Moralische Prinzipien, die Verhalten regeln
- **Aktivitätsbasierte Kostenrechnung** : Kostenrechnungsmethode, die Kosten basierend auf Aktivitäten zuweist
- **Balanced Scorecard** : Leistungsmessungsrahmen, der finanzielle und nicht-finanzielle Metriken umfasst
