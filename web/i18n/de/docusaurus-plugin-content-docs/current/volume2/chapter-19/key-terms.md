# Schlüsselbegriffe

- **Kosten-Volumen-Gewinn-Analyse (CVP)** : Methode zur Analyse, wie Betriebsentscheidungen den Gewinn basierend auf Kosten, Volumen und Preisen beeinflussen
- **Variable Kosten** : Kosten, die sich insgesamt direkt proportional zum Volumen ändern
- **Fixkosten** : Kosten, die insgesamt unabhängig vom Volumen konstant bleiben
- **Gemischte Kosten** : Kosten mit fixen und variablen Komponenten
- **Deckungsbeitrag** : Umsatzerlös minus variable Kosten
- **Deckungsbeitrag pro Einheit** : Verkaufspreis pro Einheit minus variable Kosten pro Einheit
- **Deckungsbeitragsquote** : Deckungsbeitrag dividiert durch Umsatzerlös
- **Break-Even-Punkt** : Verkaufsniveau, bei dem Umsatz Gesamtkosten entspricht (Gewinn null)
- **Zielgewinn** : Gewünschtes Gewinnniveau
- **Sicherheitsmarge** : Betrag, um den tatsächliche Verkäufe Break-Even-Verkäufe überschreiten
- **CVP-Gewinn- und Verlustrechnung** : Gewinn- und Verlustrechnung organisiert nach Kostenverhalten
- **Operativer Hebel** : Maß für Empfindlichkeit des Gewinns auf Volumenänderungen
- **Verkaufsmix** : Relative Anteil verschiedener verkaufter Produkte
- **Gewichteter durchschnittlicher Deckungsbeitrag** : Durchschnittlicher Deckungsbeitrag gewichtet nach Verkaufsmix
- **Variable Kostenrechnung** : Kostenrechnungsmethode, die nur variable Fertigungskosten einschließt
- **Vollkostenrechnung** : Kostenrechnungsmethode, die alle Fertigungskosten einschließt
- **Relevanter Bereich** : Aktivitätsbereich, in dem Kostenverhaltensannahmen gültig sind
- **Grad des operativen Hebels** : Deckungsbeitrag dividiert durch Nettoeinkommen
