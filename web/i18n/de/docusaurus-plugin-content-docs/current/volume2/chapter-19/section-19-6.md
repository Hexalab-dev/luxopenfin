# 19.6 Luxemburgische Kostenstrukturbeispiele

### Beispiel 1 : Einzelhandelsgeschäft

**Luxemburgisches Einzelhandelsgeschäft - Kostenstruktur :**

**Fixkosten (Monatlich) :**
- Miete (Premium-Standort) : €4,000
- Gehälter : €5,000
- Sozialabgaben (12,57 %; CCSS-Sätze zum 1. Januar 2026, Mutualité-Klasse 1) : €628.50
- Versicherung : €300
- Buchhaltungsdienstleistungen : €400
- Versorgungsunternehmen : €200
- Marketing (fix) : €500
- **Gesamt : €11,028.50**

**Variable Kosten (Pro €100 Verkäufe) :**
- Herstellungskosten : €60
- Verkaufsprovisionen (2%) : €2
- Kreditkartengebühren (1.5%) : €1.50
- Verpackung : €0.50
- **Gesamt : €64 pro €100 Verkäufe**

**Verkaufspreis :**
- Durchschnittlicher Aufschlag : 67% auf Kosten
- Wenn Kosten €60 sind, ist Verkaufspreis €100 (exklusive MwSt)
- MwSt-Satz : 17% (die meisten Einzelhandelswaren)
- Preis inklusive MwSt : €117

**Break-Even-Analyse :**
- Deckungsbeitrag pro €100 Verkäufe : €100 - €64 = €36
- Deckungsbeitragsquote : €36 ÷ €100 = 36%
- Break-Even (Umsatz) : €11,028.50 ÷ 0.36 = €30,635 pro Monat
- Break-Even (Einheiten) : Hängt vom durchschnittlichen Verkaufsbetrag ab

### Beispiel 2 : Dienstleistungsunternehmen (Beratung)

**Luxemburgisches Beratungsunternehmen - Kostenstruktur :**

**Fixkosten (Monatlich) :**
- Büromiete : €2,500
- Gehälter (Berater, fix) : €8,000
- Sozialabgaben (12,57 %) : €1,005.60
- Versicherung : €400
- Professionelle Gebühren : €600
- Marketing : €800
- **Gesamt : €13,305.60**

**Variable Kosten (Pro Stunde) :**
- Materialien/Versorgungsmaterialien : €10
- Reisen (variabel) : €15
- Andere variable : €5
- **Gesamt : €30 pro Stunde**

**Abrechnungssatz :**
- Satz exklusive MwSt : €120 pro Stunde
- MwSt-Satz : 17%
- Satz inklusive MwSt : €140.40 pro Stunde

**Break-Even-Analyse :**
- Deckungsbeitrag pro Stunde : €120 - €30 = €90
- Break-Even (Stunden) : €13,305.60 ÷ €90 = 147.8 → 148 Stunden pro Monat
- Break-Even (Umsatz) : 148 × €120 = €17,760 pro Monat

### Beispiel 3 : Fertigungs-KMU

**Kleiner luxemburgischer Hersteller - Kostenstruktur :**

**Fixkosten (Monatlich) :**
- Fabrikmiete : €5,000
- Gehälter : €12,000
- Sozialabgaben (12,57 %) : €1,508.40
- Abschreibung : €1,500
- Versicherung : €600
- Versorgungsunternehmen (Basis) : €400
- **Gesamt : €21,008.40**

**Variable Kosten (Pro Einheit) :**
- Direkte Materialien : €15
- Direkte Arbeit (variabel) : €8
- Variable Gemeinkosten : €4
- **Gesamt : €27 pro Einheit**

**Verkaufspreis :**
- Preis exklusive MwSt : €50 pro Einheit
- MwSt-Satz : 17%
- Preis inklusive MwSt : €58.50 pro Einheit

**Break-Even-Analyse :**
- Deckungsbeitrag pro Einheit : €50 - €27 = €23
- Break-Even (Einheiten) : €21,008.40 ÷ €23 = 913.4 → 914 Einheiten pro Monat
- Break-Even (Umsatz) : 914 × €50 = €45,700 pro Monat

### Kostenstrukturvariationen

**Unternehmen mit hohen Fixkosten :**
- Beispiel : Hotel, Restaurant mit hoher Miete
- Hoher Break-Even-Punkt
- Hoher operativer Hebel
- Gewinne empfindlich auf Volumenänderungen

**Unternehmen mit hohen variablen Kosten :**
- Beispiel : Einzelhandel mit hohen Herstellungskosten
- Niedrigerer Break-Even-Punkt
- Niedrigerer operativer Hebel
- Stabilere Gewinne

**Dienstleistungsunternehmen :**
- Oft hohe Arbeitskosten (variabel oder fix)
- Niedrigere Materialkosten
- Break-Even hängt von Auslastungsraten ab

### Strategien zur Verbesserung der Kostenstruktur

**Fixkosten reduzieren :**
- Niedrigere Miete aushandeln
- Festes Personal reduzieren (variable Arbeit verwenden)
- Einrichtungen teilen
- Nicht-kernfunktionen auslagern

**Variable Kosten reduzieren :**
- Bessere Lieferantenpreise aushandeln
- Effizienz verbessern
- Abfall reduzieren
- Prozesse optimieren

**Deckungsbeitrag erhöhen :**
- Preise erhöhen (wenn Markt es zulässt)
- Variable Kosten reduzieren
- Auf hochmargige Produkte/Dienstleistungen fokussieren
- Verkaufsmix verbessern

### Luxemburgische Compliance-Hinweis

Luxemburgische KMU sollten :
- Ihre Kostenstruktur verstehen
- Kostenanalyse regelmäßig überprüfen und aktualisieren
- Luxemburgspezifische Kosten berücksichtigen
- Alle Compliance-Kosten einbeziehen
- MwSt korrekt berücksichtigen
- Sozialabgaben in Arbeitskosten berücksichtigen
- Kosteninformationen für Preisentscheidungen verwenden
