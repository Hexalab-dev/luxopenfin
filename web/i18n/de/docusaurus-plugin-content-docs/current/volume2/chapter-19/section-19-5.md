# 19.5 Break-Even-Analyse luxemburgischer KMU

### Luxemburgspezifische Überlegungen

Bei der Durchführung der Break-Even-Analyse für luxemburgische KMU sind mehrere Faktoren einzigartig für die luxemburgische Geschäftsumgebung.

#### MwSt-Überlegungen

**MwSt-Auswirkungen auf Preisgestaltung :**
- Verkaufspreise können inklusive oder exklusive MwSt angegeben werden
- Break-Even-Analyse sollte konsistent sein (entweder alles inklusive MwSt oder alles exklusive MwSt)
- Die meisten Unternehmen analysieren exklusive MwSt für interne Zwecke

**Beispiel :**
Maries Restaurant :
- Preis exklusive MwSt : €20
- MwSt-Satz : 3% (Restaurantmahlzeiten zum Verzehr vor Ort; alkoholische Getränke wären 17%)
- Preis inklusive MwSt : €20 × 1.03 = €20.60

**Break-Even-Analyse :**
- Preise exklusive MwSt für interne Analyse verwenden
- MwSt-Auswirkungen auf Cashflow berücksichtigen
- Erhobene MwSt ist kein Umsatz (es ist eine Verbindlichkeit)

#### Luxemburgische Kostenstruktur

**Typische Fixkosten :**
- Miete (oft hoch in Luxemburg)
- Gehälter (mit Sozialabgaben)
- Versicherung
- Professionelle Gebühren (Fiduciaire, Expert-Comptable)
- RCS-Gebühren
- Versorgungsunternehmen (Grundgebühren)

**Typische variable Kosten :**
- Herstellungskosten (Materialien, Zutaten)
- Direkte Arbeit (wenn pro Einheit/Stunde bezahlt)
- Verkaufsprovisionen
- Kreditkartengebühren (Prozentsatz der Verkäufe)
- Verpackung (falls zutreffend)

**Sozialabgaben :**
- Arbeitnehmer-Sozialabgaben : Variabel (basierend auf Gehältern)
- Arbeitgeber-Sozialabgaben : Variabel (basierend auf Gehältern)
- Können in Luxemburg erheblich sein
- Sollten in Kostenanalyse einbezogen werden

#### Break-Even-Beispiel : Luxemburgisches Restaurant

**Maries Restaurant - Detaillierte Analyse :**

**Fixkosten (Monatlich) :**
- Miete : €3,500
- Gehälter (festes Personal) : €4,000
- Arbeitgeber-Sozialabgaben (12,57 %; CCSS-Sätze zum 1. Januar 2026, Mutualité-Klasse 1) : €502.80
- Versicherung : €200
- Fiduciaire-Gebühren : €300
- Versorgungsunternehmen (Basis) : €150
- Andere Fixkosten : €847.20
- **Gesamte Fixkosten : €9,500**

**Variable Kosten (Pro Mahlzeit) :**
- Zutaten : €6.00
- Direkte Arbeit (Kellner, variabel) : €1.50
- Kreditkartengebühren (2% von €20) : €0.40
- Andere variable : €0.10
- **Gesamte variable Kosten pro Mahlzeit : €8.00**

**Verkaufspreis :**
- Preis exklusive MwSt : €20.00
- MwSt (3%) : €0.60
- Preis inklusive MwSt : €20.60

**Break-Even-Analyse :**
- Deckungsbeitrag pro Mahlzeit : €20 - €8 = €12
- Break-Even (Mahlzeiten) : €9,500 ÷ €12 = 792 Mahlzeiten pro Monat
- Break-Even (Umsatz exklusive MwSt) : 792 × €20 = €15,840
- Break-Even (Umsatz inklusive MwSt) : 792 × €20.60 = €16,315

**Zielgewinn-Analyse :**
Wenn Marie €5,000 Gewinn pro Monat möchte :
- Erforderlicher Deckungsbeitrag : €9,500 + €5,000 = €14,500
- Erforderliche Mahlzeiten : €14,500 ÷ €12 = 1,208 Mahlzeiten pro Monat
- Erforderlicher Umsatz (exklusive MwSt) : 1,208 × €20 = €24,160

### Luxemburgische Geschäftsumgebungsfaktoren

**Hohe Betriebskosten :**
- Luxemburg hat relativ hohe Kosten (Miete, Gehälter)
- Break-Even-Punkte können höher sein als in anderen Ländern
- Effiziente Betriebe erforderlich, um zu konkurrieren

**Mehrsprachiger Markt :**
- Möglicherweise verschiedene Kundensegmente bedienen
- Verschiedene Preisstrategien können erforderlich sein
- Marktspezifische Break-Even-Punkte berücksichtigen

**Regulatorische Compliance :**
- Compliance-Kosten sind Fixkosten
- Müssen in Break-Even-Analyse einbezogen werden
- Kosten professioneller Dienstleistungen berücksichtigen

**Wettbewerb :**
- Wettbewerbsdruck bei Preisen
- Kostenstruktur verstehen, um zu konkurrieren
- Break-Even-Analyse hilft bei Preisentscheidungen

### Break-Even-Analyse-Tools für luxemburgische KMU

**Buchhaltungssoftware :**
- Sage BOB : Kann CVP-Analyse unterstützen
- Odoo : Hat Kostenanalysefunktionen
- Excel : Flexibles Tool für Break-Even-Analyse
- Benutzerdefinierte Tabellenkalkulationen : Können an Bedürfnisse angepasst werden

**Professionelle Dienstleistungen :**
- Fiduciaires : Können bei Kostenanalyse helfen
- Expert-Comptables : Bieten strategische Kostenanalyse
- Geschäftsberater : Spezialisierte CVP-Analyse

### Luxemburgische Compliance-Hinweis

Für luxemburgische KMU :
- Break-Even-Analyse ist nicht erforderlich, aber dringend empfohlen
- Hilft bei Geschäftsplanung und Finanzierung
- Alle luxemburgspezifischen Kosten berücksichtigen
- Compliance-Kosten in Fixkosten einbeziehen
- MwSt sollte konsistent in Analyse behandelt werden
- Sozialabgaben sind erheblich und müssen einbezogen werden
