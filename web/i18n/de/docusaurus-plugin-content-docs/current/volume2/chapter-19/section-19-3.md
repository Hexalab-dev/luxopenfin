# 19.3 Kosten-Volumen-Gewinn-Analyse für Mehrprodukt- und Dienstleistungsunternehmen anwenden

### Verkaufsmix

Der **Verkaufsmix** (auch Produktmix genannt) ist der relative Anteil verschiedener verkaufter Produkte oder Dienstleistungen. Wenn ein Unternehmen mehrere Produkte verkauft, wird die CVP-Analyse komplexer, da verschiedene Produkte unterschiedliche Deckungsbeiträge haben.

Für mehrere Produkte berechnen wir einen **gewichteten durchschnittlichen Deckungsbeitrag** basierend auf dem Verkaufsmix.

**Formel :**
**Gewichteter durchschnittlicher Deckungsbeitrag = Σ (Deckungsbeitrag pro Einheit × Verkaufsmix-Prozentsatz)**

**Beispiel :**
Maries Restaurant verkauft drei Arten von Mahlzeiten :
- Signature-Gericht : €25 Preis, €10 variable Kosten, 40% der Verkäufe
- Mittagsmenü : €15 Preis, €6 variable Kosten, 35% der Verkäufe
- Leichtes Essen : €12 Preis, €5 variable Kosten, 25% der Verkäufe

**Deckungsbeiträge :**
- Signature-Gericht : €25 - €10 = €15
- Mittagsmenü : €15 - €6 = €9
- Leichtes Essen : €12 - €5 = €7

**Gewichteter durchschnittlicher Deckungsbeitrag :**
- Signature-Gericht : €15 × 40% = €6.00
- Mittagsmenü : €9 × 35% = €3.15
- Leichtes Essen : €7 × 25% = €1.75
- **Gesamt : €10.90**

### Break-Even mit mehreren Produkten

**Break-Even-Punkt (Einheiten) = Gesamte Fixkosten ÷ Gewichteter durchschnittlicher Deckungsbeitrag**

**Beispiel :**
Fixkosten : €8,000 pro Monat
Gewichteter durchschnittlicher Deckungsbeitrag : €10.90

**Break-Even-Punkt (Einheiten) = €8,000 ÷ €10.90 = 734 Gesamtmahlzeiten**

**Break-Even nach Produkt (basierend auf Verkaufsmix) :**
- Signature-Gericht : 734 × 40% = 294 Mahlzeiten
- Mittagsmenü : 734 × 35% = 257 Mahlzeiten
- Leichtes Essen : 734 × 25% = 184 Mahlzeiten

### Break-Even in Verkaufseuros

**Gewichtete durchschnittliche Deckungsbeitragsquote :**
**Gewichtete durchschnittliche Deckungsbeitragsquote = Gewichteter durchschnittlicher Deckungsbeitrag ÷ Gewichteter durchschnittlicher Verkaufspreis**

**Gewichteter durchschnittlicher Verkaufspreis :**
- Signature-Gericht : €25 × 40% = €10.00
- Mittagsmenü : €15 × 35% = €5.25
- Leichtes Essen : €12 × 25% = €3.00
- **Gesamt : €18.25**

**Gewichtete durchschnittliche Deckungsbeitragsquote :**
€10.90 ÷ €18.25 = 0.597 oder 59.7%

**Break-Even (Euro) = €8,000 ÷ 0.597 = €13,400**

### Änderungen im Verkaufsmix

Wenn sich der Verkaufsmix ändert, ändert sich der Break-Even-Punkt.

**Beispiel :**
Wenn sich der Verkaufsmix zu mehr Signature-Gerichten verschiebt (höherer Deckungsbeitrag) :
- Neuer Mix : Signature 50%, Mittag 30%, Leicht 20%
- Neuer gewichteter durchschnittlicher Deckungsbeitrag : (€15 × 50%) + (€9 × 30%) + (€7 × 20%) = €11.60
- Neuer Break-Even : €8,000 ÷ €11.60 = 690 Mahlzeiten (von 734 gesunken)

**Auswirkung :**
- Günstige Verkaufsmixänderung (mehr hochmargige Produkte) reduziert Break-Even
- Ungünstige Verkaufsmixänderung (mehr niedrigmargige Produkte) erhöht Break-Even

### Dienstleistungsunternehmen

Dienstleistungsunternehmen können auch CVP-Analyse verwenden, haben aber typischerweise :
- Kein Inventar (Dienstleistungen werden bei Bereitstellung verbraucht)
- Unterschiedliche Kostenstrukturen (oft arbeitsintensiver)
- Unterschiedliche Umsatzerkennung (während Dienstleistungen erbracht werden)

**Beispiel :**
Ein luxemburgisches Beratungsunternehmen :
- Fixkosten : €15,000 pro Monat (Büromiete, Gehälter)
- Variable Kosten : €50 pro Stunde (Materialien, Reisen)
- Abrechnungssatz : €150 pro Stunde
- Deckungsbeitrag pro Stunde : €150 - €50 = €100

**Break-Even (Stunden) = €15,000 ÷ €100 = 150 Stunden pro Monat**

### Luxemburgische Compliance-Hinweis

Für luxemburgische KMU mit mehreren Produkten/Dienstleistungen :
- Verschiedene MwSt-Sätze können gelten (3%, 8%, 14%, 17%)
- CVP-Analyse sollte MwSt-Auswirkungen auf Preisgestaltung berücksichtigen
- Verkaufsmix beeinflusst gesamte MwSt-Verbindlichkeit
- Kostenstruktur kann je nach Produkt-/Dienstleistungstyp variieren
- Luxemburgspezifische Kosten in Analyse berücksichtigen
