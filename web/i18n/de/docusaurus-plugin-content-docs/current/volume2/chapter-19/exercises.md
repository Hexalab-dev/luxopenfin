# Kapitel 19 – Übungen und Fälle

## Multiple-Choice-Fragen

1. Variable Kosten sind Kosten, die :  
   a) Insgesamt konstant bleiben  
   b) Insgesamt direkt proportional zum Volumen ändern  
   c) Pro Einheit ändern, wenn sich das Volumen ändert  
   d) Immer fix sind  
   **Antwort :** b) Variable Kosten ändern sich insgesamt direkt proportional zum Volumen.

2. Deckungsbeitrag ist :  
   a) Verkäufe minus Fixkosten  
   b) Verkäufe minus variable Kosten  
   c) Verkäufe minus Gesamtkosten  
   d) Fixkosten minus variable Kosten  
   **Antwort :** b) Deckungsbeitrag = Verkäufe - Variable Kosten.

3. Break-Even-Punkt tritt auf, wenn :  
   a) Umsatz gleich variable Kosten ist  
   b) Umsatz gleich Fixkosten ist  
   c) Umsatz gleich Gesamtkosten ist  
   d) Deckungsbeitrag gleich null ist  
   **Antwort :** c) Break-Even tritt auf, wenn Umsatz gleich Gesamtkosten ist.

4. Wenn Verkaufspreis €20 ist, variable Kosten €8 sind und Fixkosten €6,000 sind, ist Break-Even in Einheiten :  
   a) 300 Einheiten  
   b) 500 Einheiten  
   c) 750 Einheiten  
   d) 1,000 Einheiten  
   **Antwort :** b) Break-Even = €6,000 ÷ (€20 - €8) = 500 Einheiten.

5. Sicherheitsmarge ist :  
   a) Break-Even-Verkäufe minus tatsächliche Verkäufe  
   b) Tatsächliche Verkäufe minus Break-Even-Verkäufe  
   c) Deckungsbeitrag minus Fixkosten  
   d) Verkaufspreis minus variable Kosten  
   **Antwort :** b) Sicherheitsmarge = Tatsächliche Verkäufe - Break-Even-Verkäufe.

6. Hoher operativer Hebel bedeutet :  
   a) Niedrige Fixkosten  
   b) Hohe variable Kosten  
   c) Hohe Fixkosten relativ zu variablen Kosten  
   d) Niedriger Deckungsbeitrag  
   **Antwort :** c) Hoher operativer Hebel = Hohe Fixkosten relativ zu variablen Kosten.

7. Verkaufsmix ist :  
   a) Gesamtverkaufsvolumen  
   b) Anteil verschiedener verkaufter Produkte  
   c) Durchschnittlicher Verkaufspreis  
   d) Gesamter Deckungsbeitrag  
   **Antwort :** b) Verkaufsmix ist der relative Anteil verschiedener verkaufter Produkte.

8. Variable Kostenrechnung schließt in Produktkosten ein :  
   a) Alle Fertigungskosten  
   b) Nur variable Fertigungskosten  
   c) Nur fixe Fertigungskosten  
   d) Keine Fertigungskosten  
   **Antwort :** b) Variable Kostenrechnung schließt nur variable Fertigungskosten ein.

9. Vollkostenrechnung ist erforderlich für :  
   a) Interne Entscheidungsfindung  
   b) Externe Finanzberichterstattung  
   c) CVP-Analyse  
   d) Break-Even-Analyse  
   **Antwort :** b) Vollkostenrechnung ist für externe Finanzberichterstattung erforderlich.

10. In Luxemburg sollte Break-Even-Analyse :  
    a) MwSt ignorieren  
    b) MwSt konsistent behandeln  
    c) Nur Fixkosten berücksichtigen  
    d) Sozialabgaben ausschließen  
    **Antwort :** b) MwSt sollte konsistent in Break-Even-Analyse behandelt werden.

## Probleme Serie A

**Problem A-1 : Break-Even-Berechnung**

Ein Unternehmen hat :
- Verkaufspreis : €30 pro Einheit
- Variable Kosten : €12 pro Einheit
- Fixkosten : €18,000 pro Monat

Berechnen Sie :
a) Deckungsbeitrag pro Einheit  
b) Deckungsbeitragsquote  
c) Break-Even-Punkt in Einheiten  
d) Break-Even-Punkt in Euro

**Problem A-2 : Zielgewinn**

Mit den Daten aus Problem A-1 berechnen Sie :
a) Einheiten benötigt, um €6,000 Gewinn zu erzielen  
b) Umsatz benötigt, um €6,000 Gewinn zu erzielen  
c) Wenn 1,500 Einheiten verkauft werden, wie hoch ist der Gewinn ?

**Problem A-3 : Was-wäre-wenn-Analyse**

Ein Unternehmen hat :
- Verkaufspreis : €25
- Variable Kosten : €10
- Fixkosten : €15,000
- Aktuelle Verkäufe : 1,200 Einheiten

Berechnen Sie die Auswirkung von :
a) Preis auf €28 erhöhen  
b) Variable Kosten auf €8 reduzieren  
c) Fixkosten auf €18,000 erhöhen

**Problem A-4 : Sicherheitsmarge**

Ein Unternehmen hat :
- Tatsächliche Verkäufe : 2,000 Einheiten
- Break-Even-Verkäufe : 1,500 Einheiten
- Verkaufspreis : €20 pro Einheit

Berechnen Sie :
a) Sicherheitsmarge in Einheiten  
b) Sicherheitsmarge in Euro  
c) Sicherheitsmargenquote

**Problem A-5 : Operativer Hebel**

Bei 1,000 Einheiten :
- Deckungsbeitrag : €12,000
- Nettoeinkommen : €4,000

Berechnen Sie :
a) Grad des operativen Hebels  
b) Wenn Verkäufe um 20% steigen, wie hoch ist der prozentuale Anstieg des Gewinns ?

## Probleme Serie B

**Problem B-1 : Mehrere Produkte**

Ein Unternehmen verkauft zwei Produkte :
- Produkt A : Preis €40, Variable Kosten €20, 60% der Verkäufe
- Produkt B : Preis €30, Variable Kosten €15, 40% der Verkäufe

Berechnen Sie :
a) Gewichteter durchschnittlicher Deckungsbeitrag  
b) Gewichteter durchschnittlicher Verkaufspreis  
c) Gewichtete durchschnittliche Deckungsbeitragsquote  
d) Break-Even-Punkt in Gesamteinheiten  
e) Break-Even-Punkt in Euro  
f) Break-Even-Einheiten für jedes Produkt

**Problem B-2 : Variable vs. Vollkostenrechnung**

Ein Unternehmen :
- Produziert : 2,000 Einheiten
- Verkauft : 1,800 Einheiten
- Verkaufspreis : €50
- Variable Fertigungskosten : €20
- Fixe Fertigungsgemeinkosten : €30,000
- Variable Verkaufskosten : €5 pro Einheit
- Fixe Verkaufskosten : €10,000

Berechnen Sie Nettoeinkommen unter :
a) Variabler Kostenrechnung  
b) Vollkostenrechnung  
c) Erklären Sie den Unterschied

**Problem B-3 : Vollständige CVP-Analyse**

Ein luxemburgisches Restaurant :
- Fixkosten : €12,000 pro Monat
- Variable Kosten pro Mahlzeit : €9
- Verkaufspreis pro Mahlzeit : €25 (exklusive MwSt)
- MwSt-Satz : 3% (Restaurantmahlzeiten)

Berechnen Sie :
a) Break-Even in Mahlzeiten (MwSt-Überlegung für interne Analyse ausschließen)  
b) Break-Even in Umsatz (exklusive MwSt)  
c) Mahlzeiten benötigt für €8,000 Gewinn  
d) Wenn 1,000 Mahlzeiten verkauft werden, berechnen Sie Gewinn und Sicherheitsmarge

**Problem B-4 : Kostenstrukturanalyse**

Vergleichen Sie zwei Geschäftsmodelle :
- Modell A : Fixkosten €20,000, Variable Kosten €5 pro Einheit, Preis €15
- Modell B : Fixkosten €10,000, Variable Kosten €10 pro Einheit, Preis €15

Berechnen Sie für jedes :
a) Break-Even-Punkt  
b) Gewinn bei 3,000 Einheiten  
c) Grad des operativen Hebels bei 3,000 Einheiten  
d) Welches Modell hat höheres Risiko ? Höhere potenzielle Belohnung ?

## Umfassendes Problem

**Umfassendes Problem 19 : Vollständige CVP-Analyse für Le Petit Bistro**

Marie möchte eine vollständige CVP-Analyse für ihr Restaurant durchführen, um bessere Entscheidungen zu treffen.

**Aktuelle Situation :**
- Fixkosten pro Monat : €9,500
  - Miete : €3,500
  - Gehälter (fix) : €4,000
  - Sozialabgaben (12,57 %; CCSS-Sätze zum 1. Januar 2026, Mutualité-Klasse 1) : €502.80
  - Versicherung : €200
  - Fiduciaire : €300
  - Versorgungsunternehmen (Basis) : €150
  - Andere : €847.20

**Menüartikel :**
- Signature-Gericht : Preis €25 (exkl. MwSt), Variable Kosten €10, 40% der Verkäufe
- Mittagsmenü : Preis €15 (exkl. MwSt), Variable Kosten €6, 35% der Verkäufe
- Leichtes Essen : Preis €12 (exkl. MwSt), Variable Kosten €5, 25% der Verkäufe
- MwSt-Satz : 3% (alle Mahlzeiten)

**Aktuelle Leistung :**
- Durchschnittlich 900 Mahlzeiten pro Monat
- Aktueller Verkaufsmix wie oben angegeben

**Erforderlich :**

1. **Kostenverhaltensanalyse :**  
   a) Klassifizieren Sie alle Kosten als fix oder variabel  
   b) Berechnen Sie gesamte variable Kosten pro Mahlzeit (gewichteter Durchschnitt)  
   c) Berechnen Sie gewichteten durchschnittlichen Verkaufspreis  
   d) Berechnen Sie gewichteten durchschnittlichen Deckungsbeitrag

2. **Break-Even-Analyse :**  
   a) Berechnen Sie Break-Even-Punkt in Gesamtmahlzeiten  
   b) Berechnen Sie Break-Even-Punkt in Umsatz (exklusive MwSt)  
   c) Berechnen Sie Break-Even für jeden Menüartikel  
   d) Erstellen Sie einen Break-Even-Graph (beschreiben Sie wichtige Punkte)

3. **Aktuelle Leistungsanalyse :**  
   a) Berechnen Sie aktuellen Gewinn bei 900 Mahlzeiten  
   b) Berechnen Sie Sicherheitsmarge  
   c) Berechnen Sie Grad des operativen Hebels  
   d) Analysieren Sie aktuelle Leistung

4. **Zielgewinn-Analyse :**  
   Marie möchte €6,000 Gewinn pro Monat :
   a) Berechnen Sie erforderliche Mahlzeiten  
   b) Berechnen Sie erforderlichen Umsatz  
   c) Analysieren Sie Machbarkeit

5. **Was-wäre-wenn-Szenarien :**  
   a) **Szenario 1 :** Signature-Gericht-Preis auf €28 erhöhen  
     - Berechnen Sie neuen Break-Even
     - Nehmen Sie an, Verkaufsmix ändert sich zu 50% Signature, 30% Mittag, 20% Leicht
   b) **Szenario 2 :** Variable Kosten um 10% reduzieren  
     - Berechnen Sie neuen Break-Even
     - Analysieren Sie Auswirkung
   c) **Szenario 3 :** Fixkosten um €2,000 erhöhen (einen weiteren Koch einstellen)  
     - Berechnen Sie neuen Break-Even
     - Bestimmen Sie, ob zusätzliches Volumen Kosten rechtfertigt

6. **Verkaufsmix-Analyse :**  
   a) Aktueller gewichteter durchschnittlicher Deckungsbeitrag  
   b) Wenn Verkaufsmix zu 50% Signature, 30% Mittag, 20% Leicht wechselt  
     - Berechnen Sie neuen gewichteten durchschnittlichen Deckungsbeitrag
     - Berechnen Sie neuen Break-Even
     - Analysieren Sie Auswirkung

7. **Preisstrategie :**  
   Marie erwägt eine 10%ige Preiserhöhung bei allen Artikeln :
   a) Berechnen Sie neue Preise  
   b) Berechnen Sie neue Deckungsbeiträge  
   c) Berechnen Sie neuen Break-Even  
   d) Analysieren Sie Auswirkung (berücksichtigen Sie potenzielles Volumenrückgang)

8. **Luxemburgische Überlegungen :**  
   a) Wie beeinflusst MwSt die Analyse ?  
   b) Welche luxemburgspezifischen Kosten sind enthalten ?  
   c) Wie beeinflussen Sozialabgaben die Kostenstruktur ?  
   d) Welche Compliance-Überlegungen gibt es ?

9. **Empfehlungen :**  
   Basierend auf der Analyse geben Sie Empfehlungen für :
   a) Preisstrategie  
   b) Kostenmanagement  
   c) Verkaufsmix-Optimierung  
   d) Gewinnverbesserung

## Fälle

**Fall 19-1 : Preisentscheidung**

Marie erwägt, Preise zu senken, um mehr Kunden anzuziehen. Aktuell :
- Durchschnittspreis : €20 (gewichteter Durchschnitt)
- Variable Kosten : €8
- Fixkosten : €9,500
- Aktuelle Verkäufe : 900 Mahlzeiten/Monat
- Gewinn : €2,200/Monat

Sie erwägt eine 15%ige Preissenkung, von der sie glaubt, dass sie das Volumen um 30% erhöhen wird.

**Fragen zur Analyse :**

1. Berechnen Sie die Auswirkung der Preissenkung auf Deckungsbeitrag pro Mahlzeit.

2. Berechnen Sie den neuen Break-Even-Punkt.

3. Berechnen Sie Gewinn beim neuen Volumen (900 × 1.30 = 1,170 Mahlzeiten).

4. Sollte Marie Preise senken ? Warum oder warum nicht ?

5. Welche anderen Faktoren sollte sie berücksichtigen ?

6. Welche alternativen Strategien könnten besser sein ?

**Fall 19-2 : Expansionsentscheidung**

Marie erwägt, ihr Restaurant zu erweitern, um die Kapazität zu erhöhen. Die Expansion würde :
- Fixkosten um €4,000/Monat erhöhen (zusätzliche Miete, Versorgungsunternehmen)
- Ermöglichen, 500 Mahlzeiten mehr pro Monat zu servieren
- Einstellung zusätzlichen Personals erfordern (variable Kosten)

**Fragen zur Analyse :**

1. Was ist der aktuelle Break-Even-Punkt ?

2. Was wäre der neue Break-Even-Punkt nach Expansion ?

3. Wie viele zusätzliche Mahlzeiten muss sie verkaufen, um zusätzliche Fixkosten zu decken ?

4. Wenn sie 400 zusätzliche Mahlzeiten verkaufen kann, sollte sie expandieren ?

5. Was ist das minimale zusätzliche Volumen, das erforderlich ist, um Expansion zu rechtfertigen ?

6. Welche Risiken sollte sie berücksichtigen ?
