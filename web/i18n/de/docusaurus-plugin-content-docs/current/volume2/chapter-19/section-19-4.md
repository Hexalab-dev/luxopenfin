# 19.4 Variable Kostenrechnung und Vollkostenrechnung erklären und verwenden

### Zwei Kostenrechnungsmethoden

Es gibt zwei Hauptmethoden zur Kostenrechnung von Produkten : **Variable Kostenrechnung** (auch als Direktkostenrechnung bezeichnet) und **Vollkostenrechnung** (auch als Vollkostenrechnung bezeichnet).

### Variable Kostenrechnung

Die **Variable Kostenrechnung** schließt nur variable Fertigungskosten in die Produktkosten ein. Fixe Fertigungskosten werden als Periodenkosten behandelt und in der Periode, in der sie anfallen, als Aufwand erfasst.

**Produktkosten (Variable Kostenrechnung) :**
- Direkte Materialien
- Direkte Arbeit (wenn variabel)
- Variable Fertigungsgemeinkosten

**Periodenkosten (Variable Kostenrechnung) :**
- Fixe Fertigungsgemeinkosten
- Verkaufskosten
- Verwaltungskosten

**Gewinn- und Verlustrechnungsformat (Variable Kostenrechnung) :**
```
Umsatzerlös                    €XX,XXX
Weniger : Variable Herstellungskosten (XX,XXX)
Weniger : Variable Verkauf & Verwaltung    (XX,XXX)
────────────────────────────────────────
Deckungsbeitrag               XX,XXX
Weniger : Fixe Fertigungsgemeinkosten (XX,XXX)
Weniger : Fixe Verkauf & Verwaltung       (XX,XXX)
────────────────────────────────────────
Nettoeinkommen                       €XX,XXX
```

### Vollkostenrechnung

Die **Vollkostenrechnung** schließt alle Fertigungskosten (sowohl variable als auch fixe) in die Produktkosten ein. Fixe Fertigungsgemeinkosten werden den Produkten zugeordnet.

**Produktkosten (Vollkostenrechnung) :**
- Direkte Materialien
- Direkte Arbeit
- Variable Fertigungsgemeinkosten
- Fixe Fertigungsgemeinkosten (zugeordnet)

**Periodenkosten (Vollkostenrechnung) :**
- Verkaufskosten
- Verwaltungskosten

**Gewinn- und Verlustrechnungsformat (Vollkostenrechnung) :**
```
Umsatzerlös                    €XX,XXX
Weniger : Herstellungskosten         (XX,XXX)
────────────────────────────────────────
Bruttogewinn                      XX,XXX
Weniger : Verkaufskosten            (XX,XXX)
Weniger : Verwaltungskosten     (XX,XXX)
────────────────────────────────────────
Nettoeinkommen                       €XX,XXX
```

### Wichtige Unterschiede

| Aspekt | Variable Kostenrechnung | Vollkostenrechnung |
|--------|------------------------|-------------------|
| **Fixe Fertigungsgemeinkosten** | Periodenkosten | Produktkosten |
| **Bestandsbewertung** | Niedriger (keine fixen Gemeinkosten) | Höher (schließt fixe Gemeinkosten ein) |
| **Gewinn- und Verlustrechnung** | Deckungsbeitragsformat | Traditionelles Format |
| **Nettoeinkommen** | Kann von Vollkostenrechnung abweichen | Erforderlich für externe Berichterstattung |
| **Verwendung** | Interne Entscheidungsfindung | Externe Berichterstattung, Steuern |

### Beispiel : Vergleich

**Daten :**
- Produzierte Einheiten : 1,000
- Verkaufte Einheiten : 800
- Verkaufspreis : €20 pro Einheit
- Variable Fertigungskosten : €8 pro Einheit
- Fixe Fertigungsgemeinkosten : €6,000 gesamt
- Variable Verkaufskosten : €2 pro Einheit
- Fixe Verkaufskosten : €2,000

**Variable Kostenrechnung :**
- Produktkosten pro Einheit : €8 (nur variabel)
- Fixe Gemeinkosten : €6,000 (Periodenkosten)
- Einkommen : (800 × €20) - (800 × €8) - (800 × €2) - €6,000 - €2,000 = €2,000

**Vollkostenrechnung :**
- Fixe Gemeinkosten pro Einheit : €6,000 ÷ 1,000 = €6
- Produktkosten pro Einheit : €8 + €6 = €14
- Einkommen : (800 × €20) - (800 × €14) - (800 × €2) - €2,000 = €2,800

**Unterschied :** €800 (200 Einheiten im Bestand × €4 fixe Gemeinkosten pro Einheit)

### Wann Nettoeinkommen abweicht

Das Nettoeinkommen unterscheidet sich zwischen den beiden Methoden, wenn :
- Produktion ≠ Verkäufe (Bestandsänderungen)
- Fixe Gemeinkosten unterschiedlich zugeordnet werden

**Wenn Produktion > Verkäufe :**
- Vollkostenrechnung zeigt höheres Einkommen (fixe Gemeinkosten im Bestand)
- Variable Kostenrechnung zeigt niedrigeres Einkommen (alle fixen Gemeinkosten als Aufwand)

**Wenn Produktion < Verkäufe :**
- Vollkostenrechnung zeigt niedrigeres Einkommen (fixe Gemeinkosten aus vorheriger Periode freigegeben)
- Variable Kostenrechnung zeigt höheres Einkommen

**Wenn Produktion = Verkäufe :**
- Beide Methoden zeigen dasselbe Einkommen (keine Bestandsänderung)

### Verwendungen jeder Methode

**Variable Kostenrechnung :**
- Interne Entscheidungsfindung
- CVP-Analyse
- Leistungsbewertung
- Preisentscheidungen
- Produktrentabilitätsanalyse

**Vollkostenrechnung :**
- Externe Finanzberichterstattung (erforderlich nach GAAP/IFRS)
- Steuerberichterstattung (in vielen Rechtsordnungen)
- Bestandsbewertung
- Vollkostenanalyse

### Luxemburgische Compliance-Hinweis

In Luxemburg :
- **Finanzberichterstattung** erfordert typischerweise Vollkostenrechnung (Vollkostenrechnung)
- **Steuerberichterstattung** kann Vollkostenrechnung erfordern
- **Interne Verwaltung** kann Variable Kostenrechnung für Entscheidungen verwenden
- PCN-Konten unterstützen beide Methoden
- Luxemburgische Steuerauswirkungen berücksichtigen
