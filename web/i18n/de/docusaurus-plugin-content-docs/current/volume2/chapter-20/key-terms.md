# Schlüsselbegriffe

- **Auftragskostenrechnung** : Kostenrechnungssystem, das Kosten für jeden einzelnen Auftrag sammelt
- **Prozesskostenrechnung** : Kostenrechnungssystem, das für identische Produkte verwendet wird, die in großen Mengen produziert werden
- **Direkte Materialien** : Rohstoffe, die Teil des Produkts werden und zu Aufträgen zurückverfolgt werden können
- **Direkte Arbeit** : Arbeitskosten der Mitarbeiter, die direkt an Produkten arbeiten
- **Fertigungsgemeinkosten** : Alle Fertigungskosten, die nicht leicht zu Aufträgen zurückverfolgt werden können
- **Auftragskostenblatt** : Dokument, das alle Kosten für einen spezifischen Auftrag sammelt
- **Unfertige Erzeugnisse** : Bestandskonto für teilweise abgeschlossene Aufträge
- **Fertige Erzeugnisse** : Bestandskonto für abgeschlossene Aufträge, die noch nicht verkauft wurden
- **Rohstoffbestand** : Bestandskonto für noch nicht verwendete Materialien
- **Vorbestimmter Gemeinkostensatz** : Geschätzter Gemeinkostensatz, der verwendet wird, um Gemeinkosten auf Aufträge anzuwenden
- **Angewandte Gemeinkosten** : Mit vorbestimmtem Satz auf Aufträge zugeordnete Gemeinkosten
- **Tatsächliche Gemeinkosten** : Reale Gemeinkosten, die während der Periode entstanden sind
- **Unterangewandte Gemeinkosten** : Wenn tatsächliche Gemeinkosten die angewendeten Gemeinkosten übersteigen
- **Überangewandte Gemeinkosten** : Wenn angewendete Gemeinkosten die tatsächlichen Gemeinkosten übersteigen
- **Aktivitätsbasis** : Maß, das verwendet wird, um Gemeinkosten zuzuteilen (Arbeitsstunden, Arbeitskosten, Maschinenstunden)
- **Herstellungskosten** : Kosten von Aufträgen/Produkten, die an Kunden verkauft wurden
- **Auftrag** : Spezifische Bestellung, Projekt oder Charge von Produkten
