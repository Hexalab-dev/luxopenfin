# 20.8 Erklären, wie ein Auftragskostenrechnungssystem auf eine Nichtproduktionsumgebung angewendet wird

### Auftragskostenrechnung über Produktion hinaus

Die Auftragskostenrechnung ist nicht auf die Produktion beschränkt. Sie kann auf jedes Unternehmen angewendet werden, in dem Arbeit auftragsbezogen durchgeführt wird, einschließlich Dienstleistungsunternehmen, Bauwesen und professionelle Dienstleistungen.

### Dienstleistungsunternehmen

Dienstleistungsunternehmen können die Auftragskostenrechnung verwenden, um Kosten nach Kunde, Projekt oder Engagement zu verfolgen.

**Wichtige Unterschiede :**
- Kein Fertigwarenbestand (Dienstleistungen werden bei Erbringung verbraucht)
- Kann unfertige Erzeugnisse haben (unvollständige Dienstleistungen)
- Direkte Materialien können minimal sein
- Direkte Arbeit ist oft die Hauptkosten
- Gemeinkosten müssen noch zugeordnet werden

**Beispiel : Beratungsunternehmen**

**Auftrag #201 : Finanzanalyseprojekt für Kunde ABC**

**Direkte Materialien :**
- Reisekosten : €500
- Materialien : €100
- **Gesamt : €600**

**Direkte Arbeit :**
- Senior-Berater : 40 Stunden × €100/Stunde = €4.000
- Junior-Berater : 30 Stunden × €60/Stunde = €1.800
- **Gesamt : €5.800**

**Angewandte Gemeinkosten (30% der direkten Arbeit) :**
- €5.800 × 30% = €1.740

**Gesamte Auftragskosten :**
- Direkte Materialien : €600
- Direkte Arbeit : €5.800
- Angewandte Gemeinkosten : €1.740
- **Gesamt : €8.140**

**Abrechnung :**
- Abrechnungssatz : €150/Stunde (Senior), €80/Stunde (Junior)
- Abrechnungsbetrag : (40 × €150) + (30 × €80) = €8.400
- Auftragskosten : €8.140
- Gewinn : €260

### Bauunternehmen

Bauunternehmen verwenden die Auftragskostenrechnung umfassend.

**Beispiel : Bauprojekt**

**Auftrag #301 : Bürorenovierung**

**Direkte Materialien :**
- Holz : €5.000
- Elektromaterialien : €2.000
- Sanitärmaterialien : €1.500
- Farbe und Materialien : €800
- **Gesamt : €9.300**

**Direkte Arbeit :**
- Tischler : 80 Stunden × €35/Stunde = €2.800
- Elektriker : 40 Stunden × €40/Stunde = €1.600
- Klempner : 30 Stunden × €38/Stunde = €1.140
- **Gesamt : €5.540**

**Angewandte Gemeinkosten (40% der direkten Arbeit) :**
- €5.540 × 40% = €2.216

**Gesamte Auftragskosten :**
- Direkte Materialien : €9.300
- Direkte Arbeit : €5.540
- Angewandte Gemeinkosten : €2.216
- **Gesamt : €17.056**

### Professionelle Dienstleistungen

**Beispiel : Anwaltskanzlei**

**Auftrag #401 : Unternehmensrechtliche Angelegenheit**

**Direkte Materialien :**
- Gerichtsgebühren : €500
- Einreichungsgebühren : €200
- Recherchematerialien : €300
- **Gesamt : €1.000**

**Direkte Arbeit :**
- Partner : 10 Stunden × €200/Stunde = €2.000
- Mitarbeiter : 25 Stunden × €120/Stunde = €3.000
- Rechtsanwaltsfachangestellter : 15 Stunden × €50/Stunde = €750
- **Gesamt : €5.750**

**Angewandte Gemeinkosten (25% der direkten Arbeit) :**
- €5.750 × 25% = €1.437,50

**Gesamte Auftragskosten :**
- Direkte Materialien : €1.000
- Direkte Arbeit : €5.750
- Angewandte Gemeinkosten : €1.437,50
- **Gesamt : €8.187,50**

### Buchhaltung für Dienstleistungsunternehmen

**Wichtige Konten :**
- **Unfertige Erzeugnisse** : Unvollständige Dienstleistungen
- **Dienstleistungskosten** : Statt Herstellungskosten
- **Dienstleistungserlöse** : Statt Umsatzerlöse

**Fluss :**
1. Kosten verursachen → Unfertige Erzeugnisse
2. Dienstleistung abschließen → (kann Fertige Erzeugnisse überspringen)
3. Kunde abrechnen → Dienstleistungserlöse
4. Kosten erkennen → Dienstleistungskosten

### Luxemburgische Compliance-Hinweis

Für luxemburgische Dienstleistungsunternehmen :
- Auftragskostenrechnung hilft, Kundenrentabilität zu verfolgen
- Angemessene PCN-Konten verwenden
- Dienstleistungsunternehmen können unterschiedliche Kontenstrukturen verwenden
- MwSt-Behandlung hängt vom Dienstleistungstyp ab
- Kostenverfolgung unterstützt Preisentscheidungen
- Luxemburg-spezifische Dienstleistungsbranche berücksichtigen
