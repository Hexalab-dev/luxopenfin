# 20.5 Die Kosten eines Auftrags mit der Auftragskostenrechnung berechnen

### Auftragskostenberechnung

Um die Gesamtkosten eines Auftrags zu berechnen, sammeln wir alle diesem Auftrag zugeordneten Kosten :

**Gesamte Auftragskosten = Direkte Materialien + Direkte Arbeit + Angewandte Fertigungsgemeinkosten**

### Vollständiges Beispiel : Auftragskostenberechnung

**Maries Catering - Auftrag #102 (Hochzeitsempfang für 150 Personen) :**

**Schritt 1 : Direkte Materialien**
- Lebensmittelzutaten : €800
- Getränke : €600
- Dekorationen : €200
- Verpackung/Materialien : €150
- **Gesamte direkte Materialien : €1.750**

**Schritt 2 : Direkte Arbeit**
- Küchenchef : 12 Stunden × €30/Stunde = €360
- Sous-Chef : 10 Stunden × €25/Stunde = €250
- Kellner (3) : 20 Stunden × €15/Stunde = €300
- **Gesamte direkte Arbeit : €910**

**Schritt 3 : Angewandte Fertigungsgemeinkosten**
- Vorbestimmter Gemeinkostensatz : 50% der Direktarbeitskosten
- Direktarbeitskosten : €910
- Angewandte Gemeinkosten : €910 × 50% = €455

**Schritt 4 : Gesamte Auftragskosten**
- Direkte Materialien : €1.750
- Direkte Arbeit : €910
- Angewandte Gemeinkosten : €455
- **Gesamte Auftragskosten : €3.115**

### Mehrere Aufträge-Beispiel

**Maries Catering - Mehrere Aufträge in Bearbeitung :**

**Auftrag #101 (Büromittagessen) :**
- Direkte Materialien : €400
- Direkte Arbeit : €290
- Angewandte Gemeinkosten : €145 (50% der Arbeit)
- **Gesamt : €835**

**Auftrag #102 (Hochzeit) :**
- Direkte Materialien : €1.750
- Direkte Arbeit : €910
- Angewandte Gemeinkosten : €455
- **Gesamt : €3.115**

**Auftrag #103 (Firmenveranstaltung - In Bearbeitung) :**
- Direkte Materialien : €600
- Direkte Arbeit : €400
- Angewandte Gemeinkosten : €200
- **Gesamt : €1.200** (noch nicht abgeschlossen)

**Unfertige Erzeugnisse Gesamt :**
- Auftrag #101 : €835 (abgeschlossen, noch nicht verkauft)
- Auftrag #102 : €3.115 (abgeschlossen, noch nicht verkauft)
- Auftrag #103 : €1.200 (in Bearbeitung)
- **Gesamt UEF : €5.150**

### Auftragsrentabilitätsanalyse

**Auftrag #101 :**
- Verkaufspreis : €1.500
- Auftragskosten : €835
- Bruttogewinn : €665
- Gewinnmarge : 44,3%

**Auftrag #102 :**
- Verkaufspreis : €5.000
- Auftragskosten : €3.115
- Bruttogewinn : €1.885
- Gewinnmarge : 37,7%

**Analyse :**
- Auftrag #101 hat höhere Marge (44,3% vs. 37,7%)
- Auftrag #102 hat höheren absoluten Gewinn (€1.885 vs. €665)
- Beide Aufträge sind rentabel
- Kann diese Informationen für Preisgestaltung zukünftiger Aufträge verwenden

### Kosten pro Einheit

Wenn ein Auftrag mehrere Einheiten produziert, Kosten pro Einheit berechnen :

**Beispiel :**
Auftrag #104 produziert 100 maßgeschneiderte Kuchen :
- Gesamte Auftragskosten : €2.000
- Produzierte Einheiten : 100
- Kosten pro Einheit : €2.000 ÷ 100 = €20 pro Kuchen

### Luxemburgische Compliance-Hinweis

In Luxemburg :
- Auftragskosten müssen genau berechnet werden
- PCN-Konten ordnungsgemäß verwenden
- Auftragskostenaufzeichnungen führen
- Preisentscheidungen unterstützen
- MwSt in Preisgestaltung berücksichtigen (aber von Kosten ausschließen)
- Auftragsrentabilität beeinflusst Geschäftsentscheidungen
