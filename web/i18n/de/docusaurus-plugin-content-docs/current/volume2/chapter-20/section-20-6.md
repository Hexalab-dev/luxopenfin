# 20.6 Unterangewandte oder überangewandte Gemeinkosten bestimmen und verrechnen

### Gemeinkostenanwendungsprobleme

Da wir einen vorbestimmten Gemeinkostensatz (basierend auf Schätzungen) verwenden, werden die während der Periode auf Aufträge angewendeten Gemeinkosten selten den tatsächlich entstandenen Gemeinkosten entsprechen. Diese Differenz muss am Periodenende behandelt werden.

### Unterangewandte Gemeinkosten

**Unterangewandte Gemeinkosten** treten auf, wenn die tatsächlichen Gemeinkosten die angewendeten Gemeinkosten übersteigen.

**Ursachen :**
- Tatsächliche Gemeinkosten höher als geschätzt
- Tatsächliche Aktivität niedriger als geschätzt
- Ineffiziente Gemeinkostenausgaben
- Unerwartete Kosten

**Beispiel :**
- Tatsächliche Gemeinkosten : €62.000
- Angewandte Gemeinkosten : €60.000
- Unterangewandt : €2.000

### Überangewandte Gemeinkosten

**Überangewandte Gemeinkosten** treten auf, wenn die angewendeten Gemeinkosten die tatsächlichen Gemeinkosten übersteigen.

**Ursachen :**
- Tatsächliche Gemeinkosten niedriger als geschätzt
- Tatsächliche Aktivität höher als geschätzt
- Effiziente Gemeinkostenausgaben
- Bessere Kostenkontrolle

**Beispiel :**
- Tatsächliche Gemeinkosten : €58.000
- Angewandte Gemeinkosten : €60.000
- Überangewandt : €2.000

### Verrechnung von unterangewandten/überangewandten Gemeinkosten

Es gibt zwei Hauptmethoden zur Verrechnung der Differenz :

#### Methode 1 : Abschluss auf Herstellungskosten (Einfachste)

**Wenn unterangewandt :**
```
Herstellungskosten             €2.000
    Fertigungsgemeinkosten                    €2.000
Zum Abschließen unterangewandter Gemeinkosten
```

**Wenn überangewandt :**
```
Fertigungsgemeinkosten         €2.000
    Herstellungskosten                        €2.000
Zum Abschließen überangewandter Gemeinkosten
```

**Wann zu verwenden :**
- Kleine Differenz (unwesentlich)
- Die meisten Aufträge sind verkauft
- Einfach und schnell

#### Methode 2 : Zuteilung auf Unfertige Erzeugnisse, Fertige Erzeugnisse und Herstellungskosten (Genauer)

**Wenn unterangewandt :**
Zuteilung basierend auf Endsalden in Konten.

**Beispiel :**
- Unterangewandte Gemeinkosten : €2.000
- Endsalden :
  - Unfertige Erzeugnisse : €5.000 (25%)
  - Fertige Erzeugnisse : €8.000 (40%)
  - Herstellungskosten : €7.000 (35%)
  - Gesamt : €20.000

**Zuteilung :**
- Unfertige Erzeugnisse : €2.000 × 25% = €500
- Fertige Erzeugnisse : €2.000 × 40% = €800
- Herstellungskosten : €2.000 × 35% = €700

**Buchungssatz :**
```
Unfertige Erzeugnisse                  €500
Fertige Erzeugnisse                    800
Herstellungskosten                     700
    Fertigungsgemeinkosten                        €2.000
Zum Zuteilen unterangewandter Gemeinkosten
```

**Wann zu verwenden :**
- Große Differenz (wesentlich)
- Bedeutende Bestandssalden
- Genauere Kostenverteilung

### Beispiel : Vollständige Verrechnung

**Maries Catering - Jahresende :**

**Tatsächliche Gemeinkosten :**
- Miete : €6.000
- Nebenkosten : €2.400
- Abschreibung : €1.800
- Versicherung : €1.200
- Sonstiges : €600
- **Gesamt tatsächlich : €12.000**

**Angewandte Gemeinkosten :**
- Gesamte Direktarbeitskosten : €20.000
- Gemeinkostensatz : 50% der direkten Arbeit
- Angewandte Gemeinkosten : €20.000 × 50% = €10.000

**Differenz :**
- Tatsächlich : €12.000
- Angewandt : €10.000
- **Unterangewandt : €2.000**

**Verrechnung (Abschluss auf HKS - einfache Methode) :**
```
Herstellungskosten             €2.000
    Fertigungsgemeinkosten                    €2.000
Zum Abschließen unterangewandter Gemeinkosten
```

### Auswirkung auf Jahresabschlüsse

**Vor Verrechnung :**
- Fertigungsgemeinkosten hat €2.000 Sollsaldo (unterangewandt)
- Herstellungskosten : €50.000

**Nach Verrechnung :**
- Fertigungsgemeinkosten : €0 (abgeschlossen)
- Herstellungskosten : €52.000 (erhöht um €2.000)

**Wirkung :**
- Unterangewandte Gemeinkosten erhöhen Herstellungskosten
- Reduziert Bruttogewinn und Nettoeinkommen
- Genauere Herstellungskosten

### Anpassen des vorbestimmten Satzes

Wenn Gemeinkosten konsistent unterangewandt oder überangewandt sind, Anpassung des vorbestimmten Satzes für die nächste Periode in Betracht ziehen.

**Beispiel :**
- Konsistent um 10% unterangewandt
- Kann darauf hindeuten, dass Satz zu niedrig ist
- Erhöhung des Satzes für nächste Periode in Betracht ziehen

### Luxemburgische Compliance-Hinweis

In Luxemburg :
- Unterangewandte/überangewandte Gemeinkosten müssen verrechnet werden
- Methode sollte konsistent sein
- Wesentlichkeit berücksichtigen
- Beeinflusst Herstellungskosten und Bestandswerte
- Kann Steuerberechnungen beeinflussen
- Angemessene Zuteilungsmethoden verwenden
