# Kapitelzusammenfassung

### Abschnitt 20.1 : Auftragskostenrechnung und Prozesskostenrechnung vergleichen und gegenüberstellen
- Auftragskostenrechnung : Einzigartige Produkte, Kosten nach Auftrag
- Prozesskostenrechnung : Identische Produkte, Kosten nach Prozess
- Auswahl basierend auf Produktmerkmalen
- Einige Unternehmen verwenden beide

### Abschnitt 20.2 : Drei Hauptkomponenten der Produktkosten
- Direkte Materialien : Zu Aufträgen zurückverfolgbar
- Direkte Arbeit : Arbeit direkt an Aufträgen
- Fertigungsgemeinkosten : Indirekte Kosten, zugeordnet
- Gesamte Auftragskosten = Direkte Materialien + Direkte Arbeit + Angewandte Gemeinkosten

### Abschnitt 20.3 : Fluss der Produktkosten durch Bestandskonten
- Kostenfluss : Rohstoffe → Unfertige Erzeugnisse → Fertige Erzeugnisse → Herstellungskosten
- Auftragskostenblatt verfolgt Kosten nach Auftrag
- Unfertige Erzeugnisse sammelt Kosten für alle Aufträge
- PCN-Konten unterstützen Kostenfluss

### Abschnitt 20.4 : Vorbestimmter Gemeinkostensatz
- Vorbestimmter Satz = Geschätzte Gemeinkosten ÷ Geschätzte Aktivitätsbasis
- Häufige Basen : Direktarbeitsstunden, Direktarbeitskosten, Maschinenstunden
- Gemeinkosten anwenden, während an Aufträgen gearbeitet wird
- Tatsächlich vs. angewandt wird abweichen

### Abschnitt 20.5 : Auftragskosten berechnen
- Alle Kosten für Auftrag sammeln
- Direkte Materialien + Direkte Arbeit + Angewandte Gemeinkosten
- Auftragskostenblatt dokumentiert alle Kosten
- Rentabilität nach Auftrag berechnen

### Abschnitt 20.6 : Unterangewandte/überangewandte Gemeinkosten
- Unterangewandt : Tatsächlich > Angewandt
- Überangewandt : Angewandt > Tatsächlich
- Verrechnung durch Abschluss auf HKS oder Zuteilung auf UEF, FE und HKS
- Satz anpassen, wenn konsistent abweichend

### Abschnitt 20.7 : Buchungssätze
- Materialien kaufen
- Materialien für Aufträge ausgeben
- Direkte Arbeit erfassen
- Tatsächliche Gemeinkosten verursachen
- Gemeinkosten anwenden
- Aufträge abschließen
- Aufträge verkaufen
- Unterangewandte/überangewandte Gemeinkosten abschließen

### Abschnitt 20.8 : Nichtproduktionsanwendungen
- Dienstleistungsunternehmen verwenden Auftragskostenrechnung
- Bauunternehmen verwenden Auftragskostenrechnung
- Professionelle Dienstleistungen verwenden Auftragskostenrechnung
- Ähnliche Prinzipien, an Branche angepasst

### Abschnitt 20.9 : Luxemburgische Dienstleistungsunternehmen-Auftragskostenrechnung
- Dienstleistungsunternehmen verfolgen Kosten nach Kunde/Projekt
- Direkte Arbeit oft Hauptkosten
- Gemeinkostenzuteilung erforderlich
- Mehrsprachige und grenzüberschreitende Überlegungen
- Angemessene PCN-Konten verwenden

### Abschnitt 20.10 : Luxemburgische Handwerks-/Kunsthandwerksbetriebe-Kostenrechnung
- Jedes Produkt ist einzigartig
- Direkte Materialien und Arbeit bedeutsam
- Gemeinkosten umfassen Werkstattkosten
- Auftragskostenrechnung für Preisgestaltung unerlässlich
- Kosten genau verfolgen
