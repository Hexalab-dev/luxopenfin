# Schlüsselbegriffe

- **Prozesskostenrechnung** : Kostenrechnungssystem für identische Produkte, die in großen Mengen produziert werden
- **Äquivalenzmengen** : Anzahl vollständiger Einheiten, die hätten produziert werden können, gegeben die geleistete Arbeit
- **Umwandlungskosten** : Direkte Arbeit + Fertigungsgemeinkosten
- **Prozesskostenbericht** : Bericht, der Kosten und Äquivalenzmengen für einen Prozess zusammenfasst
- **Übertragene Kosten** : Kosten aus vorherigen Verarbeitungsstufen, die an die aktuelle Stufe übertragen werden
- **Gewichtete-Durchschnitts-Methode** : Methode, die UEF-Anfang mit aktuellen Kosten kombiniert
- **FIFO-Methode** : Methode, die UEF-Anfang von aktuellen Kosten trennt
- **Physischer Fluss** : Tatsächliche Bewegung von Einheiten durch die Produktion
- **Kosten pro Äquivalenzmenge** : Gesamtkosten dividiert durch Äquivalenzmengen
- **Ausbeute** : Verhältnis von Ausgabe zu Eingabe in einem Prozess
- **Prozess** : Eine Stufe oder Abteilung in der Produktion
- **Abteilung** : Organisatorische Einheit, in der Produktion stattfindet
