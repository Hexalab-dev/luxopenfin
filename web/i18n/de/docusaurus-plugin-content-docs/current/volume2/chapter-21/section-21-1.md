# 21.1 Auftragskostenrechnung und Prozesskostenrechnung vergleichen und gegenüberstellen

### Wann jedes System verwenden

Die Wahl zwischen Auftragskostenrechnung und Prozesskostenrechnung hängt von der Art der Produkte und dem Produktionsprozess ab.

### Auftragskostenrechnung - Zusammenfassung

**Verwendet, wenn :**
- Produkte einzigartig oder maßgeschneidert sind
- Jeder Auftrag unterschiedlich ist
- Kleine Chargen oder einzelne Bestellungen
- Kosten nach Auftrag verfolgt werden

**Beispiele :**
- Maßgeschneiderte Möbel
- Bauprojekte
- Beratungsdienstleistungen
- Catering-Veranstaltungen
- Maßgeschneiderte Produktion

### Prozesskostenrechnung

**Verwendet, wenn :**
- Produkte identisch oder sehr ähnlich sind
- Große Mengen produziert werden
- Kontinuierlicher oder wiederholender Prozess
- Kosten nach Prozess/Abteilung verfolgt werden
- Durchschnittskosten pro Einheit berechnet werden

**Beispiele :**
- Brotbacken (identische Brote)
- Softdrink-Abfüllung
- Lebensmittelverarbeitung
- Chemische Produktion
- Ölraffination
- Papierproduktion

### Wichtige Unterschiede

| Aspekt | Auftragskostenrechnung | Prozesskostenrechnung |
|--------|------------------|----------------|
| **Produkttyp** | Einzigartig, maßgeschneidert | Identisch, homogen |
| **Produktion** | Kleine Chargen, Aufträge | Große Mengen, kontinuierlich |
| **Kostenakkumulation** | Nach Auftrag | Nach Prozess/Abteilung |
| **Kostenberechnung** | Gesamte Auftragskosten ÷ Einheiten im Auftrag | Gesamte Prozesskosten ÷ produzierte Einheiten |
| **Unfertige Erzeugnisse** | Mehrere Aufträge, jeder separat verfolgt | Kontinuierlicher Fluss, Einheiten in Bearbeitung |
| **Kostenaufzeichnungen** | Auftragskostenblatt pro Auftrag | Prozesskostenbericht pro Prozess |
| **Stückkosten** | Pro Auftrag berechnet | Durchschnittskosten pro Einheit |
| **Wann verwendet** | Maßgeschneiderte Arbeit, Dienstleistungen | Massenproduktion |

### Produktionsfluss-Vergleich

**Auftragskostenrechnung-Fluss :**
```
Auftrag #101 → Auftrag #102 → Auftrag #103
(Jeder separat verfolgt)
```

**Prozesskostenrechnung-Fluss :**
```
Prozess A → Prozess B → Prozess C
(Kontinuierlicher Fluss, Kosten nach Prozess)
```

### Hybride Systeme

Einige Unternehmen verwenden beide Systeme :
- Verschiedene Abteilungen verwenden verschiedene Systeme
- Einige Produkte verwenden Auftragskostenrechnung, andere Prozesskostenrechnung
- Kombinationsansatz für komplexe Operationen

**Beispiel :**
Ein Möbelunternehmen :
- Maßgeschneiderte Möbel : Auftragskostenrechnung
- Standard-Möbellinie : Prozesskostenrechnung

### Luxemburgische Unternehmensbeispiele

**Prozesskostenrechnung :**
- **Lebensmittelverarbeitung** : Massenproduktion von Lebensmittelprodukten
- **Getränkeproduktion** : Abfülloperationen
- **Bäckerei (Standardprodukte)** : Identische Brote
- **Chemische Produktion** : Homogene Produkte
- **Textilproduktion** : Kontinuierliche Produktion

**Auftragskostenrechnung :**
- **Maßgeschneiderte Produktion** : Einzigartige Produkte
- **Bauwesen** : Jedes Projekt unterschiedlich
- **Dienstleistungsunternehmen** : Jeder Kunde einzigartig
- **Handwerksbetriebe** : Jeder Artikel einzigartig

### Das richtige System wählen

**Prozesskostenrechnung verwenden, wenn :**
- Produkte identisch sind
- Massenproduktion
- Kontinuierlicher Prozess
- Kann nicht leicht einzelne Einheiten identifizieren
- Durchschnittskosten sind ausreichend

**Auftragskostenrechnung verwenden, wenn :**
- Produkte einzigartig sind
- Maßgeschneiderte Bestellungen
- Kleine Chargen
- Kann einzelne Aufträge identifizieren
- Benötigt Kosten pro Auftrag

### Luxemburgische Compliance-Hinweis

In Luxemburg :
- Beide Systeme sind für interne Verwaltung akzeptabel
- System wählen, das zu Ihrem Unternehmen passt
- PCN-Konten unterstützen beide Systeme
- Kostenaufzeichnungen müssen geführt werden
- System sollte genaue Kosteninformationen liefern
