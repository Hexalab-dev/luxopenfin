# 21.2 Umwandlungskosten erklären und identifizieren

### Produktkosten in der Prozesskostenrechnung

In der Prozesskostenrechnung werden Produktkosten oft getrennt in :
1. **Direkte Materialien**
2. **Umwandlungskosten** (Direkte Arbeit + Fertigungsgemeinkosten)

**Umwandlungskosten** sind die Kosten der Umwandlung von Rohstoffen in Fertigprodukte. Sie umfassen direkte Arbeit und Fertigungsgemeinkosten.

**Formel :**
**Umwandlungskosten = Direkte Arbeit + Fertigungsgemeinkosten**

**Warum "Umwandlung" genannt :**
- Diese Kosten "wandeln" Materialien in Fertigprodukte um
- Sie repräsentieren den Verarbeitungs-/Fertigungsaufwand
- Materialien werden durch Arbeit und Gemeinkosten "umgewandelt"

### Direkte Arbeit

**Direkte Arbeit** ist der Kosten der Mitarbeiter, die direkt an der Umwandlung von Materialien in Fertigprodukte arbeiten.

**Beispiele :**
- Maschinenbediener
- Fließbandarbeiter
- Produktionsarbeiter
- Qualitätskontrolleure (wenn direkt)

### Fertigungsgemeinkosten

**Fertigungsgemeinkosten** umfassen alle Fertigungskosten außer direkten Materialien und direkter Arbeit.

**Beispiele :**
- Indirekte Arbeit (Vorgesetzte, Wartung)
- Fabrikmiete
- Fabriknebenkosten
- Geräteabschreibung
- Fabrikversicherung
- Indirekte Materialien

### Warum Umwandlungskosten trennen ?

**Gründe :**
1. **Timing** : Materialien können zu verschiedenen Zeitpunkten hinzugefügt werden als die Umwandlung
2. **Vollendung** : Materialien und Umwandlung können auf verschiedenen Vollendungsniveaus sein
3. **Kostenkontrolle** : Separate Verfolgung hilft, Probleme zu identifizieren
4. **Analyse** : Verstehen des Verhaltens von Material- vs. Umwandlungskosten

### Beispiel : Brotproduktion

**Direkte Materialien :**
- Mehl : €0,50 pro Brot
- Hefe : €0,05 pro Brot
- Wasser : €0,02 pro Brot
- Andere Zutaten : €0,08 pro Brot
- **Gesamt Materialien : €0,65 pro Brot**

**Umwandlungskosten :**
- Direkte Arbeit : €0,20 pro Brot
- Fertigungsgemeinkosten : €0,15 pro Brot
- **Gesamt Umwandlung : €0,35 pro Brot**

**Gesamtkosten pro Brot :**
- Materialien : €0,65
- Umwandlung : €0,35
- **Gesamt : €1,00 pro Brot**

### Umwandlungskosten pro Einheit

**Formel :**
**Umwandlungskosten pro Einheit = Gesamte Umwandlungskosten ÷ Äquivalenzmengen**

**Äquivalenzmengen** berücksichtigen teilweise abgeschlossene Einheiten (wird im nächsten Abschnitt diskutiert).

### Luxemburgische Compliance-Hinweis

In Luxemburg :
- Umwandlungskosten müssen ordnungsgemäß klassifiziert werden
- Direkte Arbeit umfasst soziale Abgaben
- Gemeinkosten umfassen alle indirekten Fertigungskosten
- PCN-Konten unterstützen die Kostenklassifizierung
- Kostenaufzeichnungen sollten Materialien und Umwandlung trennen
