# 22.2 Aktivitätsbasierte Produktkosten berechnen

### ABC-Kostenrechnungsprozess

Um aktivitätsbasierte Produktkosten zu berechnen, folgen Sie diesen Schritten :

### Schritt 1 : Aktivitäten identifizieren und Kostenpools erstellen

**Hauptaktivitäten identifizieren :**
- Rüstaktivitäten
- Verarbeitungsaktivitäten
- Inspektionsaktivitäten
- Bestellaktivitäten
- Verpackungsaktivitäten
- Andere Aktivitäten

**Kostenpools erstellen :**
- Verwandte Kosten in Aktivitätskostenpools gruppieren
- Jeder Pool repräsentiert eine Aktivität

### Schritt 2 : Kosten Aktivitäten zuordnen

**Kosten verfolgen oder zuordnen :**
- Direkte Kosten : Direkt zu Aktivitäten verfolgen
- Indirekte Kosten : Basierend auf Nutzung Aktivitäten zuordnen

**Beispiel :**
- Rüstaktivität : €5 000 (Rüstarbeit, Rüstmaterialien)
- Verarbeitungsaktivität : €15 000 (Verarbeitungsarbeit, Ausrüstung)
- Inspektionsaktivität : €3 000 (Inspektionsarbeit, Ausrüstung)
- Bestellaktivität : €2 000 (Einkaufspersonal, Systeme)
- **Gesamte Gemeinkosten : €25 000**

### Schritt 3 : Kostentreiber identifizieren

**Kostentreiber** : Faktor, der die Kosten einer Aktivität verursacht oder antreibt.

**Beispiele :**
- Rüstaktivität : Anzahl der Rüstungen
- Verarbeitungsaktivität : Maschinenstunden oder direkte Arbeitsstunden
- Inspektionsaktivität : Anzahl der Inspektionen
- Bestellaktivität : Anzahl der Bestellungen

### Schritt 4 : Aktivitätssätze berechnen

**Formel :**
**Aktivitätssatz = Gesamte Aktivitätskosten ÷ Gesamtes Kostentreibervolumen**

**Beispiel :**
- Rüstaktivitätskosten : €5 000
- Anzahl der Rüstungen : 100
- Rüstsatz : €5 000 ÷ 100 = €50 pro Rüstung

- Verarbeitungsaktivitätskosten : €15 000
- Maschinenstunden : 3 000
- Verarbeitungssatz : €15 000 ÷ 3 000 = €5 pro Maschinenstunde

- Inspektionsaktivitätskosten : €3 000
- Anzahl der Inspektionen : 200
- Inspektionssatz : €3 000 ÷ 200 = €15 pro Inspektion

- Bestellaktivitätskosten : €2 000
- Anzahl der Bestellungen : 50
- Bestellsatz : €2 000 ÷ 50 = €40 pro Bestellung

### Schritt 5 : Kosten Produkten zuordnen

**Für jedes Produkt :**
- Aktivitätsverbrauch bestimmen
- Aktivitätssatz mit Verbrauch multiplizieren
- Alle Aktivitätskosten summieren
- Direkte Materialien und direkte Arbeit hinzufügen

**Beispiel : Produkt A**

**Direkte Kosten :**
- Direkte Materialien : €100
- Direkte Arbeit : €80
- **Gesamt direkt : €180**

**Aktivitätskosten :**
- Rüstungen : 2 Rüstungen × €50 = €100
- Verarbeitung : 10 Maschinenstunden × €5 = €50
- Inspektionen : 1 Inspektion × €15 = €15
- Bestellungen : 1 Bestellung × €40 = €40
- **Gesamte Aktivitätskosten : €205**

**Gesamte Produktkosten :**
- Direkte Kosten : €180
- Aktivitätskosten : €205
- **Gesamt : €385**

### Vollständiges Beispiel : Restaurant-Menüpunkte

**Maries Restaurant - ABC-Analyse :**

**Gemeinkostenaktivitäten und -kosten :**
- Menüplanung : €2 000 (Kostentreiber : Anzahl der Menüpunkte)
- Vorbereitung der Essenszubereitung : €3 000 (Kostentreiber : Anzahl der Rüstungen)
- Kochen : €8 000 (Kostentreiber : Kochstunden)
- Anrichten/Präsentation : €2 000 (Kostentreiber : Anzahl der Teller)
- Aufräumen : €1 500 (Kostentreiber : Aufräumstunden)
- **Gesamte Gemeinkosten : €16 500**

**Kostentreibervolumina :**
- Menüpunkte : 20 Punkte
- Rüstungen : 300 Rüstungen pro Monat
- Kochstunden : 400 Stunden
- Servierte Teller : 2 000 Teller
- Aufräumstunden : 150 Stunden

**Aktivitätssätze :**
- Menüplanung : €2 000 ÷ 20 = €100 pro Menüpunkt
- Rüstung : €3 000 ÷ 300 = €10 pro Rüstung
- Kochen : €8 000 ÷ 400 = €20 pro Kochstunde
- Anrichten : €2 000 ÷ 2 000 = €1 pro Teller
- Aufräumen : €1 500 ÷ 150 = €10 pro Aufräumstunde

**Menüpunkt : Signature-Gericht**

**Direkte Kosten :**
- Zutaten : €8
- Direkte Arbeit : €5
- **Gesamt direkt : €13**

**Aktivitätsverbrauch :**
- Menüplanung : 1 Punkt (über alle Punkte geteilt, aber zugeordnet)
- Rüstung : 2 Rüstungen pro Tag × 30 Tage = 60 Rüstungen
- Kochen : 0,2 Stunden pro Gericht
- Anrichten : 1 Teller pro Gericht
- Aufräumen : 0,1 Stunden pro Gericht

**Aktivitätskosten (pro Gericht) :**
- Menüplanung : €100 ÷ (durchschnittliche Gerichte pro Punkt) = €0,10 (vereinfacht)
- Rüstung : (60 Rüstungen ÷ servierte Gerichte) = €0,30 (vereinfachte Berechnung)
- Kochen : 0,2 Stunden × €20 = €4,00
- Anrichten : 1 × €1 = €1,00
- Aufräumen : 0,1 × €10 = €1,00
- **Gesamte Aktivitätskosten : €6,40**

**Gesamtkosten pro Gericht :**
- Direkt : €13,00
- Aktivität : €6,40
- **Gesamt : €19,40**

**Verkaufspreis : €25**
**Gewinn : €25 - €19,40 = €5,60 (Marge von 22,4 %)**

### Luxemburg Konformitätshinweis

In Luxemburg :
- ABC liefert genauere Kosten
- Für internes Management verwenden
- Implementierungskosten berücksichtigen
- Kann Preisentscheidungen verbessern
- PCN-Konten unterstützen ABC
- Kann Rentabilitätsanalyse verbessern
