# Schlüsselbegriffe

- **Aktivitätsbasierte Kostenrechnung (ABC)** : Kostenrechnungsmethode, die Gemeinkosten basierend auf Aktivitäten zuordnet
- **Aktivität** : Aufgabe oder Aktion, die Ressourcen verbraucht
- **Kostenpool** : Gruppierung von Kosten nach Aktivität
- **Kostentreiber** : Faktor, der Aktivitätskosten verursacht oder antreibt
- **Aktivitätssatz** : Kosten pro Einheit des Kostentreibers
- **Traditionelle Kostenrechnung** : Kostenrechnung mit einzelnem Gemeinkostensatz
- **Überkalkulation** : Zu viele Kosten einem Produkt zuordnen
- **Unterkalkulation** : Zu wenige Kosten einem Produkt zuordnen
- **Volumenverzerrung** : Tendenz, Produkte mit hohem Volumen zu überkalkulieren
- **Ressourcenverbrauch** : Menge der von einem Produkt verwendeten Ressourcen
- **Aktivitätsverbrauch** : Menge der von einem Produkt verwendeten Aktivitäten
