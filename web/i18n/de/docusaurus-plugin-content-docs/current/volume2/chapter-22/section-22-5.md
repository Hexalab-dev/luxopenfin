# 22.5 Kostenpools und Kostentreiber erklären und identifizieren

### Kostenpools

Ein **Kostenpool** ist eine Gruppierung einzelner Kosten, typischerweise nach Abteilung oder Aktivität. Bei ABC sind Kostenpools nach Aktivität organisiert.

**Zweck :**
- Verwandte Kosten zusammen gruppieren
- Kostenzuordnung vereinfachen
- Gemeinkosten organisieren

**Beispiele für Kostenpools :**
- Rüstkostenpool
- Inspektionskostenpool
- Bestellkostenpool
- Verarbeitungskostenpool
- Verpackungskostenpool

### Kostenpools erstellen

**Prozess :**
1. Aktivitäten identifizieren
2. Verwandte Kosten gruppieren
3. Kostenpool für jede Aktivität erstellen
4. Kosten in jedem Pool summieren

**Beispiel :**
- Rüstaktivität : Rüstarbeit €3 000 + Rüstmaterialien €500 + Rüstausrüstung €1 500 = Kostenpool von €5 000
- Verarbeitungsaktivität : Verarbeitungsarbeit €10 000 + Ausrüstungsabschreibung €3 000 + Versorgungsleistungen €2 000 = Kostenpool von €15 000

### Kostentreiber

Ein **Kostentreiber** ist ein Faktor, der die Kosten einer Aktivität verursacht oder antreibt. Es ist das Maß für den Aktivitätsverbrauch.

**Merkmale :**
- Verursacht die Aktivitätskosten
- Messbar
- Mit Aktivitätskosten korreliert
- Praktisch zu verfolgen

**Arten von Kostentreibern :**
- **Volumenbasiert** : Anzahl der Einheiten, Stunden usw.
- **Transaktionsbasiert** : Anzahl der Rüstungen, Bestellungen, Inspektionen
- **Dauerbasiert** : Zeit, die für Aktivität aufgewendet wird
- **Intensitätsbasiert** : Komplexität, Schwierigkeit

### Kostentreiber identifizieren

**Prozess :**
1. Verstehen, was die Aktivität verursacht
2. Identifizieren, was die Aktivitätskosten antreibt
3. Messbaren Treiber wählen
4. Korrelation überprüfen

**Beispiel : Rüstaktivität**
- Was verursacht Rüstung ? Muss von einem Produkt zu einem anderen wechseln
- Was treibt Kosten an ? Anzahl der Rüstungen (jede Rüstung braucht Zeit und Ressourcen)
- Kostentreiber : Anzahl der Rüstungen

### Häufige Kostentreiber

**Rüstaktivitäten :**
- Anzahl der Rüstungen
- Rüststunden
- Anzahl der Umstellungen

**Verarbeitungsaktivitäten :**
- Maschinenstunden
- Direkte Arbeitsstunden
- Anzahl der verarbeiteten Einheiten

**Inspektionsaktivitäten :**
- Anzahl der Inspektionen
- Inspektionsstunden
- Anzahl der inspizierten Chargen

**Bestellaktivitäten :**
- Anzahl der Bestellungen
- Anzahl der Lieferanten
- Anzahl der aufgegebenen Bestellungen

**Verpackungsaktivitäten :**
- Anzahl der Verpackungen
- Verpackungsstunden
- Anzahl der verpackten Einheiten

### Kostentreiber auswählen

**Kriterien :**
- **Kausale Beziehung** : Treiber sollte die Kosten verursachen
- **Messbarkeit** : Leicht zu messen
- **Kosteneffizienz** : Kosten zum Verfolgen sollten vernünftig sein
- **Genauigkeit** : Sollte genaue Zuordnung liefern

**Beispiel :**
Für Rüstaktivität :
- Guter Treiber : Anzahl der Rüstungen (verursacht Kosten, messbar)
- Schlechter Treiber : Anzahl der Einheiten (verursacht keine Rüstkosten)

### Kostentreibersätze

**Formel :**
**Kostentreibersatz = Gesamte Aktivitätskosten ÷ Gesamtes Kostentreibervolumen**

**Beispiel :**
- Rüstkostenpool : €5 000
- Anzahl der Rüstungen : 100
- Rüstsatz : €5 000 ÷ 100 = €50 pro Rüstung

### Mehrere Kostentreiber

Einige Aktivitäten können mehrere Kostentreiber haben, wenn Kosten durch verschiedene Faktoren angetrieben werden.

**Beispiel :**
Inspektionsaktivität :
- Grundinspektion : €2 000, angetrieben durch Anzahl der Inspektionen
- Komplexe Inspektion : €1 000, angetrieben durch Inspektionsstunden
- Gesamt : €3 000

**Zwei Sätze :**
- Grund : €2 000 ÷ 200 = €10 pro Inspektion
- Komplex : €1 000 ÷ 50 = €20 pro Inspektionsstunde

### Luxemburg Konformitätshinweis

In Luxemburg :
- Kostenpools sollten logisch und vernünftig sein
- Kostentreiber sollten tatsächlichen Verbrauch widerspiegeln
- Sollten messbar und verfolgbar sein
- Kosten zum Verfolgen vs. Nutzen berücksichtigen
- PCN-Konten verwenden, um Kostenpools zu unterstützen
- Angemessene Kostenaufzeichnungen führen
