# 22.6 Luxemburgische KMU-Anwendungen der aktivitätsbasierten Kostenrechnung

### Luxemburgische KMU-Merkmale

Luxemburgische KMU, die von ABC profitieren können :
- Dienstleistungsunternehmen mit vielfältigen Dienstleistungen
- Fertigung mit mehreren Produkten
- Unternehmen mit erheblichen Gemeinkosten
- Unternehmen mit komplexen Operationen
- Unternehmen, die genaue Kosteninformationen benötigen

### Beispiel 1 : Luxemburgisches Dienstleistungsunternehmen

**Beratungsunternehmen - ABC-Implementierung :**

**Aktivitäten :**
- Kundenakquise : €10 000 (Kostentreiber : Anzahl neuer Kunden)
- Projektkonfiguration : €8 000 (Kostentreiber : Anzahl der Projekte)
- Forschung : €12 000 (Kostentreiber : Forschungsstunden)
- Kundengespräche : €6 000 (Kostentreiber : Besprechungsstunden)
- Berichtsvorbereitung : €4 000 (Kostentreiber : Anzahl der Berichte)
- **Gesamte Gemeinkosten : €40 000**

**Kostentreibervolumina :**
- Neue Kunden : 20
- Projekte : 40
- Forschungsstunden : 400
- Besprechungsstunden : 200
- Berichte : 80

**Aktivitätssätze :**
- Kundenakquise : €10 000 ÷ 20 = €500 pro Kunde
- Projektkonfiguration : €8 000 ÷ 40 = €200 pro Projekt
- Forschung : €12 000 ÷ 400 = €30 pro Stunde
- Kundengespräche : €6 000 ÷ 200 = €30 pro Stunde
- Berichtsvorbereitung : €4 000 ÷ 80 = €50 pro Bericht

**Kundenprojektanalyse :**

**Projekt A (Einfach) :**
- Direkte Arbeit : 20 Stunden × €100 = €2 000
- Aktivitätskosten :
  - Kundenakquise : €500 (wenn neuer Kunde)
  - Projektkonfiguration : €200
  - Forschung : 5 Stunden × €30 = €150
  - Besprechungen : 2 Stunden × €30 = €60
  - Berichte : 1 × €50 = €50
  - **Gesamt Aktivität : €960**
- **Gesamtkosten : €2 960**

**Projekt B (Komplex) :**
- Direkte Arbeit : 60 Stunden × €100 = €6 000
- Aktivitätskosten :
  - Kundenakquise : €0 (bestehender Kunde)
  - Projektkonfiguration : €200
  - Forschung : 30 Stunden × €30 = €900
  - Besprechungen : 10 Stunden × €30 = €300
  - Berichte : 3 × €50 = €150
  - **Gesamt Aktivität : €1 550**
- **Gesamtkosten : €7 550**

**Erkenntnisse :**
- Komplexe Projekte verbrauchen mehr Aktivitäten
- ABC zeigt echte Kostendifferenz
- Unterstützt bessere Preisgestaltung

### Beispiel 2 : Luxemburgisches Fertigungs-KMU

**Kleiner Hersteller - ABC-Implementierung :**

**Aktivitäten :**
- Materialhandhabung : €6 000 (Kostentreiber : Anzahl der Materialbewegungen)
- Maschinenrüstung : €8 000 (Kostentreiber : Anzahl der Rüstungen)
- Qualitätsinspektion : €4 000 (Kostentreiber : Anzahl der Inspektionen)
- Produktion : €12 000 (Kostentreiber : Maschinenstunden)
- **Gesamte Gemeinkosten : €30 000**

**Kostentreibervolumina :**
- Materialbewegungen : 300
- Rüstungen : 200
- Inspektionen : 400
- Maschinenstunden : 2 000

**Aktivitätssätze :**
- Materialhandhabung : €6 000 ÷ 300 = €20 pro Bewegung
- Maschinenrüstung : €8 000 ÷ 200 = €40 pro Rüstung
- Qualitätsinspektion : €4 000 ÷ 400 = €10 pro Inspektion
- Produktion : €12 000 ÷ 2 000 = €6 pro Maschinenstunde

**Produktkostenrechnung :**

**Produkt X (Hohes Volumen, Einfach) :**
- Direkte Materialien : €50
- Direkte Arbeit : €30
- Aktivitätskosten :
  - Materialbewegungen : 1 × €20 = €20
  - Rüstungen : 0,1 × €40 = €4 (über viele Einheiten geteilt)
  - Inspektionen : 0,1 × €10 = €1
  - Produktion : 2 Stunden × €6 = €12
  - **Gesamt Aktivität : €37**
- **Gesamtkosten : €117**

**Produkt Y (Niedriges Volumen, Komplex) :**
- Direkte Materialien : €80
- Direkte Arbeit : €50
- Aktivitätskosten :
  - Materialbewegungen : 3 × €20 = €60
  - Rüstungen : 1 × €40 = €40
  - Inspektionen : 2 × €10 = €20
  - Produktion : 5 Stunden × €6 = €30
  - **Gesamt Aktivität : €150**
- **Gesamtkosten : €280**

### Beispiel 3 : Luxemburgisches Restaurant (Detailliertes ABC)

**Maries Restaurant - Vollständige ABC-Analyse :**

**Gemeinkostenaktivitäten :**
1. **Menüentwicklung** : €3 000 (Kostentreiber : Anzahl der Menüpunkte)
2. **Zutatenbestellung** : €2 500 (Kostentreiber : Anzahl der Bestellungen)
3. **Vorbereitung der Essenszubereitung** : €4 000 (Kostentreiber : Anzahl der Vorbereitungssitzungen)
4. **Kochen** : €10 000 (Kostentreiber : Kochstunden)
5. **Anrichten** : €2 000 (Kostentreiber : Anzahl der Teller)
6. **Service** : €3 000 (Kostentreiber : Servicestunden)
7. **Aufräumen** : €2 500 (Kostentreiber : Aufräumstunden)
8. **Verwaltung** : €2 000 (Kostentreiber : Anzahl der Transaktionen)
- **Gesamte Gemeinkosten : €29 000**

**Kostentreibervolumina :**
- Menüpunkte : 25
- Bestellungen : 50
- Vorbereitungssitzungen : 400
- Kochstunden : 500
- Teller : 3 000
- Servicestunden : 600
- Aufräumstunden : 200
- Transaktionen : 1 000

**Aktivitätssätze :**
- Menüentwicklung : €3 000 ÷ 25 = €120 pro Punkt
- Bestellung : €2 500 ÷ 50 = €50 pro Bestellung
- Vorbereitung : €4 000 ÷ 400 = €10 pro Sitzung
- Kochen : €10 000 ÷ 500 = €20 pro Stunde
- Anrichten : €2 000 ÷ 3 000 = €0,67 pro Teller
- Service : €3 000 ÷ 600 = €5 pro Stunde
- Aufräumen : €2 500 ÷ 200 = €12,50 pro Stunde
- Verwaltung : €2 000 ÷ 1 000 = €2 pro Transaktion

**Menüpunkt : Komplexes Signature-Gericht**

**Direkte Kosten :**
- Zutaten : €10
- Direkte Arbeit (Koch) : €8
- **Gesamt direkt : €18**

**Aktivitätsverbrauch (pro Gericht) :**
- Menüentwicklung : €120 ÷ (Gerichte pro Punkt) = €0,20
- Bestellung : (Bestellungen für diesen Punkt) ÷ Gerichte = €0,15
- Vorbereitung : 0,1 Sitzungen × €10 = €1,00
- Kochen : 0,3 Stunden × €20 = €6,00
- Anrichten : 1 × €0,67 = €0,67
- Service : 0,05 Stunden × €5 = €0,25
- Aufräumen : 0,1 Stunden × €12,50 = €1,25
- Verwaltung : 1 × €2 = €2,00
- **Gesamt Aktivität : €11,52**

**Gesamtkosten :**
- Direkt : €18,00
- Aktivität : €11,52
- **Gesamt : €29,52**

**Verkaufspreis : €35**
**Gewinn : €5,48 (Marge von 15,7 %)**

**Menüpunkt : Einfache Beilage**

**Direkte Kosten :**
- Zutaten : €3
- Direkte Arbeit : €2
- **Gesamt direkt : €5**

**Aktivitätsverbrauch (pro Gericht) :**
- Menüentwicklung : €0,20
- Bestellung : €0,10
- Vorbereitung : 0,02 × €10 = €0,20
- Kochen : 0,05 Stunden × €20 = €1,00
- Anrichten : 1 × €0,67 = €0,67
- Service : 0,02 Stunden × €5 = €0,10
- Aufräumen : 0,02 Stunden × €12,50 = €0,25
- Verwaltung : 1 × €2 = €2,00
- **Gesamt Aktivität : €4,52**

**Gesamtkosten :**
- Direkt : €5,00
- Aktivität : €4,52
- **Gesamt : €9,52**

**Verkaufspreis : €12**
**Gewinn : €2,48 (Marge von 20,7 %)**

**Analyse :**
- Einfaches Gericht hat höhere Marge (20,7 % vs. 15,7 %)
- Komplexes Gericht verbraucht mehr Aktivitäten
- ABC zeigt wahre Rentabilität
- Kann bessere Menüentscheidungen treffen

### ABC-Implementierung in luxemburgischen KMU

**Schritte :**
1. **Aktivitäten identifizieren** : Alle Hauptaktivitäten auflisten
2. **Kosten zuordnen** : Kosten jeder Aktivität bestimmen
3. **Treiber identifizieren** : Finden, was jede Aktivität antreibt
4. **Sätze berechnen** : Aktivitätssätze berechnen
5. **Auf Produkte anwenden** : Kosten Produkten/Dienstleistungen zuordnen
6. **Ergebnisse analysieren** : Mit traditioneller Kostenrechnung vergleichen
7. **Entscheidungen treffen** : Informationen für Entscheidungen verwenden

**Herausforderungen :**
- Aktivitäten identifizieren
- Kostentreiber verfolgen
- System warten
- Implementierungskosten
- Personal schulen

**Vorteile :**
- Genauere Kosten
- Bessere Entscheidungen
- Verbesserte Rentabilität
- Bessere Preisgestaltung
- Kostenmanagement

### Vereinfachtes ABC für kleine Unternehmen

**Für sehr kleine Unternehmen :**
- Nur auf Hauptaktivitäten konzentrieren
- Einfache Kostentreiber verwenden
- Nicht überkomplizieren
- Genauigkeit mit Kosten ausbalancieren

**Beispiel :**
- 3-5 Hauptaktivitäten
- Einfache Treiber (Stunden, Zählungen)
- Monatliche oder vierteljährliche Updates
- Auf hochwirksame Bereiche konzentrieren

### Luxemburg Konformitätshinweis

Für luxemburgische KMU :
- ABC ist optional, aber wertvoll
- Für internes Management verwenden
- Kosten vs. Nutzen berücksichtigen
- Einfach beginnen, bei Bedarf erweitern
- PCN-Konten unterstützen Implementierung
- Kann Rentabilität erheblich verbessern
