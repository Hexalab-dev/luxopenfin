# 27.5 MwSt auf Käufe: Vorsteuerrückforderung

### Vorsteuer verstehen

**Vorsteuer** (TVA récupérable) ist die MwSt, die Sie auf Ihre Geschäftskäufe **zahlen**. Wenn Sie MwSt-registriert sind und der Kauf für geschäftliche Zwecke ist, können Sie diese MwSt typischerweise **zurückfordern** (zurückfordern).

### Wann können Sie Vorsteuer zurückfordern?

Sie können Vorsteuer zurückfordern, wenn:

1. **MwSt-registriert**: Sie sind für MwSt registriert
2. **Gültige Rechnung**: Sie haben eine gültige MwSt-Rechnung vom Lieferanten
3. **Geschäftszweck**: Kauf ist für geschäftliche Nutzung (nicht privat)
4. **Steuerpflichtige Aktivität**: Kauf bezieht sich auf Ihre steuerpflichtigen Geschäftsaktivitäten
5. **Nicht ausgeschlossen**: Kauf ist nicht spezifisch von Rückforderung ausgeschlossen

### Vorsteuer erfassen

#### Kauf auf Kredit

**Transaktion**: €117 Inventar auf Kredit kaufen (€100 + €17 MwSt)

**PCN-Buchhaltung:**
- **Soll**: Konto 6061 (Wareneinkäufe) - €100,00
- **Soll**: Konto 421611 (Vorsteuer zurückforderbar) - €17,00
- **Haben**: Konto 44111 (Lieferanten) - €117,00

#### Kauf mit Barzahlung

**Transaktion**: €234 Ausrüstung kaufen, per Bank bezahlt (€200 + €34 MwSt)

**PCN-Buchhaltung:**
- **Soll**: Konto 222 (Technische Anlagen und Maschinen) - €200,00
- **Soll**: Konto 421611 (Vorsteuer zurückforderbar) - €34,00
- **Haben**: Konto 5131 (Bankkonto) - €234,00

### Vorsteuerrückforderungsprozess

#### Schritt 1: Zurückforderbare MwSt identifizieren

- Alle Kaufrechnungen überprüfen
- MwSt-Beträge identifizieren
- Rechnungen als gültig verifizieren (MwSt-Nummer enthalten, korrekter Satz)

#### Schritt 2: Im Buchhaltungssystem erfassen

- Rechnungen in Buchhaltungssystem eingeben
- Angemessenen Aufwandskonten zuordnen
- Vorsteuer in Konto 421611 erfassen

#### Schritt 3: In MwSt-Erklärung aufnehmen

- Alle Vorsteuer für Periode summieren
- In MwSt-Erklärungsberechnung aufnehmen
- Gegen Ausgangssteuer verrechnen

#### Schritt 4: Rückerstattung erhalten (falls zutreffend)

- Wenn Vorsteuer Ausgangssteuer übersteigt, Rückerstattung erhalten
- Rückerstattung von Steuerbehörden bearbeitet
- Normalerweise innerhalb von 4-6 Wochen erhalten

### Nicht zurückforderbare Vorsteuer

Sie **können keine** Vorsteuer zurückfordern auf:

1. **Private Ausgaben**: Käufe für private Nutzung
2. **Unterhaltung**: Geschäftsunterhaltung (mit Ausnahmen)
3. **Fahrzeuge**: Autos (mit Ausnahmen für gewerbliche Fahrzeuge)
4. **Befreite Lieferungen**: Käufe im Zusammenhang mit MwSt-befreiten Aktivitäten
5. **Blockierte Artikel**: Artikel, die spezifisch von Rückforderung blockiert sind

### Teilweise Rückforderung

Für Käufe, die **teilweise für geschäftliche und teilweise für private Nutzung** verwendet werden, können Sie MwSt nur auf den geschäftlichen Anteil zurückfordern:

**Beispiel:**
- Mobiltelefon: €234 (€200 + €34 MwSt)
- Geschäftliche Nutzung: 70%
- Private Nutzung: 30%
- **Zurückforderbare MwSt**: €34 × 70% = €23,80

### Vorsteuer auf Kapitalkäufe

Vorsteuer auf **Kapitalkäufe** (Ausrüstung, Fahrzeuge, Gebäude) ist zurückforderbar:

**Beispiel:**
- Ausrüstungskauf: €5.850 (€5.000 + €850 MwSt)
- **Zurückforderbare MwSt**: €850 (voller Betrag, wenn für geschäftliche Nutzung)

**Hinweis:** Große Kapitalkäufe können erhebliche Vorsteuer schaffen, was zu MwSt-Rückerstattungen führen kann.

### Vorsteuer auf Dienstleistungen

Vorsteuer auf **Dienstleistungen** (Buchhaltung, Recht, Beratung) ist zurückforderbar:

**Beispiel:**
- Buchhaltungsdienstleistungen: €1.170 (€1.000 + €170 MwSt)
- **Zurückforderbare MwSt**: €170

### Luxemburg-Compliance-Hinweis

**Wichtige Anforderungen:**
- **Alle Rechnungen aufbewahren** mit separat angezeigter MwSt
- **MwSt-Nummern verifizieren** auf Lieferantenrechnungen
- **Vorsteuer erfassen** in Konto 421611 (PCN)
- **In MwSt-Erklärung aufnehmen** innerhalb von Fristen
- **Frist**: Generell 3 Jahre, um Vorsteuer geltend zu machen

**Häufige Probleme:**
- Fehlende Rechnungen: Kann MwSt ohne gültige Rechnung nicht zurückfordern
- Ungültige MwSt-Nummern: Kann Betrug oder Fehler anzeigen
- Private Ausgaben: Kann MwSt auf private Käufe nicht zurückfordern
- Verspätete Ansprüche: Kann Recht auf Rückforderung verlieren, wenn zu spät

### Nachdenken

Marie kauft €1.170 Küchenausrüstung (€1.000 + €170 MwSt) und €234 private Artikel (€200 + €34 MwSt) auf derselben Rechnung. Wie sollte sie dies erfassen? Kann sie die gesamte MwSt zurückfordern?

### Konzepte in der Praxis

**Vorsteuerrückforderungsbeispiel**

Monatliche Käufe von *Le Petit Bistro*:

**Geschäftskäufe:**
- Lebensmittelinventar: €2.060 (€2.000 + €60 MwSt bei 3%)
- Ausrüstungswartung: €585 (€500 + €85 MwSt bei 17%)
- Versorgungsleistungen: €234 (€200 + €34 MwSt bei 17%)
- **Vorsteuer gesamt**: €179

**Verkäufe (Ausgangssteuer):**
- Lebensmittelverkäufe: €5.150 (€5.000 + €150 MwSt bei 3%)
- Weinverkäufe (serviert): €2.340 (€2.000 + €340 MwSt bei 17%)
- **Ausgangssteuer**: €490

**Netto-MwSt zu zahlen:**
- Ausgangssteuer: €490
- Vorsteuer: €179
- **Netto-MwSt zu zahlen**: €311

Marie kann €179 Vorsteuer zurückfordern, was ihre MwSt-Verbindlichkeit von €490 auf €311 reduziert.
