# 29.4 Sozialabgabenberechnung (Mitarbeiter- und Arbeitgeberanteile)

### Sozialabgabenberechnung verstehen

Sozialabgaben werden als Prozentsatz des **Bruttolohns** (bis zur Beitragsdeckelung) berechnet. Sowohl Mitarbeiter als auch Arbeitgeber zahlen Beiträge mit unterschiedlichen Sätzen für verschiedene Komponenten. Genaue Berechnung ist für Compliance und Kostenmanagement unerlässlich.

### Berechnungsbasis

#### Sozialabgabenpflichtiger Bruttolohn

**Basis für Berechnung:**
- Bruttolohn (wie in Abschnitt 29.3 berechnet)
- Gedeckelt bei 5 × sozialem Mindestlohn: €13.518,70 pro Monat (ab 1. Januar 2026)
- Die Pflegeversicherung ist **nicht** gedeckelt
- Umfasst alle steuerpflichtigen Komponenten
- Schließt befreite Zulagen aus (z.B. Essensgutscheine bis zur Grenze)

**Beispiel:**
- Bruttolohn: €15.000/Monat
- Beitragsbasis: €13.518,70 (gedeckelt) für alle Beiträge außer der Pflegeversicherung

### Mitarbeitersozialabgaben

#### Mitarbeiterbeitragssätze

*CCSS-Sätze zum 1. Januar 2026; jedes Jahr auf ccss.lu prüfen.*

**Gesamter Mitarbeitersatz: 12,95 %**

**Aufschlüsselung:**
- Krankenversicherung: 2,80 % (Sachleistungen) + 0,25 % (Geldleistungen)
- Rentenversicherung: 8,50 %
- Pflegeversicherung: 1,40 %
- **Gesamt**: 12,95 %

Die Pflegeversicherung wird gesetzlich auf den Bruttolohn abzüglich 1/4 des sozialen Mindestlohns berechnet (€2.703,74 / 4 = €675,94). **Die Beispiele in diesem Abschnitt vereinfachen, indem 1,40 % auf den gesamten Bruttolohn angewendet werden.**

#### Mitarbeiterberechnungsbeispiel

**Mitarbeiter mit €3.500 Bruttolohn:**

**Schritt 1: Beitragsbasis bestimmen**
- Bruttolohn: €3.500
- Unter Deckelung (€13.518,70)
- Beitragsbasis: €3.500

**Schritt 2: Mitarbeiterbeiträge berechnen**
- Krankenversicherung (2,80 % + 0,25 %): €3.500 × 3,05 % = €106,75
- Rentenversicherung (8,50 %): €3.500 × 8,50 % = €297,50
- Pflegeversicherung (1,40 %, vereinfacht): €3.500 × 1,40 % = €49,00
- **Gesamt Mitarbeiter**: €453,25

**Schritt 3: Nettolohn berechnen**
- Bruttolohn: €3.500,00
- Mitarbeitersozialabgaben: €453,25
- **Nettolohn (vor Lohnsteuerabzug)**: €3.046,75

### Arbeitgebersozialabgaben

#### Arbeitgeberbeitragssätze

**Gesamter Arbeitgebersatz: 12,57 % – 15,00 %** (je nach Mutualité-Klasse)

**Aufschlüsselung:**
- Krankenversicherung: 2,80 % + 0,25 %
- Rentenversicherung: 8,50 %
- Unfallversicherung: 0,65 % (× Bonus-Malus-Faktor 0,85–1,50)
- Arbeitsmedizin (STM): 0,14 %
- Mutualité des employeurs: 0,23 % / 0,95 % / 1,56 % / 2,66 % (Klassen 1–4)
- **Gesamt**: 12,57 % (Klasse 1) – 15,00 % (Klasse 4)

#### Arbeitgeberberechnungsbeispiel

**Arbeitgeber mit Mitarbeiter, der €3.500 Bruttolohn verdient (Mutualité-Klasse 1, Bonus-Malus-Faktor 1,00):**

**Schritt 1: Beitragsbasis bestimmen**
- Bruttolohn: €3.500
- Beitragsbasis: €3.500

**Schritt 2: Arbeitgeberbeiträge berechnen**
- Krankenversicherung (2,80 % + 0,25 %): €3.500 × 3,05 % = €106,75
- Rentenversicherung (8,50 %): €3.500 × 8,50 % = €297,50
- Unfallversicherung (0,65 %): €3.500 × 0,65 % = €22,75
- Arbeitsmedizin (0,14 %): €3.500 × 0,14 % = €4,90
- Mutualité Klasse 1 (0,23 %): €3.500 × 0,23 % = €8,05
- **Gesamt Arbeitgeber**: €439,95

### Gesamte Arbeitskosten

#### Vollständige Kostenberechnung

**Gesamte Arbeitskosten = Bruttolohn + Arbeitgebersozialabgaben**

**Beispiel:**
- Bruttolohn: €3.500,00
- Arbeitgebersozialabgaben: €439,95
- **Gesamte Arbeitskosten**: €3.939,95

**Kostenaufschlüsselung:**
- Mitarbeiter erhält: €3.046,75 (netto, vor Lohnsteuer)
- Mitarbeiter zahlt: €453,25 (Sozialabgaben)
- Arbeitgeber zahlt: €439,95 (Sozialabgaben)
- **Gesamt**: €3.939,95

### Gehalt über Beitragsdeckelung

#### Berechnung für hohe Gehälter

**Mitarbeiter mit €15.000 Bruttolohn:**

**Schritt 1: Beitragsbasis bestimmen**
- Bruttolohn: €15.000
- Beitragsdeckelung: €13.518,70
- Beitragsbasis: €13.518,70 (gedeckelt); Basis Pflegeversicherung: volles Gehalt (keine Deckelung)

**Schritt 2: Sozialabgaben berechnen**
- Mitarbeiter Kranken- + Rentenversicherung (11,55 % von €13.518,70): €1.561,41
- Mitarbeiter Pflegeversicherung (1,40 % von €15.000, vereinfacht): €210,00
- **Gesamt Mitarbeiter**: €1.771,41
- Arbeitgeber (12,57 % von €13.518,70): €1.699,30

**Schritt 3: Nettolohn berechnen**
- Bruttolohn: €15.000,00
- Mitarbeitersozialabgaben: €1.771,41
- **Nettolohn (vor Lohnsteuerabzug)**: €13.228,59

**Hinweis**: Gehalt über €13.518,70 unterliegt nicht den gedeckelten Beiträgen, aber weiterhin der Pflegeversicherung und der Einkommensteuer.

### Monatliche vs. jährliche Berechnungen

#### Monatliche Berechnung

**Standardansatz:**
- Sozialabgaben monatlich berechnen
- Basierend auf monatlichem Bruttolohn
- Monatlich berichten und zahlen

#### Jährliche Abstimmung

**Jahresendprozess:**
- Jährliche Gesamtsummen überprüfen
- Mit Jahresgehalt abstimmen
- Bei Bedarf anpassen
- Jährliche Erklärungen einreichen

### Luxemburg-Compliance-Hinweis

**Wichtige Anforderungen:**
- **Genaue Berechnung**: Richtige Sätze und Basen verwenden
- **Monatliche Berichterstattung**: Monatlich berichten und zahlen
- **Pünktliche Zahlung**: Vor Fristen zahlen, um Strafen zu vermeiden
- **Aufzeichnungen**: Berechnungsaufzeichnungen aufbewahren
- **Softwareüberprüfung**: Softwareberechnungen überprüfen

**Häufige Probleme:**
- **Satzfehler**: Falsche Beitragssätze verwenden
- **Basis-Fehler**: Falsche Komponenten einbeziehen/ausschließen
- **Deckelungsfehler**: Beitragsdeckelung nicht korrekt anwenden
- **Timing-Fehler**: In falscher Periode berechnen

### Nachdenken

*Artisan Boulangerie* hat einen Mitarbeiter mit €5.000 Bruttolohn pro Monat. Das Unternehmen ist in Mutualité-Klasse 2 (0,95 %) und hat einen Bonus-Malus-Faktor der Unfallversicherung von 1,20 (0,65 % × 1,20 = 0,78 %). Berechnen Sie das Mitarbeiternettogehalt, die Arbeitgebersozialabgaben und die gesamten Arbeitskosten.

### Konzepte in der Praxis

**Vollständige Lohnabrechnungsberechnung**

Mitarbeiterlohnabrechnung *TechLux Solutions*:

**Mitarbeiterdetails:**
- Bruttolohn: €4.500/Monat
- Unfallversicherungssatz: 0,65 % (Bonus-Malus-Faktor 1,00); Mutualité-Klasse 1 (0,23 %)

**Mitarbeitersozialabgaben (12,95 %):**
- Krankenversicherung (2,80 % + 0,25 %): €126,00 + €11,25 = €137,25
- Rentenversicherung (8,50 %): €382,50
- Pflegeversicherung (1,40 %, vereinfacht auf das gesamte Brutto): €63,00
- **Gesamt Mitarbeiter**: €582,75

**Arbeitgebersozialabgaben (12,57 %):**
- Krankenversicherung (2,80 % + 0,25 %): €137,25
- Rentenversicherung (8,50 %): €382,50
- Unfallversicherung (0,65 %): €29,25
- Arbeitsmedizin (0,14 %): €6,30
- Mutualité Klasse 1 (0,23 %): €10,35
- **Gesamt Arbeitgeber**: €565,65

**Ergebnisse:**
- Nettolohn (vor Lohnsteuerabzug): €4.500 - €582,75 = €3.917,25
- Gesamte Arbeitskosten: €4.500 + €565,65 = €5.065,65
- Sozialabgaben als % des Bruttolohns: 25,52 %
