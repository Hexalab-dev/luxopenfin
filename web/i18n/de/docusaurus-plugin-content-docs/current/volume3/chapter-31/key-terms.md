# Schlüsselbegriffe

- **E-Rechnung (Electronic Invoice)** : Rechnung, die in elektronischem Format ausgestellt, übertragen und empfangen wird
- **UBL (Universal Business Language)** : XML-basierter Standard für Geschäftsdokumente einschließlich Rechnungen
- **Peppol (Pan-European Public Procurement On-Line)** : Europäisches Netzwerk für E-Rechnungsstellung mit BIS-Format
- **Fiskalische Kassensystem** : Manipulationssicheres Kassensystem erforderlich für Einzelhandel und Gastronomie
- **FAIA (Fichier d'Audit Informatisé AED)** : Luxemburgs standardisiertes Format für Steuerprüfungsdaten
- **OECD SAF-T (Standard Audit File for Tax)** : Internationaler Standard für Steuerprüfungsdateien
- **CSV (Comma-Separated Values)** : Einfaches Textformat zum Speichern tabellarischer Daten
- **Excel** : Microsoft Excel-Dateiformat für strukturierte Daten
- **Digitale Signatur** : Elektronische Signatur, die Authentizität und Integrität sicherstellt
- **Authentizität** : Rechnung stammt vom angegebenen Lieferanten und wurde nicht verändert
- **Integrität** : Rechnungsinhalt ist vollständig und wurde nicht modifiziert
- **Zertifizierte Ausrüstung** : Fiskalische Kassensysteme zertifiziert von luxemburgischen Behörden
- **Datenexport** : Prozess des Exportierens von Daten aus Buchhaltungssoftware
- **Datenimport** : Prozess des Importierens von Daten in Buchhaltungssoftware
- **Feldmapping** : Prozess des Mappens von Quellfeldern zu Zielfeldern während Import
- **Integration** : Verbindung zwischen verschiedenen Softwaresystemen
- **Compliance-Best-Practices** : Empfohlene Praktiken zur Sicherstellung kontinuierlicher Compliance
