# 31.3 Digitale Rechnungsformate (UBL, Peppol)

## Überblick

**Digitale Rechnungsformate** bieten standardisierte Strukturen für elektronische Rechnungen. Luxemburg unterstützt mehrere Formate, wobei **UBL (Universal Business Language)** und **Peppol** die wichtigsten europäischen Standards sind. Das Verstehen dieser Formate ist für die E-Rechnungsstellung wesentlich.

## UBL (Universal Business Language)

### Was ist UBL?

**UBL** ist ein XML-basierter Standard für Geschäftsdokumente, einschließlich Rechnungen. Er bietet eine standardisierte Struktur, die Interoperabilität zwischen verschiedenen Systemen und Ländern sicherstellt.

### UBL-Struktur

**UBL-Rechnung enthält:**
- **Kopfzeileninformationen**: Rechnungsnummer, Datum, Parteien
- **Artikelzeilen**: Produkt-/Dienstleistungsdetails, Mengen, Preise
- **Steuerinformationen**: Umsatzsteuerberechnungen, Steuersummen
- **Zahlungsinformationen**: Zahlungsbedingungen, Methoden
- **Zusätzliche Informationen**: Notizen, Referenzen

### UBL-Vorteile

**Vorteile:**
- **Standardisierung**: Konsistente Struktur zwischen Systemen
- **Interoperabilität**: Funktioniert mit verschiedenen Software
- **Compliance**: Erfüllt EU E-Rechnungsanforderungen
- **Automatisierung**: Ermöglicht automatisierte Verarbeitung
- **International**: Wird in ganz Europa verwendet

## Peppol

### Was ist Peppol?

**Peppol (Pan-European Public Procurement On-Line)** ist ein europäisches Netzwerk für E-Rechnungsstellung, ursprünglich für öffentliche Beschaffung entwickelt, aber jetzt für B2B- und B2G-Rechnungsstellung verwendet.

### Peppol-Netzwerk

**Peppol bietet:**
- **Netzwerkinfrastruktur**: Sicherer Netzwerk für E-Rechnungsaustausch
- **Standardformat**: Peppol BIS (Business Interoperability Specifications)
- **Zugangspunkte**: Dienstleister für Netzwerkzugang
- **Validierung**: Automatische Rechnungsvalidierung
- **Lieferung**: Sichere Lieferbestätigung

### Peppol-Vorteile

**Vorteile:**
- **Netzwerkbasiert**: Sichere, zuverlässige Lieferung
- **Standardisiert**: Konsistentes Format in ganz Europa
- **Validiert**: Automatische Validierung
- **Verfolgt**: Lieferbestätigung
- **Europäisch**: Weit verbreitet in Europa

## Formatvergleich

### UBL vs. Peppol

| Aspekt | UBL | Peppol |
|--------|-----|--------|
| **Typ** | Formatstandard | Netzwerk + Format |
| **Struktur** | XML-basiert | XML-basiert (Peppol BIS) |
| **Lieferung** | Verschiedene Methoden | Netzwerkbasiert |
| **Validierung** | Manuell/Software | Automatisch |
| **Umfang** | Nur Format | Format + Netzwerk |
| **Anwendungsfall** | Allgemeine E-Rechnungsstellung | B2B/B2G E-Rechnungsstellung |

### Formatauswahl

**Überlegungen:**
- **Empfängeranforderungen**: Welches Format akzeptiert Empfänger?
- **Software-Support**: Welche Formate unterstützt Ihre Software?
- **Netzwerkzugang**: Benötigen Sie Peppol-Netzwerkzugang?
- **Automatisierungsbedarf**: Wie viel Automatisierung benötigen Sie?
- **Kosten**: Was sind die Kosten für jede Option?

## Umsetzung

### UBL-Umsetzung

**Schritte:**
1. UBL-konforme Software wählen
2. Rechnungsvorlagen konfigurieren
3. UBL XML-Rechnungen generieren
4. UBL-Format validieren
5. An Empfänger übertragen

### Peppol-Umsetzung

**Schritte:**
1. Peppol-Zugangspunktanbieter wählen
2. Bei Peppol-Netzwerk registrieren
3. Peppol BIS-Format konfigurieren
4. Peppol-Rechnungen generieren
5. Über Peppol-Netzwerk senden

## Software-Support

### Buchhaltungssoftware

**Die meisten Buchhaltungssoftware unterstützen:**
- **UBL-Export**: Rechnungen im UBL-Format exportieren
- **Peppol-Integration**: Mit Peppol-Netzwerk verbinden
- **Formatkonvertierung**: Zwischen Formaten konvertieren
- **Validierung**: Rechnungsformate validieren

### Beliebte Software

**Software mit E-Rechnungs-Support:**
- **Sage BOB**: UBL- und Peppol-Support
- **Odoo**: E-Rechnungsmodule
- **SAP**: Unternehmens-E-Rechnungsstellung
- **Andere Software**: Auf E-Rechnungsfähigkeiten prüfen

## Luxemburg Compliance-Hinweis

**Wichtige Anforderungen:**
- **Format-Compliance**: E-Rechnungen müssen in unterstütztem Format sein
- **Empfängerannahme**: Empfänger muss gewähltes Format akzeptieren
- **Software-Support**: Software muss gewähltes Format unterstützen
- **Validierung**: Rechnungen müssen vor Versand validiert werden
- **Speicherung**: E-Rechnungen müssen in zugänglichem Format gespeichert werden

**Häufige Probleme:**
- **Formatehler**: Rechnungen nicht im korrekten Format
- **Software-Limitierungen**: Software unterstützt gewähltes Format nicht
- **Empfänger-Kompatibilität**: Empfänger akzeptiert Format nicht
- **Validierungsfehler**: Rechnungen bestehen Validierung nicht
- **Netzwerkprobleme**: Peppol-Netzwerkzugangsprobleme
