# Schlüsselbegriffe

- **Kassensystem (POS)** : System zur Erfassung von Verkaufstransaktionen am Verkaufspunkt
- **Cetrel** : Luxemburgisches Zahlungssystem für Kartenzahlungen
- **Trinkgeld** : Gratifikation an Servicepersonal (Bargeld-Trinkgelder vs. Karten-Trinkgelder/Servicegebühren)
- **FIFO (First-In-First-Out)** : Inventarbewertungsmethode, die annimmt, dass ältestes Inventar zuerst verkauft wird
- **Gewichteter Durchschnitt** : Inventarbewertungsmethode mit Durchschnittskosten
- **Kundenrückgaben** : Von Kunden zurückgegebene Produkte, reduzierend Verkäufe
- **Kundenrabatte** : Preisreduzierungen für beschädigte Waren oder Rabatte
- **Zeitbasierte Abrechnung** : Abrechnungsmethode basierend auf geleisteten Stunden
- **Projektbuchhaltung** : Buchhaltungssystem, das Kosten und Umsatz nach Projekt verfolgt
- **Umsatzerkennung** : Prozess der Erfassung von Umsatz, wenn verdient
- **Vorauszahlungen (Nicht verdienter Umsatz)** : Vor Dienstleistungserbringung erhaltene Zahlungen
- **Retainer** : Vorausbezahlte Servicevereinbarung, erkannt, wenn Dienstleistungen erbracht
- **Zahlungsgateway** : Dienst, der Online-Zahlungen verarbeitet
- **Grenzüberschreitende Umsatzsteuer** : Umsatzsteuerregeln für Verkäufe über EU-Grenzen
- **Digitale Güter** : Elektronische Produkte (Software, E-Books, Musik, Videos)
- **One-Stop-Shop (OSS)** : EU-System für vereinfachte Umsatzsteuerberichterstattung
- **Direkte Materialien** : Direkt in Produktion verwendete Rohstoffe
- **Direkte Arbeit** : Direkt mit Produktion verbundene Arbeit
- **Auftragskostenrechnung** : Kostenrechnungsmethode, die Kosten nach Auftrag/Bestellung verfolgt
- **Sonderbestellung** : Einzigartige Produktbestellung für spezifischen Kunden
