# 16.7 Luxemburgische Anforderungen für Kapitalflussrechnungen

### Anforderungen

**Wer muss vorbereiten :**
- Größere Unternehmen (basierend auf Größenkriterien)
- Kann für RCS-Hinterlegung erforderlich sein
- Nützlich für alle Unternehmen

**Format :**
- Muss PCN-Format einhalten
- Muss alle Abschnitte einschließen
- Muss genau sein
- Muss Standards einhalten

### Luxemburgische Compliance-Hinweis

Anforderungen in Luxemburg :
- Größenbasierte Anforderungen
- Muss PCN-Format einhalten
- Muss beim RCS hinterlegt werden, falls erforderlich
- Muss Standards einhalten

### Nachdenken

Warum möchten kleinere Unternehmen möglicherweise immer noch eine Kapitalflussrechnung vorbereiten, auch wenn es nicht erforderlich ist ?
