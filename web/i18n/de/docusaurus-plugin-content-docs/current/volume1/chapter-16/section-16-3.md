# 16.3 Kapitalflussrechnung mit indirekter Methode vorbereiten

### Indirekte Methode

**Indirekte Methode :**
- Beginnt mit Nettoeinkommen
- Passt für nicht-bare Posten an
- Passt für Änderungen in Umlaufvermögen/Verbindlichkeiten an
- Zeigt Kasse aus Betriebstätigkeiten

### Betriebliche Tätigkeiten (Indirekte Methode)

**Format :**
```
Nettoeinkommen
+ Abschreibungsaufwand
+ Verlust aus Verkauf von Vermögenswerten
- Gewinn aus Verkauf von Vermögenswerten
+ Abnahme des Umlaufvermögens
- Zunahme des Umlaufvermögens
+ Zunahme der kurzfristigen Verbindlichkeiten
- Abnahme der kurzfristigen Verbindlichkeiten
= Kasse aus betrieblichen Tätigkeiten
```

### Beispiel

**Informationen :**
- Nettoeinkommen : €50,000
- Abschreibungen : €10,000
- Forderungen erhöht : €5,000
- Inventar erhöht : €3,000
- Verbindlichkeiten erhöht : €2,000
- Gehälterverbindlichkeiten verringert : €1,000

**Berechnung :**
```
Nettoeinkommen                          €50,000
+ Abschreibungen                       10,000
- Zunahme der Forderungen    (5,000)
- Zunahme des Inventars        (3,000)
+ Zunahme der Verbindlichkeiten        2,000
- Abnahme der Gehälterverbindlichkeiten     (1,000)
Kasse aus betrieblichen Tätigkeiten       €53,000
```

**Erklärung :**
- Nettoeinkommen : Ausgangspunkt
- Abschreibungen : Hinzugefügt (nicht-barer Aufwand)
- Zunahme der Forderungen : Subtrahiert (Kasse noch nicht erhalten)
- Zunahme des Inventars : Subtrahiert (Kasse verwendet, um Inventar zu kaufen)
- Zunahme der Verbindlichkeiten : Hinzugefügt (Kasse noch nicht gezahlt)
- Abnahme der Gehälterverbindlichkeiten : Subtrahiert (Kasse wurde gezahlt)

### Häufige Anpassungen

**Nicht-bare Posten (Hinzufügen) :**
- Abschreibungsaufwand
- Amortisationsaufwand
- Verlust aus Verkauf von Vermögenswerten
- Forderungsausfallaufwand (wenn Verwendungsmethode verwendet)

**Nicht-bare Posten (Subtrahieren) :**
- Gewinn aus Verkauf von Vermögenswerten

**Umlaufvermögensänderungen :**
- Zunahme : Subtrahieren (Kasse verwendet)
- Abnahme : Hinzufügen (Kasse freigegeben)

**Kurzfristige Verbindlichkeitsänderungen :**
- Zunahme : Hinzufügen (Kasse noch nicht gezahlt)
- Abnahme : Subtrahieren (Kasse wurde gezahlt)

### Vollständiges Beispiel : Betriebliche Tätigkeiten

**Gewinn- und Verlustrechnung :**
- Nettoeinkommen : €80,000
- Abschreibungen : €15,000
- Verlust aus Verkauf von Ausstattung : €2,000

**Bilanzänderungen :**
- Forderungen : +€8,000
- Inventar : -€3,000
- Vorauszahlungen : +€1,000
- Verbindlichkeiten : +€5,000
- Gehälterverbindlichkeiten : -€2,000
- MwSt-Verbindlichkeiten : +€1,000

**Berechnung :**
```
Nettoeinkommen                          €80,000
+ Abschreibungen                       15,000
+ Verlust aus Verkauf von Ausstattung           2,000
- Zunahme der Forderungen    (8,000)
+ Abnahme des Inventars               3,000
- Zunahme der Vorauszahlungen       (1,000)
+ Zunahme der Verbindlichkeiten        5,000
- Abnahme der Gehälterverbindlichkeiten       (2,000)
+ Zunahme der MwSt-Verbindlichkeiten             1,000
Kasse aus betrieblichen Tätigkeiten       €95,000
```

### Luxemburgische Compliance-Hinweis

Indirekte Methode in Luxemburg :
- Häufigste Methode
- Muss PCN-Format einhalten
- Muss alle Anpassungen zeigen
- Muss Standards einhalten
