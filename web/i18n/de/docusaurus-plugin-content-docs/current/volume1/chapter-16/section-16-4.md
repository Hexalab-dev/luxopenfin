# 16.4 Vollständige Kapitalflussrechnung mit indirekter Methode vorbereiten

### Vollständige Rechnung

**Format :**
```
Kapitalflussrechnung
[Firmenname]
[Zeitraum]

BETRIEBLICHE TÄTIGKEITEN
Nettoeinkommen                          €XX,XXX
Anpassungen :
  Abschreibungen                        X,XXX
  [Andere Anpassungen]                 X,XXX
Änderungen im Umlaufvermögen/Verbindlichkeiten :
  [Änderungen]                           X,XXX
Kasse aus betrieblichen Tätigkeiten       €XX,XXX

INVESTITIONSTÄTIGKEITEN
Kauf von Ausstattung               (€XX,XXX)
Verkauf von Ausstattung                      X,XXX
Kasse aus (verwendet in) Investition        (€XX,XXX)

FINANZIERUNGSTÄTIGKEITEN
Kreditaufnahme                              X,XXX
Darlehenstilgung                    (X,XXX)
Dividendenzahlung                 (X,XXX)
Kasse aus (verwendet in) Finanzierung         €XX,XXX

Nettoveränderung der Kasse                    €XX,XXX
Anfangskasse                         XX,XXX
Endkasse                           €XX,XXX
```

### Luxemburgisches PCN-Format

**PCN-Anforderungen :**
- Muss PCN-Struktur einhalten
- Muss ordentliche Klassifikationen verwenden
- Muss alle Aktivitäten zeigen
- Muss Standards einhalten

### Luxemburgische Compliance-Hinweis

Vollständige Rechnung in Luxemburg :
- Muss PCN-Format einhalten
- Muss alle Abschnitte einschließen
- Muss genau sein
- Muss hinterlegt werden, falls erforderlich
