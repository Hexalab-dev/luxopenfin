# Schlüsselbegriffe

- **Direkte Methode** : Zeigt tatsächliche Kassenempfänge und -zahlungen
- **Finanzierungstätigkeiten** : Kasse aus Kreditaufnahme, Eigenkapital, Dividenden
- **Indirekte Methode** : Beginnt mit Nettoeinkommen und passt an
- **Investitionstätigkeiten** : Kasse aus Kauf/Verkauf von Vermögenswerten
- **Betriebliche Tätigkeiten** : Kasse aus täglichen Betriebstätigkeiten
- **Kapitalflussrechnung** : Zeigt Kassenempfänge und -zahlungen
