# 16.6 Anhang : Vollständige Kapitalflussrechnung mit direkter Methode vorzubereiten

### Direkte Methode

**Direkte Methode :**
- Zeigt tatsächliche Kassenempfänge und -zahlungen
- Detaillierter
- Weniger häufig
- Zeigt Kasse von Kunden, Kasse an Lieferanten, etc.

**Format :**
```
Kasse von Kunden                  €XX,XXX
Kasse an Lieferanten                    (XX,XXX)
Kasse an Mitarbeiter                    (XX,XXX)
Kasse für Aufwendungen                    (XX,XXX)
Kasse aus betrieblichen Tätigkeiten       €XX,XXX
```

### Luxemburgische Compliance-Hinweis

Direkte Methode in Luxemburg :
- Weniger häufig
- Detaillierter
- Muss PCN-Format einhalten
- Muss Standards einhalten
