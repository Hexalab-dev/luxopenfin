# 16.5 Informationen aus der Kapitalflussrechnung verwenden, um Kennzahlen zur Bewertung von Liquidität und Solvenz vorzubereiten

### Cashflow-Kennzahlen

**Betriebliche Cashflow-Kennzahl :**
**Betriebliche Cashflow-Kennzahl = Kasse aus Betriebstätigkeiten ÷ Kurzfristige Verbindlichkeiten**

**Freier Cashflow :**
**Freier Cashflow = Kasse aus Betriebstätigkeiten - Kapitalausgaben**

**Cashflow zu Schulden :**
**Cashflow zu Schulden = Kasse aus Betriebstätigkeiten ÷ Gesamtschulden**

### Luxemburgische Überlegungen

**Kennzahlen helfen :**
- Liquidität bewerten
- Solvenz bewerten
- Performance vergleichen
- Entscheidungen treffen

### Luxemburgische Compliance-Hinweis

Cashflow-Kennzahlen in Luxemburg :
- Nützlich für Analyse
- Helfen bei Entscheidungen
- Mit Benchmarks vergleichen
- Wichtig für Stakeholder
