# Kapitel 16 – Übungen und Fälle

## Multiple-Choice-Fragen

1. Die Kapitalflussrechnung zeigt :  
   a) Nur Gewinn  
   b) Kassenempfänge und -zahlungen  
   c) Nur Vermögenswerte  
   d) Nur Verbindlichkeiten  
   **Antwort :** b) Kapitalflussrechnung zeigt Kassenempfänge und -zahlungen.

2. Betriebliche Tätigkeiten umfassen :  
   a) Kauf von Ausstattung  
   b) Kasse von Kunden  
   c) Aktienausgabe  
   d) Dividendenzahlung  
   **Antwort :** b) Betriebliche Tätigkeiten umfassen Kasse von Kunden.

3. Die indirekte Methode beginnt mit :  
   a) Kassenbestand  
   b) Nettoeinkommen  
   c) Erträge  
   d) Aufwendungen  
   **Antwort :** b) Indirekte Methode beginnt mit Nettoeinkommen.

---

## Fragen

1. Was ist der Zweck der Kapitalflussrechnung ?

2. Wie unterscheiden sich betriebliche, Investitions- und Finanzierungstätigkeiten ?

3. Wie wird die indirekte Methode verwendet, um Kasse aus Betriebstätigkeiten zu berechnen ?

4. Welche Informationen werden benötigt, um eine Kapitalflussrechnung vorzubereiten ?

5. Was sind die luxemburgischen Anforderungen für Kapitalflussrechnungen ?

## Umfassendes Problem

**Umfassendes Problem 16 : Vollständige Kapitalflussrechnung**

**Le Petit Bistro** muss eine Kapitalflussrechnung für 2024 vorbereiten.

**Gewinn- und Verlustrechnung (2024) :**
- Nettoeinkommen : €120,000
- Abschreibungsaufwand : €25,000
- Amortisationsaufwand : €3,000
- Verlust aus Verkauf von Ausstattung : €2,000
- Zinsaufwand : €5,000

**Bilanzänderungen (2023 bis 2024) :**

**Vermögenswerte :**
- Kasse : €30,000 → €68,000
- Forderungen : €40,000 → €50,000
- Inventar : €60,000 → €55,000
- Vorauszahlungen : €5,000 → €7,000
- Ausstattung : €200,000 → €230,000
- Kumulierte Abschreibungen : (€50,000) → (€65,000)
- Immaterielle Vermögenswerte (nach Amortisation) : €100,000 → €97,000

**Verbindlichkeiten :**
- Verbindlichkeiten : €25,000 → €30,000
- MwSt-Verbindlichkeiten : €8,000 → €10,000
- Gehälterverbindlichkeiten : €12,000 → €10,000
- Langfristiges Darlehen : €100,000 → €80,000

**Eigenkapital :**
- Grundkapital : €150,000 → €150,000
- Gewinnrücklagen : €90,000 → €162,000

**Zusätzliche Informationen :**
- Ausstattung gekauft : €50,000 Kasse
- Ausstattung verkauft : Kosten €20,000, Kumulierte Abschreibungen €10,000, Kasse erhalten €8,000
- Darlehenstilgung : €20,000 Hauptbetrag
- Dividenden gezahlt : €48,000
- Zinsen gezahlt : €5,000

**Erforderlich :**

1. Berechnen Sie Kasse aus betrieblichen Tätigkeiten mit der indirekten Methode.

2. Berechnen Sie Kasse aus Investitionstätigkeiten.

3. Berechnen Sie Kasse aus Finanzierungstätigkeiten.

4. Bereiten Sie vollständige Kapitalflussrechnung vor.

5. Stimmen Sie Anfangs- und Endkassenbestände ab.

6. Analysieren Sie Cashflow :
   a) Generiert das Unternehmen positiven Betriebscashflow ?
   b) Was sind die Hauptverwendungen der Kasse ?
   c) Wie finanziert das Unternehmen seine Aktivitäten ?
   d) Was sind die Cashflow-Auswirkungen ?

7. Erklären Sie luxemburgische Anforderungen :
   a) PCN-Formatanforderungen
   b) Wann Kapitalflussrechnung erforderlich ist
   c) RCS-Hinterlegungsanforderungen
   d) Offenlegungsanforderungen
