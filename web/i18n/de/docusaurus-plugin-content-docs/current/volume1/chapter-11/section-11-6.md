# 11.6 Luxemburgische Anlagevermögensbuchhaltung (PCN Klasse 2 - Immobilisations)

### PCN Klasse 2 : Immobilisations (Anlagevermögen)

**Klasse 2** im PCN enthält alle langfristigen Vermögenswerte.

**Kontobereiche :**
- 20–21 : Immaterielle Vermögenswerte (Immobilisations Incorporelles)
- 21 : Immaterielle Vermögenswerte (Fortsetzung)
- 22 : Materielle Vermögenswerte (Immobilisations Corporelles)
- 22 : Materielle Vermögenswerte (Fortsetzung)
- …9 sub-accounts : Kumulierte Abschreibungen (Amortissements)
- …9 sub-accounts : Kumulierte Abschreibungen (Amortissements Incorporels)
- 23 : Finanzielle Vermögenswerte (Immobilisations Financières)

### Immaterielle Vermögenswerte (21)

**Hauptkonten :**
- **211** : Forschung und Entwicklungskosten
- **212** : Konzessionen, Patente, Lizenzen
- **213** : Firmenwert
- **21** : Andere immaterielle Vermögenswerte

**Beispiel :**
```
212    Patente                     €50,000
```

### Materielle Vermögenswerte (22)

**Hauptkonten :**
- **2211** : Grund und Boden (Terrains)
- **2213** : Gebäude (Constructions)
- **2221** : Technische Anlagen
- **222** : Ausstattung und Maschinen (Matériel et Outillage)
- **2232** : Fahrzeuge (Matériel de Transport)
- **2234** : Mobiliar und Einrichtungen (Mobilier)
- **2235** : Computerausstattung (Matériel Informatique)
- **2238** : Andere materielle Vermögenswerte

**Beispiel : Restaurantausstattung :**
```
222    Ausstattung                   €25,000
```

**Beispiel : Fahrzeug :**
```
2232   Fahrzeuge                    €30,000
```

### Kumulierte Abschreibungen (…9 sub-accounts)

**Hauptkonten :**
- **22139** : Kumulierte Abschreibungen - Gebäude
- **2229** : Kumulierte Abschreibungen - Ausstattung
- **22329** : Kumulierte Abschreibungen - Fahrzeuge
- **22389** : Kumulierte Abschreibungen - Andere

**Beispiel :**
```
2229   Kumulierte Abschreibungen - Ausstattung €10,000
```

### Finanzielle Vermögenswerte (23)

**Hauptkonten :**
- **231** : Beteiligungen an Tochtergesellschaften
- **235** : Andere Finanzinvestitionen
- **236** : Gewährte Darlehen

### Luxemburgische Compliance-Hinweis

PCN Klasse 2 Anforderungen :
- Muss ordentliche Kontenklassifikationen verwenden
- Muss separate Konten für verschiedene Vermögenswerttypen führen
- Muss kumulierte Abschreibungen separat verfolgen
- Muss PCN-Struktur einhalten
- Muss Vermögenswerte unterstützen
- Muss ordentliche Jahresabschlussdarstellung ermöglichen
