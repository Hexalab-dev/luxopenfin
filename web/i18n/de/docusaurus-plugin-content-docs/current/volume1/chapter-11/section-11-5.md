# 11.5 Einige spezielle Probleme in der Buchhaltung für langfristige Vermögenswerte beschreiben

### Spezielle Probleme

Mehrere spezielle Situationen erfordern Aufmerksamkeit in der Buchhaltung für langfristige Vermögenswerte :

1. **Wertminderung**
2. **Veräußerung von Vermögenswerten**
3. **Tausch von Vermögenswerten**
4. **Reparaturen und Verbesserungen**

### Wertminderung

**Wertminderung** tritt auf, wenn der Buchwert eines Vermögenswerts seinen erzielbaren Betrag übersteigt.

**Wann testen :**
- Signifikanter Wertrückgang
- Nutzungsänderung
- Marktbedingungen ändern sich
- Jährlicher Test für Firmenwert

**Wertminderungsverlust :**
**Wertminderungsverlust = Buchwert - Erzielbarer Betrag**

**Buchung :**
```
63     Wertminderungsverlust             €[Betrag]
[Vermögenswertkonto] oder [Kumulierte Abschreibungen]    €[Betrag]
Zur Erfassung der Vermögenswertwertminderung
```

**Luxemburg :** Muss Wertminderungsregeln befolgen und testen, wenn Indikatoren vorhanden sind.

### Veräußerung von Vermögenswerten

**Wenn ein Vermögenswert verkauft oder entsorgt wird :**

**Schritte :**
1. Abschreibung bis zum Veräußerungsdatum erfassen
2. Vermögenswert und kumulierte Abschreibungen entfernen
3. Gewinn oder Verlust erfassen
4. Erhaltene Kasse erfassen (wenn verkauft)

**Beispiel : Verkauf von Ausstattung**
- Ursprüngliche Kosten : €10,000
- Kumulierte Abschreibungen : €7,000
- Buchwert : €3,000
- Verkaufspreis : €4,000
- Gewinn : €1,000

**Buchung :**
```
5131   Kasse                        €4,000
2229   Kumulierte Abschreibungen     €7,000
222    Ausstattung                                €10,000
744    Gewinn aus Verkauf von Ausstattung                 €1,000
Zur Erfassung des Verkaufs von Ausstattung
```

**Wenn Verkaufspreis €2,000 war (Verlust) :**
```
5131   Kasse                        €2,000
2229   Kumulierte Abschreibungen     €7,000
644    Verlust aus Verkauf von Ausstattung     €1,000
222    Ausstattung                                €10,000
Zur Erfassung des Verkaufs von Ausstattung mit Verlust
```

### Tausch von Vermögenswerten

**Vermögenswerttausch :**
- Alten Vermögenswert gegen neuen Vermögenswert eintauschen
- Kann Barzahlung beinhalten
- Muss Gewinn oder Verlust bestimmen

**Luxemburg :** Muss Tauschregeln befolgen und ordentlich buchen.

### Reparaturen und Verbesserungen

**Ordentliche Reparaturen :**
- Vermögenswert in funktionsfähigem Zustand halten
- Sofort als Aufwand
- Verlängern nicht Nutzungsdauer

**Verbesserungen (Besserungen) :**
- Verbessern Vermögenswert oder verlängern Nutzungsdauer
- Aktiviert
- Zu Vermögenswertkosten hinzugefügt

**Beispiel :**
- Laufende Wartung : €500 (Aufwand)
- Große Renovierung, die Nutzungsdauer verlängert : €10,000 (Aktivieren)

### Luxemburgische Compliance-Hinweis

Spezielle Probleme in Luxemburg :
- Muss Wertminderungsregeln befolgen
- Muss Veräußerungen ordentlich buchen
- Muss Reparaturen von Verbesserungen unterscheiden
- Muss Steuerregeln einhalten
- Muss ordentliche Dokumentation führen
