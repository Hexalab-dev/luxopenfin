# 11.4 Buchhaltung für immaterielle Vermögenswerte beschreiben und verwandte Transaktionen erfassen

### Immaterielle Vermögenswerte

**Immaterielle Vermögenswerte** sind nicht-physische Vermögenswerte, die zukünftige wirtschaftliche Vorteile bieten.

### Arten immaterieller Vermögenswerte

**Immaterielle Vermögenswerte mit begrenzter Nutzungsdauer :**
- Patente (rechtliche Dauer, normalerweise 20 Jahre)
- Urheberrechte (Leben des Autors + 70 Jahre, aber Geschäftsnutzung kürzer)
- Franchisen (Vertragslaufzeit)
- Softwarelizenzen (Lizenzlaufzeit)

**Immaterielle Vermögenswerte mit unbegrenzter Nutzungsdauer :**
- Firmenwert
- Marken (können unbegrenzt erneuert werden)

### Abschreibungen

**Abschreibungen** ist der Prozess der Zuordnung der Kosten eines immateriellen Vermögenswerts über seine Nutzungsdauer.

**Ähnlich wie Abschreibung :**
- Zuordnungsprozess
- Gleicht Kosten mit Perioden ab
- Reduziert Vermögenswertwert

**Unterschied :**
- Abschreibungen für immaterielle Vermögenswerte
- Abschreibung für materielle Vermögenswerte

### Immaterielle Vermögenswerte mit begrenzter Nutzungsdauer

**Abschreibungen :**
- Über Nutzungsdauer abschreiben
- Normalerweise linear
- Ähnlich wie Abschreibung

**Beispiel : Patent**
- Kosten : €50,000
- Nutzungsdauer : 10 Jahre
- Jährliche Abschreibungen : €50,000 ÷ 10 = €5,000

**Buchung :**
```
632    Abschreibungsaufwand        €5,000
2129   Kumulierte Abschreibungen                €5,000
Zur Erfassung der Patentabschreibungen
```

**PCN-Konten :**
- 632 : Abschreibungsaufwand (Klasse 6)
- 2129 : Kumulierte Abschreibungen (Klasse 2 - Gegenkonto)

### Immaterielle Vermögenswerte mit unbegrenzter Nutzungsdauer

**Keine Abschreibungen :**
- Werden nicht abgeschrieben
- Jährlich auf Wertminderung getestet
- Herabgeschrieben, wenn wertgemindert

**Beispiel : Firmenwert**
- Gekauft bei Unternehmensübernahme
- Nicht abgeschrieben
- Auf Wertminderung getestet

### Kauf immaterieller Vermögenswerte

**Beispiel : Patentkauf**
- Patentkauf : €50,000

**Buchung :**
```
212    Patente                     €50,000
5131   Kasse (oder 44111  Verbindlichkeiten)                €50,000
Zur Erfassung des Patentkaufs
```

**PCN-Konto :**
- 212 : Patente (Klasse 2 - Immaterielle Vermögenswerte)

### Intern entwickelte immaterielle Vermögenswerte

**Forschung und Entwicklung :**
- Forschungskosten : Normalerweise als Aufwand
- Entwicklungskosten : Können aktiviert werden, wenn Kriterien erfüllt

**Luxemburgische Regeln :**
- Generell werden F&E-Kosten als Aufwand erfasst
- Einige Entwicklungskosten können aktiviert werden
- Muss spezifische Kriterien befolgen

### Luxemburgische Compliance-Hinweis

Immaterielle Vermögenswerte in Luxemburg :
- Müssen ordentlich klassifiziert sein (PCN Klasse 2)
- Begrenzte Nutzungsdauer : Abschreiben
- Unbegrenzte Nutzungsdauer : Auf Wertminderung testen
- Müssen in Jahresabschlüssen offengelegt werden
- Müssen Rechnungslegungsstandards einhalten
- Müssen ordentliche Dokumentation führen
