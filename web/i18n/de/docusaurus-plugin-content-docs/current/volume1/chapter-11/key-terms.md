# Schlüsselbegriffe

- **Kumulierte Abschreibungen** : Gegenkonto, das die insgesamt vorgenommenen Abschreibungen zeigt
- **Abschreibungen** : Zuordnung der Kosten eines immateriellen Vermögenswerts über die Nutzungsdauer
- **Aktivieren** : Kosten als Vermögenswert statt als Aufwand erfassen
- **Abschreibung** : Zuordnung der Kosten eines materiellen Vermögenswerts über die Nutzungsdauer
- **Immaterielle Vermögenswerte** : Nicht-physische Vermögenswerte, die zukünftige Vorteile bieten
- **Restwert** : Geschätzter Wert des Vermögenswerts am Ende der Nutzungsdauer
- **Materielle Vermögenswerte** : Physische Vermögenswerte, die gesehen und berührt werden können
- **Nutzungsdauer** : Erwartete Periode, in der ein Vermögenswert verwendet wird
