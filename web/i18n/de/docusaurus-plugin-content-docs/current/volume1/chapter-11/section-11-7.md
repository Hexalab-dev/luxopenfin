# 11.7 Luxemburgische Abschreibungsregeln und steuerliche Auswirkungen

### Luxemburgische steuerliche Abschreibung

**Steuerliche Abschreibung :**
- Unterscheidet sich von buchhalterischer Abschreibung
- Muss Steuerregeln befolgen
- Beeinflusst zu versteuerndes Einkommen
- Verschiedene Sätze für verschiedene Vermögenswerttypen

### Häufige steuerliche Abschreibungssätze

**Gebäude :**
- Neue Gebäude : 2-4% pro Jahr
- Gebrauchte Gebäude : Variiert
- Lineare Methode

**Ausstattung :**
- Allgemeine Ausstattung : 10-20% pro Jahr
- Degressiv oder linear
- Beschleunigte Methoden erlaubt

**Fahrzeuge :**
- Autos : 20-25% pro Jahr
- LKWs : 15-20% pro Jahr
- Degressiv üblich

**Computerausstattung :**
- 33% pro Jahr (beschleunigt)
- Oft vollständig in 3 Jahren abgeschrieben

### Buchhalterische vs. steuerliche Abschreibung

**Unterschiede :**
- Buchhalterisch : Rechnungslegungsstandards befolgen
- Steuerlich : Steuerregeln befolgen
- Kann verschiedene Methoden verwenden
- Erzeugt temporäre Unterschiede

**Beispiel :**
- Ausstattung : €10,000
- Buchhalterisch : Linear, 5 Jahre = €2,000/Jahr
- Steuerlich : Degressiv, 20% = €2,000 Jahr 1, €1,600 Jahr 2, etc.

**Ergebnis :** Temporärer Unterschied im zu versteuernden Einkommen

### Luxemburgische Compliance-Hinweis

Abschreibung in Luxemburg :
- Muss Steuerregeln für Steuerzwecke befolgen
- Kann verschiedene Methode für Bücher verwenden
- Muss Aufzeichnungen für beide führen
- Muss Unterschiede abstimmen
- Beeinflusst Steuerberechnungen
- Muss ordentlich dokumentiert sein
