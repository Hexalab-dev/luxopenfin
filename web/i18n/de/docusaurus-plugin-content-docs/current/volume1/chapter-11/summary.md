# Kapitel-Zusammenfassung

### Abschnitt 11.1 : Materielle vs. immaterielle Vermögenswerte
- Materiell : Physische Vermögenswerte (Ausstattung, Gebäude)
- Immateriell : Nicht-physische Vermögenswerte (Patente, Firmenwert)
- Unterschiedliche buchhalterische Behandlung
- PCN Klasse 2 für beide

### Abschnitt 11.2 : Aktivierte Kosten vs. Aufwendungen
- Aktivieren : Langfristige Vorteile, erhebliche Kosten
- Als Aufwand : Sofortiger Vorteil, nicht erhebliche Kosten
- Alle direkten Kosten in Vermögenswertkosten einbeziehen
- MwSt ausschließen (wenn erstattungsfähig)

### Abschnitt 11.3 : Abschreibungsmethoden
- Linear : Konstanter Betrag jedes Jahr
- Degressiv : Beschleunigte Methode
- Leistungsmethode : Basierend auf Nutzung
- Muss konsistente Methode verwenden

### Abschnitt 11.4 : Immaterielle Vermögenswerte
- Begrenzte Nutzungsdauer : Abschreiben
- Unbegrenzte Nutzungsdauer : Auf Wertminderung testen
- Firmenwert : Nicht abgeschrieben
- Patente : Abgeschrieben

### Abschnitt 11.5 : Spezielle Probleme
- Wertminderung : Herabschreiben, wenn Wert sinkt
- Veräußerung : Vermögenswert entfernen, Gewinn/Verlust erfassen
- Reparaturen vs. Verbesserungen : Als Aufwand vs. aktivieren

### Abschnitt 11.6 : Luxemburgische PCN Klasse 2
- 21 : Immaterielle Vermögenswerte
- 22 : Materielle Vermögenswerte
- …9 sub-accounts : Kumulierte Abschreibungen
- Muss ordentliche Klassifikationen verwenden

### Abschnitt 11.7 : Luxemburgische Abschreibungsregeln
- Steuersätze unterscheiden sich nach Vermögenswerttyp
- Kann von buchhalterischer Abschreibung abweichen
- Muss Steuerregeln für Steuer befolgen
- Beeinflusst zu versteuerndes Einkommen

### Abschnitt 11.8 : Luxemburgische immaterielle Vermögenswerte
- Firmenwert : Nicht abgeschrieben
- Patente : Abgeschrieben
- Marken : Können unbegrenzt sein
- Muss Standards einhalten
