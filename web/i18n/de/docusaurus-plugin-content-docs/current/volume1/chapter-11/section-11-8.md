# 11.8 Luxemburgische immaterielle Vermögenswerte (Firmenwert, Patente, etc.)

### Immaterielle Vermögenswerte in Luxemburg

**Häufige immaterielle Vermögenswerte :**
- Firmenwert
- Patente
- Marken
- Software
- Lizenzen
- Franchisen

### Firmenwert

**Firmenwert :**
- Entsteht bei Unternehmensübernahmen
- Überschuss des Kaufpreises über den beizulegenden Zeitwert der Nettovermögenswerte
- Unbegrenzte Nutzungsdauer
- Nicht abgeschrieben
- Auf Wertminderung getestet

**PCN-Konto :**
- **213** : Firmenwert (Fonds de Commerce)

### Patente

**Patente :**
- Rechtlicher Schutz für Erfindungen
- Begrenzte Nutzungsdauer (normalerweise 20 Jahre)
- Über Nutzungsdauer abgeschrieben
- Kann gekauft oder intern entwickelt werden

**PCN-Konto :**
- **212** : Patente (Brevets)

### Marken

**Marken :**
- Markennamen, Logos
- Können unbegrenzte Nutzungsdauer haben
- Nicht abgeschrieben, wenn unbegrenzt
- Auf Wertminderung getestet

**PCN-Konto :**
- **21** : Andere immaterielle Vermögenswerte (oder spezifisches Unterkonto)

### Software

**Software :**
- Gekaufte Software : Aktivieren und abschreiben
- Intern entwickelt : Normalerweise als Aufwand, kann aktiviert werden, wenn Kriterien erfüllt
- Begrenzte Nutzungsdauer
- Über Nutzungsdauer abgeschrieben

**PCN-Konto :**
- **21** : Andere immaterielle Vermögenswerte (oder spezifisches Unterkonto)

### Luxemburgische Compliance-Hinweis

Immaterielle Vermögenswerte in Luxemburg :
- Müssen ordentlich klassifiziert sein (PCN Klasse 2)
- Begrenzte Nutzungsdauer : Abschreiben
- Unbegrenzte Nutzungsdauer : Auf Wertminderung testen
- Müssen offengelegt werden
- Müssen Rechnungslegungsstandards einhalten
- Müssen ordentliche Dokumentation führen
