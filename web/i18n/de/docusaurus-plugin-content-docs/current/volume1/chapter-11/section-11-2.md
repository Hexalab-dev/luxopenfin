# 11.2 Aktivierte Kosten im Vergleich zu Aufwendungen analysieren und klassifizieren

### Aktivierte Kosten vs. Aufwendungen

**Aktivierte Kosten :**
- Als Vermögenswerte erfasst
- Über Nutzungsdauer abgeschrieben
- Kosten mit Perioden abgleichen, die profitieren

**Aufwendungen :**
- Sofort erfasst
- Reduzieren Einkommen in aktueller Periode
- Kein zukünftiger Vorteil

### Wann aktivieren

**Aktivieren wenn :**
- Vermögenswert hat Nutzungsdauer über 1 Jahr
- Vermögenswert bietet zukünftige wirtschaftliche Vorteile
- Kosten sind erheblich
- Vermögenswert wird in Geschäftsbetrieben verwendet

**Als Aufwand wenn :**
- Vorteil wird sofort verbraucht
- Kosten sind nicht erheblich
- Wartung oder Reparatur (verlängert nicht Nutzungsdauer)
- Laufende Betriebsausgabe

### Beispiele : Aktivieren

**Ausstattungskauf :**
- Kaufpreis : €10,000
- Lieferung : €500
- Installation : €1,000
- **Gesamt aktiviert : €11,500**

**Buchung :**
```
222    Ausstattung                   €11,500
5131   Kasse (oder 44111  Verbindlichkeiten)                €11,500
Zur Erfassung des Ausstattungskaufs
```

**Gebäudeverbesserungen :**
- Renovierung, die Nutzungsdauer verlängert : €50,000
- **Aktivieren : €50,000**

### Beispiele : Als Aufwand

**Reparaturen :**
- Laufende Wartung : €500
- **Aufwand : €500**

**Buchung :**
```
6122   Reparaturen und Instandhaltung    €500
5131   Kasse                                    €500
Zur Erfassung der laufenden Wartung
```

**Kleine Käufe :**
- Büromaterial : €100
- **Aufwand : €100** (nicht erheblich, sofort verbraucht)

### Kostenkomponenten

**Was in Vermögenswertkosten einbeziehen :**

1. **Kaufpreis** : Rechnungsbetrag
2. **Lieferkosten** : Versand, Fracht
3. **Installationskosten** : Einrichtung, Montage
4. **Rechtskosten** : Titel, Registrierung
5. **Testkosten** : Erste Tests
6. **Andere direkte Kosten** : Notwendig, um Vermögenswert bereit zu machen

**Was NICHT einbeziehen :**

1. **Finanzierungskosten** : Zinsen (separat als Aufwand)
2. **Schulungskosten** : Mitarbeiterschulung (als Aufwand)
3. **Betriebskosten** : Laufende Wartung (als Aufwand)

### Luxemburgische Überlegungen

**MwSt-Behandlung :**
- MwSt auf Vermögenswertkäufe ist normalerweise erstattungsfähig
- Separately erfasst (MwSt erstattungsfähig)
- Nicht in Vermögenswertkosten einbezogen

**Beispiel :**
- Ausstattung : €10,000 (ohne MwSt)
- MwSt 17% : €1,700
- Gesamt : €11,700

**Buchung :**
```
222    Ausstattung                   €10,000
421611 MwSt erstattungsfähig              1,700
5131   Kasse (oder 44111  Verbindlichkeiten)                €11,700
Zur Erfassung des Ausstattungskaufs mit MwSt
```

### Luxemburgische Compliance-Hinweis

Für aktivierte Kosten in Luxemburg :
- Muss PCN Klasse 2 Anforderungen befolgen
- Muss alle direkten Kosten einbeziehen
- Muss MwSt ausschließen (wenn erstattungsfähig)
- Muss ordentlich dokumentiert sein
- Muss Steuerregeln einhalten
- Muss Vermögenswerte unterstützen

### Nachdenken

Ein Unternehmen kauft Ausstattung für €5,000 und gibt €500 für Lieferung und €1,000 für Installation aus. Sollten alle diese Kosten aktiviert werden ? Warum oder warum nicht ?
