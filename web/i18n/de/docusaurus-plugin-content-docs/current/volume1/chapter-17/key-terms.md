# Schlüsselbegriffe

- **Prozentualer Abschluss** : Jahresabschluss mit Posten als Prozentsätze
- **Vergleichender Abschluss** : Jahresabschluss, der mehrere Perioden zeigt
- **Finanzkennzahl** : Beziehung zwischen zwei Posten des Jahresabschlusses
- **Rendite des Vermögens (ROA)** : Nettoeinkommen als Prozentsatz des Vermögens
- **Eigenkapitalrendite (ROE)** : Nettoeinkommen als Prozentsatz des Eigenkapitals
