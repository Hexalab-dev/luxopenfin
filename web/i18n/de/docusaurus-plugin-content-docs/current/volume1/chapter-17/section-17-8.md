# 17.8 Luxemburgische KMU-Leistungsindikatoren

### Schlüsselindikatoren

**Für luxemburgische KMU :**
- Rentabilitätskennzahlen
- Liquiditätskennzahlen
- Effizienzkennzahlen
- Wachstumsindikatoren

### Typische Werte

**Restaurantbranche :**
- Bruttomarge : 30-50%
- Nettomarge : 5-15%
- Liquiditätsgrad 3 : größer als 1.5

**Einzelhandelsbranche :**
- Bruttomarge : 40-60%
- Nettomarge : 3-10%
- Inventarumschlag : 4-6 mal

### Luxemburgische Compliance-Hinweis

Leistungsindikatoren in Luxemburg :
- Variieren je nach Branche
- Helfen, Leistung zu bewerten
- Mit Benchmarks vergleichen
- Entscheidungen unterstützen
