# 17.3 Prozentuale Jahresabschlüsse vorbereiten

### Prozentuale Abschlüsse

**Prozentuale Abschlüsse :**
- Drücken Posten als Prozentsätze aus
- Gewinn- und Verlustrechnung : % der Erträge
- Bilanz : % des Gesamtvermögens
- Ermöglichen Vergleich unabhängig von Größe

### Format Gewinn- und Verlustrechnung

```
                    Betrag      % der Erträge
Erträge          €100,000         100.0%
Warenkosten  60,000          60.0%
Bruttogewinn         40,000          40.0%
Aufwendungen             30,000          30.0%
Nettoeinkommen       € 10,000          10.0%
```

### Format Bilanz

```
                    Betrag      % des Vermögens
Vermögenswerte            €200,000         100.0%
  Umlaufvermögen    80,000          40.0%
  Anlagevermögen     120,000          60.0%
Verbindlichkeiten        100,000          50.0%
Eigenkapital             100,000          50.0%
```

### Luxemburgische Compliance-Hinweis

Prozentuale Abschlüsse in Luxemburg :
- Nützlich für Vergleich
- Helfen, Struktur zu identifizieren
- Unterstützen Analyse
- Nützlich für Benchmarking
