# Kapitel 17 – Übungen und Fälle

## Multiple-Choice-Fragen

1. Vergleichende Jahresabschlüsse zeigen :  
   a) Nur eine Periode  
   b) Mehrere Perioden nebeneinander  
   c) Nur Prozentsätze  
   d) Nur Kennzahlen  
   **Antwort :** b) Vergleichende Abschlüsse zeigen mehrere Perioden.

2. Prozentuale Abschlüsse drücken Posten als aus :  
   a) Eurobeträge  
   b) Prozentsätze  
   c) Kennzahlen  
   d) Änderungen  
   **Antwort :** b) Prozentuale Abschlüsse verwenden Prozentsätze.

3. ROA misst :  
   a) Nur Rentabilität  
   b) Vermögenseffizienz  
   c) Nur Liquidität  
   d) Nur Hebelwirkung  
   **Antwort :** b) ROA misst Effizienz, mit der Vermögen Gewinn erzielt.

## Fragen

1. Warum ist Jahresabschlussanalyse notwendig ?

2. Wie helfen vergleichende Abschlüsse bei der Analyse ?

3. Was sind die Vorteile prozentualer Abschlüsse ?

4. Welche Arten von Finanzkennzahlen werden verwendet ? Geben Sie Beispiele.

5. Wie wird ROA berechnet und interpretiert ?

## Probleme Serie A

**Problem A-1 : Vergleichende Analyse**

Bereiten Sie vergleichende Gewinn- und Verlustrechnung für 2023 und 2024 vor :
- Erträge 2023 : €200,000, Aufwendungen : €150,000
- Erträge 2024 : €240,000, Aufwendungen : €170,000
- Zeigen Sie Euro- und Prozentsatzänderungen

**Problem A-2 : Prozentualer Abschluss**

Bereiten Sie prozentuale Gewinn- und Verlustrechnung vor :
- Erträge : €300,000
- Warenkosten : €180,000
- Betriebsaufwendungen : €80,000
- Nettoeinkommen : €40,000

**Problem A-3 : Liquiditätskennzahlen**

Berechnen Sie Liquiditätskennzahlen :
- Umlaufvermögen : €120,000
- Inventar : €40,000
- Kurzfristige Verbindlichkeiten : €60,000
- Berechnen Sie : Liquiditätsgrad 3 und Liquiditätsgrad 2

**Problem A-4 : Rentabilitätskennzahlen**

Berechnen Sie Rentabilitätskennzahlen :
- Erträge : €500,000
- Bruttogewinn : €200,000
- Nettoeinkommen : €60,000
- Durchschnittliches Vermögen : €400,000
- Durchschnittliches Eigenkapital : €250,000
- Berechnen Sie : Bruttomarge, Nettomarge, ROA, ROE

**Problem A-5 : Effizienzkennzahlen**

Berechnen Sie Effizienzkennzahlen :
- Erträge : €400,000
- Warenkosten : €240,000
- Durchschnittliches Inventar : €60,000
- Durchschnittliche Forderungen : €50,000
- Durchschnittliches Vermögen : €500,000
- Berechnen Sie : Inventarumschlag, Forderungsumschlag, Vermögensumschlag

## Probleme Serie B

**Problem B-1 : Vollständige Kennzahlenanalyse**

Aus den folgenden Daten berechnen Sie alle Hauptkennzahlen :

**Bilanz :**
- Umlaufvermögen : €150,000 (Inventar : €50,000)
- Anlagevermögen : €300,000
- Kurzfristige Verbindlichkeiten : €75,000
- Langfristige Schulden : €150,000
- Eigenkapital : €225,000

**Gewinn- und Verlustrechnung :**
- Erträge : €600,000
- Warenkosten : €360,000
- Betriebsaufwendungen : €180,000
- Nettoeinkommen : €60,000

**Zusätzlich :**
- Durchschnittliches Inventar : €45,000
- Durchschnittliche Forderungen : €40,000

**Problem B-2 : Vergleichende Analyse**

Bereiten Sie vergleichende Bilanzen und Gewinn- und Verlustrechnungen für 2023 und 2024 vor, zeigen Sie alle Änderungen und Trends.

**Problem B-3 : Prozentuale Analyse**

Bereiten Sie prozentuale Bilanz und Gewinn- und Verlustrechnung vor, und analysieren Sie die Struktur.

**Problem B-4 : DuPont-Analyse**

Verwenden Sie ROA = Gewinnmarge × Vermögensumschlag, analysieren Sie :
- Nettoeinkommen : €80,000
- Erträge : €500,000
- Durchschnittliches Vermögen : €400,000
- Berechnen und interpretieren Sie ROA-Komponenten

## Umfassendes Problem

**Umfassendes Problem 17 : Vollständige Jahresabschlussanalyse**

**Le Petit Bistro** benötigt eine vollständige Finanzanalyse für 2023 und 2024.

**Jahresabschlüsse :**

**2023 :**
- Erträge : €400,000
- Warenkosten : €240,000
- Betriebsaufwendungen : €120,000
- Nettoeinkommen : €40,000
- Umlaufvermögen : €100,000 (Inventar : €30,000)
- Anlagevermögen : €200,000
- Kurzfristige Verbindlichkeiten : €50,000
- Langfristige Schulden : €100,000
- Eigenkapital : €150,000

**2024 :**
- Erträge : €480,000
- Warenkosten : €288,000
- Betriebsaufwendungen : €140,000
- Nettoeinkommen : €52,000
- Umlaufvermögen : €120,000 (Inventar : €40,000)
- Anlagevermögen : €250,000
- Kurzfristige Verbindlichkeiten : €60,000
- Langfristige Schulden : €120,000
- Eigenkapital : €190,000

**Zusätzliche Informationen :**
- Durchschnittliches Inventar 2023 : €28,000
- Durchschnittliches Inventar 2024 : €35,000
- Durchschnittliche Forderungen 2023 : €35,000
- Durchschnittliche Forderungen 2024 : €42,000

**Erforderlich :**

1. Bereiten Sie vergleichende Gewinn- und Verlustrechnungen (2023 und 2024) vor, zeigen Sie :
   a) Euroänderungen
   b) Prozentsatzänderungen
   c) Trends

2. Bereiten Sie vergleichende Bilanzen (2023 und 2024) vor, zeigen Sie :
   a) Euroänderungen
   b) Prozentsatzänderungen
   c) Trends

3. Bereiten Sie prozentuale Gewinn- und Verlustrechnungen für beide Jahre vor.

4. Bereiten Sie prozentuale Bilanzen für beide Jahre vor.

5. Berechnen Sie alle Hauptfinanzkennzahlen für beide Jahre :
   a) Liquiditätskennzahlen (Liquiditätsgrad 3, Liquiditätsgrad 2)
   b) Solvenzkennzahlen (Verschuldungsgrad, Verschuldungsgrad zu Vermögen)
   c) Rentabilitätskennzahlen (Bruttomarge, Nettomarge, ROA, ROE)
   d) Effizienzkennzahlen (Inventarumschlag, Forderungsumschlag, Vermögensumschlag)

6. Analysieren Sie Trends :
   a) Welche Kennzahlen verbesserten sich ?
   b) Welche Kennzahlen gingen zurück ?
   c) Was sind die Auswirkungen ?

7. Vergleichen Sie mit luxemburgischen KMU-Benchmarks :
   a) Wie schneidet das Unternehmen ab ?
   b) Was sind Stärkenbereiche ?
   c) Was sind Bereiche, die Verbesserung benötigen ?

8. Geben Sie Empfehlungen :
   a) Welche Maßnahmen sollten ergriffen werden ?
   b) Was sind die Prioritäten ?
   c) Wie kann Leistung verbessert werden ?

4. Was sind die Einschränkungen des Benchmarkings ?

5. Wie kann Benchmarking Entscheidungsfindung unterstützen ?

6. Was sind die luxemburgspezifischen Überlegungen ?
