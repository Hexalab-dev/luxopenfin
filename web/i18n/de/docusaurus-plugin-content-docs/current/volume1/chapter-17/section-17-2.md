# 17.2 Vergleichende Jahresabschlüsse vorbereiten

### Vergleichende Abschlüsse

**Vergleichende Jahresabschlüsse :**
- Zeigen mehrere Perioden nebeneinander
- Ermöglichen Perioden-zu-Perioden-Vergleich
- Zeigen Änderungen in Beträgen und Prozentsätzen
- Identifizieren Trends

### Format

**Gewinn- und Verlustrechnung :**
```
                   2024        2023      Änderung      % Änderung
Erträge          €100,000   €90,000    €10,000      11.1%
Aufwendungen           70,000     65,000      5,000       7.7%
Nettoeinkommen       € 30,000   €25,000     €5,000      20.0%
```

### Analyse

**Änderungen zeigen :**
- Wachstum oder Rückgang
- Trends
- Bereiche, die Aufmerksamkeit benötigen

### Luxemburgische Compliance-Hinweis

Vergleichende Abschlüsse in Luxemburg :
- Nützlich für Analyse
- Helfen, Trends zu identifizieren
- Unterstützen Entscheidungsfindung
- Können für einige Hinterlegungen erforderlich sein
