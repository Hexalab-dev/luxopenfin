# 17.1 Bedarf und Zweck der Jahresabschlussanalyse beschreiben

### Bedarf an Analyse

**Rohzahlen erzählen nicht die ganze Geschichte :**
- Bedarf an Berechnung von Kennzahlen
- Bedarf an Vergleich von Perioden
- Bedarf an Vergleich mit Benchmarks
- Bedarf an Identifizierung von Trends

### Zweck


**Abbildung 17.1:** Financial Statement Analysis Framework

```
                    Financial Statements
                           │
        ┌──────────────────┼──────────────────┐
        │                  │                  │
   Horizontal          Vertical          Ratio
   Analysis            Analysis          Analysis
        │                  │                  │
Compare periods    Compare to total    Calculate ratios
over time          (common-size)        │
        │                  │        ┌────┴────┐
        │                  │        │         │
    Trends            Percentages  Liquidity Profitability
        │                  │        │         │
    Growth            Structure   Current  Gross
    Patterns          Analysis    Ratio    Margin
                                           │
                                      Return on
                                      Aktiva
```

*Alternativtext: Diagram showing the financial statement analysis framework with three main approaches: Horizontal Analysis (comparing periods over time to identify trends and growth patterns), Vertical Analysis (comparing to total using common-size statements to analyze structure), and Ratio Analysis (calculating liquidity ratios like current ratio and profitability ratios like gross margin and return on assets), demonstrating the different methods of analyzing financial statements.*

**Analyse hilft :**
- Leistung bewerten
- Stärken und Schwächen identifizieren
- Entscheidungen treffen
- Mit Stakeholdern kommunizieren
- Für Zukunft planen

### Nutzer der Analyse

**Interne Nutzer :**
- Management
- Eigentümer
- Mitarbeiter

**Externe Nutzer :**
- Investoren
- Gläubiger
- Lieferanten
- Regierung

### Luxemburgische Compliance-Hinweis

Finanzanalyse in Luxemburg :
- Wichtig für alle Unternehmen
- Hilft bei Entscheidungsfindung
- Unterstützt Compliance
- Nützlich für Stakeholder
