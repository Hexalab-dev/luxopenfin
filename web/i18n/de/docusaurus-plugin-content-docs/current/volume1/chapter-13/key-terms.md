# Schlüsselbegriffe

- **Anleihenverbindlichkeiten** : Langfristige Schuldverschreibungen
- **Effektivzinsmethode** : Zinsberechnung basierend auf Buchwert
- **Nennwert** : Betrag, der bei Fälligkeit zurückzuzahlen ist
- **Langfristige Verbindlichkeiten** : Verpflichtungen, die über ein Jahr hinaus fällig sind
- **Barwert** : Aktueller Wert unter Berücksichtigung des Zeitwerts des Geldes
