# 13.5 Luxemburgische langfristige Schulden (PCN Klasse 1)

### PCN Klasse 1 : Financement Permanent (Dauerfinanzierung)

**Klasse 1** enthält Eigenkapital und langfristige Finanzierung.

**Kontobereiche :**
- 10–13 : Grundkapital (Capital Social)
- 13 : Rücklagen (Réserves)
- 19 : Langfristige Schulden (Emprunts)
- 18 : Rückstellungen (Provisions pour Risques et Charges)

### Langfristige Schuldenkonten (19)

**Hauptkonten :**
- **1942** : Langfristige Darlehen (Emprunts)
- **1932** : Anleihenverbindlichkeiten (Obligations)
- **1942** : Hypotheken (Hypothèques)
- **4726** : Andere langfristige Schulden (Autres Emprunts)

### Luxemburgische Compliance-Hinweis

PCN Klasse 1 Anforderungen :
- Muss ordentliche Kontenklassifikationen verwenden
- Muss kurzfristige und langfristige Teile trennen
- Muss genaue Aufzeichnungen führen
- Muss PCN-Struktur einhalten
- Muss alle Salden unterstützen
