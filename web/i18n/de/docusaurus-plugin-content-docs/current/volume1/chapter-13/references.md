# Referenzen und weiterführende Literatur

### Offizielle luxemburgische Quellen

- **Guichet.lu - Langfristige Verbindlichkeiten** : https://guichet.public.lu/en/entreprises/gestion-juridique-comptabilite/comptable/enregistrement/
  - Langfristige Verbindlichkeitsbuchhaltungsanforderungen
  - PCN Klasse 1 Informationen

- **Commission des Normes Comptables (CNC)** : https://cnc.lu
  - PCN Klasse 1 Anforderungen
  - Langfristige Verbindlichkeitsbuchhaltungsstandards
  - Jahresabschlussdarstellung

- **Administration des Contributions Directes (ACD)** : https://impotsdirects.public.lu
  - Steuerbehandlung von Zinsaufwand
  - Darlehensdokumentationsanforderungen
  - Steuercompliance

### Bankressourcen

- **Luxemburgische Bankenvereinigung** : https://www.abbl.lu
  - Darlehensinformationen
  - Bankdienstleistungen
  - Finanzierungsoptionen

### Bildungsressourcen

- **House of Training** : https://www.houseoftraining.lu
  - Langfristige Verbindlichkeitsbuchhaltungskurse
  - Darlehensbuchhaltungsschulung
  - Finanzmanagement-Workshops

### Weiterführende Literatur

- "Précis de droit comptable" von Denis Colin (Legitech)
  - Luxemburgische langfristige Verbindlichkeitsbuchhaltung
  - PCN Klasse 1 Anforderungen
  - Darlehensbuchhaltung

- OpenStax Principles of Financial Accounting
  - Universelle langfristige Verbindlichkeitskonzepte
  - Effektivzinsmethode
  - Anleihenbuchhaltung
