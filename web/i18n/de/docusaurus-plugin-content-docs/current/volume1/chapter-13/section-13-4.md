# 13.4 Anhang : Besondere Themen im Zusammenhang mit langfristigen Verbindlichkeiten

### Besondere Themen

**Leasingverpflichtungen :**
- Operating-Leasing vs. Finanzierungsleasing
- Finanzierungsleasing als Verbindlichkeiten erfasst
- Müssen Leasingbuchhaltungsstandards einhalten

**Wandelbare Schuld :**
- Schuld, die in Eigenkapital umgewandelt werden kann
- Besondere Buchhaltungsüberlegungen
- Weniger üblich für KMU

**Schuldenrestrukturierung :**
- Änderung von Schuldbedingungen
- Besondere Buchhaltungsbehandlung
- Kann Gewinn oder Verlust beinhalten

### Luxemburgische Compliance-Hinweis

Besondere Themen in Luxemburg :
- Müssen Buchhaltungsstandards einhalten
- Müssen Vorschriften einhalten
- Müssen ordentliche Dokumentation führen
- Müssen angemessene PCN-Konten verwenden
