# 13.3 Buchungen vorbereiten, um Lebenszyklus von Anleihen widerzuspiegeln

### Anleihenverbindlichkeiten

**Anleihen** sind langfristige Schuldverschreibungen, die von Unternehmen zur Kapitalbeschaffung ausgegeben werden.

### Anleihenlebenszyklus

**1. Ausgabe :**
- Unternehmen gibt Anleihen an Investoren aus
- Erhält Kasse
- Erfasst Anleihenverbindlichkeiten

**Beispiel :**
- Ausgabe €100,000 Anleihen zum Nennwert, 6% Zinsen

**Buchung :**
```
5131   Kasse                       €100,000
1932   Anleihenverbindlichkeiten                          €100,000
Zur Erfassung der Anleihenausgabe zum Nennwert
```

**2. Zinszahlungen :**
- Zinsen periodisch zahlen (normalerweise halbjährlich)
- Zinsaufwand erfassen

**Beispiel :**
- Halbjährliche Zinsen : €100,000 × 6% × 6/12 = €3,000

**Buchung :**
```
6552   Zinsaufwand           €3,000
5131   Kasse                                    €3,000
Zur Erfassung der halbjährlichen Zinszahlung
```

**3. Fälligkeit :**
- Kapital bei Fälligkeit zurückzahlen
- Anleihenverbindlichkeiten entfernen

**Buchung :**
```
1932   Anleihenverbindlichkeiten             €100,000
5131   Kasse                                   €100,000
Zur Erfassung der Anleihenrückzahlung bei Fälligkeit
```

### Anleihen zu Abschlag oder Aufschlag ausgegeben

**Wenn Marktzins > angegebener Zins :**
- Anleihen zu Abschlag ausgegeben
- Abschlag über Anleihenlebensdauer amortisiert

**Wenn Marktzins < angegebener Zins :**
- Anleihen zu Aufschlag ausgegeben
- Aufschlag über Anleihenlebensdauer amortisiert

### Luxemburgische Compliance-Hinweis

Anleihen in Luxemburg :
- Weniger üblich für KMU
- Müssen ordentlich klassifiziert sein
- Müssen Abschlag/Aufschlag buchen
- Müssen Vorschriften einhalten
- Müssen ordentliche PCN-Konten verwenden
