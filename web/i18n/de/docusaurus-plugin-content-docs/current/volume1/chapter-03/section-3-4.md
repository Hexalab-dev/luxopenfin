# 3.4 Geschäftstransaktionen mit der Bilanzgleichung analysieren und Auswirkungen auf Finanzberichte zeigen

### Transaktionsanalyse-Rahmen

Um Transaktionen ordnungsgemäß zu analysieren, folgen Sie diesem systematischen Ansatz:

1. **Transaktion identifizieren** und Beleg
2. **Betroffene Konten bestimmen** (mindestens zwei)
3. **Jedes Konto klassifizieren** (Vermögen, Verbindlichkeit, Eigenkapital, Ertrag, Aufwand)
4. **Erhöhung oder Verringerung** für jedes Konto bestimmen
5. **Soll/Haben-Regeln anwenden**
6. **Überprüfen, dass Gleichung ausgeglichen ist**
7. **PCN-Konten identifizieren**

### Umfassende Transaktionsbeispiele

Analysieren wir eine Reihe von Transaktionen für Maries Restaurant und zeigen die Auswirkungen auf die Bilanzgleichung und Finanzberichte.

#### Ausgangsposition

**Bilanz, 1. November 2024:**
```
Vermögen = Verbindlichkeiten + Eigenkapital
€10,000 = €0 + €10,000
(Kasse)              (Grundkapital)
```

#### Transaktion 1: Ausstattungskauf

**Transaktion:** Restaurant kauft 15.000 € Küchenausstattung, zahlt 5.000 € bar und unterschreibt einen Wechsel für 10.000 €.

**Analyse:**
- Ausstattung (Vermögen) erhöht sich: +€15,000
- Kasse (Vermögen) verringert sich: -€5,000
- Wechselverbindlichkeiten (Verbindlichkeit) erhöhen sich: +€10,000

**Auswirkung auf die Gleichung:**
```
Vorher:  €10,000 = €0 + €10,000
Nachher: €20,000 = €10,000 + €10,000
        (€15,000 Ausstattung + €5,000 Kasse)
```

**PCN-Konten:**
- Soll: 222 Ausstattung (Klasse 2) €15,000
- Haben: 5131 Kasse (Klasse 5) €5,000
- Haben: 4421 Wechselverbindlichkeiten (Klasse 4) €10,000

**Auswirkung auf Finanzberichte:**
- **Bilanz:** Vermögen erhöht sich (Ausstattung), Kasse verringert sich, Verbindlichkeiten erhöhen sich
- **Gewinn- und Verlustrechnung:** Keine Auswirkung (keine Erträge oder Aufwendungen)

#### Transaktion 2: Vorratskauf auf Kredit

**Transaktion:** Restaurant kauft 2.000 € Lebensmittelvorräte auf Kredit von einem Lieferanten.

**Analyse:**
- Vorräte (Vermögen) erhöhen sich: +€2,000
- Lieferanten (Verbindlichkeit) erhöhen sich: +€2,000

**Auswirkung auf die Gleichung:**
```
Vorher:  €20,000 = €10,000 + €10,000
Nachher: €22,000 = €12,000 + €10,000
```

**PCN-Konten:**
- Soll: 361 Vorräte (Klasse 3) €2,000
- Haben: 44111 Lieferanten (Klasse 4) €2,000

**Auswirkung auf Finanzberichte:**
- **Bilanz:** Vermögen erhöht sich, Verbindlichkeiten erhöhen sich
- **Gewinn- und Verlustrechnung:** Keine Auswirkung (Vorräte sind Vermögen, nicht Aufwand bis zum Verkauf)

#### Transaktion 3: Dienstleistungen gegen Bargeld erbringen (mit MwSt)

**Transaktion:** Das Restaurant organisiert eine private Veranstaltung für einen Kunden (Dekoration, Musik und Servicepersonal, ohne Speisen und Getränke) für 1.000 €, per Überweisung erhalten. Diese Leistungen unterliegen dem MwSt-Normalsatz von 17 % (Speisen und alkoholfreie Getränke wären mit 3 % besteuert).

**Analyse:**
- Kasse (Vermögen) erhöht sich: +€1,170 (€1,000 + €170 MwSt)
- Dienstleistungserlöse (Ertrag, erhöht Eigenkapital) erhöhen sich: +€1,000
- MwSt-Verbindlichkeit (Verbindlichkeit) erhöht sich: +€170

**Auswirkung auf die Gleichung:**
```
Vorher:  €22,000 = €12,000 + €10,000
Nachher: €23,170 = €12,170 + €11,000
        (Erträge erhöhen Eigenkapital)
```

**PCN-Konten:**
- Soll: 5131 Kasse (Klasse 5) €1,170
- Haben: 703 Dienstleistungserlöse (Klasse 7) €1,000
- Haben: 461411 MwSt-Verbindlichkeit (Klasse 4) €170

**Auswirkung auf Finanzberichte:**
- **Bilanz:** Vermögen erhöht sich, Verbindlichkeiten (MwSt) erhöhen sich, Eigenkapital erhöht sich
- **Gewinn- und Verlustrechnung:** Erträge erhöhen sich (beeinflusst Nettoergebnis)

#### Transaktion 4: Gehälter zahlen

**Transaktion:** Restaurant zahlt 3.000 € Gehälter an Mitarbeiter.

**Analyse:**
- Kasse (Vermögen) verringert sich: -€3,000
- Gehaltsaufwand (Aufwand, verringert Eigenkapital) erhöht sich: +€3,000

**Auswirkung auf die Gleichung:**
```
Vorher:  €23,170 = €12,170 + €11,000
Nachher: €20,170 = €12,170 + €8,000
        (Aufwendungen verringern Eigenkapital)
```

**PCN-Konten:**
- Soll: 6211 Gehaltsaufwand (Klasse 6) €3,000
- Haben: 5131 Kasse (Klasse 5) €3,000

**Auswirkung auf Finanzberichte:**
- **Bilanz:** Vermögen verringert sich, Eigenkapital verringert sich
- **Gewinn- und Verlustrechnung:** Aufwendungen erhöhen sich (verringern Nettoergebnis)

#### Transaktion 5: Lieferanten zahlen

**Transaktion:** Restaurant zahlt 1.500 € an Lieferanten für vorherigen Vorratskauf.

**Analyse:**
- Kasse (Vermögen) verringert sich: -€1,500
- Lieferanten (Verbindlichkeit) verringert sich: -€1,500

**Auswirkung auf die Gleichung:**
```
Vorher:  €20,170 = €12,170 + €8,000
Nachher: €18,670 = €10,670 + €8,000
```

**PCN-Konten:**
- Soll: 44111 Lieferanten (Klasse 4) €1,500
- Haben: 5131 Kasse (Klasse 5) €1,500

**Auswirkung auf Finanzberichte:**
- **Bilanz:** Vermögen verringert sich, Verbindlichkeiten verringern sich
- **Gewinn- und Verlustrechnung:** Keine Auswirkung (Zahlung einer Verbindlichkeit, nicht Aufwand)

### Zusammenfassung der Transaktionsauswirkungen

| Transaktion | Vermögen | Verbindlichkeiten | Eigenkapital | Erträge | Aufwendungen |
|------------|----------|-------------------|--------------|---------|--------------|
| 1. Ausstattungskauf | +€10,000 | +€10,000 | - | - | - |
| 2. Vorratskauf | +€2,000 | +€2,000 | - | - | - |
| 3. Dienstleistungen erbringen | +€1,170 | +€170 | +€1,000 | +€1,000 | - |
| 4. Gehälter zahlen | -€3,000 | - | -€3,000 | - | +€3,000 |
| 5. Lieferanten zahlen | -€1,500 | -€1,500 | - | - | - |
| **Nettoänderung** | **+€8,670** | **+€670** | **-€2,000** | **+€1,000** | **+€3,000** |

**Endgleichung:**
```
€18,670 = €10,670 + €8,000
Vermögen = Verbindlichkeiten + Eigenkapital ✓
```

### Luxemburgische MwSt-Überlegungen

Bei der Analyse von Transaktionen in Luxemburg immer MwSt berücksichtigen:

**Verkaufstransaktionen:**
- Erträge erfassen (netto MwSt)
- MwSt-Verbindlichkeit (461411) erfassen
- Gesamt Bargeld/Forderungen enthält MwSt

**Kauftransaktionen:**
- Aufwand/Vermögen erfassen (netto MwSt, wenn abzugsfähig)
- MwSt-Vorsteuer (421611) erfassen, wenn Unternehmen MwSt abziehen kann
- Gesamt Bargeld/Verbindlichkeiten enthält MwSt
