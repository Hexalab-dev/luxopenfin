# Referenzen und weiterführende Literatur

## Offizielle luxemburgische Quellen

- **Guichet.lu - Buchhaltungspflichten**: https://guichet.public.lu/en/entreprises/gestion-juridique-comptabilite/comptable/enregistrement/obligations-comptables.html
  - Anforderungen an doppelte Buchführung
  - Aufzeichnungspflichten
  - Aufbewahrungsanforderungen

- **Commission des Normes Comptables (CNC)**: https://cnc.lu
  - PCN-Kontenklassifikationen
  - Buchhaltungsstandards
  - Richtlinien zur Transaktionsbuchung

- **Handelsgesetzbuch (Code de Commerce)**:
  - Rechtliche Anforderungen an die Buchhaltung
  - Verpflichtung zur doppelten Buchführung
  - Aufbewahrungsanforderungen

## PCN-Ressourcen

- **Anhang A: PCN-Kontenplan** (dieses Lehrbuch)
  - Vollständige Kontenliste
  - Kontenklassifikationen
  - Transaktionszuordnungsbeispiele

- **KPMG Luxembourg PCN-Leitfaden**: https://assets.kpmg.com/content/dam/kpmg/lu/pdf/luxembourg-standard-chart-accounts-FR-web.pdf

## Software-Ressourcen

- **Sage BOB**: https://www.sage.com/fr-be/products/sage-bob
  - PCN-konforme Buchhaltungssoftware
  - Automatisierung der doppelten Buchführung
  - Luxemburg-spezifische Funktionen

- **Odoo Luxembourg**: https://www.odoo.com
  - Open-Source-ERP mit PCN-Unterstützung
  - Doppelte Buchführung
  - Luxemburg-Lokalisierung

## Bildungsressourcen

- **House of Training**: https://www.houseoftraining.lu
  - Buchhaltungskurse
  - PCN-Schulungen
  - Workshops zur doppelten Buchführung

## Weiterführende Literatur

- "Précis de droit comptable" von Denis Colin (Legitech)
  - Luxemburgisches Buchhaltungsrecht
  - Anforderungen an doppelte Buchführung
  - Rechtliche Verpflichtungen

- OpenStax Principles of Financial Accounting
  - Universelle Buchhaltungsprinzipien
  - Transaktionsanalyse
  - Buchungssätze und Übertragung
