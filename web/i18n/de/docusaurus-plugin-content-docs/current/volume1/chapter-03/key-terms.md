# Schlüsselbegriffe

- **Buchhaltungszyklus**: Prozess der Erfassung, Klassifizierung und Zusammenfassung von Transaktionen
- **Bilanzgleichung**: Vermögen = Verbindlichkeiten + Eigenkapital
- **Periodenrechnung**: Buchung von Transaktionen, wenn sie auftreten, nicht wenn Geld den Besitzer wechselt
- **Haben**: Rechte Seite eines Kontos; erhöht Verbindlichkeiten, Eigenkapital, Erträge; verringert Vermögen, Aufwendungen
- **Soll**: Linke Seite eines Kontos; erhöht Vermögen, Aufwendungen; verringert Verbindlichkeiten, Eigenkapital, Erträge
- **Doppelte Buchführung**: System, bei dem jede Transaktion mindestens zwei Konten betrifft
- **Erweiterte Bilanzgleichung**: Vermögen = Verbindlichkeiten + Grundkapital + Gewinnrücklagen + Erträge - Aufwendungen - Entnahmen
- **Journal**: Chronologische Aufzeichnung aller Transaktionen
- **Buchungssatz**: Formale Erfassung einer Transaktion
- **Hauptbuch**: Sammlung aller Konten mit Salden
- **Periodenabgrenzung**: Aufwendungen werden in derselben Periode wie zugehörige Erträge gebucht
- **Normalsaldo**: Seite des Kontos, auf der Erhöhungen gebucht werden
- **Übertragung**: Übertragung von Buchungssätzen auf Konten
- **Ertragsrealisierungsprinzip**: Erträge werden gebucht, wenn sie verdient werden, nicht wenn Geld erhalten wird
- **Beleg**: Originaldokument, das eine Transaktion belegt (Rechnung, Quittung usw.)
- **T-Konto**: Visuelle Darstellung eines Kontos
- **Saldenliste**: Liste aller Konten und Salden zur Überprüfung, dass Soll = Haben
