# 12.6 Luxemburgische Sozialabgaben und Gehaltsverbindlichkeiten

### Sozialabgaben in Luxemburg

**Sozialabgaben** umfassen :
- Arbeitnehmer-Sozialversicherungsbeiträge
- Arbeitgeber-Sozialversicherungsbeiträge
- Krankenversicherung
- Rentenbeiträge
- Pflegeversicherung (nur Arbeitnehmer)
- Unfallversicherung, Arbeitsmedizin und Mutualité des employeurs (nur Arbeitgeber)

**CCSS-Sätze zum 1. Januar 2026** (jedes Jahr auf ccss.lu prüfen):

| Beitrag | Arbeitnehmer | Arbeitgeber |
|---|---|---|
| Krankenversicherung (Sach- + Geldleistungen) | 2,80 % + 0,25 % | 2,80 % + 0,25 % |
| Rentenversicherung | 8,50 % | 8,50 % |
| Pflegeversicherung | 1,40 % | – |
| Unfallversicherung | – | 0,65 % |
| Arbeitsmedizin (STM) | – | 0,14 % |
| Mutualité des employeurs (Klassen 1–4) | – | 0,23 %–2,66 % |
| **Gesamt (Beispiele: Mutualité-Klasse 1)** | **12,95 %** | **12,57 %** |

Die Pflegeversicherung wird gesetzlich auf das Bruttogehalt abzüglich 1/4 des sozialen Mindestlohns berechnet; die folgenden Beispiele vereinfachen, indem 1,40 % auf das gesamte Brutto angewendet werden.

### Arbeitnehmer-Sozialabgaben

**Arbeitnehmer-Teil :**
- Vom Bruttogehalt abgezogen
- Von Arbeitgeber zahlbar
- Verschiedene Sätze gelten

**Beispiel :**
- Bruttogehalt : €5,000
- Arbeitnehmer-Sozialabgaben : €647.50 (12,95 %)

**Buchung :**
```
6211   Gehaltsaufwand           €5,000
4714   Gehaltsverbindlichkeiten                        €4,352.50
4621   Arbeitnehmer-Sozialabgaben-Verbindlichkeiten         €647.50
Zur Erfassung des Gehalts mit Arbeitnehmer-Sozialabgaben
```

### Arbeitgeber-Sozialabgaben

**Arbeitgeber-Teil :**
- Zusätzliche Kosten für Arbeitgeber
- Nicht von Arbeitnehmer abgezogen
- Verschiedene Sätze gelten

**Beispiel :**
- Bruttogehalt : €5,000
- Arbeitgeber-Sozialabgaben : €628.50 (12,57 %)

**Buchung :**
```
6211   Gehaltsaufwand           €628.50
4621   Arbeitgeber-Sozialabgaben-Verbindlichkeiten         €628.50
Zur Erfassung der Arbeitgeber-Sozialabgaben
```

### Gesamtgehaltskosten

**Gesamtkosten :**
- Bruttogehalt : €5,000 (enthält bereits die einbehaltenen €647.50 Arbeitnehmer-Sozialabgaben)
- Arbeitgeber-Sozialabgaben : €628.50
- **Gesamtkosten : €5,628.50**

### Zahlung der Sozialabgaben

**Zahlung :**
```
4621   Arbeitnehmer-Sozialabgaben-Verbindlichkeiten €647.50
4621   Arbeitgeber-Sozialabgaben-Verbindlichkeiten    628.50
5131   Kasse                                   €1,276.00
Zur Erfassung der Zahlung der Sozialabgaben
```

### Luxemburgische Compliance-Hinweis

Sozialabgaben in Luxemburg :
- Müssen korrekt berechnet werden
- Müssen rechtzeitig gezahlt werden
- Müssen Sätze einhalten
- Müssen Aufzeichnungen führen
- Strafen für verspätete Zahlung
- Müssen ordentliche PCN-Konten verwenden
