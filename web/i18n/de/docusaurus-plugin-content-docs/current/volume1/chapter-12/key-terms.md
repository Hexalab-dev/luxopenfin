# Schlüsselbegriffe

- **Verbindlichkeiten aus Lieferungen und Leistungen** : Beträge, die Lieferanten geschuldet werden
- **Kurzfristige Verbindlichkeiten** : Verpflichtungen, die innerhalb eines Jahres fällig sind
- **Sozialabgaben** : Sozialversicherungsbeiträge
- **MwSt-Verbindlichkeiten** : MwSt, die Steuerbehörden geschuldet wird
- **Gehaltsverbindlichkeiten** : Löhne, die Arbeitnehmern geschuldet werden
- **Kurzfristige Wechselverbindlichkeiten** : Wechsel, die innerhalb eines Jahres fällig sind
- **Nicht erbrachte Leistungen** : Vorauszahlungen
