# 12.2 Bezahlte Freizeit analysieren und klassifizieren

### Bezahlte Freizeit (PTO)

**Bezahlte Freizeit** umfasst :
- Urlaubstage
- Krankheitstage
- Feiertage
- Andere bezahlte Abwesenheiten

**Warum PTO passivieren :**
- Arbeitnehmer verdienen PTO während der Arbeit
- Verbindlichkeit existiert für ungenutzte PTO
- Muss Aufwand mit Periode abgleichen, in der verdient wurde
- Erforderlich für genaue Jahresabschlüsse

### Luxemburgische Urlaubsanforderungen

**Gesetzliches Minimum :**
- Luxemburgisches Arbeitsrecht erfordert Mindesturlaub
- Typischerweise 25-26 Tage pro Jahr für Vollzeitbeschäftigte
- Muss verfolgt und bezahlt werden, wenn genommen
- Kann sich ansammeln (mit Grenzen)

### Passivierung von PTO

**Passivierungsmethode :**
- PTO passivieren, während Arbeitnehmer es verdienen
- Verbindlichkeit für ungenutzte PTO erfassen
- Aufwand mit Periode abgleichen, in der verdient wurde
- Gewährleistet genaue Periodenberichterstattung

**Beispiel :**
- Arbeitnehmer verdient 20 Urlaubstage pro Jahr
- Am Jahresende, 5 Tage ungenutzt
- Tägliches Gehalt : €200
- Verbindlichkeit : 5 × €200 = €1,000

**Buchung :**
```
6211   Gehaltsaufwand           €1,000
4714   Aufgelaufene Urlaubsverbindlichkeiten                €1,000
Zur Passivierung ungenutzter Urlaubsverbindlichkeiten
```

**PCN-Konto :**
- **4718** : Andere Verbindlichkeiten (Autres Dettes)

**Wenn Urlaub genommen wird :**
```
4714   Aufgelaufene Urlaubsverbindlichkeiten    €1,000
4714   Gehaltsverbindlichkeiten                        €1,000
Zur Erfassung der Urlaubsverbindlichkeiten, wenn genommen
```

### Monatliche Passivierung

**Bessere Praxis :**
- PTO monatlich passivieren
- Genauere Periodenabgrenzung
- Bessere Cashflow-Planung

**Beispiel : Monatliche Passivierung**
- Arbeitnehmer verdient 20 Tage/Jahr = 1,67 Tage/Monat
- Monatsgehalt : €4,000
- Tagesrate : €4,000 ÷ 20 = €200
- Monatliche Passivierung : 1,67 × €200 = €334

**Monatliche Buchung :**
```
6211   Gehaltsaufwand           €334
4714   Aufgelaufene Urlaubsverbindlichkeiten                €334
Zur Passivierung der Urlaubsverbindlichkeiten für den Monat
```

### Luxemburgische Überlegungen

**Luxemburgisches Arbeitsrecht :**
- Mindesturlaubsanforderungen (25-26 Tage typisch)
- Muss Urlaubspassivierungen genau verfolgen
- Muss bezahlen, wenn genommen
- Muss Arbeitsvorschriften einhalten
- Kann vorgetragen werden (mit Grenzen)

**Compliance-Anforderungen :**
- Urlaubsaufzeichnungen führen
- Tage verfolgen, die verdient und genommen wurden
- Verbindlichkeit genau berechnen
- Bei Fälligkeit zahlen
- Arbeitsrecht einhalten

### Luxemburgische Compliance-Hinweis

PTO in Luxemburg :
- Muss Arbeitsrecht einhalten (Minimum 25-26 Tage)
- Muss ordentlich passivieren (monatlich empfohlen)
- Muss genau verfolgen (Tage verdient vs. genommen)
- Muss bei Fälligkeit zahlen
- Muss Aufzeichnungen führen
- Muss ordentliche PCN-Konten verwenden
