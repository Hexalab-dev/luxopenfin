# Kapitel 12 – Übungen und Fälle

## Multiple-Choice-Fragen

1. Kurzfristige Verbindlichkeiten sind Verpflichtungen, die fällig sind innerhalb von :  
   a) 6 Monaten  
   b) 1 Jahr  
   c) 2 Jahren  
   d) 5 Jahren  
   **Antwort :** b) Kurzfristige Verbindlichkeiten sind innerhalb eines Jahres (oder Betriebszyklus) fällig.

2. Welches PCN-Konto wird für MwSt-Verbindlichkeiten verwendet ?  
   a) 44111  
   b) 461411  
   c) 4714  
   d) 4718  

   **Antwort :** b) 461411 ist MwSt-Verbindlichkeiten (TVA à Payer).

3. Sozialabgaben in Luxemburg umfassen :  
   a) Nur Arbeitnehmerbeiträge  
   b) Nur Arbeitgeberbeiträge  
   c) Arbeitnehmer- und Arbeitgeberbeiträge  
   d) Nur Krankenversicherung  
   **Antwort :** c) Sozialabgaben umfassen Arbeitnehmer- und Arbeitgeber-Teile.

4. MwSt-Verbindlichkeiten werden berechnet als :  
   a) MwSt auf Käufen nur  
   b) MwSt auf Verkäufen nur  
   c) MwSt auf Verkäufen minus MwSt auf Käufen  
   d) MwSt auf Käufen minus MwSt auf Verkäufen  
   **Antwort :** c) NettomwSt = MwSt-Verbindlichkeiten (Verkäufe) - MwSt erstattungsfähig (Käufe).

5. Welches ist eine kurzfristige Verbindlichkeit ?  
   a) Langfristiges Darlehen  
   b) Gebäude  
   c) Verbindlichkeiten aus Lieferungen und Leistungen  
   d) Ausstattung  
   **Antwort :** c) Verbindlichkeiten aus Lieferungen und Leistungen sind eine kurzfristige Verbindlichkeit.

## Probleme Serie A

**Problem A-1 : Verbindlichkeiten aus Lieferungen und Leistungen**

Ein luxemburgisches Einzelhandelsgeschäft macht die folgenden Käufe auf Kredit. Erfassen Sie jeden mit ordentlichen PCN-Konten :

a) Kauf €5,000 Inventar (ohne MwSt), MwSt 17%, erstattungsfähig
b) Kauf €2,000 Materialien (ohne MwSt), MwSt 17%, erstattungsfähig
c) Zahlung €5,850 an Lieferanten (von Kauf a)
d) Zahlung €2,340 an Lieferanten (von Kauf b)

**Problem A-2 : MwSt-Verbindlichkeiten**

Ein Unternehmen hat die folgenden MwSt-Transaktionen für den Monat :
- Verkäufe (ohne MwSt) : €20,000, MwSt 17%
- Verkäufe (ohne MwSt) : €5,000, MwSt 3% (Lebensmittelprodukte)
- Käufe (ohne MwSt) : €12,000, MwSt 17%, erstattungsfähig
- Käufe (ohne MwSt) : €3,000, MwSt 3%, erstattungsfähig (Lebensmittel)

Berechnen :
a) Gesamte MwSt-Verbindlichkeiten
b) Gesamte MwSt erstattungsfähig
c) NettomwSt zu zahlen
d) MwSt-Zahlung erfassen

**Problem A-3 : Gehaltsverbindlichkeiten**

Erfassen Sie die folgenden Gehaltsabrechnungstransaktionen :
a) Bruttogehälter : €8,000
b) Arbeitnehmer-Sozialabgaben : 12,95 % (€1,036.00)
c) Arbeitgeber-Sozialabgaben : 12,57 % (€1,005.60)
d) Nettozahlung an Arbeitnehmer : €6,964.00

*In diesen Aufgaben verwendete Sätze: CCSS-Sätze zum 1. Januar 2026 (Arbeitnehmer 12,95 % inkl. 1,40 % Pflegeversicherung, vereinfacht auf das gesamte Brutto; Arbeitgeber 12,57 % mit Mutualité-Klasse 1), siehe Abschnitt 12.6. Jedes Jahr auf ccss.lu prüfen.*
e) Zahlung von Gehältern und Sozialabgaben

**Problem A-4 : Aufgelaufene Aufwendungen**

Erfassen Sie die folgenden aufgelaufenen Aufwendungen am Monatsende :
a) Aufgelaufene Gehälter : €2,000
b) Aufgelaufene Zinsen : €150
c) Aufgelaufene Versorgungsleistungen : €300

**Problem A-5 : Nicht erbrachte Leistungen**

Ein Unternehmen erhält Vorauszahlungen :
a) Kunde zahlt €2,000 im Voraus für Dienstleistungen
b) Dienstleistungen erbracht (€1,500)
c) Verbleibende Dienstleistungen nächsten Monat erbracht

Erfassen Sie alle Transaktionen.

## Probleme Serie B

**Problem B-1 : Vollständiger kurzfristiger Verbindlichkeitszyklus**

Ein luxemburgisches Unternehmen hat die folgenden Transaktionen im November :

1. Kauf €10,000 Inventar auf Kredit (ohne MwSt), MwSt 17%
2. Verkäufe : €15,000 (ohne MwSt), MwSt 17%
3. Gehälter passivieren : €5,000
4. Arbeitnehmer-Sozialabgaben berechnen : 12,95 %
5. Arbeitgeber-Sozialabgaben berechnen : 12,57 %
6. Gehälter und Sozialabgaben zahlen
7. NettomwSt für den Monat berechnen und zahlen

Erfassen Sie alle Transaktionen mit ordentlichen PCN-Konten.

**Problem B-2 : MwSt-Erklärungsvorbereitung**

Bereiten Sie MwSt-Zusammenfassung für vierteljährliche Erklärung vor :

**Verkäufe :**
- Standardsatz (17%) : €50,000
- Reduzierter Satz (3%) : €10,000

**Käufe :**
- Standardsatz (17%) : €30,000
- Reduzierter Satz (3%) : €5,000

Berechnen Sie NettomwSt und bereiten Sie Buchung für Zahlung vor.

**Problem B-3 : Vollständiger Gehaltsabrechnungszyklus**

Vollständige Gehaltsabrechnungsbuchhaltung für den Monat :
- Bruttogehälter : €20,000
- Arbeitnehmer-Sozialabgaben : 12,95 %
- Arbeitgeber-Sozialabgaben : 12,57 %
- Einkommensteuer einbehalten : 10% (illustrativer Wert; in der Praxis gemäß Steuerkarte des jeweiligen Arbeitnehmers)

Berechnen und erfassen Sie alle Gehaltsabrechnungstransaktionen.

**Problem B-4 : Kurzfristige Verbindlichkeits-Analyse**

Ein Unternehmen hat die folgenden kurzfristigen Verbindlichkeiten :
- Verbindlichkeiten aus Lieferungen und Leistungen : €25,000
- MwSt-Verbindlichkeiten : €5,000
- Gehaltsverbindlichkeiten : €8,000
- Sozialabgaben-Verbindlichkeiten : €3,000
- Zinsverbindlichkeiten : €500
- Nicht erbrachte Leistungen : €2,000

Berechnen Sie gesamte kurzfristige Verbindlichkeiten und erklären Sie Cashflow-Auswirkungen.

## Umfassendes Problem

**Umfassendes Problem 12 : Vollständige kurzfristige Verbindlichkeits-Verwaltung**

**Le Petit Bistro** muss alle kurzfristigen Verbindlichkeiten ordnungsgemäß für den Monat November 2024 buchen.

**Transaktionen :**

**1-30. November :**
- Kreditkäufe : €15,000 (ohne MwSt), MwSt 17%, erstattungsfähig
- Bar- und Kreditverkäufe : €25,000 (ohne MwSt), MwSt 17%
- Lebensmittelverkäufe : €5,000 (ohne MwSt), MwSt 3%
- Bruttogehälter verdient : €12,000
- Arbeitnehmer-Sozialabgaben : 12,95 % (€1,554.00)
- Arbeitgeber-Sozialabgaben : 12,57 % (€1,508.40)
- Aufgelaufene Zinsen auf Darlehen : €200
- Kunden-Vorauszahlung : €3,000 (für Catering im Dezember)

**Anpassungen 30. November :**
- Gehälter für letzte Woche passivieren : €3,000
- Arbeitnehmer-Sozialabgaben passivieren : €388.50
- Arbeitgeber-Sozialabgaben passivieren : €377.10
- Zinsen passivieren : €200

**Erforderlich :**

1. Erfassen Sie alle Kauf-Transaktionen mit ordentlicher MwSt-Behandlung.

2. Erfassen Sie alle Verkaufs-Transaktionen mit ordentlicher MwSt-Behandlung.

3. Erfassen Sie Gehaltsabrechnungstransaktionen :
   a) Gehälter verdient und gezahlt
   b) Sozialabgaben (Arbeitnehmer und Arbeitgeber)
   c) Passivierungen am Monatsende

4. Berechnen Sie NettomwSt für November :
   a) MwSt-Verbindlichkeiten (aus Verkäufen)
   b) MwSt erstattungsfähig (aus Käufen)
   c) NettomwSt zu zahlen
   d) MwSt-Zahlung erfassen

5. Erfassen Sie Nicht erbrachte Leistungen-Transaktion.

6. Bereiten Sie kurzfristige Verbindlichkeiten-Abschnitt der Bilanz vor (30. November).

7. Analysieren Sie Cashflow-Anforderungen :
   a) Wann sind Zahlungen fällig ?
   b) Wie viel Bargeld wird benötigt ?
   c) Was sind die Zahlungsfristen ?

8. Erklären Sie luxemburgische Compliance-Anforderungen :
   a) MwSt-Abgabefristen
   b) Sozialabgaben-Zahlungsfristen
   c) PCN-Kontenklassifikationen
   d) Dokumentationsanforderungen
