# Kapitel-Zusammenfassung

### Abschnitt 12.1 : Kurzfristige Verbindlichkeiten
- Verpflichtungen, die innerhalb eines Jahres fällig sind
- Umfassen Verbindlichkeiten aus Lieferungen und Leistungen, MwSt-Verbindlichkeiten, Gehaltsverbindlichkeiten
- Müssen ordentlich klassifiziert sein
- PCN Klasse 4

### Abschnitt 12.2 : Bezahlte Freizeit
- Müssen passiviert werden
- Verbindlichkeit für ungenutzte PTO erfassen
- Arbeitsrecht einhalten
- Genau verfolgen

### Abschnitt 12.3 : Kurzfristige Schulden
- Wechselverbindlichkeiten, die innerhalb eines Jahres fällig sind
- Muss Zinsen passivieren
- Kurzfristiger Teil langfristiger Schulden
- Ordentliche Klassifikation

### Abschnitt 12.4 : Luxemburgische PCN Klasse 4
- 44 : Lieferanten
- 4216 / 4614 : MwSt
- 462 : Sozialabgaben
- 461 : Steuern
- Muss ordentliche Konten verwenden

### Abschnitt 12.5 : MwSt-Verbindlichkeiten
- MwSt auf Verkäufen sammeln
- MwSt auf Käufen zahlen
- NettomwSt an Behörden
- Über eCDF abgeben
- Nach Satz verfolgen

### Abschnitt 12.6 : Sozialabgaben
- Arbeitnehmer- und Arbeitgeber-Teile
- Erhebliche Kosten
- Müssen rechtzeitig gezahlt werden
- Ordentliche Buchhaltung erforderlich
