# 12.1 Kurzfristige Verbindlichkeiten identifizieren und beschreiben

### Was sind kurzfristige Verbindlichkeiten ?

**Kurzfristige Verbindlichkeiten** sind Verpflichtungen, die :
- Innerhalb eines Jahres (oder Betriebszyklus, wenn länger) bezahlt werden müssen
- Mit kurzfristigen Vermögenswerten beglichen werden oder durch Schaffung neuer kurzfristiger Verbindlichkeiten
- Verbindlichkeiten aus Lieferungen und Leistungen, aufgelaufene Aufwendungen, kurzfristige Schulden, etc. umfassen

### Arten kurzfristiger Verbindlichkeiten

```
   │         │        │         │        │         │

```

*Alternativtext: Diagram showing the classification of current liabilities into three main categories: Trade Payables (Verbindlichkeiten, VAT Payable), Accrued Aufwendungen (Gehälter Payable, Social Charges Payable), and Short-Term Debt (Interest Payable, Notes Payable), demonstrating the different types of current liabilities.*

**Häufige kurzfristige Verbindlichkeiten :**

1. **Verbindlichkeiten aus Lieferungen und Leistungen** : Beträge, die Lieferanten geschuldet werden
2. **MwSt-Verbindlichkeiten** : MwSt, die Steuerbehörden geschuldet wird
3. **Gehaltsverbindlichkeiten** : Löhne, die Arbeitnehmern geschuldet werden
4. **Sozialabgaben-Verbindlichkeiten** : Sozialversicherungsbeiträge
5. **Zinsverbindlichkeiten** : Zinsen auf Darlehen
6. **Kurzfristige Wechselverbindlichkeiten** : Wechsel, die innerhalb eines Jahres fällig sind
7. **Nicht erbrachte Leistungen** : Vorauszahlungen
8. **Aufgelaufene Aufwendungen** : Aufwendungen, die entstanden, aber noch nicht bezahlt wurden
9. **Kurzfristiger Teil langfristiger Schulden** : Teil langfristiger Schulden, der innerhalb eines Jahres fällig ist
10. **Steuerverbindlichkeiten** : Einkommensteuer und andere Steuern

### Verbindlichkeiten aus Lieferungen und Leistungen

**Verbindlichkeiten aus Lieferungen und Leistungen** sind Beträge, die Lieferanten für auf Kredit gekaufte Waren oder Dienstleistungen geschuldet werden.

**Eigenschaften :**
- Entstehen aus Kreditkäufen
- Normalerweise innerhalb von 30-60 Tagen fällig
- Normalerweise keine Zinsen berechnet
- Wichtig für Cashflow-Management
- Müssen rechtzeitig bezahlt werden, um Beziehungen aufrechtzuerhalten

**Beispiel :**
- Inventar auf Kredit kaufen : €5,000

**Buchung :**
```
361    Inventar                   €5,000
44111  Verbindlichkeiten aus Lieferungen und Leistungen                        €5,000
Zur Erfassung des Kreditkaufs
```

**Zahlung :**
```
44111  Verbindlichkeiten aus Lieferungen und Leistungen            €5,000
5131   Kasse                                    €5,000
Zur Erfassung der Zahlung an Lieferanten
```

**PCN-Konto :**
- **44111** : Verbindlichkeiten aus Lieferungen und Leistungen - Lieferanten (Fournisseurs)

**Verwaltung von Verbindlichkeiten aus Lieferungen und Leistungen :**
- Zahlungsfälligkeiten verfolgen
- Vorteil von Skonti bei früher Zahlung nutzen
- Gute Lieferantenbeziehungen aufrechterhalten
- Alterung der Verbindlichkeiten überwachen
- Ausreichend Bargeld für Zahlungen sicherstellen

### Aufgelaufene Aufwendungen

**Aufgelaufene Aufwendungen** sind Aufwendungen, die entstanden, aber noch nicht bezahlt wurden.

**Häufige Arten :**
- Aufgelaufene Gehälter
- Aufgelaufene Zinsen
- Aufgelaufene Versorgungsleistungen
- Aufgelaufene Miete
- Aufgelaufene Steuern

**Beispiel : Aufgelaufene Gehälter**
- Arbeitnehmer arbeiteten letzte Woche des Monats
- Gehälter verdient, aber noch nicht bezahlt : €3,000

**Buchung :**
```
6211   Gehaltsaufwand           €3,000
4714   Gehaltsverbindlichkeiten                        €3,000
Zur Erfassung verdienter, aber noch nicht gezahlter Gehälter
```

**Bei Zahlung :**
```
4714   Gehaltsverbindlichkeiten            €3,000
5131   Kasse                                    €3,000
Zur Erfassung der Zahlung aufgelaufener Gehälter
```

### Nicht erbrachte Leistungen

**Nicht erbrachte Leistungen** (auch als aufgeschobene Erträge bezeichnet) sind Vorauszahlungen für noch nicht erbrachte Waren oder Dienstleistungen.

**Beispiel :**
- Kunde zahlt €1,000 im Voraus für Catering-Dienstleistungen
- Dienstleistungen werden nächsten Monat erbracht

**Buchung (Kasse erhalten) :**
```
5131   Kasse                        €1,000
482    Nicht erbrachte Leistungen                        €1,000
Zur Erfassung der Vorauszahlung
```

**Wenn Dienstleistungen erbracht werden :**
```
482    Nicht erbrachte Leistungen           €1,000
703    Dienstleistungserlöse                        €1,000
Zur Erfassung der Erträge, wenn Dienstleistungen erbracht werden
```

**PCN-Konto :**
- **482** : Nicht erbrachte Leistungen (Produits Différés)

### MwSt-Verbindlichkeiten

**MwSt-Verbindlichkeiten** ist MwSt, die auf Verkäufen gesammelt wurde und an Steuerbehörden gezahlt werden muss.

**Wie MwSt-Verbindlichkeiten entstehen :**
- Unternehmen sammelt MwSt auf Verkäufen
- MwSt wird zum Verkaufspreis hinzugefügt
- Unternehmen hält MwSt bis zur Zahlung an Behörden
- MwSt ist eine Verbindlichkeit bis zur Zahlung

**Beispiel :**
- Verkauf : €1,000 (ohne MwSt), MwSt 17%

**Buchung :**
```
5131   Kasse (oder 4011   Forderungen) €1,170
7061   Umsatzerlöse                          €1,000
461411 MwSt-Verbindlichkeiten                              €170
Zur Erfassung des Verkaufs mit MwSt
```

**Wichtig :** MwSt-Verbindlichkeiten werden zum Zeitpunkt des Verkaufs erfasst, nicht wenn Kasse erhalten wird. Dies gewährleistet ordentliche Periodenabgrenzung.

**Zahlung (MwSt-Erklärung) :**
```
461411 MwSt-Verbindlichkeiten                €170
5131   Kasse                                    €170
Zur Erfassung der MwSt-Zahlung
```

**PCN-Konto :**
- **461411** : MwSt-Verbindlichkeiten (TVA à Payer)

**MwSt-Verbindlichkeiten-Verwaltung :**
- MwSt auf allen Verkäufen verfolgen
- Muss MwSt-Erklärung abgeben (monatlich/vierteljährlich/jährlich)
- Muss vor Fälligkeit zahlen
- Strafen für verspätete Zahlung
- Muss ordentliche Aufzeichnungen führen

### Gehaltsverbindlichkeiten

**Gehaltsverbindlichkeiten** sind Löhne, die von Arbeitnehmern verdient, aber noch nicht gezahlt wurden.

**Beispiel :**
- Gehälter verdient, aber nicht bezahlt : €5,000

**Buchung :**
```
6211   Gehaltsaufwand           €5,000
4714   Gehaltsverbindlichkeiten                        €5,000
Zur Erfassung der Gehaltsverbindlichkeiten
```

**Zahlung :**
```
4714   Gehaltsverbindlichkeiten            €5,000
5131   Kasse                                    €5,000
Zur Erfassung der Gehaltszahlung
```

**PCN-Konto :**
- **4714** : Gehaltsverbindlichkeiten (Salaires à Payer)

### Luxemburgische Compliance-Hinweis

Kurzfristige Verbindlichkeiten in Luxemburg :
- Müssen ordentlich klassifiziert sein (PCN Klasse 4)
- Müssen genau erfasst werden
- Müssen rechtzeitig bezahlt werden
- MwSt und Sozialabgaben sind obligatorisch
- Strafen für verspätete Zahlung
- Müssen ordentliche Dokumentation führen
