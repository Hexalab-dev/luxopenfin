# 12.4 Luxemburgische kurzfristige Verbindlichkeiten (PCN Klasse 4 - Fournisseurs)

### PCN Klasse 4 : Tiers (Dritte Parteien)

**Klasse 4** enthält alle Verpflichtungen gegenüber Dritten.

**Kontobereiche :**
- 44 : Lieferanten (Fournisseurs)
- 40 : Kunden (Clients)
- 42 / 47 : Andere Dritte
- 4216 / 4614 : MwSt-Konten (TVA)
- 462 : Sozialabgaben (Charges Sociales)
- 461 : Steuerkonten (Impôts)
- 47 : Andere Verbindlichkeiten (Autres Dettes)
- 48 : Aufgeschobene Erträge (Produits Différés)

### Lieferantenkonten (44)

**Hauptkonten :**
- **44111** : Verbindlichkeiten aus Lieferungen und Leistungen - Lieferanten
- **4421** : Wechselverbindlichkeiten gegenüber Lieferanten
- **4421** : Wechselverbindlichkeiten
- **44113** : Anzahlungen an Lieferanten

### MwSt-Konten (4216 / 4614)

**Hauptkonten :**
- **461411** : MwSt-Verbindlichkeiten
- **421611** : MwSt erstattungsfähig
- **461412** : MwSt fällig
- **421612** : MwSt-Guthaben

### Sozialabgaben (462)

**Hauptkonten :**
- **4714** : Gehaltsverbindlichkeiten
- **4621** : Sozialabgaben-Verbindlichkeiten
- **4621** : Arbeitnehmer-Sozialabgaben-Verbindlichkeiten
- **4621** : Arbeitgeber-Sozialabgaben-Verbindlichkeiten

### Steuerkonten (461)

**Hauptkonten :**
- **46121** : Einkommensteuer-Verbindlichkeiten
- **46122** : Gemeindliche Gewerbesteuer-Verbindlichkeiten
- **461** : Andere Steuerverbindlichkeiten

### Luxemburgische Compliance-Hinweis

PCN Klasse 4 Anforderungen :
- Muss ordentliche Kontenklassifikationen verwenden
- Muss genaue Aufzeichnungen führen
- Muss alle Salden unterstützen
- Muss PCN-Struktur einhalten
- Muss ordentliche Berichterstattung ermöglichen
