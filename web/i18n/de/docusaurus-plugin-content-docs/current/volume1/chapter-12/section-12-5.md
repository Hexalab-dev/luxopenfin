# 12.5 Luxemburgische MwSt-Verbindlichkeitsbuchhaltung (Klasse 4 - TVA)

### MwSt-Verbindlichkeiten-Prozess

**MwSt-Sammlung :**
- MwSt auf Verkäufen sammeln
- Als MwSt-Verbindlichkeiten erfassen
- Muss an Behörden gezahlt werden

**MwSt-Erstattung :**
- MwSt auf Käufen zahlen
- Als MwSt erstattungsfähig erfassen
- Kann gegen MwSt-Verbindlichkeiten verrechnet werden

**NettomwSt :**
**NettomwSt = MwSt-Verbindlichkeiten - MwSt erstattungsfähig**

### MwSt-Erklärungsprozess

**Monatlich/Vierteljährlich/Jährlich :**
1. MwSt-Verbindlichkeiten berechnen (aus Verkäufen)
2. MwSt erstattungsfähig berechnen (aus Käufen)
3. NettomwSt berechnen
4. MwSt-Erklärung abgeben (eCDF)
5. NettomwSt zahlen

**Beispiel :**
- MwSt-Verbindlichkeiten : €5,000
- MwSt erstattungsfähig : €3,000
- NettomwSt : €2,000

**Buchung :**
```
461411 MwSt-Verbindlichkeiten                €2,000
421611 MwSt erstattungsfähig                        €2,000
5131   Kasse                                    €2,000
Zur Erfassung der NettomwSt-Zahlung
```

### MwSt-Sätze in Luxemburg

**Standard-Sätze :**
- 17% : Standardsatz (die meisten Waren und Dienstleistungen)
- 14% : Reduzierter Satz (einige Waren)
- 8% : Super-reduzierter Satz (einige Waren)
- 3% : Super-super-reduzierter Satz (Lebensmittel, Bücher, etc.)

**Muss nach Satz verfolgen :**
- Verschiedene Sätze für verschiedene Artikel
- Muss nach Satz in MwSt-Erklärung berichten
- Muss ordentliche Aufzeichnungen führen

### Luxemburgische Compliance-Hinweis

MwSt-Verbindlichkeiten in Luxemburg :
- Müssen genau berechnet werden
- Müssen rechtzeitig abgegeben werden (eCDF)
- Müssen rechtzeitig gezahlt werden
- Müssen nach Satz verfolgt werden
- Müssen Dokumentation führen
- Strafen für verspätete Zahlung
