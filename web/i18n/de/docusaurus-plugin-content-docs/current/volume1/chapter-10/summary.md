# Kapitel-Zusammenfassung

### Abschnitt 10.1 : Grundlegende Inventarbewertungsmethoden
- Drei Methoden : FIFO, Gewogener Durchschnitt, Spezifische Identifikation
- FIFO : Die zuerst gekauften Artikel sind die zuerst verkauften
- Gewogener Durchschnitt : Alle Einheiten haben die gleichen durchschnittlichen Kosten
- Spezifische Identifikation : Jeden Artikel individuell verfolgen
- LIFO nach Lux GAAP für vertretbare Gegenstände ebenfalls erlaubt (nach IFRS verboten)
- Muss konsistente Methode verwenden

### Abschnitt 10.2 : Periodische Methode
- Inventar nur am Periodenende aktualisiert
- HKV = Anfangsbestand + Einkäufe - Endbestand
- Endinventar aus körperlicher Zählung
- Kosten zugeordnet mit FIFO oder gewogenem Durchschnitt
- Anpassungsbuchungen übertragen auf HKV

### Abschnitt 10.3 : Perpetuelle Methode
- Inventar kontinuierlich aktualisiert
- HKV bei jedem Verkauf erfasst
- Kosten zugeordnet mit FIFO oder gewogenem Durchschnitt
- Immer aktuelles Inventar kennen
- Bessere Inventarkontrolle

### Abschnitt 10.4 : Auswirkungen von Inventarfehlern
- Endinventar überbewertet : HKV unterbewertet, Nettoergebnis überbewertet
- Endinventar unterbewertet : HKV überbewertet, Nettoergebnis unterbewertet
- Fehler korrigieren sich über zwei Perioden selbst
- Jahresabschlüsse jeder Periode sind immer noch falsch

### Abschnitt 10.5 : Inventarverwaltungs-Kennzahlen
- Inventarumschlag = HKV ÷ Durchschnittliches Inventar
- Tage Umsatz im Inventar = 365 ÷ Umschlag
- Höherer Umschlag = besser
- Niedrigere Tage = besser
- Variiert je nach Branche

### Abschnitt 10.6 : Luxemburgische Bewertungsmethoden
- FIFO, gewogener Durchschnitt und LIFO (vertretbare Gegenstände) erlaubt
- LIFO nur nach IFRS (IAS 2) verboten
- Muss konsistent sein
- Muss offengelegt werden
- Muss PCN einhalten

### Abschnitt 10.7 : Luxemburgische PCN Klasse 3
- 301 : Rohstoffe
- 311 : Unfertige Erzeugnisse
- 321 : Fertige Erzeugnisse
- 361 : Waren
- 607 : Herstellungskosten der verkauften Waren
- Muss ordentlich klassifiziert sein
