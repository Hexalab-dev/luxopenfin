# 10.2 Die Herstellungskosten der verkauften Waren und das Endinventar mit der periodischen Methode berechnen

### Periodisches Inventarsystem

In einem **periodischen Inventarsystem** werden die Inventaraufzeichnungen nur am Periodenende aktualisiert. Während der Periode werden Einkäufe in einem Einkaufskonto erfasst, und die Herstellungskosten der verkauften Waren werden am Periodenende berechnet.

### Formel für Herstellungskosten der verkauften Waren (Periodisch)

**Formel :**
**Herstellungskosten der verkauften Waren = Anfangsbestand + Einkäufe - Endbestand**

**Komponenten :**
- **Anfangsbestand** : Inventar zu Beginn der Periode
- **Einkäufe** : Während der Periode gekaufte Waren
- **Endbestand** : Inventar am Ende der Periode (aus körperlicher Zählung)

### Berechnung des Endinventars (Periodisch)

**Schritte :**
1. Körperliche Inventarzählung am Periodenende durchführen
2. Kosten jedes Artikels bestimmen (unter Verwendung der Kostenflussannahme)
3. Gesamtwert des Endinventars berechnen

### Beispiel : FIFO mit periodischem System

**Informationen :**
- Anfangsbestand (1. Jan) : 100 Einheiten @ €10 = €1,000
- Einkäufe :
  - 10. Jan : 150 Einheiten @ €12 = €1,800
  - 20. Jan : 200 Einheiten @ €14 = €2,800
- Körperliche Zählung (31. Jan) : 180 Einheiten vorhanden

**FIFO-Kostenzuordnung :**
- Älteste Kosten sind in HKV, neueste Kosten im Endinventar
- Endinventar (180 Einheiten) : Neueste Einkäufe
  - 180 Einheiten @ €14 = €2,520 (vom Einkauf am 20. Jan)

**Berechnung der Herstellungskosten der verkauften Waren :**
- Anfangsbestand : €1,000
- Einkäufe : €1,800 + €2,800 = €4,600
- Verfügbare Waren : €1,000 + €4,600 = €5,600
- Endinventar : €2,520
- **Herstellungskosten der verkauften Waren : €5,600 - €2,520 = €3,080**

**Überprüfung :**
- Verkaufte Einheiten : 100 + 150 + 200 - 180 = 270 Einheiten
- HKV : 100 @ €10 + 150 @ €12 + 20 @ €14 = €1,000 + €1,800 + €280 = €3,080 ✓

### Beispiel : Gewogener Durchschnitt mit periodischem System

**Gleiche Informationen :**
- Anfangsbestand : 100 Einheiten @ €10 = €1,000
- Einkäufe :
  - 10. Jan : 150 Einheiten @ €12 = €1,800
  - 20. Jan : 200 Einheiten @ €14 = €2,800
- Gesamt verfügbar : 450 Einheiten @ €12,44 Durchschnitt = €5,600
- Körperliche Zählung : 180 Einheiten

**Gewogene Durchschnittskosten :**
- Gesamtkosten : €5,600
- Gesamteinheiten : 450
- Durchschnittskosten : €5,600 ÷ 450 = €12,44 pro Einheit

**Kostenzuordnung :**
- Endinventar : 180 Einheiten @ €12,44 = €2,239
- Herstellungskosten der verkauften Waren : 270 Einheiten @ €12,44 = €3,361

**Überprüfung :**
- HKV + End = €3,361 + €2,239 = €5,600 ✓

### Anpassungsbuchungen (Periodisch)

**Am Periodenende :**

**Schritt 1 : Anfangsbestand und Einkäufe auf HKV übertragen**
```
607    Herstellungskosten der verkauften Waren          €5,600
361    Inventar (Anfang)                   €1,000
6061   Einkäufe                                 €4,600
Zur Übertragung von Anfangsbestand und Einkäufen auf HKV
```

**Schritt 2 : Endinventar erfassen**
```
361    Inventar (Ende)          €2,520
607    Herstellungskosten der verkauften Waren                      €2,520
Zur Erfassung des Endinventars (FIFO-Beispiel)
```

**Ergebnis :**
- Herstellungskosten der verkauften Waren : €5,600 - €2,520 = €3,080
- Inventar : €2,520

### Luxemburgische Überlegungen

**Periodisches System :**
- Weniger häufig in modernen Unternehmen
- Wird noch von einigen kleinen Unternehmen verwendet
- Erfordert körperliche Zählung am Periodenende
- Muss konsistente Kostenflussannahme verwenden

### Luxemburgische Compliance-Hinweis

Für periodisches Inventar in Luxemburg :
- Muss konsistente Bewertungsmethode verwenden (FIFO oder gewogener Durchschnitt)
- Muss körperliche Zählung durchführen
- Muss Endinventar ordnungsgemäß bewerten
- Muss Herstellungskosten der verkauften Waren genau berechnen
- Muss PCN Klasse 3 Anforderungen einhalten
- Muss ordentliche Dokumentation führen
