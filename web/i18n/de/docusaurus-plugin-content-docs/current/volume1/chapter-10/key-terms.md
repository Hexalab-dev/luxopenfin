# Schlüsselbegriffe

- **Kostenflussannahme** : Methode zur Zuordnung von Kosten zu verkauften Waren und Endinventar
- **FIFO (First-In, First-Out)** : Inventarmethode, die annimmt, dass die zuerst gekauften Artikel die zuerst verkauften sind
- **Inventarumschlag** : Kennzahl, die misst, wie oft Inventar verkauft und ersetzt wird
- **Periodisches Inventarsystem** : System, in dem Inventar nur am Periodenende aktualisiert wird
- **Perpetuielles Inventarsystem** : System, in dem Inventar kontinuierlich aktualisiert wird
- **Spezifische Identifikation** : Inventarmethode, die die spezifischen Kosten jedes Artikels verfolgt
- **Gewogener Durchschnitt** : Inventarmethode, die Durchschnittskosten für alle Einheiten verwendet
- **Tage Umsatz im Inventar** : Durchschnittliche Anzahl von Tagen, die Inventar vor dem Verkauf gehalten wird
