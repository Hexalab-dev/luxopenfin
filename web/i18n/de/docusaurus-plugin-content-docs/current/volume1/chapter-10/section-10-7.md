# 10.7 Luxemburgische PCN Klasse 3 Inventarkonten

### PCN Klasse 3 : Inventar

**Klasse 3** im PCN enthält alle inventarbezogenen Konten.

**Kontobereiche :**
- 30 : Rohstoffe
- 31 : Unfertige Erzeugnisse
- 32 : Fertige Erzeugnisse
- 361 : Waren

### Hauptinventarkonten

#### 301 : Rohstoffe

**Verwendung :**
- Materialien, die in der Produktion verwendet werden
- Zutaten für die Fertigung
- Zu montierende Komponenten

**Beispiel :** Fertigungsunternehmen
```
301    Rohstoffe              €5,000
```

#### 311 : Unfertige Erzeugnisse

**Verwendung :**
- Teilweise fertiggestellte Produkte
- Fertigung in Arbeit
- Bau in Arbeit

**Beispiel :** Fertigungsunternehmen
```
311    Unfertige Erzeugnisse           €3,000
```

#### 321 : Fertige Erzeugnisse

**Verwendung :**
- Fertiggestellte Produkte, bereit zum Verkauf
- Fertigungsunternehmen
- Produkte, die auf Verkauf warten

**Beispiel :** Fertigungsunternehmen
```
321    Fertige Erzeugnisse             €8,000
```

#### 361 : Waren

**Verwendung :**
- Zum Wiederverkauf gekaufte Waren
- Einzelhandelsunternehmen
- Großhandelsunternehmen
- Restaurants (Einzelhandelsartikel)

**Beispiel :** Einzelhandelsgeschäft
```
361    Waren                €15,000
```

### Inventar-Unterkonten

**Kann Unterkonten erstellen :**
- 3611 : Waren - Kategorie A
- 3612 : Waren - Kategorie B
- 3011 : Rohstoffe - Typ X
- 3012 : Rohstoffe - Typ Y

**Zweck :**
- Bessere Verfolgung
- Mehrere Produkttypen
- Verschiedene MwSt-Sätze
- Bessere Verwaltung

### Konten für Herstellungskosten der verkauften Waren

**PCN-Konten :**
- **607** : Herstellungskosten der verkauften Waren
- **601** : Verbrauch von Rohstoffen
- **607** : Herstellungskosten der verkauften Erzeugnisse

**Für Einzelhandelsunternehmen :**
- Verwenden 607 : Herstellungskosten der verkauften Waren

**Für Fertigung :**
- Verwenden 601 : Verbrauch von Rohstoffen
- Verwenden 607 : Herstellungskosten der verkauften Erzeugnisse

### Inventarbewertungskonten

**Rückstellungskonten :**
- **3619** : Wertberichtigung des Inventars

**Verwendung :**
- Wenn Inventarwert unter Kosten liegt
- Abschreibungen auf Nettoveräußerungswert
- Veraltetes Inventar

### Luxemburgische Compliance-Hinweis

PCN Klasse 3 Inventarkonten müssen :
- Ordentlich klassifiziert sein
- Richtige Kontonummern verwenden
- Inventarwerte unterstützen
- Ordentliche Berechnung der Herstellungskosten der verkauften Waren ermöglichen
- Jahresabschlussdarstellung unterstützen
- PCN-Anforderungen einhalten
