# Schlüsselbegriffe

- **Rechnungswesen-Informationssystem (RIS)** : System, das Finanzinformationen sammelt, verarbeitet, speichert und berichtet
- **Kassenausgangsjournal** : Spezielles Journal, das alle ausgezahlten Barmittel erfasst
- **Kasseneingangsjournal** : Spezielles Journal, das alle erhaltenen Barmittel erfasst
- **eCDF** : Elektronische Sammlung von Finanzdaten - Luxemburgs elektronische Einreichungsplattform
- **FAIA** : Fichier d'Audit Informatisé AED - Computergestützte Prüfdatei (XML, OECD SAF-T)
- **Fiskale Registrierkasse** : Zertifizierte Registrierkasse, die rechtliche Anforderungen erfüllt
- **Hauptjournal** : Journal für Transaktionen, die nicht in spezielle Journale passen
- **Einkaufsjournal** : Spezielles Journal, das Kreditkäufe erfasst
- **Verkaufsjournal** : Spezielles Journal, das Kreditverkäufe erfasst
- **Nebenbuch** : Detailliertes Buch für einzelne Elemente (Kunden, Lieferanten), die ein Hauptbuch-Kontrollkonto unterstützen
