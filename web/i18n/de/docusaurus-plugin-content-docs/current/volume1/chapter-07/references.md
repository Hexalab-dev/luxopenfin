# Referenzen und weiterführende Literatur

### Offizielle luxemburgische Quellen

- **eCDF-Plattform** : https://ecdf.public.lu
  - Elektronische Einreichungsverfahren
  - Benutzerhandbücher und Tutorials
  - Technische Anforderungen

- **Guichet.lu - Digitale Rechnungsstellung** : https://guichet.public.lu/en/entreprises/fiscalite/tva/facturation-electronique.html
  - Anforderungen an digitale Rechnungen
  - Formatspezifikationen
  - Compliance-Richtlinien

- **Administration des Contributions Directes (ACD)** : https://impotsdirects.public.lu
  - FAIA-Anforderungen
  - Prüfungsverfahren
  - Technische Spezifikationen

  - Luxemburgische Lokalisierung
