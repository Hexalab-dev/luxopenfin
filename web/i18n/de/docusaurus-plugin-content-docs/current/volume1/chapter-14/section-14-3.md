# 14.3 Transaktionen und Auswirkungen auf Jahresabschlüsse für Bardividenden, Sachdividenden, Aktiendividenden und Aktiensplits erfassen

### Bardividenden

**Bardividenden :**
- Ausschüttung von Kasse an Aktionäre
- Reduzieren Gewinnrücklagen
- Schaffen Verbindlichkeit bei Erklärung

**Erklärung :**
```
141    Gewinnrücklagen          €5,000
4712   Dividendenverbindlichkeiten                      €5,000
Zur Erklärung der Bardividende
```

**Zahlung :**
```
4712   Dividendenverbindlichkeiten          €5,000
5131   Kasse                                   €5,000
Zur Zahlung der Bardividende
```

### Aktiendividenden

**Aktiendividenden :**
- Ausschüttung zusätzlicher Aktien
- Keine Kasse gezahlt
- Reduzieren Gewinnrücklagen
- Erhöhen Grundkapital

**Beispiel :**
- 10% Aktiendividende auf 10,000 Aktien
- Ausgabe 1,000 neue Aktien

**Buchung :**
```
141    Gewinnrücklagen          €[Betrag]
101    Grundkapital                           €[Betrag]
Zur Erfassung der Aktiendividende
```

### Aktiensplits

**Aktiensplits :**
- Erhöhen Anzahl der Aktien
- Reduzieren Nennwert proportional
- Keine Buchung (nur Vermerk)
- Keine Änderung des Gesamteigenkapitals

**Beispiel :**
- 2-für-1 Aktiensplit
- 10,000 Aktien @ €10 Nennwert → 20,000 Aktien @ €5 Nennwert
- Keine Buchung erforderlich

### Luxemburgische Compliance-Hinweis

Dividenden in Luxemburg :
- Muss Gesellschaftsrecht einhalten
- Muss ausreichende Gewinnrücklagen haben
- Muss Ausschüttungsregeln einhalten
- Muss ordentliche PCN-Konten verwenden
- Steuerauswirkungen gelten
