# 14.2 Transaktionen für Aktienausgabe und -rückkauf analysieren und erfassen

### Aktienausgabe

**Zum Nennwert :**
- Ausgabepreis = Nennwert
- Zum Nennwert erfassen

**Über Nennwert :**
- Ausgabepreis > Nennwert
- Nennwert zu Grundkapital
- Überschuss zu Agio

**Beispiel :**
- Ausgabe 1,000 Aktien, Nennwert €1, Ausgabepreis €10
- Nennwert : €1,000
- Agio : €9,000

**Buchung :**
```
5131   Kasse                       €10,000
101    Grundkapital                          €1,000
111    Agio                           €9,000
Zur Erfassung der Aktienausgabe über Nennwert
```

**PCN-Konten :**
- **101** : Grundkapital
- **111** : Agio (Prime d'Émission)

### Aktienrückkauf

**Eigene Aktien :**
- Unternehmen kauft eigene Aktien zurück
- Reduziert ausstehende Aktien
- Als Gegen-Eigenkapital erfasst

**Beispiel :**
- Rückkauf 100 Aktien zu €12 pro Aktie

**Buchung :**
```
502    Eigene Aktien             €1,200
5131   Kasse                                   €1,200
Zur Erfassung des Aktienrückkaufs
```

**PCN-Konto :**
- **502** : Eigene Aktien (Actions Propres)

### Luxemburgische Compliance-Hinweis

Aktientransaktionen in Luxemburg :
- Muss Gesellschaftsrecht einhalten
- Muss ordentliche PCN-Konten verwenden
- Muss Aufzeichnungen führen
- Muss beim RCS hinterlegen
- Muss formenspezifische Regeln einhalten
