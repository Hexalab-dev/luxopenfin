# 14.5 Anwendbarkeit des Gewinns je Aktie als Methode zur Leistungsmessung diskutieren

### Gewinn je Aktie (GPA)

**GPA-Formel :**
**GPA = Nettoeinkommen ÷ Gewichtete Durchschnittsanzahl ausstehender Aktien**

**Zweck :**
- Rentabilität pro Aktie messen
- Zwischen Unternehmen vergleichen
- Wichtig für Investoren

**Beispiel :**
- Nettoeinkommen : €50,000
- Ausstehende Aktien : 10,000
- GPA : €50,000 ÷ 10,000 = €5.00 pro Aktie

### Luxemburgische Überlegungen

**GPA in Luxemburg :**
- Erforderlich für öffentliche Unternehmen
- Optional für private Unternehmen
- Nützlich zur Leistungsmessung
- Kann für jede Gesellschaft berechnet werden

### Luxemburgische Compliance-Hinweis

GPA in Luxemburg :
- Erforderliche Offenlegung für einige Unternehmen
- Muss korrekt berechnet werden
- Muss offengelegt werden, wenn wesentlich
- Nützlich für Analyse
