# 14.7 Luxemburgische Grundkapitalbuchhaltung (PCN Klasse 1)

### PCN Klasse 1 : Financement Permanent

**Klasse 1** enthält Eigenkapital und langfristige Finanzierung.

**Kontobereiche :**
- 10–13 : Grundkapital (Capital Social)
- 13 : Rücklagen (Réserves)
- 19 : Langfristige Schulden

### Grundkapitalkonten

**Hauptkonten :**
- **101** : Grundkapital (Capital Social)
- **111** : Agio (Prime d'Émission)
- **131** : Gesetzliche Rücklage (Réserve Légale)
- **138** : Andere Rücklagen (Autres Réserves)
- **141** : Gewinnrücklagen (Résultat Reporté)

### Luxemburgische Compliance-Hinweis

PCN Klasse 1 Anforderungen :
- Muss ordentliche Kontenklassifikationen verwenden
- Muss genaue Aufzeichnungen führen
- Muss PCN-Struktur einhalten
- Muss alle Salden unterstützen
- Muss ordentliche Berichterstattung ermöglichen
