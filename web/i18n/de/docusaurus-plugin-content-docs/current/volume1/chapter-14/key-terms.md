# Schlüsselbegriffe

- **Dividenden** : Ausschüttungen an Aktionäre
- **Gewinn je Aktie (GPA)** : Nettoeinkommen pro Aktie
- **Gewinnrücklagen** : Akkumulierte nicht ausgeschüttete Gewinne
- **Grundkapital** : Von Eigentümern investierter Betrag
- **Aktiendividende** : Ausschüttung zusätzlicher Aktien
- **Aktiensplit** : Aktien erhöhen, Nennwert proportional verringern
- **Eigene Aktien** : Von Unternehmen zurückgekaufte eigene Aktien
