# 9.9 Luxemburgische MwSt auf Forderungen und Rückstellungen für Forderungsausfälle

### MwSt bei Kreditverkäufen

**MwSt-Erfassung :**
- MwSt ist fällig, wenn Verkauf getätigt wird (Umsatzerlöse erfasst)
- Nicht wenn Bargeld erhalten wird
- MwSt-Verbindlichkeit zum Zeitpunkt des Verkaufs erstellt

**Beispiel :**
- Kreditverkauf : €1,000 (ohne MwSt), MwSt 17%
- Umsatzerlöse : €1,000
- MwSt-Verbindlichkeit : €170
- Forderungen aus Lieferungen und Leistungen : €1,170

**Journalbuchung :**
```
4011   Forderungen aus Lieferungen und Leistungen        €1,170
7061   Umsatzerlöse                          €1,000
461411 MwSt-Verbindlichkeit                                  €170
Zur Erfassung des Kreditverkaufs mit MwSt
```

### MwSt wenn Forderung uneinbringlich wird

**MwSt-Erstattung :**
- Wenn Forderung uneinbringlich wird, kann MwSt erstattungsfähig sein
- Muss luxemburgische MwSt-Regeln befolgen
- Ordentliche Dokumentation erforderlich
- Kann MwSt-Verbindlichkeit anpassen müssen

**Bedingungen für MwSt-Erstattung :**
- Forderung muss definitiv uneinbringlich sein
- Ordentliche Dokumentation (Rechtsverfahren, Insolvenz, etc.)
- Muss MwSt ursprünglich gezahlt haben
- Muss luxemburgische MwSt-Verfahren befolgen

**Beispiel :**
- Forderung von €1,170 (€1,000 + €170 MwSt) wird uneinbringlich
- MwSt ist erstattungsfähig

**Journalbuchung (Abschreibung) :**
```
4019   Rückstellung für zweifelhafte Forderungen €1,000
4011   Forderungen aus Lieferungen und Leistungen                                €1,000
Zur Abschreibung des Nettobetrags gegen die Wertberichtigung
```

**Journalbuchung (MwSt-Erstattung) :**
```
461411 MwSt-Verbindlichkeit                  €170
4011   Forderungen aus Lieferungen und Leistungen                    €170
Zur Berichtigung der Umsatzsteuer auf die uneinbringliche Forderung
```

Kontrolle: 4011 wird mit €1,000 + €170 = €1,170 im Haben gebucht und ist damit ausgeglichen. Beide Buchungen können zusammengefasst werden (Soll 4019 €1,000, Soll 461411 €170, Haben 4011 €1,170). Die Wertberichtigung deckt nur den Nettobetrag; die ursprünglich erklärte Umsatzsteuer wird berichtigt, sobald die Forderung endgültig uneinbringlich ist. Ohne Wertberichtigung (direkte Abschreibung) wird statt 4019 das Konto 6451 Verluste aus uneinbringlichen Forderungen mit €1,000 belastet.

### Rückstellungen für Forderungsausfälle und Steuern

**Steuerbehandlung :**
- Rückstellungen für Forderungsausfälle können steuerlich absetzbar sein
- Muss luxemburgische Steuervorschriften befolgen
- Muss vernünftig und nachweisbar sein
- Kann Anpassung für Steuerzwecke erfordern

**Luxemburgische Regeln :**
- Rückstellungen müssen auf vernünftigen Schätzungen basieren
- Müssen dokumentiert sein
- Können für Steuerzwecke angepasst werden
- Spezifische Regeln gelten

### MwSt-Erklärungsauswirkungen

**MwSt bei Verkäufen :**
- Gemeldet in Periode, in der Verkauf getätigt wird
- Nicht wenn Bargeld erhalten wird
- Muss MwSt nach Satz verfolgen

**MwSt-Erstattung :**
- Gemeldet, wenn Forderung abgeschrieben wird
- Muss ordentliche Dokumentation haben
- Kann Anpassung einreichen müssen

### Luxemburgische Compliance-Hinweis

MwSt auf Forderungen in Luxemburg :
- MwSt fällig, wenn Verkauf getätigt wird
- MwSt kann bei Forderungsausfällen erstattungsfähig sein
- Muss ordentliche Verfahren befolgen
- Muss Dokumentation führen
- Muss korrekt in MwSt-Erklärung melden
- Muss luxemburgische MwSt-Regeln einhalten

### Dokumentationsanforderungen

**Erforderliche Dokumentation :**
- Originalrechnungen
- Nachweis von Einzugsbemühungen
- Rechtsverfahren (falls zutreffend)
- Insolvenzdokumente (falls zutreffend)
- MwSt-Erstattungsdokumentation
- Berechnungen der Rückstellungen für Forderungsausfälle
