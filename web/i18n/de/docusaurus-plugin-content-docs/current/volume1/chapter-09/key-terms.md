# Schlüsselbegriffe

- **Forderungen aus Lieferungen und Leistungen** : Beträge, die dem Unternehmen von Kunden geschuldet werden, die auf Kredit gekauft haben
- **Forderungsumschlag** : Kennzahl, die misst, wie oft Forderungen eingezogen werden
- **Rückstellung für zweifelhafte Forderungen** : Gegenkonto zum Vermögen, das uneinbringliche Forderungen schätzt
- **Rückstellungsmethode** : Methode zur Buchhaltung von Forderungsausfällen mit Schätzungen
- **Durchschnittliche Einzugsdauer** : Durchschnittliche Anzahl von Tagen, um Forderungen einzuziehen
- **Forderungsausfallaufwand** : Aufwand für uneinbringliche Forderungen
- **Direkte Abschreibungsmethode** : Abschreibung von Forderungsausfällen, wenn sie auftreten (nicht bevorzugt)
- **Wechselforderungen** : Formelles schriftliches Zahlungsversprechen mit Zinsen
- **Prinzip der Umsatzerlöserfassung** : Umsatzerlöse erfasst, wenn verdient, nicht wenn Bargeld erhalten
- **Uneinbringliche Forderungen** : Forderungen aus Lieferungen und Leistungen, die nicht eingezogen werden können (Forderungsausfälle)
