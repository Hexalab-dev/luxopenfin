# Referenzen und weiterführende Literatur

### Offizielle luxemburgische Quellen

- **Guichet.lu - MwSt bei Forderungsausfällen** : https://guichet.public.lu/en/entreprises/fiscalite/tva/
  - MwSt-Erstattung bei Forderungsausfällen
  - Dokumentationsanforderungen
  - Verfahren

- **Administration des Contributions Directes (ACD)** : https://impotsdirects.public.lu
  - Steuerbehandlung von Forderungsausfällen
  - Rückstellungen für Forderungsausfälle
  - Dokumentationsanforderungen

- **Commission des Normes Comptables (CNC)** : https://cnc.lu
  - PCN-Anforderungen für Forderungen
  - Rechnungslegungsstandards
  - Jahresabschlussdarstellung

### Rechnungslegungsstandards

- **Luxemburg GAAP** : Rechnungslegungsstandards für Forderungen
- **IFRS** : Internationale Standards (falls zutreffend)

### Bildungsressourcen

- **House of Training** : https://www.houseoftraining.lu
  - Kurse zur Forderungsverwaltung
  - Kreditverwaltungsschulung
  - Buchhaltungskurse

### Weiterführende Literatur

- "Précis de droit comptable" von Denis Colin (Legitech)
  - Luxemburgische Forderungsbuchhaltung
  - PCN Klasse 4 Anforderungen
  - MwSt auf Forderungen

- OpenStax Principles of Financial Accounting
  - Universelle Forderungskonzepte
  - Forderungsausfallbuchhaltung
  - Forderungsverwaltung
