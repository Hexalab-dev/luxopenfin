# 9.6 Andere Arten von Forderungen identifizieren und buchen

### Arten von Forderungen

Neben Forderungen aus Lieferungen und Leistungen können Unternehmen andere Arten von Forderungen haben :

1. **Wechselforderungen** (in nächster Sektion behandelt)
2. **Sonstige Forderungen**
3. **Vorschüsse an Mitarbeiter**
4. **Steuererstattungen**
5. **Zinserträge**

### Sonstige Forderungen

**Sonstige Forderungen** umfassen verschiedene Beträge, die dem Unternehmen geschuldet werden und keine Handelsforderungen sind.

**Beispiele :**
- Versicherungsansprüche
- Steuererstattungen
- Anzahlungen bei Lieferanten
- Vorschüsse an Mitarbeiter
- Verschiedene Forderungen

**PCN-Konto :**
- 4218 : Sonstige Forderungen (Klasse 4)

**Beispiel : Versicherungsanspruch :**
```
4218   Sonstige Forderungen          €2,000
[Angemessenes Konto]                          €2,000
Zur Erfassung des Versicherungsanspruchs
```

### Vorschüsse an Mitarbeiter

**Mitarbeitervorschüsse :**
- Geld an Mitarbeiter vorgestreckt
- Normalerweise durch Lohnabzug zurückgezahlt
- Umlaufvermögen

**PCN-Konto :**
- 42111 : Vorschüsse an Mitarbeiter (Klasse 4)

**Beispiel :**
- Vorschuss von €500 an Mitarbeiter

**Journalbuchung :**
```
42111  Vorschüsse an Mitarbeiter      €500
5131   Kasse                                    €500
Zur Erfassung des Vorschusses an Mitarbeiter
```

**Rückzahlung :**
```
6211   Lohnaufwand           €2,000
42111  Vorschüsse an Mitarbeiter                   €500
5131   Kasse (oder 4714   Lohnverbindlichkeiten)      €1,500
Zur Erfassung der Lohnzahlung mit Vorschussabzug
```

### Steuererstattungen

**Steuererstattungen :**
- Überzahlung von Steuern
- Erstattung von Steuerbehörden erwartet
- Umlaufvermögen

**PCN-Konto :**
- 4214 : Steuererstattungen (Klasse 4)

**Beispiel :**
- MwSt-Erstattung von €1,000 erwartet

**Journalbuchung :**
```
4214   Steuererstattungen     €1,000
421611 MwSt-Erstattungsanspruch (oder 461411 MwSt-Verbindlichkeit) €1,000
Zur Erfassung der erwarteten MwSt-Erstattung
```

**Bei Erhalt :**
```
5131   Kasse                        €1,000
4214   Steuererstattungen                  €1,000
Zur Erfassung des Erhalts der Steuererstattung
```

### Zinserträge

**Zinserträge :**
- Zinsen verdient, aber noch nicht erhalten
- Normalerweise auf Wechselforderungen oder Investitionen
- Umlaufvermögen

**PCN-Konto :**
- 4218 : Zinserträge (Klasse 4)

**Beispiel :**
- Zinsen von €100 verdient, aber nicht erhalten

**Journalbuchung :**
```
4218   Zinserträge        €100
7552   Zinserträge                        €100
Zur Erfassung der Zinserträge
```

**Bei Erhalt :**
```
5131   Kasse                        €100
4218   Zinserträge                                €100
Zur Erfassung des Erhalts der Zinsen
```

### Luxemburgische Compliance-Hinweis

Sonstige Forderungen in Luxemburg müssen :
- Ordentlich klassifiziert sein (PCN Klasse 4)
- Angemessen bewertet sein
- Einziehbar sein
- Ordentliche Dokumentation führen
- Können Steuerberechnungen beeinflussen
