# 9.8 Luxemburgische Kundenkontoverwaltung (PCN Klasse 4 - Tiers)

### PCN Klasse 4 : Tiers (Dritte Parteien)

**Klasse 4** im PCN enthält alle Konten, die sich auf Dritte beziehen (Kunden, Lieferanten, Mitarbeiter, Regierung, etc.).

**Kontobereiche :**
- 44 : Lieferanten
- 40 : Kunden
- 42 / 47 : Andere Dritte Parteien
- 4216 / 4614 : MwSt-Konten
- 462 : Sozialabgaben
- 461 : Steuerkonten
- 47 : Andere Verbindlichkeiten
- 48 : Aufgeschobene Umsatzerlöse
- 18 : Rückstellungen
- 4019 (value adjustments on customers) : Wertberichtigungen und Rückstellungen

### Kundenkonten (40)

**Hauptkonten :**
- **4011** : Forderungen aus Lieferungen und Leistungen - Kunden
- **4012** : Wechselforderungen
- **4012** : Wechselforderungen
- **4012** : Scheckforderungen
- **4311** : Anzahlungen von Kunden
- **4013** : Zweifelhafte Forderungen

**Unterkonten :**
- Kann Unterkonten für einzelne Kunden erstellen
- Beispiel : 40111 (Kunde A), 40112 (Kunde B)

### Lieferantenkonten (44)

**Hauptkonten :**
- **44111** : Verbindlichkeiten aus Lieferungen und Leistungen - Lieferanten
- **4421** : Wechselverbindlichkeiten
- **4421** : Wechselverbindlichkeiten
- **4421** : Scheckverbindlichkeiten
- **44113** : Anzahlungen an Lieferanten

### MwSt-Konten (4216 / 4614)

**Hauptkonten :**
- **461411** : MwSt-Verbindlichkeit
- **421611** : MwSt-Erstattungsanspruch
- **461412** : MwSt fällig
- **421612** : MwSt-Guthaben

### Rückstellung für zweifelhafte Forderungen

**PCN-Konto :**
- **4019** : Rückstellung für zweifelhafte Forderungen (Wertberichtigung der Forderungen aus Lieferungen und Leistungen)

**Darstellung :**
- Gegenkonto zum Vermögen
- Von Forderungen aus Lieferungen und Leistungen abgezogen
- Zeigt realisierbaren Nettowert

### Kundenkontoverwaltung

**Beste Praktiken :**

1. **Kontoeinrichtung**
   - Unterkonto für jeden Kunden erstellen
   - Kundeninformationen einbeziehen
   - Kreditlimits festlegen
   - Zahlungsbedingungen definieren

2. **Transaktionserfassung**
   - Alle Verkäufe schnell erfassen
   - Alle Zahlungen schnell erfassen
   - Zahlungen Rechnungen zuordnen
   - Salden regelmäßig aktualisieren

3. **Überwachung**
   - Regelmäßige Altersstrukturberichte
   - Kreditlimits überwachen
   - Zahlungshistorie verfolgen
   - Problematische Konten identifizieren

4. **Einzug**
   - Überfällige Konten nachverfolgen
   - Erinnerungen senden
   - Bei Bedarf eskalieren
   - Einzugsbemühungen dokumentieren

### Luxemburgische Compliance-Hinweis

Kundenkontoverwaltung in Luxemburg muss :
- Ordentliche PCN-Konten verwenden (Klasse 4)
- Genaue Aufzeichnungen führen
- MwSt-Compliance unterstützen
- Forderungsausfallschätzung ermöglichen
- Prüfungsanforderungen unterstützen
- Ordentliche Dokumentation führen
