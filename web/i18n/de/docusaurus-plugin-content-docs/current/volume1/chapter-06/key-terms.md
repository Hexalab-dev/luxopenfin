# Schlüsselbegriffe

- **Kosten der verkauften Waren (COGS)** : Kosten der während der Periode verkauften Waren
- **Bruttogewinn** : Umsatzerlöse - Kosten der verkauften Waren
- **Bruttogewinnmarge** : (Bruttogewinn ÷ Nettoumsätze) × 100
- **Vorräte** : Zum Verkauf im normalen Geschäftsverlauf gehaltene Waren
- **Handelsunternehmen** : Unternehmen, das fertige Waren kauft und weiterverkauft
- **Nettoumsätze** : Bruttoumsätze - Verkaufsrückgaben - Verkaufsrabatte - Verkaufsskonti
- **Permanentes Lagerbestandssystem** : Vorräte kontinuierlich mit jedem Kauf und Verkauf aktualisiert
- **Periodisches Lagerbestandssystem** : Vorräte nur am Periodenende aktualisiert
- **Kaufskonto** : Rabatt für frühe Zahlung an Lieferanten
- **Verkaufsskonto** : Rabatt für frühe Zahlung durch Kunden
- **Verkaufsrückgaben** : Von Kunden zurückgegebene Waren
- **Verkaufsrabatte** : Preisreduktionen für beschädigte Waren, die von Kunden behalten werden
