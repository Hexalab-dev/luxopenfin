# Kapitel-Zusammenfassung

### Abschnitt 6.1 : Handelsgeschäfte definieren und beschreiben
- Handelsunternehmen kaufen und verkaufen fertige Waren weiter
- Unterschiedlich von Dienstleistungsunternehmen (haben Vorräte und COGS)
- Gewinn- und Verlustrechnung enthält : Verkäufe - COGS = Bruttogewinn - Aufwendungen = Nettoergebnis
- Vorräte sind ein Schlüsselvermögen (PCN Klasse 3)
- Häufig in Luxemburg : Einzelhandel, Großhandel, E-Commerce, gemischte Unternehmen

### Abschnitt 6.2 : Permanente und periodische Lagerbestandssysteme vergleichen und gegenüberstellen
- Permanent : Vorräte kontinuierlich aktualisiert, COGS zum Verkaufszeitpunkt
- Periodisch : Vorräte am Periodenende aktualisiert, COGS am Periodenende berechnet
- Permanentes System ist für die meisten modernen Unternehmen bevorzugt
- Luxemburgische Unternehmen verwenden typischerweise permanentes System
- Beide Systeme unter PCN akzeptabel

### Abschnitt 6.3 : Transaktionen für Warenkäufe analysieren und erfassen
- Käufe im Vorratskonto (permanent) oder Käufe-Konto (periodisch) erfasst
- Muss MwSt-Vorsteuer separat erfassen
- Kaufrückgaben und -rabatte reduzieren Vorräte
- Kaufskonti reduzieren Vorratskosten
- Verschiedene MwSt-Sätze erfordern separate Verfolgung

### Abschnitt 6.4 : Transaktionen für Warenverkäufe analysieren und erfassen
- Verkäufe erfasst : Umsatz und MwSt-Verbindlichkeiten
- COGS erfasst : Kosten der verkauften Waren und Reduzierung der Vorräte
- Verkaufsrückgaben und -rabatte reduzieren Umsatz
- Verkaufsskonti reduzieren Umsatz
- Verschiedene MwSt-Sätze auf Verkäufe erfordern sorgfältige Verfolgung

### Abschnitt 6.5 : Transaktionen für Fracht eingehend diskutieren und erfassen
- Fracht eingehend ist Teil der Vorratskosten (keine separate Aufwendung)
- Zwei Methoden : In Vorräte einschließen oder separates Fracht eingehend-Konto
- Methode 1 (in Vorräte einschließen) ist im Allgemeinen bevorzugt
- Fracht ausgehend ist eine Betriebsaufwendung (keine Vorratskosten)
- MwSt auf Fracht ist normalerweise erstattungsfähig

### Abschnitt 6.6 : Gewinn- und Verlustrechnungen für Handelsunternehmen beschreiben und erstellen
- Mehrstufiges Format zeigt : Nettoumsätze - COGS = Bruttogewinn - Aufwendungen = Nettoergebnis
- Einfaches Format : Erträge - Aufwendungen = Nettoergebnis
- Mehrstufig bevorzugt für bessere Analyse
- Bruttogewinnmarge ist eine Schlüsselmetrik
- Muss PCN-Format für Luxemburg-Einreichung befolgen

### Abschnitt 6.7 : Periodisches Lagerbestandssystem (Anhang)
- Käufe im Käufe-Konto erfasst
- COGS am Periodenende berechnet : Anfang + Käufe - Ende
- Erfordert physische Lagerbestandszählung
- Weniger häufig in modernen Unternehmen
- Weiterhin unter PCN akzeptabel

### Abschnitt 6.8 : Luxemburgische Einzelhandels-/Gastgewerbe-Lagerbuchhaltung
- PCN Klasse 3 : Lagerkonten
- 361 : Waren (Einzelhandel)
- 301 : Rohstoffe (Zutaten)
- Muss konsistente Bewertungsmethode verwenden (FIFO, gewichteter Durchschnitt)
- Muss PCN-Anforderungen einhalten

### Abschnitt 6.9 : Luxemburgische MwSt auf Waren
- Vier MwSt-Sätze : 3 %, 8 %, 14 %, 17 %
- Verschiedene Sätze für verschiedene Warentypen
- Muss MwSt nach Satz für MwSt-Erklärung verfolgen
- Muss MwSt separat erfassen (nicht in Vorratskosten)
- Kritisch für eCDF-Einreichungs-Compliance
