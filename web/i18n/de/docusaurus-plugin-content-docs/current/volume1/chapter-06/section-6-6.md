# 6.6 Mehrstufige und einfache Gewinn- und Verlustrechnungen für Handelsunternehmen beschreiben und erstellen

### Gewinn- und Verlustrechnungsformate

Handelsunternehmen können Gewinn- und Verlustrechnungen in zwei Formaten erstellen :

1. **Mehrstufige Gewinn- und Verlustrechnung** (Detaillierter)
2. **Einfache Gewinn- und Verlustrechnung** (Einzelschritt, weniger detailliert)

### Mehrstufige Gewinn- und Verlustrechnung

**Format :** Zeigt mehrere Zwischensummen und Berechnungen

**Struktur :**
```
Umsatzerlöse
- Verkaufsrückgaben
- Verkaufsrabatte
- Verkaufsskonti
= Nettoumsätze

- Kosten der verkauften Waren
= Bruttogewinn

- Betriebsaufwendungen
= Betriebsergebnis

+ Sonstige Erträge
- Sonstige Aufwendungen
= Ergebnis vor Steuern

- Ertragsteueraufwand
= Nettoergebnis
```

### Beispiel : Mehrstufige Gewinn- und Verlustrechnung

**Mode Luxembourg SARL - Einzelhandelsbekleidungsgeschäft**

```
Mode Luxembourg SARL
Gewinn- und Verlustrechnung
Für das Jahr bis 31. Dezember 2024

UMSÄTZE
  Umsatzerlöse (7061)                    €150,000
  Weniger : Verkaufsrückgaben (709)                (2,000)
  Weniger : Verkaufsrabatte (709)              (500)
  Weniger : Verkaufsskonti (709)             (1,000)
Nettoumsätze                                    €146,500

KOSTEN DER VERKAUFTEN WAREN
  Kosten der verkauften Waren (607)                (80,000)
Bruttogewinn                                  €66,500

BETRIEBSAUFWENDUNGEN
  Gehaltsaufwand (6211)                  €25,000
  Mietaufwand (6111)                       8,000
  Nebenkostenaufwand (6184)                  2,500
  Versicherungsaufwand (614)                  1,200
  Abschreibungsaufwand (633)               3,000
  Lieferaufwand (6162)                   1,500
  Sonstige Betriebsaufwendungen (6188)           2,800
Summe Betriebsaufwendungen                     (45,000)

BETRIEBSERGEBNIS                               €21,500

SONSTIGE ERTRÄGE
  Zinserträge (7552)                      500
Summe sonstige Erträge                             500

SONSTIGE AUFWENDUNGEN
  Zinsaufwand (6552)                    (800)
Summe sonstige Aufwendungen                           (800)

ERGEBNIS VOR STEUERN                          €21,200

ERTRAGSTEUERAUFWAND (671)                    (3,000)

NETTOERGEBNIS                                     €18,200
```

**Schlüsselberechnungen :**
- Nettoumsätze : 150.000 € - 2.000 € - 500 € - 1.000 € = 146.500 €
- Bruttogewinn : 146.500 € - 80.000 € = 66.500 €
- Bruttogewinnmarge : (66.500 € ÷ 146.500 €) × 100 = 45,4 %
- Betriebsergebnis : 66.500 € - 45.000 € = 21.500 €
- Nettoergebnis : 21.200 € - 3.000 € = 18.200 €

### Einfache Gewinn- und Verlustrechnung

**Format :** Einzelschritt, alle Erträge zusammen, alle Aufwendungen zusammen

**Struktur :**
```
Gesamterträge
- Gesamtaufwendungen
= Nettoergebnis
```

### Beispiel : Einfache Gewinn- und Verlustrechnung

```
Mode Luxembourg SARL
Gewinn- und Verlustrechnung
Für das Jahr bis 31. Dezember 2024

ERTRÄGE
  Nettoumsätze (7061)                         €146,500
  Zinserträge (7552)                      500
Gesamterträge                                €147,000

AUFWENDUNGEN
  Kosten der verkauften Waren (607)                 €80,000
  Gehaltsaufwand (6211)                   25,000
  Mietaufwand (6111)                        8,000
  Nebenkostenaufwand (6184)                   2,500
  Versicherungsaufwand (614)                   1,200
  Abschreibungsaufwand (633)                3,000
  Lieferaufwand (6162)                    1,500
  Zinsaufwand (6552)                      800
  Sonstige Betriebsaufwendungen (6188)            2,800
  Ertragsteueraufwand (671)                  3,000
Gesamtaufwendungen                               (128,800)

NETTOERGEBNIS                                     €18,200
```

### Vergleich

**Vorteile mehrstufig :**
- Zeigt Bruttogewinn (wichtig für Handel)
- Trennt Betrieb von anderen Aktivitäten
- Detailliertere Analyse möglich
- Besser für Managemententscheidungen
- Bevorzugtes Format für die meisten Unternehmen

**Vorteile einfach :**
- Einfacher zu erstellen
- Leichter zu verstehen
- Weniger detailliert
- Geeignet für sehr kleine Unternehmen

**Luxemburgische Empfehlung :** Mehrstufiges Format für bessere Analyse und Entscheidungsfindung verwenden.

### Luxemburgische Format-Anforderungen

**PCN-Anforderungen :**
- Muss PCN-Kontenklassifizierungen befolgen
- Muss ordnungsgemäße Kontonummern einschließen
- Kann beide Formate verwenden (mehrstufig bevorzugt)
- Muss auf Französisch, Deutsch oder Englisch sein
- Muss beim RCS eingereicht werden

**Für RCS-Einreichung :**
- Mehrstufiges Format ist Standard
- Muss Bruttogewinn zeigen
- Muss alle erforderlichen Konten einschließen
- Muss PCN-Präsentation befolgen

### Bruttogewinn-Analyse

Die **Bruttogewinnmarge** ist eine Schlüsselmetrik für Handelsunternehmen :

**Formel :**
**Bruttogewinnmarge % = (Bruttogewinn ÷ Nettoumsätze) × 100**

**Interpretation :**
- **Hohe Marge (über 40 %) :** Gute Preise, niedrige Kosten oder Premium-Produkte
- **Mittlere Marge (20-40 %) :** Typisch für viele Einzelhandelsunternehmen
- **Niedrige Marge (unter 20 %) :** Starker Wettbewerb, niedrige Preise oder hohe Kosten

**Branchen-Benchmarks (Luxemburg) :**
- Bekleidungseinzelhandel : 40-60 %
- Lebensmittelläden : 20-30 %
- Elektronik : 15-25 %
- Restaurants : 30-50 % (Lebensmittelkosten)

### Luxemburg-Compliance-Hinweis

Gewinn- und Verlustrechnungen für luxemburgische Unternehmen müssen :
- PCN-Format befolgen
- Ordentliche Kontenklassifizierungen einschließen
- Bruttogewinn zeigen (mehrstufig bevorzugt)
- Genau und vollständig sein
- Beim RCS als Teil der Jahresabschlüsse eingereicht werden
- Steuererklärungsvorbereitung unterstützen
