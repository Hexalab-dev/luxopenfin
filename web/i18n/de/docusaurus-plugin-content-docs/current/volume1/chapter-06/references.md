# Referenzen und weiterführende Literatur

### Offizielle luxemburgische Quellen

- **Guichet.lu - Lagerverwaltung** : https://guichet.public.lu/en/entreprises/gestion-juridique-comptabilite/comptable/enregistrement/
  - Anforderungen an Lagerbuchhaltung
  - PCN Klasse 3 Informationen

- **Portail Fiscal - MwSt auf Waren** : https://pfi.public.lu/tva
  - MwSt-Sätze für verschiedene Waren
  - MwSt-Erklärungsvorbereitung
  - Grenzüberschreitende MwSt-Regeln

- **Commission des Normes Comptables (CNC)** : https://cnc.lu
  - PCN-Lageranforderungen
  - Vorratsbewertungsmethoden
  - Jahresabschlusspräsentation

### MwSt-Ressourcen

- **MwSt-Satz-Datenbank** : https://pfi.public.lu/tva
  - Vollständige MwSt-Satz-Referenz
  - Sektorspezifische Sätze
  - Updates und Änderungen

### Lagerverwaltung

- **Best-Practice-Leitfäden** : Verfügbar von der Luxemburger Handelskammer
- **Lagerverwaltungssoftware** : Sage BOB, Odoo mit Lager-Modulen

### Bildungsressourcen

- **House of Training** : https://www.houseoftraining.lu
  - Lagerverwaltungskurse
  - MwSt-Schulung
  - Handelsbuchhaltungs-Workshops

- "Précis de droit comptable" von Denis Colin (Legitech)
  - Luxemburgische Lagerbuchhaltung
  - MwSt auf Waren
  - PCN-Anforderungen

- OpenStax Principles of Financial Accounting
  - Universelle Handelskonzepte
  - Lagerbestandssysteme
  - Kosten der verkauften Waren
