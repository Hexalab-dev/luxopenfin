# 6.8 Luxemburgische Einzelhandels-/Gastgewerbe-Lagerbuchhaltung (PCN Klasse 3)

### PCN Klasse 3 : Lagerkonten

**Klasse 3** enthält alle lagerbezogenen Konten gemäß PCN 2020.

**Kontenbereiche :**
- 30 : Rohstoffe (Matières Premières)
- 31 : Unfertige Erzeugnisse (En Cours de Fabrication)
- 32 : Fertigerzeugnisse (Produits Finis)
- 361 : Waren (Marchandises)

### Lagerkonten für verschiedene Unternehmensarten

#### Einzelhandelsunternehmen

**Hauptkonto :**
- **361 : Waren** (Marchandises)

**Verwendung :**
- Alle zum Verkauf gehaltenen Waren
- Gekaufte Fertigerzeugnisse
- Bereit zum Verkauf an Kunden

**Beispiel :** Vorräte eines Bekleidungsgeschäfts
```
361    Waren                €25,000
```

#### Restaurants/Gastgewerbe

**Lebensmittelzutaten :**
- **301 : Rohstoffe** (für zuzubereitende Zutaten)
- Oder **361 : Waren** (wenn als Waren behandelt)

**Einzelhandelsartikel :**
- **361 : Waren** (Wein, Kaffeebohnen, zum Verkauf stehende Waren)

**Beispiel :** Restaurant mit beiden
```
301    Rohstoffe (Lebensmittel)         €5,000
361    Waren (Wein, Einzelhandel)   €3,000
```

#### Fertigungsunternehmen

**Rohstoffe :**
- **301 : Rohstoffe**

**Unfertige Erzeugnisse :**
- **311 : Unfertige Erzeugnisse**

**Fertigerzeugnisse :**
- **321 : Fertigerzeugnisse**

### Vorratsbewertungsmethoden

**Luxemburg erlaubt :**
- **FIFO** (First-In, First-Out)
- **Gewichteter Durchschnitt**
- **Spezifische Identifikation** (für einzigartige Artikel)

**Luxemburgische Anforderung :**
- Muss konsistente Methode verwenden
- Muss in Anhängen zu Jahresabschlüssen offengelegt werden
- Muss vernünftig und nachvollziehbar sein

### Komponenten der Vorratskosten

**Vorratskosten umfassen :**
- Kaufpreis
- Fracht eingehend
- Einfuhrzölle (falls zutreffend)
- Andere Kosten, um Vorräte verkaufsbereit zu machen

**Umfassen NICHT :**
- Verkaufsaufwendungen
- Verwaltungsaufwendungen
- Lagerkosten (außer wenn für Verkauf notwendig)

### Luxemburgische MwSt und Vorräte

**MwSt-Behandlung :**
- Vorräte zu **Nettokosten** erfasst (MwSt ausgeschlossen)
- MwSt-Vorsteuer (421611) separat erfasst
- MwSt auf Verkäufe als MwSt-Verbindlichkeiten (461411) erfasst
- Verschiedene MwSt-Sätze erfordern separate Verfolgung

**Beispiel : Gemischte Vorräte**

Restaurant-Vorräte :
- Lebensmittelzutaten (MwSt 3 %) : 1.000 € netto
- Wein (MwSt 14 %) : 500 € netto
- Ausrüstung/Vorlieferungen (MwSt 17 %) : 200 € netto

**Erfassung :**
```
361    Vorräte - Lebensmittel             €1,000
361    Vorräte - Getränke         500
361    Vorräte - Vorlieferungen          200
421611 MwSt-Vorsteuer               103  (€30 + €70 + €34)
44111  Verbindlichkeiten aus L.u.L.                          €1,803
```

### Lagerverwaltung

**Best Practices :**
- Regelmäßige Lagerbestandszählungen (auch mit permanentem System)
- Ordnungsgemäße Dokumentation
- Sichere Lagerung
- Rotation (FIFO für Verderbliches)
- Überwachung auf Diebstahl oder Verderb

### Luxemburg-Compliance-Hinweis

Für Vorräte in Luxemburg :
- Muss PCN Klasse 3 Konten verwenden
- Muss Vorräte ordnungsgemäß bewerten
- Muss konsistente Bewertungsmethode verwenden
- Muss in Jahresabschlüssen offengelegt werden
- Muss Vorratswerte mit Dokumentation unterstützen
- Muss MwSt-Anforderungen einhalten
