# Schlüsselbegriffe

- **Periodenrechnung**: Erfassung von Transaktionen, wenn sie auftreten, nicht wenn Geld den Besitzer wechselt
- **Abgegrenzte Aufwendungen**: Entstandene, aber noch nicht gezahlte oder erfasste Aufwendungen
- **Abgegrenzte Erträge**: Verdiente, aber noch nicht erhaltene oder erfasste Erträge
- **Angepasste Probebilanz**: Probebilanz, die nach Anpassungsbuchungen erstellt wird
- **Anpassungsbuchungen**: Journaleinträge, die am Periodenende vorgenommen werden, um Konten zu aktualisieren
- **Abschreibung**: Systematische Verteilung der Vermögenswertkosten über Nutzungsdauer
- **Matching-Prinzip**: Aufwendungen werden in derselben Periode erfasst wie zugehörige Erträge
- **Vorausbezahlte Aufwendungen**: Im Voraus gezahlte Aufwendungen, als Vermögenswerte erfasst
- **Rückstellung**: Geschätzte Verbindlichkeit für zukünftige Verpflichtungen
- **Prinzip der Ertragserfassung**: Erträge werden erfasst, wenn sie verdient werden, nicht wenn Geld erhalten wird
- **Zeitperiodenkonzept**: Geschäftsaktivitäten werden in spezifische Perioden für Berichtszwecke unterteilt
- **Nicht verdiente Erträge**: Im Voraus erhaltenes Geld für zukünftige Dienstleistungen, als Verbindlichkeiten erfasst
