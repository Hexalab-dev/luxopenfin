# Schlüsselbegriffe

- **Kapitalkonto** : Partner-Eigenkapital in Personengesellschaft
- **Personengesellschaft** : Unternehmen, das von zwei oder mehr Partnern besessen wird
- **Gesellschaftsvertrag** : Vertrag, der Personengesellschaftsbedingungen definiert
- **Gewinnzuweisung** : Verteilung von Gewinnen an Partner
- **SNC** : Société en Nom Collectif (Offene Handelsgesellschaft)
- **SCS** : Société en Commandite Simple (Kommanditgesellschaft)
