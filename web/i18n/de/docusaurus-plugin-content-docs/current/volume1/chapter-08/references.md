# Referenzen und weiterführende Literatur

### Offizielle luxemburgische Quellen

- **Guichet.lu - Kassenhandhabung** : https://guichet.public.lu/en/entreprises/
  - Kassenhandhabungsvorschriften
  - Anforderungen an fiskale Registrierkassen
  - Compliance-Richtlinien

- **CSSF (Finanzsektoraufsicht)** : https://www.cssf.lu
  - Bankvorschriften
  - Zahlungssystemaufsicht
  - Geldwäschebekämpfung

- **Luxemburger Bankenverband** : https://www.abbl.lu
  - Informationen zu Bankdienstleistungen
  - Zahlungsmethoden
  - Branchenstandards

### Zahlungssystem-Ressourcen

- **SEPA** : https://www.europeanpaymentscouncil.eu
  - SEPA-Informationen
  - Standards und Verfahren
  - Implementierungsleitfäden

- **Worldline (ehemals Cetrel)** : https://worldline.com
  - Zahlungsabwicklungsdienste
  - Händlerdienste
  - Integrationsinformationen

### Interne Kontroll-Ressourcen

- **COSO-Rahmenwerk** : Rahmenwerk für interne Kontrolle
- **Luxemburger Handelskammer** : Best-Practice-Leitfäden

### Bildungsressourcen

- **House of Training** : https://www.houseoftraining.lu
  - Kurse zu internen Kontrollen
  - Schulung zur Betrugsprävention
  - Cash-Management-Workshops

### Weiterführende Literatur

- "Précis de droit comptable" von Denis Colin (Legitech)
  - Luxemburgische Anforderungen an interne Kontrollen
  - Kassenhandhabungsvorschriften
  - Compliance-Anforderungen

- OpenStax Principles of Financial Accounting
  - Universelle Konzepte interner Kontrollen
  - Betrugsprävention
  - Cash-Management
