# 5.1 Abschlussbuchungen für ein Unternehmen beschreiben und vorbereiten

### Was sind Abschlussbuchungen?

**Abschlussbuchungen** sind Journaleinträge, die am Ende einer Rechnungslegungsperiode vorgenommen werden, um Salden von temporären Konten (Erträge und Aufwendungen) auf permanente Konten (Eigenkapital/Gewinnrücklagen) zu übertragen.

### Zweck von Abschlussbuchungen


**Abbildung 5.1:** Complete Accounting Cycle

```

        │
        ↓

        │
        ↓
3. Record in Journal
        │
        ↓
4. Post to Ledger
        │
        ↓
5. Prepare Unadjusted Trial Balance
        │
        ↓
6. Prepare Adjusting Entries
        │
        ↓
7. Post Adjusting Entries
        │
        ↓
8. Prepare Adjusted Trial Balance
        │
        ↓
9. Prepare Financial Statements
        │
        ↓
10. Prepare Closing Entries
        │
        ↓
11. Post Closing Entries
        │
        ↓
12. Prepare Post-Closing Trial Balance
        │
        ↓
    Ready for Next Period
```

**Warum Konten schließen?**

1. **Temporäre Konten zurücksetzen** : Ertrags- und Aufwandskonten werden für die nächste Periode auf null zurückgesetzt
2. **Gewinnrücklagen aktualisieren** : Nettoergebnis oder Verlust wird auf Gewinnrücklagen übertragen
3. **Für nächste Periode vorbereiten** : Konten sind bereit, Transaktionen der neuen Periode zu sammeln
4. **Buchhaltungszyklus vervollständigen** : Der Abschluss ist der letzte Schritt vor Beginn einer neuen Periode

### Temporäre vs. permanente Konten

**Temporäre Konten** (Am Periodenende geschlossen) :
- **Ertragskonten** (Klasse 7) : Auf null zurückgesetzt
- **Aufwandskonten** (Klasse 6) : Auf null zurückgesetzt
- **Ergebnis** (temporäres Konto, das im Abschlussprozess verwendet wird)

**Permanente Konten** (Nicht geschlossen) :
- **Vermögenskonten** (Klassen 2, 3, 4, 5) : Salden werden vorgetragen
- **Verbindlichkeitskonten** (Klassen 1, 4) : Salden werden vorgetragen
- **Eigenkapitalkonten** (Klasse 1) : Aktualisiert, aber nicht zurückgesetzt

### Der Abschlussprozess

Der Abschlussprozess umfasst vier Schritte:

1. **Ertragskonten schließen** → Ergebnis
2. **Aufwandskonten schließen** → Ergebnis
3. **Ergebnis schließen** → Gewinnrücklagen
4. **Entnahmen/Ausschüttungen schließen** → Gewinnrücklagen (falls zutreffend)

### Schritt 1: Ertragskonten schließen

**Zweck :** Alle Ertragskontensalden auf das Ergebnis übertragen

**Prozess :**
- Jedes Ertragskonto mit seinem Saldo belasten
- Ergebnis mit Gesamterträgen gutschreiben

**Beispiel :**

Aus angepasster Probebilanz:
- Dienstleistungserlöse (703) : Guthabensaldo von 13.000 €

**Abschlussbuchung :**
```
Datum : 2024-11-30

703    Dienstleistungserlöse              €13,000
142    Ergebnis                                       €13,000
Um Ertragskonten auf das Ergebnis zu schließen
```

**PCN-Hinweis :** Das Ergebnis ist normalerweise Konto 142 oder ein temporäres Konto. Einige Unternehmen verwenden eine direkte Abschlussmethode.

**Nach Abschluss :**
- Dienstleistungserlöse : 0 €
- Ergebnis : Guthabensaldo von 13.000 €

### Schritt 2: Aufwandskonten schließen

**Zweck :** Alle Aufwandskontensalden auf das Ergebnis übertragen

**Prozess :**
- Jedes Aufwandskonto mit seinem Saldo gutschreiben
- Ergebnis mit Gesamtaufwendungen belasten

**Beispiel :**

Aus angepasster Probebilanz:
- Gehaltsaufwand (6211) : Sollsaldo von 9.500 €
- Mietaufwand (6111) : Sollsaldo von 2.400 €
- Nebenkostenaufwand (6184) : Sollsaldo von 1.500 €
- Versicherungsaufwand (614) : Sollsaldo von 100 €
- Abschreibungsaufwand (633) : Sollsaldo von 500 €
- Zinsaufwand (6552) : Sollsaldo von 100 €
- Materialaufwand (6185) : Sollsaldo von 1.000 €

**Gesamtaufwendungen :** 15.100 €

**Abschlussbuchung :**
```
Datum : 2024-11-30

142    Ergebnis                        €15,100
6211   Gehaltsaufwand                         €9,500
6111   Mietaufwand                             2,400
6184   Nebenkostenaufwand                      1,500
6185   Materialaufwand                         1,000
614    Versicherungsaufwand                      100
633    Abschreibungsaufwand                      500
6552   Zinsaufwand                               100
Um Aufwandskonten auf das Ergebnis zu schließen
```

**Nach Abschluss :**
- Alle Aufwandskonten : 0 €
- Ergebnis : 15.100 € Soll, 13.000 € Haben = Sollsaldo von 2.100 € (Nettoverlust)

### Schritt 3: Ergebnis schließen

**Zweck :** Nettoergebnis oder Nettoverlust auf Gewinnrücklagen übertragen

**Prozess :**
- Bei Nettoergebnis : Ergebnis belasten, Gewinnrücklagen gutschreiben
- Bei Nettoverlust : Ergebnis gutschreiben, Gewinnrücklagen belasten

**Beispiel (Nettoverlust) :**

Das Ergebnis hat einen Sollsaldo von 2.100 € (Nettoverlust)

**Abschlussbuchung :**
```
Datum : 2024-11-30

141    Gewinnrücklagen            €2,100
142    Ergebnis                               €2,100
Um das Ergebnis (Nettoverlust) auf Gewinnrücklagen zu schließen
```

**Nach Abschluss :**
- Ergebnis : 0 €
- Gewinnrücklagen : Um 2.100 € verringert (Nettoverlust)

**Bei Nettoergebnis (Alternatives Beispiel) :**

Wenn das Ergebnis einen Guthabensaldo von 2.000 € (Nettoergebnis) hätte:

**Abschlussbuchung :**
```
Datum : 2024-11-30

142    Ergebnis                        €2,000
141    Gewinnrücklagen                            €2,000
Um das Ergebnis (Nettoergebnis) auf Gewinnrücklagen zu schließen
```

### Schritt 4: Entnahmen/Ausschüttungen schließen (Falls zutreffend)

**Zweck :** Eigentümerentnahmen oder Ausschüttungen auf Gewinnrücklagen übertragen

**Hinweis :** Dieser Schritt gilt, wenn das Unternehmen ein Entnahmekonto hat (üblich bei Einzelunternehmen) oder Ausschüttungen vornimmt (bei Kapitalgesellschaften).

**Beispiel (Entnahmen) :**

Wenn der Eigentümer während der Periode 500 € entnommen hat:

**Abschlussbuchung :**
```
Datum : 2024-11-30

141    Gewinnrücklagen            €500
10611  Eigentümerentnahmen                      €500
Um Entnahmen auf Gewinnrücklagen zu schließen
```

**PCN-Hinweis :** Entnahmen sind normalerweise in Klasse 3 oder werden über Eigenkapitalkonten gehandhabt, je nach Entitätstyp.

### Alternative: Direkte Abschlussmethode

Einige Unternehmen schließen direkt auf Gewinnrücklagen, ohne das Ergebnis zu verwenden:

**Schritt 1: Erträge schließen**
```
703    Dienstleistungserlöse              €13,000
141    Gewinnrücklagen                            €13,000
```

**Schritt 2: Aufwendungen schließen**
```
141    Gewinnrücklagen            €15,100
6211   Gehaltsaufwand                         €9,500
6111   Mietaufwand                             2,400
[Weitere Aufwendungen...]
```

**Ergebnis :** Gleich wie bei Verwendung des Ergebnisses, aber mit weniger Einträgen.

### Vollständiges Abschlussbeispiel

Schließen wir die Bücher für Le Petit Bistro mit der Ergebnismethode:

**Aus angepasster Probebilanz :**
- Dienstleistungserlöse : 13.000 € Haben
- Gesamtaufwendungen : 15.100 € Soll
- Nettoverlust : 2.100 €

**Abschlussbuchungen :**

**Buchung 1: Erträge schließen**
```
703    Dienstleistungserlöse              €13,000
142    Ergebnis                                       €13,000
Um Ertragskonten zu schließen
```

**Buchung 2: Aufwendungen schließen**
```
142    Ergebnis                        €15,100
6211   Gehaltsaufwand                         €9,500
6111   Mietaufwand                             2,400
6184   Nebenkostenaufwand                      1,500
6185   Materialaufwand                         1,000
614    Versicherungsaufwand                      100
633    Abschreibungsaufwand                      500
6552   Zinsaufwand                               100
Um Aufwandskonten zu schließen
```

**Buchung 3: Ergebnis schließen**
```
141    Gewinnrücklagen            €2,100
142    Ergebnis                               €2,100
Um das Ergebnis (Nettoverlust) auf Gewinnrücklagen zu schließen
```

### Übertragung von Abschlussbuchungen auf T-Konten

**Dienstleistungserlöse :**
```
Dienstleistungserlöse (703)
─────────────────────────────
Nov 30  Abschluss    €13,000 │  Nov 01-30  Erträge  €13,000
─────────────────────────────
Saldo  €0
```

**Ergebnis :**
```
Ergebnis (142)
─────────────────────────────
Nov 30  Aufwendungen    €15,100 │  Nov 30  Erträge   €13,000
                                │  Nov 30  Abschluss  €2,100
─────────────────────────────
Saldo  €0
```

**Gewinnrücklagen :**
```
Gewinnrücklagen (141)
─────────────────────────────
Nov 30  Nettoverlust  €2,100  │  Nov 01  Saldo    €2,600
─────────────────────────────
        │  Saldo  €500
```

### Luxemburg-Compliance-Hinweis

In Luxemburg müssen Abschlussbuchungen:
- Am Periodenende vorgenommen werden (monatlich, vierteljährlich oder jährlich)
- Ordnungsgemäße PCN-Kontenklassifizierungen verwenden
- Dokumentiert und 10 Jahre aufbewahrt werden
- Vor der Einreichung von Jahresabschlüssen abgeschlossen werden
- PCN-Standards für die Kontenbehandlung befolgen
