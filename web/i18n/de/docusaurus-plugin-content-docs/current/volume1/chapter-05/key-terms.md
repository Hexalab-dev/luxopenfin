# Schlüsselbegriffe

- **Abschlussbuchungen** : Journaleinträge, die temporäre Kontensalden auf permanente Konten übertragen
- **Aktuelle Quote** : Umlaufvermögen ÷ Kurzfristige Verbindlichkeiten ; misst Liquidität
- **Ergebnis** : Temporäres Konto, das im Abschlussprozess verwendet wird, um Erträge und Aufwendungen zusammenzufassen
- **Liquidität** : Fähigkeit, kurzfristige Verpflichtungen mit Umlaufvermögen zu erfüllen
- **Permanente Konten** : Konten, die Salden vortragen (Vermögenswerte, Verbindlichkeiten, Eigenkapital)
- **Saldenliste nach Abschluss** : Saldenliste, die nach Abschlussbuchungen vorbereitet wird, enthält nur permanente Konten
- **Temporäre Konten** : Konten, die am Periodenende geschlossen werden (Erträge, Aufwendungen)
- **Working Capital** : Umlaufvermögen - Kurzfristige Verbindlichkeiten ; Überschuss des Umlaufvermögens über kurzfristige Verbindlichkeiten
