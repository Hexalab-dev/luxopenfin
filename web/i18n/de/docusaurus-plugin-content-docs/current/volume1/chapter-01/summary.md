# Kapitelzusammenfassung

### Abschnitt 1.1 – Bedeutung der Buchhaltung
- Buchhaltung = Erfassen, messen, buchen, kommunizieren.  
- Grundgleichung **Aktiva = Passiva + Eigenkapital**.  
- Finanzbuchhaltung dient externen Stakeholdern (PCN).  
- Managementbuchhaltung unterstützt interne Entscheidungen.  
- Beide Stränge sind für KMU unverzichtbar.

### Abschnitt 1.2 – Nutzer der Informationen
- Externe Nutzer: Investoren, Kreditgeber, ACD, RCS/CNC.  
- Interne Nutzer: Eigentümer*innen, Manager*innen, Mitarbeitende.  
- Jeder benötigt unterschiedliche Daten (Rentabilität, Cashflow, Compliance).

### Abschnitt 1.3 – Buchhaltungszyklus & Rollen
- Schritte: identifizieren → erfassen → Hauptbuch → Summen/Salden → Anpassungen → Abschlüsse → Abschlussbuchungen.  
- Berufsrollen: Fiduciairen, Experts-Comptables, interne Buchhalter*innen.  
- Schlüsselanforderung: PCN-Konformität und vollständige Belegführung.

### Abschnitt 1.4 – Stakeholder
- Buchhaltung schafft Vertrauen, ermöglicht Entscheidungen, sichert Rechtskonformität und fördert Wachstum.  
- Verstöße führen zu Bußgeldern und Reputationsschäden.

### Abschnitt 1.5 – Karrierewege
- Praxis (Fiduciaire, Audit), Industrie, öffentlicher Sektor, Bildung, Unternehmertum.  
- Kompetenzen: Technik (PCN, Steuerrecht, Software) + Soft Skills + Mehrsprachigkeit.  
- OEC und Berufsverbände bieten Unterstützung.

### Abschnitt 1.6 – Luxemburger Rahmen
- OEC reguliert den Beruf; Fiduciairen sind lizenziert.  
- Rechtsgrundlagen: Code de Commerce, PCN 2020, Steuerrecht.  
- CNC, RCS, CSSF überwachen die Einhaltung.
