# Résumé du chapitre

### Section 19.1 : Calculer un seuil de rentabilité en unités et en euros
- Les coûts se comportent comme variables, fixes ou mixtes
- Les coûts variables changent avec le volume ; les coûts fixes restent constants
- Marge sur coûts variables = Prix de vente - Coût variable
- Le seuil de rentabilité est où le revenu est égal aux coûts totaux
- Seuil de rentabilité (unités) = Coûts fixes ÷ Marge sur coûts variables par unité
- Seuil de rentabilité (euros) = Coûts fixes ÷ Ratio de marge sur coûts variables
- La marge de sécurité montre de combien les ventes peuvent baisser avant la perte

### Section 19.2 : Appliquer l'analyse coût-volume-profit pour les entreprises à produit unique
- L'analyse CVP aide à la prise de décision
- Le compte de résultat CVP montre le format de contribution
- L'analyse de simulation évalue différents scénarios
- L'effet de levier opérationnel mesure la sensibilité aux changements de volume
- Effet de levier opérationnel élevé = risque élevé, récompense élevée
- Les considérations fiscales affectent les calculs de profit cible

### Section 19.3 : Appliquer l'analyse coût-volume-profit pour les entreprises à produits et services multiples
- Le mix de ventes est la proportion de différents produits vendus
- La marge sur coûts variables moyenne pondérée tient compte du mix de ventes
- L'analyse du seuil de rentabilité nécessite de considérer le mix de ventes
- Les changements dans le mix de ventes affectent le seuil de rentabilité
- Les entreprises de services peuvent utiliser l'analyse CVP
- Différents taux de TVA peuvent s'appliquer à différents produits

### Section 19.4 : Expliquer et utiliser la méthode des coûts variables et la méthode des coûts complets
- La méthode des coûts variables inclut uniquement les coûts de fabrication variables
- La méthode des coûts complets inclut tous les coûts de fabrication
- Le résultat net diffère lorsque production ≠ ventes
- La méthode des coûts variables meilleure pour les décisions internes
- La méthode des coûts complets requise pour la communication externe
- Les deux méthodes ont leurs utilisations

### Section 19.5 : Analyse du seuil de rentabilité des PME luxembourgeoises
- La TVA doit être gérée de manière cohérente dans l'analyse
- Le Luxembourg a des coûts d'exploitation élevés
- Les charges sociales sont significatives
- Les seuils de rentabilité peuvent être plus élevés que dans d'autres pays
- Considérer tous les coûts spécifiques au Luxembourg
- Utiliser des outils appropriés et de l'aide professionnelle

### Section 19.6 : Exemples de structure de coûts luxembourgeoise
- Différentes industries ont différentes structures de coûts
- Commerce de détail : Coûts variables élevés (COGS)
- Services : Coûts de main-d'œuvre élevés
- Fabrication : Mélange de fixes et variables
- Stratégies pour améliorer la structure de coûts
- Examen et mise à jour réguliers nécessaires
