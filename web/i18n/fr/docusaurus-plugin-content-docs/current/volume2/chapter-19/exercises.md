# Chapitre 19 – Exercices et cas

## Questions à choix multiples

1. Les coûts variables sont des coûts qui :  
   a) Restent constants en total  
   b) Changent en total en proportion directe du volume  
   c) Changent par unité lorsque le volume change  
   d) Sont toujours fixes  
   **Réponse :** b) Les coûts variables changent en total en proportion directe du volume.

2. La marge sur coûts variables est :  
   a) Ventes moins coûts fixes  
   b) Ventes moins coûts variables  
   c) Ventes moins coûts totaux  
   d) Coûts fixes moins coûts variables  
   **Réponse :** b) Marge sur coûts variables = Ventes - Coûts variables.

3. Le seuil de rentabilité se produit lorsque :  
   a) Le revenu est égal aux coûts variables  
   b) Le revenu est égal aux coûts fixes  
   c) Le revenu est égal aux coûts totaux  
   d) La marge sur coûts variables est égale à zéro  
   **Réponse :** c) Le seuil de rentabilité se produit lorsque le revenu est égal aux coûts totaux.

4. Si le prix de vente est €20, le coût variable est €8, et les coûts fixes sont €6,000, le seuil de rentabilité en unités est :  
   a) 300 unités  
   b) 500 unités  
   c) 750 unités  
   d) 1,000 unités  
   **Réponse :** b) Seuil de rentabilité = €6,000 ÷ (€20 - €8) = 500 unités.

5. La marge de sécurité est :  
   a) Ventes au seuil de rentabilité moins ventes réelles  
   b) Ventes réelles moins ventes au seuil de rentabilité  
   c) Marge sur coûts variables moins coûts fixes  
   d) Prix de vente moins coût variable  
   **Réponse :** b) Marge de sécurité = Ventes réelles - Ventes au seuil de rentabilité.

6. Un effet de levier opérationnel élevé signifie :  
   a) Coûts fixes faibles  
   b) Coûts variables élevés  
   c) Coûts fixes élevés par rapport aux coûts variables  
   d) Marge sur coûts variables faible  
   **Réponse :** c) Effet de levier opérationnel élevé = Coûts fixes élevés par rapport aux coûts variables.

7. Le mix de ventes est :  
   a) Volume total des ventes  
   b) Proportion de différents produits vendus  
   c) Prix de vente moyen  
   d) Marge sur coûts variables totale  
   **Réponse :** b) Le mix de ventes est la proportion relative de différents produits vendus.

8. La méthode des coûts variables inclut dans les coûts des produits :  
   a) Tous les coûts de fabrication  
   b) Seulement les coûts de fabrication variables  
   c) Seulement les coûts de fabrication fixes  
   d) Aucun coût de fabrication  
   **Réponse :** b) La méthode des coûts variables inclut uniquement les coûts de fabrication variables.

9. La méthode des coûts complets est requise pour :  
   a) La prise de décision interne  
   b) La communication financière externe  
   c) L'analyse CVP  
   d) L'analyse du seuil de rentabilité  
   **Réponse :** b) La méthode des coûts complets est requise pour la communication financière externe.

10. Au Luxembourg, l'analyse du seuil de rentabilité devrait :  
    a) Ignorer la TVA  
    b) Gérer la TVA de manière cohérente  
    c) Considérer uniquement les coûts fixes  
    d) Exclure les charges sociales  
    **Réponse :** b) La TVA devrait être gérée de manière cohérente dans l'analyse du seuil de rentabilité.

## Problèmes Série A

**Problème A-1 : Calcul du seuil de rentabilité**

Une entreprise a :
- Prix de vente : €30 par unité
- Coût variable : €12 par unité
- Coûts fixes : €18,000 par mois

Calculez :
a) Marge sur coûts variables par unité  
b) Ratio de marge sur coûts variables  
c) Seuil de rentabilité en unités  
d) Seuil de rentabilité en euros

**Problème A-2 : Profit cible**

En utilisant les données du Problème A-1, calculez :
a) Unités nécessaires pour gagner €6,000 de profit  
b) Revenus nécessaires pour gagner €6,000 de profit  
c) Si 1,500 unités sont vendues, quel est le profit ?

**Problème A-3 : Analyse de simulation**

Une entreprise a :
- Prix de vente : €25
- Coût variable : €10
- Coûts fixes : €15,000
- Ventes actuelles : 1,200 unités

Calculez l'impact de :
a) Augmenter le prix à €28  
b) Réduire le coût variable à €8  
c) Augmenter les coûts fixes à €18,000

**Problème A-4 : Marge de sécurité**

Une entreprise a :
- Ventes réelles : 2,000 unités
- Ventes au seuil de rentabilité : 1,500 unités
- Prix de vente : €20 par unité

Calculez :
a) Marge de sécurité en unités  
b) Marge de sécurité en euros  
c) Ratio de marge de sécurité

**Problème A-5 : Effet de levier opérationnel**

À 1,000 unités :
- Marge sur coûts variables : €12,000
- Résultat net : €4,000

Calculez :
a) Degré d'effet de levier opérationnel  
b) Si les ventes augmentent de 20%, quel est le pourcentage d'augmentation du profit ?

## Problèmes Série B

**Problème B-1 : Produits multiples**

Une entreprise vend deux produits :
- Produit A : Prix €40, Coût variable €20, 60% des ventes
- Produit B : Prix €30, Coût variable €15, 40% des ventes
- Coûts fixes : €24,000

Calculez :
a) Marge sur coûts variables moyenne pondérée  
b) Prix de vente moyen pondéré  
c) Ratio de marge sur coûts variables moyenne pondérée  
d) Seuil de rentabilité en unités totales  
e) Seuil de rentabilité en euros  
f) Unités au seuil de rentabilité pour chaque produit

**Problème B-2 : Méthode des coûts variables vs. Méthode des coûts complets**

Une entreprise :
- Produit : 2,000 unités
- Vend : 1,800 unités
- Prix de vente : €50
- Coût de fabrication variable : €20
- Frais généraux de fabrication fixes : €30,000
- Vente variable : €5 par unité
- Vente fixe : €10,000

Calculez le résultat net sous :
a) Méthode des coûts variables  
b) Méthode des coûts complets  
c) Expliquez la différence

**Problème B-3 : Analyse CVP complète**

Un restaurant luxembourgeois :
- Coûts fixes : €12,000 par mois
- Coût variable par repas : €9
- Prix de vente par repas : €25 (excluant la TVA)
- Taux de TVA : 3% (repas de restaurant)

Calculez :
a) Seuil de rentabilité en repas (excluant la considération TVA pour l'analyse interne)  
b) Seuil de rentabilité en revenus (excluant la TVA)  
c) Repas nécessaires pour €8,000 de profit  
d) Si 1,000 repas sont vendus, calculez le profit et la marge de sécurité

**Problème B-4 : Analyse de structure de coûts**

Comparez deux modèles commerciaux :
- Modèle A : Coûts fixes €20,000, Coût variable €5 par unité, Prix €15
- Modèle B : Coûts fixes €10,000, Coût variable €10 par unité, Prix €15

Calculez pour chacun :
a) Seuil de rentabilité  
b) Profit à 3,000 unités  
c) Degré d'effet de levier opérationnel à 3,000 unités  
d) Quel modèle a un risque plus élevé ? Une récompense potentielle plus élevée ?

## Problème complet

**Problème complet 19 : Analyse CVP complète pour Le Petit Bistro**

Marie veut effectuer une analyse CVP complète pour son restaurant pour prendre de meilleures décisions.

**Situation actuelle :**
- Coûts fixes par mois : €9,500
  - Loyer : €3,500
  - Salaires (fixes) : €4,000
  - Charges sociales (12,57 % ; taux CCSS au 1er janvier 2026, Mutualité classe 1) : €502.80
  - Assurance : €200
  - Fiduciaire : €300
  - Services publics (base) : €150
  - Autres : €847.20

**Articles du menu :**
- Plat Signature : Prix €25 (excl. TVA), Coût variable €10, 40% des ventes
- Menu Déjeuner : Prix €15 (excl. TVA), Coût variable €6, 35% des ventes
- Repas Léger : Prix €12 (excl. TVA), Coût variable €5, 25% des ventes
- Taux de TVA : 3% (tous les repas consommés sur place ; les boissons alcoolisées seraient à 17%)

**Performance actuelle :**
- Moyenne de 900 repas par mois
- Mix de ventes actuel comme indiqué ci-dessus

**Requis :**

1. **Analyse du comportement des coûts :**  
   a) Classez tous les coûts comme fixes ou variables  
   b) Calculez le coût variable total par repas (moyenne pondérée)  
   c) Calculez le prix de vente moyen pondéré  
   d) Calculez la marge sur coûts variables moyenne pondérée

2. **Analyse du seuil de rentabilité :**  
   a) Calculez le seuil de rentabilité en repas totaux  
   b) Calculez le seuil de rentabilité en revenus (excluant la TVA)  
   c) Calculez le seuil de rentabilité pour chaque article du menu  
   d) Créez un graphique de seuil de rentabilité (décrivez les points clés)

3. **Analyse de la performance actuelle :**  
   a) Calculez le profit actuel à 900 repas  
   b) Calculez la marge de sécurité  
   c) Calculez le degré d'effet de levier opérationnel  
   d) Analysez la performance actuelle

4. **Analyse du profit cible :**  
   Marie veut €6,000 de profit par mois :
   a) Calculez les repas requis  
   b) Calculez les revenus requis  
   c) Analysez la faisabilité

5. **Scénarios de simulation :**  
   a) **Scénario 1 :** Augmenter le prix du Plat Signature à €28  
     - Calculez le nouveau seuil de rentabilité
     - Supposez que le mix de ventes change à 50% Signature, 30% Déjeuner, 20% Léger
   b) **Scénario 2 :** Réduire les coûts variables de 10%  
     - Calculez le nouveau seuil de rentabilité
     - Analysez l'impact
   c) **Scénario 3 :** Augmenter les coûts fixes de €2,000 (embaucher un autre cuisinier)  
     - Calculez le nouveau seuil de rentabilité
     - Déterminez si le volume supplémentaire justifie le coût

6. **Analyse du mix de ventes :**  
   a) Marge sur coûts variables moyenne pondérée actuelle  
   b) Si le mix de ventes se déplace à 50% Signature, 30% Déjeuner, 20% Léger  
     - Calculez la nouvelle marge sur coûts variables moyenne pondérée
     - Calculez le nouveau seuil de rentabilité
     - Analysez l'impact

7. **Stratégie de tarification :**  
   Marie envisage une augmentation de prix de 10% sur tous les articles :
   a) Calculez les nouveaux prix  
   b) Calculez les nouvelles marges sur coûts variables  
   c) Calculez le nouveau seuil de rentabilité  
   d) Analysez l'impact (considérez la diminution potentielle du volume)

8. **Considérations luxembourgeoises :**  
   a) Comment la TVA affecte-t-elle l'analyse ?  
   b) Quels coûts spécifiques au Luxembourg sont inclus ?  
   c) Comment les charges sociales affectent-elles la structure de coûts ?  
   d) Quelles considérations de conformité y a-t-il ?

9. **Recommandations :**  
   Basé sur l'analyse, fournissez des recommandations pour :
   a) Stratégie de tarification  
   b) Gestion des coûts  
   c) Optimisation du mix de ventes  
   d) Amélioration du profit

## Cas

**Cas 19-1 : Décision de tarification**

Marie envisage de baisser les prix pour attirer plus de clients. Actuellement :
- Prix moyen : €20 (moyenne pondérée)
- Coût variable : €8
- Coûts fixes : €9,500
- Ventes actuelles : 900 repas/mois
- Profit : €2,200/mois

Elle envisage une réduction de prix de 15%, ce qui, selon elle, augmentera le volume de 30%.

**Questions pour l'analyse :**

1. Calculez l'impact de la réduction de prix sur la marge sur coûts variables par repas.

2. Calculez le nouveau seuil de rentabilité.

3. Calculez le profit au nouveau volume (900 × 1.30 = 1,170 repas).

4. Marie devrait-elle réduire les prix ? Pourquoi ou pourquoi pas ?

5. Quels autres facteurs devrait-elle considérer ?

6. Quelles stratégies alternatives pourraient être meilleures ?

**Cas 19-2 : Décision d'expansion**

Marie envisage d'agrandir son restaurant pour augmenter la capacité. L'expansion :
- Augmenterait les coûts fixes de €4,000/mois (loyer supplémentaire, services publics)
- Lui permettrait de servir 500 repas de plus par mois
- Nécessiterait l'embauche de personnel supplémentaire (coût variable)

**Questions pour l'analyse :**

1. Quel est le seuil de rentabilité actuel ?

2. Quel serait le nouveau seuil de rentabilité après l'expansion ?

3. Combien de repas supplémentaires doit-elle vendre pour couvrir les coûts fixes supplémentaires ?

4. Si elle peut vendre 400 repas supplémentaires, devrait-elle s'agrandir ?

5. Quel est le volume supplémentaire minimum nécessaire pour justifier l'expansion ?

6. Quels risques devrait-elle considérer ?
