# 19.6 Exemples de structure de coûts luxembourgeoise

### Exemple 1 : Magasin de détail

**Magasin de détail luxembourgeois - Structure de coûts :**

**Coûts fixes (Mensuels) :**
- Loyer (emplacement privilégié) : €4,000
- Salaires : €5,000
- Charges sociales (12,57 % ; taux CCSS au 1er janvier 2026, Mutualité classe 1) : €628.50
- Assurance : €300
- Services comptables : €400
- Services publics : €200
- Marketing (fixe) : €500
- **Total : €11,028.50**

**Coûts variables (Par €100 de ventes) :**
- Coût des marchandises vendues : €60
- Commissions de vente (2%) : €2
- Frais de carte de crédit (1.5%) : €1.50
- Emballage : €0.50
- **Total : €64 par €100 de ventes**

**Prix de vente :**
- Majoration moyenne : 67% sur le coût
- Si le coût est €60, le prix de vente est €100 (excluant la TVA)
- Taux de TVA : 17% (la plupart des biens de détail)
- Prix incluant la TVA : €117

**Analyse du seuil de rentabilité :**
- Marge sur coûts variables par €100 de ventes : €100 - €64 = €36
- Ratio de marge sur coûts variables : €36 ÷ €100 = 36%
- Seuil de rentabilité (revenus) : €11,028.50 ÷ 0.36 = €30,635 par mois
- Seuil de rentabilité (unités) : Dépend du montant de vente moyen

### Exemple 2 : Entreprise de services (Conseil)

**Cabinet de conseil luxembourgeois - Structure de coûts :**

**Coûts fixes (Mensuels) :**
- Loyer de bureau : €2,500
- Salaires (consultants, fixes) : €8,000
- Charges sociales (12,57 %) : €1,005.60
- Assurance : €400
- Frais professionnels : €600
- Marketing : €800
- **Total : €13,305.60**

**Coûts variables (Par heure) :**
- Matériaux/fournitures : €10
- Déplacements (variables) : €15
- Autres variables : €5
- **Total : €30 par heure**

**Taux de facturation :**
- Taux excluant la TVA : €120 par heure
- Taux de TVA : 17%
- Taux incluant la TVA : €140.40 par heure

**Analyse du seuil de rentabilité :**
- Marge sur coûts variables par heure : €120 - €30 = €90
- Seuil de rentabilité (heures) : €13,305.60 ÷ €90 = 147.8 → 148 heures par mois
- Seuil de rentabilité (revenus) : 148 × €120 = €17,760 par mois

### Exemple 3 : PME de fabrication

**Petit fabricant luxembourgeois - Structure de coûts :**

**Coûts fixes (Mensuels) :**
- Loyer d'usine : €5,000
- Salaires : €12,000
- Charges sociales (12,57 %) : €1,508.40
- Amortissement : €1,500
- Assurance : €600
- Services publics (base) : €400
- **Total : €21,008.40**

**Coûts variables (Par unité) :**
- Matières premières directes : €15
- Main-d'œuvre directe (variable) : €8
- Frais généraux variables : €4
- **Total : €27 par unité**

**Prix de vente :**
- Prix excluant la TVA : €50 par unité
- Taux de TVA : 17%
- Prix incluant la TVA : €58.50 par unité

**Analyse du seuil de rentabilité :**
- Marge sur coûts variables par unité : €50 - €27 = €23
- Seuil de rentabilité (unités) : €21,008.40 ÷ €23 = 913.4 → 914 unités par mois
- Seuil de rentabilité (revenus) : 914 × €50 = €45,700 par mois

### Variations de structure de coûts

**Entreprise à coûts fixes élevés :**
- Exemple : Hôtel, restaurant avec loyer élevé
- Seuil de rentabilité élevé
- Effet de levier opérationnel élevé
- Profits sensibles aux changements de volume

**Entreprise à coûts variables élevés :**
- Exemple : Commerce de détail avec coût élevé des marchandises
- Seuil de rentabilité plus faible
- Effet de levier opérationnel plus faible
- Profits plus stables

**Entreprise de services :**
- Souvent coûts de main-d'œuvre élevés (variables ou fixes)
- Coûts de matériaux plus faibles
- Seuil de rentabilité dépend des taux d'utilisation

### Stratégies pour améliorer la structure de coûts

**Réduire les coûts fixes :**
- Négocier un loyer plus bas
- Réduire le personnel fixe (utiliser la main-d'œuvre variable)
- Partager les installations
- Externaliser les fonctions non essentielles

**Réduire les coûts variables :**
- Négocier de meilleurs prix avec les fournisseurs
- Améliorer l'efficacité
- Réduire le gaspillage
- Optimiser les processus

**Augmenter la marge sur coûts variables :**
- Augmenter les prix (si le marché le permet)
- Réduire les coûts variables
- Se concentrer sur les produits/services à marge élevée
- Améliorer le mix de ventes

### Note de conformité luxembourgeoise

Les PME luxembourgeoises devraient :
- Comprendre leur structure de coûts
- Examiner et mettre à jour régulièrement l'analyse des coûts
- Considérer les coûts spécifiques au Luxembourg
- Inclure tous les coûts de conformité
- Tenir compte de la TVA correctement
- Considérer les charges sociales dans les coûts de main-d'œuvre
- Utiliser les informations sur les coûts pour les décisions de tarification
