# 19.3 Appliquer l'analyse coût-volume-profit pour les entreprises à produits et services multiples

### Mix de ventes

Le **mix de ventes** (également appelé mix de produits) est la proportion relative de différents produits ou services vendus. Lorsqu'une entreprise vend plusieurs produits, l'analyse CVP devient plus complexe car différents produits ont différentes marges sur coûts variables.

Pour plusieurs produits, nous calculons une **marge sur coûts variables moyenne pondérée** basée sur le mix de ventes.

**Formule :**
**Marge sur coûts variables moyenne pondérée = Σ (Marge sur coûts variables par unité × Pourcentage du mix de ventes)**

**Exemple :**
Le restaurant de Marie vend trois types de repas :
- Plat Signature : €25 prix, €10 coût variable, 40% des ventes
- Menu Déjeuner : €15 prix, €6 coût variable, 35% des ventes
- Repas Léger : €12 prix, €5 coût variable, 25% des ventes

**Marges sur coûts variables :**
- Plat Signature : €25 - €10 = €15
- Menu Déjeuner : €15 - €6 = €9
- Repas Léger : €12 - €5 = €7

**Marge sur coûts variables moyenne pondérée :**
- Plat Signature : €15 × 40% = €6.00
- Menu Déjeuner : €9 × 35% = €3.15
- Repas Léger : €7 × 25% = €1.75
- **Total : €10.90**

### Seuil de rentabilité avec plusieurs produits

**Seuil de rentabilité (Unités) = Coûts fixes totaux ÷ Marge sur coûts variables moyenne pondérée**

**Exemple :**
Coûts fixes : €8,000 par mois
Marge sur coûts variables moyenne pondérée : €10.90

**Seuil de rentabilité (Unités) = €8,000 ÷ €10.90 = 734 repas totaux**

**Seuil de rentabilité par produit (basé sur le mix de ventes) :**
- Plat Signature : 734 × 40% = 294 repas
- Menu Déjeuner : 734 × 35% = 257 repas
- Repas Léger : 734 × 25% = 184 repas

### Seuil de rentabilité en euros de ventes

**Ratio de marge sur coûts variables moyenne pondérée :**
**Ratio de marge sur coûts variables moyenne pondérée = Marge sur coûts variables moyenne pondérée ÷ Prix de vente moyen pondéré**

**Prix de vente moyen pondéré :**
- Plat Signature : €25 × 40% = €10.00
- Menu Déjeuner : €15 × 35% = €5.25
- Repas Léger : €12 × 25% = €3.00
- **Total : €18.25**

**Ratio de marge sur coûts variables moyenne pondérée :**
€10.90 ÷ €18.25 = 0.597 ou 59.7%

**Seuil de rentabilité (Euros) = €8,000 ÷ 0.597 = €13,400**

### Changements dans le mix de ventes

Si le mix de ventes change, le seuil de rentabilité change.

**Exemple :**
Si le mix de ventes se déplace vers plus de Plats Signature (marge sur coûts variables plus élevée) :
- Nouveau mix : Signature 50%, Déjeuner 30%, Léger 20%
- Nouvelle marge sur coûts variables moyenne pondérée : (€15 × 50%) + (€9 × 30%) + (€7 × 20%) = €11.60
- Nouveau seuil de rentabilité : €8,000 ÷ €11.60 = 690 repas (en baisse de 734)

**Impact :**
- Changement favorable du mix de ventes (plus de produits à marge élevée) réduit le seuil de rentabilité
- Changement défavorable du mix de ventes (plus de produits à marge faible) augmente le seuil de rentabilité

### Entreprises de services

Les entreprises de services peuvent également utiliser l'analyse CVP, mais elles ont généralement :
- Pas d'inventaire (les services sont consommés au fur et à mesure qu'ils sont fournis)
- Structures de coûts différentes (souvent plus intensives en main-d'œuvre)
- Reconnaissance des revenus différente (au fur et à mesure que les services sont effectués)

**Exemple :**
Un cabinet de conseil luxembourgeois :
- Coûts fixes : €15,000 par mois (loyer de bureau, salaires)
- Coûts variables : €50 par heure (matériaux, déplacements)
- Taux de facturation : €150 par heure
- Marge sur coûts variables par heure : €150 - €50 = €100

**Seuil de rentabilité (Heures) = €15,000 ÷ €100 = 150 heures par mois**

### Note de conformité luxembourgeoise

Pour les PME luxembourgeoises avec plusieurs produits/services :
- Différents taux de TVA peuvent s'appliquer (3%, 8%, 14%, 17%)
- L'analyse CVP devrait considérer l'impact de la TVA sur la tarification
- Le mix de ventes affecte la responsabilité TVA globale
- La structure de coûts peut varier selon le type de produit/service
- Considérer les coûts spécifiques au Luxembourg dans l'analyse
