# 21.4 Expliquer et calculer les unités équivalentes et le coût total de production dans une étape de traitement ultérieure

### Processus multi-étapes

De nombreux processus de fabrication ont plusieurs étapes. Chaque étape est un processus séparé, et les unités passent d'une étape à la suivante.

**Exemple :**
Production de pain :
- Étape 1 : Département de mélange
- Étape 2 : Département de cuisson
- Étape 3 : Département d'emballage

### Flux de coûts dans les processus multi-étapes

**Étape 1 (Mélange) :**
- Coûts : Matières premières directes, main-d'œuvre directe, frais généraux
- Sortie : Unités partiellement complétées
- Transférées à l'étape 2

**Étape 2 (Cuisson) :**
- Coûts : Matières supplémentaires (si applicable), main-d'œuvre directe, frais généraux
- Entrée : Unités de l'étape 1 (avec coûts déjà attachés)
- Sortie : Unités davantage traitées
- Transférées à l'étape 3

**Étape 3 (Emballage) :**
- Coûts : Matières d'emballage, main-d'œuvre directe, frais généraux
- Entrée : Unités de l'étape 2
- Sortie : Produits finis

### Coûts transférés

Les **coûts transférés** sont les coûts accumulés dans les étapes de traitement précédentes qui sont transférés à l'étape actuelle avec les unités.

**Important :**
- Les coûts transférés sont comme des matières ajoutées au début
- Ils représentent tous les coûts des étapes précédentes
- Les unités transférées sont 100% complètes pour les coûts transférés

### Exemple : Étape de traitement ultérieure

**Boulangerie luxembourgeoise - Département de cuisson (étape 2) :**

**Flux physique :**
- Unités transférées du mélange : 800
- Unités complétées : 750
- Unités en cours (fin) : 50 (100% complètes pour les coûts transférés, 80% complètes pour les matières ajoutées ici, 70% complètes pour la conversion)

**Coûts :**
- Coûts transférés : €824 (du département de mélange)
- Matières ajoutées en cuisson : €100
- Main-d'œuvre directe : €150
- Frais généraux de fabrication : €100
- **Total : €1 174**

**Étape 1 : Calculer les unités équivalentes**

**Coûts transférés :**
- Complétées : 750 × 100% = 750
- En cours : 50 × 100% = 50
- **Total : 800**

**Matières ajoutées en cuisson :**
- Complétées : 750 × 100% = 750
- En cours : 50 × 80% = 40
- **Total : 790**

**Conversion :**
- Complétées : 750 × 100% = 750
- En cours : 50 × 70% = 35
- **Total : 785**

**Étape 2 : Calculer le coût par unité équivalente**

**Coûts transférés :**
€824 ÷ 800 = €1,03 par unité équivalente

**Matières ajoutées :**
€100 ÷ 790 = €0,127 par unité équivalente (arrondi)

**Conversion :**
€250 ÷ 785 = €0,318 par unité équivalente (arrondi)

**Coût total par unité :**
€1,03 + €0,127 + €0,318 = €1,475 par unité équivalente

**Étape 3 : Allouer les coûts**

**Aux unités complétées (750) :**
- Coûts transférés : 750 × €1,03 = €772,50
- Matières : 750 × €0,127 = €95,25
- Conversion : 750 × €0,318 = €238,50
- **Total : €1 106,25**

**Aux unités en cours (50) :**
- Coûts transférés : 50 × €1,03 = €51,50
- Matières : 40 × €0,127 = €5,08
- Conversion : 35 × €0,318 = €11,13
- **Total : €67,71**

**Vérification :**
€1 106,25 + €67,71 = €1 173,96 ≈ €1 174 ✓ (arrondi)

### Méthode de la moyenne pondérée vs. méthode FIFO

**Méthode de la moyenne pondérée :**
- Combine les coûts ECF début avec les coûts actuels
- Calcul plus simple
- Plus couramment utilisée
- Utilisée dans les exemples ci-dessus

**Méthode FIFO :**
- Sépare l'ECF début des coûts actuels
- Plus complexe
- Suppose que l'ECF début est complété en premier
- Plus précise si les coûts changent significativement

**Ce chapitre se concentre sur la méthode de la moyenne pondérée (la plus courante).**

### Accumulation des coûts à travers les étapes

**Coût total par unité :**
- Coût étape 1 : €1,03
- Coût étape 2 : €0,445 (€0,127 + €0,318)
- **Total : €1,475**

**Pour les unités complétées :**
- Tous les coûts de toutes les étapes sont inclus
- Les coûts transférés s'accumulent à travers les étapes
- Le coût final inclut tout le traitement

### Note de conformité luxembourgeoise

Au Luxembourg :
- Les processus multi-étapes nécessitent un suivi attentif des coûts
- Les coûts transférés doivent être correctement comptabilisés
- Unités équivalentes calculées pour chaque étape
- Rapports de coût de processus pour chaque étape
- Utiliser les comptes PCN pour chaque département/processus
- L'accumulation des coûts soutient l'évaluation des stocks
