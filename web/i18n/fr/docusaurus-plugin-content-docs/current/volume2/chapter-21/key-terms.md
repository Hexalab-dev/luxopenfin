# Termes clés

- **Coût de revient par processus** : Système de calcul des coûts pour les produits identiques produits en grandes quantités
- **Unités équivalentes** : Nombre d'unités complètes qui auraient pu être produites compte tenu du travail effectué
- **Coûts de conversion** : Main-d'œuvre directe + Frais généraux de fabrication
- **Rapport de coût de processus** : Rapport résumant les coûts et les unités équivalentes pour un processus
- **Coûts transférés** : Coûts des étapes de traitement précédentes transférés à l'étape actuelle
- **Méthode de la moyenne pondérée** : Méthode combinant l'ECF début avec les coûts actuels
- **Méthode FIFO** : Méthode séparant l'ECF début des coûts actuels
- **Flux physique** : Mouvement réel des unités à travers la production
- **Coût par unité équivalente** : Coûts totaux divisés par les unités équivalentes
- **Rendement** : Ratio de la sortie à l'entrée dans un processus
- **Processus** : Un stade ou département dans la production
- **Département** : Unité organisationnelle où la production se produit
