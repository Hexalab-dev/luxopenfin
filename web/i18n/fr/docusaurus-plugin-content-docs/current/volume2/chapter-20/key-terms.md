# Termes clés

- **Coût de revient par commande** : Système de calcul des coûts qui accumule les coûts pour chaque commande individuelle
- **Coût de revient par processus** : Système de calcul des coûts utilisé pour les produits identiques produits en grandes quantités
- **Matières premières directes** : Matières premières qui deviennent partie du produit et peuvent être tracées aux commandes
- **Main-d'œuvre directe** : Coût de main-d'œuvre des employés qui travaillent directement sur les produits
- **Frais généraux de fabrication** : Tous les coûts de fabrication qui ne peuvent pas être facilement tracés aux commandes
- **Fiche de coût de commande** : Document qui accumule tous les coûts pour une commande spécifique
- **En cours de fabrication** : Compte d'inventaire pour les commandes partiellement complétées
- **Produits finis** : Compte d'inventaire pour les commandes complétées pas encore vendues
- **Inventaire des matières premières** : Compte d'inventaire pour les matières pas encore utilisées
- **Taux de frais généraux prédéterminé** : Taux de frais généraux estimé utilisé pour appliquer les frais généraux aux commandes
- **Frais généraux appliqués** : Frais généraux alloués aux commandes en utilisant le taux prédéterminé
- **Frais généraux réels** : Coûts réels de frais généraux encourus pendant la période
- **Frais généraux sous-appliqués** : Lorsque les frais généraux réels dépassent les frais généraux appliqués
- **Frais généraux sur-appliqués** : Lorsque les frais généraux appliqués dépassent les frais généraux réels
- **Base d'activité** : Mesure utilisée pour allouer les frais généraux (heures de main-d'œuvre, coût de main-d'œuvre, heures machine)
- **Coût des marchandises vendues** : Coût des commandes/produits vendus aux clients
- **Commande** : Commande, projet ou lot de produits spécifique
