# 20.5 Calculer le coût d'une commande en utilisant le coût de revient par commande

### Calcul du coût de commande

Pour calculer le coût total d'une commande, nous accumulons tous les coûts assignés à cette commande :

**Coût total de la commande = Matières premières directes + Main-d'œuvre directe + Frais généraux de fabrication appliqués**

### Exemple complet : Calcul du coût de commande

**Traiteur de Marie - Commande #102 (Réception de mariage pour 150 personnes) :**

**Étape 1 : Matières premières directes**
- Ingrédients alimentaires : €800
- Boissons : €600
- Décorations : €200
- Emballage/fournitures : €150
- **Total matières premières directes : €1,750**

**Étape 2 : Main-d'œuvre directe**
- Chef principal : 12 heures × €30/heure = €360
- Sous-chef : 10 heures × €25/heure = €250
- Serveurs (3) : 20 heures × €15/heure = €300
- **Total main-d'œuvre directe : €910**

**Étape 3 : Frais généraux de fabrication appliqués**
- Taux de frais généraux prédéterminé : 50% du coût de main-d'œuvre directe
- Coût de main-d'œuvre directe : €910
- Frais généraux appliqués : €910 × 50% = €455

**Étape 4 : Coût total de la commande**
- Matières premières directes : €1,750
- Main-d'œuvre directe : €910
- Frais généraux appliqués : €455
- **Coût total de la commande : €3,115**

### Exemple de plusieurs commandes

**Traiteur de Marie - Plusieurs commandes en cours :**

**Commande #101 (Déjeuner d'affaires) :**
- Matières premières directes : €400
- Main-d'œuvre directe : €290
- Frais généraux appliqués : €145 (50% de la main-d'œuvre)
- **Total : €835**

**Commande #102 (Mariage) :**
- Matières premières directes : €1,750
- Main-d'œuvre directe : €910
- Frais généraux appliqués : €455
- **Total : €3,115**

**Commande #103 (Événement d'entreprise - En cours) :**
- Matières premières directes : €600
- Main-d'œuvre directe : €400
- Frais généraux appliqués : €200
- **Total : €1,200** (pas encore complété)

**Total En cours de fabrication :**
- Commande #101 : €835 (complétée, pas encore vendue)
- Commande #102 : €3,115 (complétée, pas encore vendue)
- Commande #103 : €1,200 (en cours)
- **Total ECF : €5,150**

### Analyse de rentabilité par commande

**Commande #101 :**
- Prix de vente : €1,500
- Coût de la commande : €835
- Bénéfice brut : €665
- Marge bénéficiaire : 44.3%

**Commande #102 :**
- Prix de vente : €5,000
- Coût de la commande : €3,115
- Bénéfice brut : €1,885
- Marge bénéficiaire : 37.7%

**Analyse :**
- La Commande #101 a une marge plus élevée (44.3% vs. 37.7%)
- La Commande #102 a un profit absolu plus élevé (€1,885 vs. €665)
- Les deux commandes sont rentables
- Peut utiliser ces informations pour tarifer les futures commandes

### Coût par unité

Si une commande produit plusieurs unités, calculer le coût par unité :

**Exemple :**
La Commande #104 produit 100 gâteaux personnalisés :
- Coût total de la commande : €2,000
- Unités produites : 100
- Coût par unité : €2,000 ÷ 100 = €20 par gâteau

### Note de conformité luxembourgeoise

Au Luxembourg :
- Les coûts de commande doivent être calculés avec précision
- Utiliser les comptes PCN correctement
- Maintenir les dossiers de coûts par commande
- Soutenir les décisions de tarification
- Considérer la TVA dans la tarification (mais exclure du coût)
- La rentabilité par commande affecte les décisions commerciales
