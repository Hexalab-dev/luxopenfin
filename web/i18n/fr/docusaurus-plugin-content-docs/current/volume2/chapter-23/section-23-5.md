# 23.5 Expliquer comment les budgets sont utilisés pour évaluer les objectifs

### Évaluation de la performance

Les budgets fournissent des références pour évaluer la performance :
- **Budget vs. Réel** : Comparer les résultats réels aux objectifs budgétés
- **Analyse des écarts** : Analyser les différences (écarts) entre le réel et le budget
- **Gestion par exception** : Se concentrer sur les écarts significatifs

### Types d'écarts

- **Écart favorable** : Résultats réels meilleurs que le budget
- **Écart défavorable** : Résultats réels pires que le budget

**Exemples :**
- Ventes réelles > ventes budgétées = écart favorable sur les ventes
- Dépenses réelles > dépenses budgétées = écart défavorable sur les dépenses

### Processus d'analyse des écarts

1. Calculer l'écart (réel - budget)
2. Déterminer si l'écart est favorable ou défavorable
3. Enquêter sur les écarts significatifs
4. Déterminer les causes
5. Prendre des mesures correctives si nécessaire
6. Mettre à jour les budgets futurs si nécessaire

### Facteurs quantitatifs et qualitatifs

L'évaluation budgétaire doit considérer les facteurs qualitatifs :
- Conditions du marché
- Changements réglementaires
- Fluctuations des devises
- Problèmes de personnel
- Perturbations opérationnelles (par exemple, chaîne d'approvisionnement, pandémies)

### Considérations comportementales

- Éviter de punir les gestionnaires pour des écarts hors de leur contrôle
- Reconnaître les réalisations
- Utiliser les budgets pour l'amélioration continue, pas pour blâmer

### Indicateurs clés de performance (KPI)

Les budgets incluent souvent des KPI :
- Croissance des revenus
- Marge brute
- Marge d'exploitation
- Cycle de conversion de trésorerie
- Retour sur investissement

### Tableau de bord équilibré

Les budgets peuvent intégrer des objectifs non financiers (satisfaction client, amélioration des processus, apprentissage et croissance).

### Note de conformité Luxembourg

Au Luxembourg, l'analyse des écarts budgétaires aide les PME à répondre aux changements économiques (par exemple, réglementations sur les travailleurs transfrontaliers, coûts énergétiques). Les banques peuvent demander des explications sur les écarts pour les clauses restrictives.
