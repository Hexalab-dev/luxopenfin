# LuxOpenFin <FeatureTag state="DEV" />

Bienvenue sur LuxOpenFin, la plateforme ouverte de comptabilité dédiée aux PME luxembourgeoises. Propulsé par Docusaurus, le site réunit les volumes, outils interactifs et ressources complémentaires.

- **Volume 1** – Comptabilité financière pour PME luxembourgeoises  
- **Volume 2** – Comptabilité de gestion pour PME luxembourgeoises  
- **Volume 3** – Conformité et pratiques spécifiques au Luxembourg  
- **Annexes** – PCN 2020, références TVA, calendrier fiscal, états financiers modèles, etc.

La migration des contenus depuis le dépôt Markdown d’origine est en cours. Pendant cette phase, certaines sections resteront temporairement indicées comme brouillons avant d’être complétées.
