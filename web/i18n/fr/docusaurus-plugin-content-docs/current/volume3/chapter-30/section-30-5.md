# 30.5 Plateforme eCDF : Soumission électronique

## Vue d'ensemble

La plateforme **eCDF (électronique Collecte des Données Financières)** est le système électronique obligatoire du Luxembourg pour la transmission des données financières. Le bilan et le compte de résultat sont établis et validés sur eCDF au format structuré standard ; les comptes annuels sont ensuite déposés au RCS via le portail LBR, qui reprend les données structurées d'eCDF, l'annexe et les éventuels rapports étant joints en PDF.

## Fonctionnalités de la plateforme eCDF

### Système de dépôt électronique

**eCDF** fournit :
- Dépôt électronique sécurisé des comptes annuels
- Intégration avec le RCS (Registre de Commerce et des Sociétés)
- Capacités de signature numérique
- Gestion de documents
- Historique et suivi des dépôts

### Dépôt électronique obligatoire

**Article 30** de la Loi Comptable exige le **dépôt électronique** des comptes annuels via la plateforme eCDF.

**Exceptions** : Des exceptions très limitées peuvent s'appliquer dans des circonstances spécifiques, mais le dépôt électronique est l'exigence standard.

## Inscription et accès eCDF

### Exigences d'inscription

**Pour utiliser eCDF, les sociétés doivent :**
1. S'inscrire à la plateforme eCDF
2. Obtenir des certificats numériques pour l'authentification
3. Configurer les utilisateurs autorisés
4. Compléter le processus d'inscription

### Méthodes d'accès

**Options d'accès :**
- **Accès direct** : Via le portail eCDF avec certificat numérique
- **Représentant autorisé** : Via comptable ou conseiller juridique
- **Intégration logicielle** : Via logiciel comptable avec intégration eCDF

## Processus de dépôt via eCDF

### Étape 1 : Préparer les documents

**Documents requis :**
- Bilan (au format requis)
- Compte de résultats (au format requis)
- Annexes (au format requis)
- Rapport d'audit (si applicable)
- Rapport de gestion (si applicable)

### Étape 2 : Formater les documents

**Formats de fichiers :**
- **Format XML** : Format préféré pour les données structurées
- **Format PDF** : Pour les documents justificatifs
- **Format Excel** : Pour certains documents complémentaires

**Exigences de format :**
- Doit être conforme aux spécifications techniques eCDF
- Doit être validé avant la soumission
- Doit inclure les métadonnées requises

### Étape 3 : Télécharger et valider

**Processus de téléchargement :**
1. Se connecter à la plateforme eCDF
2. Sélectionner le type de dépôt (comptes annuels)
3. Télécharger les documents
4. Valider le format et le contenu
5. Examiner les documents téléchargés

**Validation :**
- Le système valide le format de fichier
- Le système valide les champs requis
- Le système vérifie l'exhaustivité
- Les erreurs doivent être corrigées avant la soumission

### Étape 4 : Signature numérique

**Signature numérique :**
- Les documents doivent être signés numériquement
- La signature confirme l'authenticité
- La signature engage la société au dépôt

### Étape 5 : Soumettre et confirmer

**Soumission :**
1. Examiner tous les documents téléchargés
2. Appliquer la signature numérique
3. Soumettre le dépôt
4. Recevoir la confirmation
5. Sauvegarder la confirmation pour les dossiers

## Exigences techniques eCDF

### Spécifications de format de fichier

**Format XML :**
- Doit suivre le schéma XML eCDF
- Doit inclure tous les éléments requis
- Doit valider contre le schéma

**Format PDF :**
- Doit être un PDF consultable
- Doit inclure des métadonnées appropriées
- Doit être correctement formaté

### Exigences de certificat numérique

**Certificats :**
- Doit être émis par une autorité de certification reconnue
- Doit être valide et non expiré
- Doit être correctement installé

## Avantages du dépôt électronique

### Efficacité

**Avantages :**
- Traitement plus rapide
- Confirmation immédiate
- Réduction de la paperasserie
- Validation automatisée

### Exactitude

**Avantages :**
- La validation de format prévient les erreurs
- Champs requis imposés
- Vérifications de cohérence
- Réduction des erreurs manuelles

### Accessibilité

**Avantages :**
- Accès 24/7 à la plateforme
- Historique de dépôt en ligne
- Récupération facile des documents
- Accès public aux comptes déposés

## Note de conformité Luxembourg

**Exigences critiques :**
- **Dépôt électronique obligatoire** : Doit déposer via eCDF
- **Signature numérique** : Les documents doivent être signés numériquement
- **Conformité de format** : Doit suivre les spécifications techniques eCDF
- **Dépôt en temps opportun** : Doit respecter le délai de 7 mois
- **Conservation des dossiers** : Conserver la confirmation du dépôt

**Problèmes courants :**
- **Problèmes techniques** : Problèmes d'accès ou de téléchargement de la plateforme
- **Erreurs de format** : Documents non au format requis
- **Problèmes de certificat** : Problèmes de certificat numérique
- **Échecs de validation** : Documents ne passant pas la validation
- **Documents manquants** : Ne pas inclure tous les documents requis
