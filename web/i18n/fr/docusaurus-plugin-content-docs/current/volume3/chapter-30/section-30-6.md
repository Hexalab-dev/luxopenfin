# 30.6 Exigences FAIA (Fichier d'Audit Informatisé AED)

## Vue d'ensemble

Le **FAIA (Fichier d'Audit Informatisé AED)** est un format de fichier électronique standardisé requis à des fins d'audit fiscal au Luxembourg. Les sociétés doivent être en mesure de fournir leurs données comptables au format FAIA lorsqu'elles sont demandées par les autorités fiscales (Administration de l'Enregistrement et des Domaines - AED).

## Objectif et base juridique FAIA

### Objectif

**FAIA** sert de :
- Format standardisé pour les données d'audit fiscal
- Soumission électronique des registres comptables
- Processus d'audit efficace pour les autorités fiscales
- Outil de vérification de conformité

### Base juridique

**Exigence légale :**
- Les sociétés doivent conserver les registres comptables dans un format pouvant être exporté vers FAIA
- Les autorités fiscales peuvent demander des fichiers FAIA lors des audits
- Le format FAIA est obligatoire pour certaines procédures fiscales

## Format de fichier FAIA

### Spécifications techniques

**Format FAIA :**
- **Basé sur OECD SAF-T (Standard Audit File for Tax)** : Norme internationale pour les fichiers d'audit fiscal
- **Format XML** : Données structurées en XML
- **Schéma standardisé** : Suit le schéma FAIA spécifique au Luxembourg
- **Données complètes** : Inclut toutes les transactions comptables

### Structure du fichier

**Le fichier FAIA contient :**
- **Informations d'en-tête** : Identification de la société, période couverte
- **Plan de comptes** : Plan de comptes complet (PCN)
- **Écritures comptables** : Toutes les écritures comptables pour la période
- **Soldes de comptes** : Soldes d'ouverture et de clôture
- **Informations complémentaires** : Données supplémentaires selon les besoins

## Exigences de données FAIA

### Informations requises

**Doit inclure :**
- Toutes les transactions comptables
- Plan de comptes complet
- Soldes de comptes
- Dates des transactions
- Montants des transactions
- Références de comptes (comptes PCN)
- Descriptions des transactions
- Références aux documents justificatifs

### Couverture de période

**Couverture :**
- Couvre généralement l'exercice fiscal
- Peut couvrir une période d'audit spécifique
- Doit inclure toutes les transactions pour la période
- Doit être complet et exact

## Génération de fichiers FAIA

### Depuis le logiciel comptable

**La plupart des logiciels comptables** peuvent exporter au format FAIA :
- **Sage BOB** : Fonctionnalité d'export FAIA
- **Odoo** : Module d'export FAIA
- **Autres logiciels** : Vérifier la capacité d'export FAIA

**Processus d'export :**
1. Sélectionner la période à exporter
2. Choisir l'option d'export FAIA
3. Générer le fichier FAIA
4. Valider le format de fichier
5. Sauvegarder le fichier pour soumission

### Génération manuelle

**Si le logiciel ne supporte pas FAIA :**
- Peut nécessiter une conversion manuelle des données
- Utiliser des outils de conversion FAIA
- Consulter un spécialiste informatique
- Envisager une mise à niveau logicielle

## Soumission FAIA

### Quand requis

**Les fichiers FAIA peuvent être requis :**
- Lors d'audits fiscaux
- Pour des procédures fiscales spécifiques
- Sur demande des autorités fiscales
- Pour vérification de conformité

### Processus de soumission

**Soumission :**
1. Générer le fichier FAIA pour la période demandée
2. Valider le format et le contenu du fichier
3. Soumettre aux autorités fiscales (AED)
4. Conserver une copie pour les dossiers
5. Confirmer la réception

## Conformité FAIA

### Exigences logicielles

**Le logiciel comptable doit :**
- Conserver les données dans un format exportable
- Supporter la fonctionnalité d'export FAIA
- Générer des fichiers FAIA valides
- Inclure toutes les données requises

### Qualité des données

**Les fichiers FAIA doivent :**
- Être complets et exacts
- Inclure toutes les informations requises
- Suivre le schéma FAIA
- Être correctement formatés
- Être validés avant soumission

## Note de conformité Luxembourg

**Exigences importantes :**
- **Capacité FAIA** : Le logiciel doit supporter l'export FAIA
- **Maintien des données** : Conserver les données dans un format exportable
- **Génération de fichiers** : Être en mesure de générer des fichiers FAIA sur demande
- **Conformité de format** : Les fichiers doivent suivre le schéma FAIA
- **Exhaustivité** : Les fichiers doivent inclure toutes les données requises

**Problèmes courants :**
- **Limitations logicielles** : Le logiciel ne supporte pas l'export FAIA
- **Erreurs de format** : Fichiers ne suivant pas le schéma FAIA
- **Données incomplètes** : Informations requises manquantes
- **Échecs de validation** : Fichiers ne passant pas la validation
- **Problèmes de timing** : Incapacité à générer des fichiers rapidement lorsqu'ils sont demandés
