# 29.4 Calcul des charges sociales (portions employé et employeur)

### Comprendre le calcul des charges sociales

Les charges sociales sont calculées en pourcentage du **salaire brut** (jusqu'au plafond de cotisation). Les employés et les employeurs paient tous deux des cotisations, avec des taux différents pour différents composants. Un calcul précis est essentiel pour la conformité et la gestion des coûts.

### Base de calcul

#### Salaire brut soumis aux cotisations

**Base pour le calcul :**
- Salaire brut (tel que calculé dans la section 29.3)
- Plafonné à 5 × le salaire social minimum : €13 518,70 par mois (à partir du 1er janvier 2026)
- L'assurance dépendance n'est **pas** plafonnée
- Inclut tous les composants imposables
- Exclut les allocations exonérées (par ex., chèques-repas jusqu'à la limite)

**Exemple :**
- Salaire brut : €15 000/mois
- Base de cotisation : €13 518,70 (plafonnée) pour toutes les cotisations sauf l'assurance dépendance

### Charges sociales des employés

#### Taux de cotisation des employés

*Taux CCSS au 1er janvier 2026 ; à vérifier chaque année sur ccss.lu.*

**Taux total employé : 12,95 %**

**Répartition :**
- Assurance Maladie : 2,80 % (prestations en nature) + 0,25 % (prestations en espèces)
- Assurance Pension : 8,50 %
- Assurance Dépendance : 1,40 %
- **Total** : 12,95 %

L'assurance dépendance est légalement calculée sur le salaire brut diminué d'un quart du salaire social minimum (€2 703,74 / 4 = €675,94). **Les exemples de cette section simplifient en appliquant 1,40 % au salaire brut total.**

#### Exemple de calcul employé

**Employé avec €3 500 de salaire brut :**

**Étape 1 : Déterminer la base de cotisation**
- Salaire brut : €3 500
- En dessous du plafond (€13 518,70)
- Base de cotisation : €3 500

**Étape 2 : Calculer les cotisations employé**
- Assurance Maladie (2,80 % + 0,25 %) : €3 500 × 3,05 % = €106,75
- Assurance Pension (8,50 %) : €3 500 × 8,50 % = €297,50
- Assurance Dépendance (1,40 %, simplifiée) : €3 500 × 1,40 % = €49,00
- **Total Employé** : €453,25

**Étape 3 : Calculer le salaire net**
- Salaire brut : €3 500,00
- Charges sociales employé : €453,25
- **Salaire net (avant retenue d'impôt)** : €3 046,75

### Charges sociales des employeurs

#### Taux de cotisation des employeurs

**Taux total employeur : 12,57 % – 15,00 %** (selon la classe de Mutualité)

**Répartition :**
- Assurance Maladie : 2,80 % + 0,25 %
- Assurance Pension : 8,50 %
- Assurance Accident : 0,65 % (× facteur bonus-malus 0,85 à 1,50)
- Santé au travail (STM) : 0,14 %
- Mutualité des employeurs : 0,23 % / 0,95 % / 1,56 % / 2,66 % (classes 1 à 4)
- **Total** : 12,57 % (classe 1) – 15,00 % (classe 4)

#### Exemple de calcul employeur

**Employeur avec employé gagnant €3 500 de salaire brut (Mutualité classe 1, facteur bonus-malus 1,00) :**

**Étape 1 : Déterminer la base de cotisation**
- Salaire brut : €3 500
- Base de cotisation : €3 500

**Étape 2 : Calculer les cotisations employeur**
- Assurance Maladie (2,80 % + 0,25 %) : €3 500 × 3,05 % = €106,75
- Assurance Pension (8,50 %) : €3 500 × 8,50 % = €297,50
- Assurance Accident (0,65 %) : €3 500 × 0,65 % = €22,75
- Santé au travail (0,14 %) : €3 500 × 0,14 % = €4,90
- Mutualité classe 1 (0,23 %) : €3 500 × 0,23 % = €8,05
- **Total Employeur** : €439,95

### Coût total de la main-d'œuvre

#### Calcul du coût complet

**Coût Total de la Main-d'œuvre = Salaire Brut + Charges Sociales Employeur**

**Exemple :**
- Salaire brut : €3 500,00
- Charges sociales employeur : €439,95
- **Coût total de la main-d'œuvre** : €3 939,95

**Répartition des coûts :**
- Employé reçoit : €3 046,75 (net, avant impôt)
- Employé paie : €453,25 (charges sociales)
- Employeur paie : €439,95 (charges sociales)
- **Total** : €3 939,95

### Salaire au-dessus du plafond de cotisation

#### Calcul pour salaires élevés

**Employé avec €15 000 de salaire brut :**

**Étape 1 : Déterminer la base de cotisation**
- Salaire brut : €15 000
- Plafond de cotisation : €13 518,70
- Base de cotisation : €13 518,70 (plafonnée) ; base de l'assurance dépendance : salaire total (sans plafond)

**Étape 2 : Calculer les charges sociales**
- Employé maladie + pension (11,55 % de €13 518,70) : €1 561,41
- Employé assurance dépendance (1,40 % de €15 000, simplifiée) : €210,00
- **Total employé** : €1 771,41
- Employeur (12,57 % de €13 518,70) : €1 699,30

**Étape 3 : Calculer le salaire net**
- Salaire brut : €15 000,00
- Charges sociales employé : €1 771,41
- **Salaire net (avant retenue d'impôt)** : €13 228,59

**Note** : Le salaire au-dessus de €13 518,70 n'est pas soumis aux cotisations plafonnées, mais reste soumis à l'assurance dépendance et à l'impôt sur le revenu.

### Calculs mensuels vs. annuels

#### Calcul mensuel

**Approche standard :**
- Calculer les charges sociales mensuellement
- Basé sur le salaire brut mensuel
- Déclarer et payer mensuellement

#### Réconciliation annuelle

**Processus de fin d'année :**
- Réviser les totaux annuels
- Réconcilier avec le salaire annuel
- Ajuster si nécessaire
- Déposer les déclarations annuelles

### Note de conformité Luxembourg

**Exigences importantes :**
- **Calcul précis** : Utiliser les taux et bases corrects
- **Déclarations mensuelles** : Déclarer et payer mensuellement
- **Paiement à temps** : Payer avant les délais pour éviter les pénalités
- **Tenue de registres** : Maintenir les registres de calcul
- **Vérification logiciel** : Vérifier les calculs du logiciel

**Problèmes courants :**
- **Erreurs de taux** : Utiliser des taux de cotisation incorrects
- **Erreurs de base** : Inclure/exclure les mauvais composants
- **Erreurs de plafonnement** : Ne pas appliquer correctement le plafond de cotisation
- **Erreurs de timing** : Calculer dans la mauvaise période

### Réfléchir

*Artisan Boulangerie* a un employé gagnant €5 000 de salaire brut par mois. L'entreprise est en Mutualité classe 2 (0,95 %) et a un facteur bonus-malus d'assurance accident de 1,20 (0,65 % × 1,20 = 0,78 %). Calculer le salaire net de l'employé, les charges sociales de l'employeur et le coût total de la main-d'œuvre.

### Exemple pratique

**Calcul complet de la paie**

Paie de l'employé de *TechLux Solutions* :

**Détails de l'employé :**
- Salaire brut : €4 500/mois
- Taux d'assurance accident : 0,65 % (facteur bonus-malus 1,00) ; Mutualité classe 1 (0,23 %)

**Charges Sociales Employé (12,95 %) :**
- Assurance Maladie (2,80 % + 0,25 %) : €126,00 + €11,25 = €137,25
- Assurance Pension (8,50 %) : €382,50
- Assurance Dépendance (1,40 %, simplifiée sur le brut total) : €63,00
- **Total Employé** : €582,75

**Charges Sociales Employeur (12,57 %) :**
- Assurance Maladie (2,80 % + 0,25 %) : €137,25
- Assurance Pension (8,50 %) : €382,50
- Assurance Accident (0,65 %) : €29,25
- Santé au travail (0,14 %) : €6,30
- Mutualité classe 1 (0,23 %) : €10,35
- **Total Employeur** : €565,65

**Résultats :**
- Salaire net (avant retenue d'impôt) : €4 500 - €582,75 = €3 917,25
- Coût total de la main-d'œuvre : €4 500 + €565,65 = €5 065,65
- Charges sociales en % du brut : 25,52 %
