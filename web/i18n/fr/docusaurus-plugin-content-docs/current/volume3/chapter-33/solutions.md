# Chapitre 33 – Solutions

## Solutions à choix multiples

1. **b)** La conformité PCN est obligatoire et la plus importante.

2. **b)** Sage BOB est un logiciel comptable spécifique au Luxembourg avec conformité PCN.

3. **b)** L'édition communautaire Odoo est un logiciel open-source gratuit.

4. **b)** Excel peut être approprié pour très petites entreprises seulement, mais a des limitations.

5. **a)** Le logiciel cloud a un coût initial plus faible (basé sur abonnement).

6. **b)** La migration de données devrait être planifiée et testée à fond.

7. **b)** L'intégration bancaire permet l'import automatique de transactions.

8. **b)** Les sauvegardes devraient être faites quotidiennement pour entreprises actives.

9. **c)** Les données doivent être conservées pendant 10 ans (exigence Luxembourg).

10. **c)** L'intégration logicielle aide à réduire les coûts, économiser du temps et améliorer l'exactitude.
