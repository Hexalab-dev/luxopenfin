# Termes clés

- **Sage BOB** : Logiciel comptable spécifique au Luxembourg populaire
- **Odoo** : Système ERP open-source avec localisation Luxembourg
- **Conformité PCN** : Support logiciel pour Plan Comptable Normalisé
- **Logiciel Cloud** : Logiciel hébergé en ligne, accessible via internet
- **Logiciel Sur site** : Logiciel installé sur vos propres ordinateurs
- **Migration de données** : Processus de transfert de données d'un système à un autre
- **Mapping de champs** : Processus de mapping des champs source vers champs destination
- **Intégration bancaire** : Connexion entre logiciel comptable et banque
- **Intégration POS** : Connexion entre logiciel comptable et système de point de vente
- **Intégration paie** : Connexion entre logiciel comptable et système de paie
- **Sauvegarde** : Copie de données pour protection et récupération
- **Sauvegarde complète** : Sauvegarde complète des données
- **Sauvegarde incrémentielle** : Sauvegarde de seulement données modifiées
- **Chiffrement des données** : Processus de codage des données pour sécurité
- **Contrôles d'accès** : Mesures de sécurité contrôlant l'accès aux données
- **Récupération après sinistre** : Procédures pour récupérer après perte de données
- **Coût total de possession (CTP)** : Coût total incluant achat, implémentation, support
- **Licence logicielle** : Droit d'utiliser le logiciel (unique ou abonnement)
- **API (Interface de programmation d'applications)** : Interface pour intégration logicielle
- **Validation des données** : Processus de vérification de l'exactitude et complétude des données
