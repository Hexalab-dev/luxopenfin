# Chapitre 33 – Exercices et cas

## Questions à choix multiples

1. Le critère de sélection de logiciel le plus important pour les entreprises luxembourgeoises est :
   a) Coût
   b) Conformité PCN
   c) Facilité d'utilisation
   d) Cloud vs. sur site
   **Réponse :** b) La conformité PCN est obligatoire et la plus importante.

2. Sage BOB est :
   a) Logiciel open-source
   b) Logiciel comptable spécifique au Luxembourg
   c) Seulement pour grandes entreprises
   d) Non conforme PCN
   **Réponse :** b) Sage BOB est un logiciel comptable spécifique au Luxembourg avec conformité PCN.

3. L'édition communautaire Odoo est :
   a) Logiciel payant
   b) Logiciel open-source gratuit
   c) Seulement pour grandes entreprises
   d) Non personnalisable
   **Réponse :** b) L'édition communautaire Odoo est un logiciel open-source gratuit.

4. Excel pour la comptabilité est :
   a) Recommandé pour toutes les entreprises
   b) Approprié pour très petites entreprises seulement
   c) Entièrement conforme PCN
   d) A intégration eCDF
   **Réponse :** b) Excel peut être approprié pour très petites entreprises seulement, mais a des limitations.

5. Les avantages du logiciel cloud incluent :
   a) Coût initial plus faible
   b) Pas d'internet requis
   c) Contrôle total sur le système
   d) Paiement unique
   **Réponse :** a) Le logiciel cloud a un coût initial plus faible (basé sur abonnement).

6. La migration de données devrait être :
   a) Faite sans planification
   b) Planifiée et testée
   c) Faite manuellement seulement
   d) Ignorée si possible
   **Réponse :** b) La migration de données devrait être planifiée et testée à fond.

7. L'intégration bancaire permet :
   a) Saisie manuelle seulement
   b) Import automatique de transactions
   c) Pas de réconciliation
   d) Accès hors ligne seulement
   **Réponse :** b) L'intégration bancaire permet l'import automatique de transactions.

8. Les sauvegardes devraient être :
   a) Faites mensuellement
   b) Faites quotidiennement pour entreprises actives
   c) Pas nécessaires
   d) Faites seulement une fois
   **Réponse :** b) Les sauvegardes devraient être faites quotidiennement pour entreprises actives.

9. Les données doivent être conservées pendant :
   a) 5 ans
   b) 7 ans
   c) 10 ans
   d) 15 ans
   **Réponse :** c) Les données doivent être conservées pendant 10 ans (exigence Luxembourg).

10. L'intégration logicielle aide à :
    a) Seulement réduire les coûts
    b) Seulement économiser du temps
    c) Réduire les coûts, économiser du temps et améliorer l'exactitude
    d) Seulement améliorer la sécurité
    **Réponse :** c) L'intégration logicielle aide à réduire les coûts, économiser du temps et améliorer l'exactitude.
