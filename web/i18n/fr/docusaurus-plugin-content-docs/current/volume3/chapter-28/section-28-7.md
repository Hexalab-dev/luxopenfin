# 28.7 Considérations de prix de transfert

### Comprendre les prix de transfert

Les **prix de transfert** font référence au prix des transactions entre parties liées (par ex. société mère et filiale, entreprises sous contrôle commun). Le Luxembourg a des règles de prix de transfert pour assurer que les transactions entre parties liées sont effectuées à prix de pleine concurrence (comme si entre parties indépendantes).

### Quand les règles de prix de transfert s'appliquent

#### Transactions entre parties liées

**Les règles de prix de transfert s'appliquent lorsque :**
- Transactions entre entreprises liées
- Transactions avec parties liées étrangères
- Transactions avec entreprises sous contrôle commun
- Autres situations de parties liées

**Parties liées incluent :**
- Sociétés mères et filiales
- Entreprises sous contrôle commun
- Entreprises avec relations de propriété significatives
- Autres entités liées

### Principe de pleine concurrence

#### Principe fondamental

**Principe de pleine concurrence :**
- Transactions doivent être tarifées comme si entre parties indépendantes
- Prix doivent refléter conditions du marché
- Aucun déplacement artificiel de profit autorisé

**Objectif :**
- Prévenir évasion fiscale par déplacement de profit
- Assurer allocation fiscale équitable
- Maintenir intégrité de la base fiscale

### Méthodes de prix de transfert

#### 1. Prix comparable sur le marché libre (CUP)

**Méthode :**
- Comparer prix avec transactions similaires entre parties indépendantes
- Méthode la plus directe lorsque comparables disponibles
- Méthode préférée lorsque données disponibles

**Exemple :**
- Vente entre parties liées : €100 par unité
- Vente entre parties indépendantes : €100 par unité
- Prix est à pleine concurrence

#### 2. Méthode du coût majoré

**Méthode :**
- Ajouter marge appropriée aux coûts
- Utilisée pour transactions de fabrication ou services
- Marge doit refléter taux du marché

**Exemple :**
- Coût de fabrication : €80
- Marge du marché : 25%
- Prix à pleine concurrence : €100

#### 3. Méthode du prix de revente

**Méthode :**
- Commencer avec prix de revente
- Soustraire marge brute appropriée
- Utilisée pour transactions de distribution

**Exemple :**
- Prix de revente : €120
- Marge brute du marché : 20%
- Prix d'achat à pleine concurrence : €96

#### 4. Méthode transactionnelle de la marge nette (TNMM)

**Méthode :**
- Comparer marges de profit net
- Utilisée lorsque autres méthodes non applicables
- Nécessite données d'entreprises comparables

#### 5. Méthode du partage des bénéfices

**Méthode :**
- Partager bénéfices basés sur contributions
- Utilisée pour transactions intégrées complexes
- Nécessite analyse détaillée

### Exigences de documentation

#### Documentation de prix de transfert

**Documentation requise :**
1. **Fichier maître** : Politiques de prix de transfert à l'échelle du groupe
2. **Fichier local** : Transactions spécifiques au Luxembourg
3. **Rapport pays par pays** : Pour grands groupes (si applicable)

**Documentation doit inclure :**
- Description des transactions entre parties liées
- Méthode de prix de transfert utilisée
- Analyse de comparabilité
- Analyse économique
- Données et calculs de support

### Exigences de conformité

#### Exigences annuelles

**Obligations annuelles :**
- Maintenir documentation de prix de transfert
- Assurer prix à pleine concurrence
- Réviser et mettre à jour documentation
- Être préparé pour révision des autorités fiscales

#### Révision des autorités fiscales

**Révisions potentielles :**
- Autorités fiscales peuvent réviser prix de transfert
- Peuvent demander documentation
- Peuvent contester prix si pas à pleine concurrence
- Peuvent ajuster prix et impôt en conséquence

### Pénalités pour non-conformité

#### Pénalités de documentation

**Pénalités :**
- **€10 000 - €250 000** : Pour documentation manquante ou inadéquate
- **Pénalités supplémentaires** : Pour échecs répétés
- **Intérêts** : Sur impôt supplémentaire évalué

#### Pénalités d'ajustement de prix

**Pénalités :**
- Ajustements fiscaux si prix pas à pleine concurrence
- Intérêts sur impôt supplémentaire
- Pénalités potentielles pour non-conformité délibérée

### Meilleures pratiques

#### 1. Identifier parties liées

- Maintenir liste des parties liées
- Identifier toutes transactions entre parties liées
- Surveiller pour nouvelles relations

#### 2. Documenter transactions

- Documenter toutes transactions entre parties liées
- Maintenir documentation de prix
- Conserver analyse économique de support

#### 3. Utiliser méthodes appropriées

- Sélectionner méthode de prix de transfert appropriée
- Appliquer méthode de manière cohérente
- Mettre à jour méthodes selon besoin

#### 4. Révision régulière

- Réviser prix de transfert annuellement
- Mettre à jour documentation
- Assurer conformité continue

#### 5. Support professionnel

- Consulter spécialistes en prix de transfert
- Obtenir documentation professionnelle
- Assurer conformité aux règles

### Note de conformité Luxembourg

**Exigences importantes :**
- **Prix à pleine concurrence** : Toutes transactions entre parties liées doivent être à pleine concurrence
- **Documentation** : Maintenir documentation appropriée de prix de transfert
- **Cohérence** : Appliquer méthodes de manière cohérente
- **Révision** : Révision et mise à jour régulières de documentation
- **Conseil professionnel** : Consulter spécialistes pour situations complexes

**Problèmes courants :**
- **Documentation manquante** : Ne pas maintenir documentation requise
- **Prix non à pleine concurrence** : Prix ne reflétant pas conditions du marché
- **Méthodes incohérentes** : Changer méthodes sans justification
- **Analyse inadéquate** : Analyse économique insuffisante

### Réfléchir

*TechLux Solutions* a une filiale en France. Ils vendent produits à la filiale au coût (pas de marge). Est-ce acceptable ? Que devraient-ils considérer ?

### Exemple pratique

**Conformité prix de transfert**

Transaction entre parties liées de *TechLux Solutions* :

**Transaction :**
- Parent (Luxembourg) vend à filiale (France)
- Coût du produit : €80
- Prix du marché : €100
- Prix actuel : €80 (au coût)

**Analyse :**
- Prix actuel : Pas à pleine concurrence
- Prix du marché : €100
- **Ajustement requis** : Prix devrait être €100

**Documentation :**
- Analyse de prix comparable sur marché libre
- Recherche de prix du marché
- Justification économique
- Documentation de prix de transfert préparée

**Résultat** : Prix ajusté à €100, documentation maintenue, conformité assurée.
