# 26.6 Exigences de conformité PCN

### Fondement légal

La conformité PCN n'est pas optionnelle—c'est une exigence légale en vertu du Code de commerce du Luxembourg. Toutes les entreprises opérant au Luxembourg doivent maintenir leurs enregistrements comptables selon les normes PCN.

### Exigences obligatoires

#### 1. Utilisation de la structure de comptes PCN

**Exigence** : Toutes les entreprises doivent organiser leurs comptes selon les sept classes PCN (1-7).

**Conformité :**
- Utiliser les numéros de comptes PCN standard pour les comptes principaux
- Maintenir les sept classes dans votre plan de comptes
- Assurer que les classifications de comptes correspondent aux définitions PCN

**Conséquences de non-conformité :**
- Rejet du dépôt RCS
- Pénalités des autorités fiscales
- Complications d'audit
- Difficultés à obtenir un financement

#### 2. Préparation des états financiers

**Exigence** : Les états financiers doivent être préparés en utilisant les classifications de comptes PCN.

**Conformité :**
- Comptes du bilan des Classes 1-5
- Comptes du compte de résultat des Classes 6-7
- Classification appropriée de tous les comptes
- Application cohérente sur toutes les périodes de reporting

#### 3. Conformité du dépôt RCS

**Exigence** : Les comptes annuels déposés au RCS doivent utiliser la structure PCN.

**Conformité :**
- Bilan formaté selon PCN
- Compte de résultat utilisant les classifications de comptes PCN
- Notes aux états financiers expliquant l'utilisation des comptes
- Dépôt électronique via la plateforme eCDF

**Délai** : 7 mois après la fin de l'exercice fiscal

#### 4. Conformité avec les autorités fiscales

**Exigence** : Les déclarations fiscales et la documentation de support doivent référencer les comptes PCN.

**Conformité :**
- Déclarations d'impôt sur les sociétés référençant les comptes PCN
- Déclarations TVA intégrant la structure PCN
- Annexes utilisant les numéros de comptes PCN
- Documentation disponible pour les audits fiscaux

#### 5. Préparation à l'audit

**Exigence** : Les enregistrements comptables doivent être prêts pour l'audit et conformes au PCN.

**Conformité :**
- Documentation complète du plan de comptes
- Toutes les transactions correctement classées
- Documentation de support disponible
- Réconciliations de comptes effectuées régulièrement

### Liste de contrôle de conformité

Utilisez cette liste pour assurer la conformité PCN :

- [ ] Le plan de comptes utilise la structure PCN 2020
- [ ] Les sept classes (1-7) sont incluses
- [ ] Les numéros de comptes principaux suivent les normes PCN
- [ ] Les sous-comptes sont correctement documentés
- [ ] Les états financiers utilisent les classifications PCN
- [ ] Le dépôt RCS est conforme au PCN
- [ ] Les déclarations fiscales référencent les comptes PCN
- [ ] Le logiciel comptable est configuré PCN
- [ ] Le personnel est formé sur l'utilisation PCN
- [ ] La documentation est maintenue et mise à jour

### Conformité logicielle

#### Exigences du logiciel comptable

**Logiciel conforme PCN :**
- Doit supporter la structure de comptes PCN 2020
- Devrait inclure un plan de comptes PCN pré-configuré
- Doit générer des états financiers conformes PCN
- Devrait supporter l'intégration eCDF et FAIA

**Logiciels conformes PCN populaires :**
- Sage BOB (spécifique Luxembourg)
- Odoo (avec localisation Luxembourg)
- Autres logiciels avec modules PCN

#### Configuration logicielle

**Paramètres requis :**
- Plan de comptes PCN 2020 installé
- Numérotation des comptes suivant la structure PCN
- Modèles d'états financiers utilisant le format PCN
- Comptes TVA correctement configurés (Classe 4)
- Intégration avec la plateforme eCDF

### Exigences de documentation

#### Document de plan de comptes

**Contenu requis :**
- Liste complète des comptes utilisés
- Descriptions et objectifs des comptes
- Explications des comptes personnalisés
- Structure des sous-comptes
- Mapping des comptes pour les transactions courantes

#### Manuel comptable

**Contenu requis :**
- Procédures de conformité PCN
- Lignes directrices de classification des transactions
- Instructions d'utilisation des comptes
- Procédures de reporting
- Détails de configuration logicielle

### Révisions régulières de conformité

#### Révisions mensuelles

- Vérifier que toutes les transactions utilisent les comptes PCN
- Vérifier que les classifications de comptes sont correctes
- Réviser l'utilisation des sous-comptes
- Assurer que les comptes TVA sont correctement utilisés

#### Révisions trimestrielles

- Réviser la préparation des états financiers
- Vérifier les réconciliations de comptes
- Vérifier la conformité aux exigences de reporting
- Mettre à jour la documentation au besoin

#### Révisions annuelles

- Révision complète du plan de comptes
- Vérifier la conformité du dépôt RCS
- Réviser la préparation des déclarations fiscales
- Mettre à jour le manuel comptable
- Former le personnel sur tout changement

### Problèmes de conformité courants

#### Problème 1 : Classes de comptes manquantes

**Problème** : Ne pas utiliser les sept classes PCN

**Solution** : Assurer que toutes les classes sont dans votre plan de comptes, même si certains comptes restent à zéro

#### Problème 2 : Classifications de comptes incorrectes

**Problème** : Utiliser les mauvais comptes PCN pour les transactions

**Solution** : Réviser le mapping des transactions, former le personnel, mettre à jour les procédures

#### Problème 3 : Numéros de comptes non-PCN

**Problème** : Créer des comptes en dehors de la structure PCN

**Solution** : Supprimer les comptes non-PCN, reclasser les transactions vers les comptes PCN

#### Problème 4 : Application incohérente

**Problème** : Utiliser différentes structures de comptes sur différentes périodes

**Solution** : Standardiser l'utilisation des comptes, documenter les procédures, former le personnel

### Note de conformité Luxembourg

La conformité PCN est surveillée par :
- **RCS** : Révision des dépôts de comptes annuels
- **Autorités fiscales (ACD)** : Révision des déclarations fiscales et documentation de support
- **Auditeurs** : Vérification de la conformité lors des audits statutaires
- **Banques** : Peuvent exiger des états financiers conformes PCN pour le financement

La non-conformité peut entraîner :
- Amendes et pénalités
- Rejets de dépôts
- Complications d'audit
- Difficultés à obtenir un financement
- Conséquences légales

### Réfléchir

La boulangerie de Sophie fonctionne depuis deux ans. Lors d'un audit, l'auditeur découvre que certaines transactions ont été enregistrées en utilisant des numéros de comptes non-PCN. Quelles étapes Sophie devrait-elle prendre pour corriger ce problème et assurer la conformité future ?

### Exemple pratique

**Exemple d'audit de conformité**

Lors d'un audit annuel, *Le Petit Bistro* a été trouvé avoir :

1. **Problème** : Certains comptes de charges ne suivaient pas la structure PCN
2. **Impact** : Les états financiers ne pouvaient pas être correctement réconciliés
3. **Solution** :
   - Reclassé toutes les transactions vers les comptes PCN
   - Mis à jour le plan de comptes
   - Formé le personnel sur l'utilisation appropriée des comptes
   - Implémenté des révisions de conformité mensuelles

4. **Résultat** : Conformité complète atteinte, audit terminé avec succès

Les révisions régulières de conformité préviennent de tels problèmes et assurent des opérations fluides.
