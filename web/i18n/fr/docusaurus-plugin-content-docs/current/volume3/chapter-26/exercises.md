# Chapitre 26 – Exercices et cas

## Questions à choix multiples

1. Le PCN (Plan Comptable Normalisé) est :
   a) Optionnel pour les petites entreprises
   b) Obligatoire pour toutes les entreprises au Luxembourg
   c) Seulement requis pour les grandes corporations
   d) Une recommandation, pas une exigence
   **Réponse :** b) Le PCN est obligatoire pour toutes les entreprises opérant au Luxembourg.

2. Combien de classes de comptes principales le PCN a-t-il ?
   a) Cinq
   b) Six
   c) Sept
   d) Huit
   **Réponse :** c) Le PCN a sept classes de comptes principales (1-7).

3. Quelle classe PCN est utilisée pour les comptes clients ?
   a) Classe 1
   b) Classe 4
   c) Classe 5
   d) Classe 7
   **Réponse :** b) La Classe 4 est utilisée pour les comptes de tiers, y compris les clients (Compte 4011, dans le groupe 40 Créances résultant de ventes et prestations de services).

4. Le compte 7061 dans le PCN représente :
   a) Les achats de marchandises
   b) Les ventes de marchandises
   c) Le compte de trésorerie
   d) Les comptes fournisseurs
   **Réponse :** b) Le compte 7061 représente les ventes de marchandises (Classe 7 - Comptes de produits, groupe 70 Montant net du chiffre d'affaires).

5. Quel compte est utilisé pour la TVA récupérable ?
   a) 461411
   b) 461412
   c) 421611
   d) 421612
   **Réponse :** c) Le compte 421611 (TVA en amont) est utilisé pour la TVA récupérable. 461411 est la TVA en aval, 461412 la TVA à payer à l'AED et 421612 la TVA à recevoir de l'AED.

6. Les sous-comptes dans le PCN :
   a) Ne sont pas autorisés
   b) Peuvent être utilisés pour un suivi détaillé tout en maintenant la conformité
   c) Doivent suivre un système de numérotation différent
   d) Sont seulement pour les grandes entreprises
   **Réponse :** b) Les sous-comptes peuvent être utilisés pour un suivi détaillé (ex. 40111, 40112 sous 4011) tout en maintenant la conformité PCN.

7. La norme PCN actuelle est :
   a) PCN 2011
   b) PCN 2015
   c) PCN 2020
   d) PCN 2025
   **Réponse :** c) PCN 2020 est la norme actuelle.

8. Quelle classe contient les immobilisations ?
   a) Classe 1
   b) Classe 2
   c) Classe 3
   d) Classe 4
   **Réponse :** b) La Classe 2 contient les frais d'établissement et les actifs immobilisés (incorporels, corporels et financiers).

9. Lors de l'achat de marchandises à crédit, quels comptes sont affectés ?
   a) Débit 6061, Crédit 44111
   b) Débit 44111, Crédit 6061
   c) Débit 6061, Crédit 5131
   d) Débit 7061, Crédit 4011
   **Réponse :** a) Achat de marchandises à crédit : Débit 6061 (Achats de marchandises), Crédit 44111 (Fournisseurs).

10. La conformité PCN est requise pour :
    a) Seulement les dépôts RCS
    b) Seulement les déclarations fiscales
    c) Les états financiers, les dépôts RCS et les déclarations fiscales
    d) Seulement les grandes entreprises
    **Réponse :** c) La conformité PCN est requise pour les états financiers, les dépôts RCS et les déclarations fiscales.

## Questions

1. Expliquez l'objectif du PCN et pourquoi il est obligatoire au Luxembourg.

2. Décrivez les sept classes de comptes PCN et fournissez un exemple de compte pour chaque classe.

3. Comment fonctionne le système de numérotation des comptes PCN ? Fournissez des exemples de numéros de comptes de différentes classes.

4. Expliquez comment mapper une transaction de vente au comptant (avec TVA) aux comptes PCN. Incluez tous les comptes affectés.

5. Quelle est la différence entre le compte 421611 et le compte 461411 dans le PCN ? Quand utiliseriez-vous chacun ?

6. Comment les entreprises peuvent-elles personnaliser leur plan de comptes tout en maintenant la conformité PCN ?

7. Décrivez les exigences clés pour la conformité PCN au Luxembourg.

8. Quelles sont les conséquences de la non-conformité aux exigences PCN ?

9. Expliquez comment fonctionnent les sous-comptes dans le système PCN. Fournissez un exemple.

10. En quoi PCN 2020 diffère-t-il de PCN 2011 ? Quelles améliorations ont été apportées ?
