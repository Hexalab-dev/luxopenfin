# Chapitre 26 – Solutions

## Solutions des questions à choix multiples

1. **b)** Le PCN est obligatoire pour toutes les entreprises opérant au Luxembourg en vertu du Code de commerce.

2. **c)** Le PCN a sept classes de comptes principales (1-7).

3. **b)** La Classe 4 contient les comptes de tiers, y compris les clients (Compte 4011).

4. **b)** Le compte 7061 représente les ventes de marchandises (Classe 7 - Comptes de produits).

5. **c)** Le compte 421611 (TVA en amont) est utilisé pour la TVA récupérable.

6. **b)** Les sous-comptes peuvent être utilisés pour un suivi détaillé tout en maintenant la conformité PCN.

7. **c)** PCN 2020 est la norme actuelle.

8. **b)** La Classe 2 contient les frais d'établissement et les actifs immobilisés.

9. **a)** Achat de marchandises à crédit : Débit 6061 (Achats de marchandises), Crédit 44111 (Fournisseurs).

10. **c)** La conformité PCN est requise pour les états financiers, les dépôts RCS et les déclarations fiscales.
