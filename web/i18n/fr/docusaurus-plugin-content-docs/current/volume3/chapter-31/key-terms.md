# Termes clés

- **Facture électronique (E-Invoice)** : Facture émise, transmise et reçue en format électronique
- **UBL (Universal Business Language)** : Standard basé sur XML pour les documents commerciaux incluant les factures
- **Peppol (Pan-European Public Procurement On-Line)** : Réseau européen pour la facturation électronique avec format BIS
- **Caisse enregistreuse fiscale** : Système de caisse enregistreuse inviolable requis pour la vente au détail et l'hôtellerie-restauration
- **FAIA (Fichier d'Audit Informatisé AED)** : Format standardisé du Luxembourg pour les données d'audit fiscal
- **OECD SAF-T (Standard Audit File for Tax)** : Standard international pour les fichiers d'audit fiscal
- **CSV (Comma-Separated Values)** : Format texte simple pour stocker des données tabulaires
- **Excel** : Format de fichier Microsoft Excel pour données structurées
- **Signature numérique** : Signature électronique assurant l'authenticité et l'intégrité
- **Authenticité** : La facture provient du fournisseur indiqué et n'a pas été modifiée
- **Intégrité** : Le contenu de la facture est complet et n'a pas été modifié
- **Équipement certifié** : Caisses enregistreuses fiscales certifiées par les autorités luxembourgeoises
- **Export de données** : Processus d'export de données depuis le logiciel comptable
- **Import de données** : Processus d'import de données dans le logiciel comptable
- **Mapping de champs** : Processus de mapping des champs source aux champs destination pendant l'import
- **Intégration** : Connexion entre différents systèmes logiciels
- **Meilleures pratiques de conformité** : Pratiques recommandées pour assurer une conformité continue
