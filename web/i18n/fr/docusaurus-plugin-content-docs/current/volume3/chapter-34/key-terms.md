# Termes clés

- **Contrôles internes** : Processus et procédures pour protéger les actifs, assurer l'exactitude et prévenir la fraude
- **Cadre de contrôle** : Structure pour mettre en place et maintenir les contrôles internes
- **Séparation des fonctions** : Séparer les fonctions incompatibles (autorisation, enregistrement, garde, réconciliation)
- **Contrôles compensatoires** : Contrôles supplémentaires qui compensent le manque de séparation
- **Contrôles préventifs** : Contrôles qui empêchent les erreurs ou la fraude de se produire
- **Contrôles détectifs** : Contrôles qui détectent les erreurs ou la fraude après qu'elles se sont produites
- **Contrôles correctifs** : Contrôles qui corrigent les erreurs ou la fraude après détection
- **Contrôles de trésorerie** : Contrôles protégeant la trésorerie contre le vol et assurant un enregistrement précis
- **Réconciliation bancaire** : Processus de comparaison des relevés bancaires aux enregistrements comptables
- **Caisse** : Petit fonds de trésorerie pour dépenses mineures
- **Contrôles d'inventaire** : Contrôles protégeant l'inventaire et assurant des enregistrements précis
- **Comptage cyclique** : Comptage régulier d'une partie de l'inventaire
- **Contrôles des comptes clients** : Contrôles protégeant les créances et assurant le recouvrement
- **Analyse de l'ancienneté** : Analyse des créances par ancienneté
- **Provision pour créances douteuses** : Estimation des créances irrécouvrables
- **Contrôles des comptes fournisseurs** : Contrôles assurant des payables précis et prévenant la fraude
- **Bon de commande** : Document autorisant un achat
- **Fraude** : Tromperie intentionnelle pour gain personnel
- **Détournement d'actifs** : Vol ou mauvaise utilisation des actifs
- **Dénonciateur** : Personne qui signale la fraude, les manquements ou les violations
- **Représailles** : Action défavorable contre un dénonciateur
