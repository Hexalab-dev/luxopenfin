# 34.3 Contrôles de trésorerie

## Vue d'ensemble

Les **contrôles de trésorerie** sont critiques car la trésorerie est l'actif le plus liquide et le plus vulnérable au vol. Des contrôles de trésorerie efficaces protègent la trésorerie, assurent un enregistrement précis et préviennent la fraude. Comprendre les procédures de contrôle de trésorerie est essentiel pour toutes les entreprises.

## Contrôles des encaissements

### Procédures d'encaissement

**Procédures :**
- Enregistrer tous les encaissements immédiatement
- Émettre des reçus pour tous les encaissements
- Utiliser des reçus pré-numérotés
- Déposer la trésorerie quotidiennement
- Réconcilier les encaissements aux dépôts

### Contrôles physiques

**Contrôles physiques :**
- Stockage sécurisé de la trésorerie (coffre-fort, tiroir verrouillé)
- Accès limité à la trésorerie
- Contrôles de caisse enregistreuse
- Comptages quotidiens de trésorerie
- Comptages surprises de trésorerie

## Contrôles des décaissements

### Autorisation

**Procédures d'autorisation :**
- Exiger une approbation pour les paiements
- Définir des limites d'approbation
- Approbation du propriétaire pour les montants significatifs
- Documenter les approbations
- Examiner les demandes de paiement

### Procédures de paiement

**Procédures de paiement :**
- Utiliser des chèques ou des paiements électroniques (pas de trésorerie si possible)
- Chèques pré-numérotés
- Exiger une documentation justificative
- Faire correspondre les factures aux paiements
- Annuler les factures payées

## Réconciliation bancaire

### Processus de réconciliation

**Réconciliation mensuelle :**
1. Comparer le relevé bancaire aux enregistrements
2. Identifier les différences
3. Enquêter sur les écarts
4. Ajuster les enregistrements
5. Documenter la réconciliation

### Contrôles de réconciliation

**Contrôles :**
- Réconcilier mensuellement (minimum)
- Le propriétaire ou une personne indépendante réconcilie
- Examiner la réconciliation
- Enquêter sur tous les écarts
- Documenter la réconciliation

## Contrôles de caisse

### Fonds de caisse

**Procédures de caisse :**
- Établir un fonds de caisse fixe
- Désigner un gardien
- Exiger des reçus pour tous les décaissements
- Réapprovisionner le fonds périodiquement
- Réconcilier la caisse régulièrement

### Contrôles

**Contrôles de caisse :**
- Limiter la taille du fonds
- Exiger des reçus
- Comptages surprises
- Réconcilier régulièrement
- Examiner les décaissements

## Note de conformité Luxembourg

**Exigences importantes :**
- **Gestion de la trésorerie** : Doit gérer la trésorerie de manière sécurisée
- **Tenue de registres** : Doit enregistrer toutes les transactions de trésorerie
- **Réconciliation** : Doit réconcilier les comptes bancaires
- **Documentation** : Doit maintenir la documentation
- **Examen** : Le propriétaire devrait examiner les contrôles de trésorerie

**Problèmes courants :**
- **Contrôles inadéquats** : Contrôles de trésorerie insuffisants
- **Pas de réconciliation** : Ne pas réconcilier les comptes bancaires
- **Vol de trésorerie** : Trésorerie vulnérable au vol
- **Erreurs d'enregistrement** : Erreurs dans l'enregistrement de la trésorerie
- **Manque de supervision** : Supervision du propriétaire insuffisante
