# 27.5 TVA sur les achats : Récupération de la TVA déductible

### Comprendre la TVA déductible

La **TVA déductible** (TVA récupérable) est la TVA que vous **payez** sur vos achats professionnels. Si vous êtes inscrit à la TVA et que l'achat est à des fins professionnelles, vous pouvez généralement **récupérer** (récupérer) cette TVA.

### Quand pouvez-vous récupérer la TVA déductible ?

Vous pouvez récupérer la TVA déductible lorsque :

1. **Inscrit à la TVA** : Vous êtes inscrit à la TVA
2. **Facture valide** : Vous avez une facture TVA valide du fournisseur
3. **Usage professionnel** : L'achat est à usage professionnel (pas personnel)
4. **Activité taxable** : L'achat est lié à vos activités professionnelles taxables
5. **Non exclu** : L'achat n'est pas spécifiquement exclu de la récupération

### Enregistrement de la TVA déductible

#### Achat à crédit

**Transaction** : Acheter €117 d'inventaire à crédit (€100 + €17 TVA)

**Comptabilité PCN :**
- **Débit** : Compte 6061 (Achats de marchandises) - €100,00
- **Débit** : Compte 421611 (TVA en amont) - €17,00
- **Crédit** : Compte 44111 (Fournisseurs) - €117,00

#### Achat avec paiement comptant

**Transaction** : Acheter €234 d'équipement, payé par banque (€200 + €34 TVA)

**Comptabilité PCN :**
- **Débit** : Compte 222 (Installations techniques et machines) - €200,00
- **Débit** : Compte 421611 (TVA en amont) - €34,00
- **Crédit** : Compte 5131 (Compte bancaire) - €234,00

### Processus de récupération de la TVA déductible

#### Étape 1 : Identifier la TVA récupérable

- Examiner toutes les factures d'achat
- Identifier les montants TVA
- Vérifier que les factures sont valides (incluent numéro TVA, taux correct)

#### Étape 2 : Enregistrer dans le système comptable

- Saisir les factures dans le système comptable
- Allouer aux comptes de charges appropriés
- Enregistrer la TVA déductible dans le Compte 421611

#### Étape 3 : Inclure dans la déclaration TVA

- Additionner toute la TVA déductible pour la période
- Inclure dans le calcul de la déclaration TVA
- Compenser contre la TVA collectée

#### Étape 4 : Recevoir remboursement (si applicable)

- Si TVA déductible dépasse TVA collectée, recevoir remboursement
- Remboursement traité par les autorités fiscales
- Généralement reçu dans 4-6 semaines

### TVA déductible non récupérable

Vous **ne pouvez pas** récupérer la TVA déductible sur :

1. **Dépenses personnelles** : Achats à usage personnel
2. **Divertissement** : Divertissement professionnel (avec exceptions)
3. **Véhicules** : Voitures (avec exceptions pour véhicules commerciaux)
4. **Fournitures exonérées** : Achats liés aux activités exonérées de TVA
5. **Articles bloqués** : Articles spécifiquement bloqués de la récupération

### Récupération partielle

Pour les achats utilisés **partiellement à des fins professionnelles et partiellement à usage personnel**, vous pouvez récupérer la TVA uniquement sur la partie professionnelle :

**Exemple :**
- Téléphone portable : €234 (€200 + €34 TVA)
- Usage professionnel : 70%
- Usage personnel : 30%
- **TVA récupérable** : €34 × 70% = €23,80

### TVA déductible sur achats d'immobilisations

La TVA déductible sur les **achats d'immobilisations** (équipements, véhicules, bâtiments) est récupérable :

**Exemple :**
- Achat d'équipement : €5 850 (€5 000 + €850 TVA)
- **TVA récupérable** : €850 (montant complet, si usage professionnel)

**Note :** Les gros achats d'immobilisations peuvent créer une TVA déductible importante, ce qui peut entraîner des remboursements TVA.

### TVA déductible sur services

La TVA déductible sur les **services** (comptabilité, juridique, conseil) est récupérable :

**Exemple :**
- Services comptables : €1 170 (€1 000 + €170 TVA)
- **TVA récupérable** : €170

### Note de conformité Luxembourg

**Exigences importantes :**
- **Conserver toutes les factures** avec TVA affichée séparément
- **Vérifier les numéros TVA** sur les factures fournisseurs
- **Enregistrer la TVA déductible** dans le Compte 421611 (PCN)
- **Inclure dans la déclaration TVA** dans les délais
- **Délai** : Généralement 3 ans pour réclamer la TVA déductible

**Problèmes courants :**
- Factures manquantes : Ne peut pas récupérer TVA sans facture valide
- Numéros TVA invalides : Peut indiquer fraude ou erreurs
- Dépenses personnelles : Ne peut pas récupérer TVA sur achats personnels
- Réclamations tardives : Peut perdre le droit de récupérer si trop tard

### Réfléchir

Marie achète €1 170 d'équipement de cuisine (€1 000 + €170 TVA) et €234 d'articles personnels (€200 + €34 TVA) sur la même facture. Comment devrait-elle enregistrer cela ? Peut-elle récupérer toute la TVA ?

### Exemple pratique

**Exemple de récupération de TVA déductible**

Achats mensuels de *Le Petit Bistro* :

**Achats professionnels :**
- Inventaire alimentaire : €2 060 (€2 000 + €60 TVA à 3%)
- Maintenance équipement : €585 (€500 + €85 TVA à 17%)
- Services publics : €234 (€200 + €34 TVA à 17%)
- **TVA déductible totale** : €179

**Ventes (TVA collectée) :**
- Ventes alimentaires : €5 150 (€5 000 + €150 TVA à 3%)
- Ventes de vin (servi) : €2 340 (€2 000 + €340 TVA à 17%)
- **TVA collectée** : €490

**TVA nette à payer :**
- TVA collectée : €490
- TVA déductible : €179
- **TVA nette à payer** : €311

Marie peut récupérer €179 de TVA déductible, réduisant sa responsabilité TVA de €490 à €311.
