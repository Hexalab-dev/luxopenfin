# Chapitre 27 – Exercices et cas

## Questions à choix multiples

1. Le taux TVA standard du Luxembourg est :
   a) 15%
   b) 17%
   c) 19%
   d) 20%
   **Réponse :** b) Le taux TVA standard du Luxembourg est 17%.

2. Quel taux TVA s'applique au vin dans un restaurant ?
   a) 17%
   b) 14%
   c) 8%
   d) 3%
   **Réponse :** a) Le vin servi dans les restaurants est soumis à 17% de TVA (les boissons alcoolisées servies sur place sont au taux standard ; seuls certains vins vendus au détail sont à 14%).

3. L'inscription TVA est obligatoire lorsque le chiffre d'affaires annuel dépasse :
   a) €25 000
   b) €35 000
   c) €50 000
   d) €100 000
   **Réponse :** c) L'inscription TVA est obligatoire lorsque le chiffre d'affaires annuel dépasse €50 000 (seuil de franchise depuis le 1er janvier 2025 ; il était de €35 000 auparavant).

4. Le compte 461411 dans PCN représente :
   a) TVA déductible
   b) TVA sur ventes (TVA collectée)
   c) TVA à payer
   d) TVA remboursable
   **Réponse :** b) Le compte 461411 (TVA en aval) représente la TVA sur ventes (TVA collectée).

5. Quel compte est utilisé pour la TVA déductible ?
   a) 461412
   b) 461411
   c) 421611
   d) 421612
   **Réponse :** c) Le compte 421611 (TVA en amont) est utilisé pour la TVA déductible.

6. Le dépôt eCDF est :
   a) Optionnel
   b) Obligatoire pour toutes les déclarations TVA
   c) Seulement pour les grandes entreprises
   d) Seulement pour les déclarants trimestriels
   **Réponse :** b) Le dépôt eCDF est obligatoire pour toutes les déclarations TVA.

7. Les fournitures intra-UE B2B sont :
   a) Soumises à 17% TVA
   b) Taux zéro (0% TVA)
   c) Soumises à la TVA du pays du client
   d) Exonérées de TVA
   **Réponse :** b) Les fournitures intra-UE B2B sont à taux zéro lorsque le client fournit un numéro TVA UE valide.

8. Si la TVA déductible dépasse la TVA collectée :
   a) Payer la différence
   b) Recevoir un remboursement
   c) Reporter à la période suivante
   d) Aucune action nécessaire
   **Réponse :** b) Si la TVA déductible dépasse la TVA collectée, vous avez droit à un remboursement.

9. Le régime TVA PME est disponible pour les entreprises avec chiffre d'affaires jusqu'à :
   a) €35 000
   b) €50 000
   c) €75 000
   d) €100 000
   **Réponse :** b) Le régime TVA PME est disponible pour les entreprises avec chiffre d'affaires jusqu'à €50 000.

10. La TVA sur les denrées alimentaires de base (pain, lait) est :
    a) 17%
    b) 14%
    c) 8%
    d) 3%
    **Réponse :** d) Les denrées alimentaires de base sont soumises à 3% de TVA (taux super-réduit).
