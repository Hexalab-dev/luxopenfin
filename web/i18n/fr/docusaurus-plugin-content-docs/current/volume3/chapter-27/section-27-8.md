# 27.8 TVA sur les importations et exportations (UE et non-UE)

### Comprendre la TVA transfrontalière

Les transactions transfrontalières (importations et exportations) ont des règles TVA spéciales qui diffèrent des transactions nationales. Comprendre ces règles est essentiel pour les entreprises engagées dans le commerce international.

### Transactions UE

#### Fournitures intra-UE (B2B)

**Fourniture à une entreprise UE :**
- **Traitement TVA** : **Taux zéro** (0% TVA)
- **Exigence** : Le client doit fournir un numéro TVA UE valide
- **Documentation** : La facture doit montrer le numéro TVA du client
- **Reporting** : Déclarer dans la liste des ventes EC (si applicable)

**Exemple :**
- Entreprise luxembourgeoise vend €1 000 de marchandises à une entreprise française
- L'entreprise française fournit le numéro TVA : FR12345678901
- **Taux TVA** : 0% (taux zéro)
- La facture montre : "Fourniture intra-UE - TVA : 0%"

#### Acquisitions intra-UE (B2B)

**Achat d'une entreprise UE :**
- **Traitement TVA** : **Autoliquidation** - vous comptabilisez la TVA
- **Taux TVA** : Le taux TVA du Luxembourg s'applique
- **Auto-évaluation** : Vous calculez et payez la TVA au Luxembourg
- **Récupération** : Peut récupérer la TVA comme TVA déductible

**Exemple :**
- Entreprise luxembourgeoise achète €1 000 de marchandises d'une entreprise allemande
- **Autoliquidation** : Vous comptabilisez €170 de TVA (17% au Luxembourg)
- **Enregistrement PCN :**
  - Débit 6061 (Achats de marchandises) : €1 000
  - Débit 421611 (TVA en amont) : €170
  - Crédit 44111 (Fournisseurs) : €1 000
  - Crédit 461411 (TVA en aval, autoliquidée) : €170

#### Liste des ventes EC

**Quand requis :**
- Fournir des marchandises à des entreprises UE dépassant le seuil
- Doit déposer la liste des ventes EC avec la déclaration TVA

**Informations requises :**
- Numéros TVA clients
- Montants des transactions
- Dates des transactions

### Transactions non-UE

#### Exportations vers pays non-UE

**Traitement TVA :**
- **Taux zéro** (0% TVA)
- Les marchandises doivent quitter l'UE
- Documentation d'exportation requise
- Preuve d'exportation nécessaire

**Exemple :**
- Entreprise luxembourgeoise exporte €5 000 de marchandises vers les USA
- **Taux TVA** : 0% (exportation à taux zéro)
- **Documentation** : Déclaration d'exportation, documents d'expédition
- **Preuve** : Certificat d'exportation douanière

#### Importations de pays non-UE

**Traitement TVA :**
- **TVA payable à l'importation**
- TVA calculée sur valeur douanière + droits
- Payée au moment de l'importation
- Peut être récupérée comme TVA déductible

**Exemple :**
- Importer marchandises de Chine : €10 000
- Droits de douane : €500
- **Base TVA** : €10 500
- **TVA (17%)** : €1 785
- **Total à payer** : €12 285 (€10 000 + €500 + €1 785)

**Récupération :**
- TVA payée à l'importation : €1 785
- Peut récupérer comme TVA déductible dans la déclaration TVA
- **Enregistrement PCN :**
  - Débit 6061 (Achats de marchandises) : €10 500
  - Débit 421611 (TVA en amont) : €1 785
  - Crédit 5131 (Banque) : €12 285

### Vente à distance (E-commerce)

#### Vente à distance UE

**Quand applicable :**
- Vendre des marchandises à des consommateurs UE
- Dépasser les seuils de vente à distance
- Doit s'inscrire à la TVA dans le pays du client

**Seuils :**
- **€10 000** : Seuil annuel (peut utiliser TVA du pays d'origine)
- **Plus de €10 000** : Doit s'inscrire dans le pays du client

**Exemple :**
- Entreprise luxembourgeoise vend en ligne à des consommateurs français
- Ventes annuelles : €15 000
- **Doit s'inscrire** à la TVA en France
- Facturer les taux TVA français aux clients français

#### Vente à distance non-UE

**Traitement TVA :**
- **Taux zéro** pour les exportations
- Documentation d'exportation requise
- Preuve d'exportation nécessaire

### Services numériques

#### Services numériques B2B (UE)

**Traitement TVA :**
- **Autoliquidation** s'applique
- Le client comptabilise la TVA dans son pays
- Aucune TVA luxembourgeoise

#### Services numériques B2C (UE)

**Traitement TVA :**
- **TVA dans le pays du client**
- Doit s'inscrire à la TVA dans chaque pays UE (ou utiliser l'OSS)
- Facturer le taux TVA du pays du client
- En dessous du seuil européen de €10 000 pour les ventes B2C transfrontalières, la TVA luxembourgeoise peut s'appliquer

**OSS (guichet unique, a remplacé le MOSS le 1er juillet 2021) :**
- Inscription unique au Luxembourg (régime de l'Union pour les entreprises de l'UE, régime hors Union pour les entreprises hors UE)
- Une déclaration OSS trimestrielle couvrant tous les pays UE
- Payer la TVA due à chaque pays via l'OSS
- L'IOSS (guichet unique à l'importation) couvre les envois importés jusqu'à €150

### Exigences de documentation

#### Pour les exportations

- **Déclaration d'exportation** : Déclaration d'exportation douanière
- **Documents d'expédition** : Connaissement, lettre de transport aérien
- **Preuve d'exportation** : Certificat d'exportation douanière
- **Facture** : Facture montrant 0% TVA

#### Pour les importations

- **Déclaration d'importation** : Déclaration d'importation douanière
- **Documents douaniers** : Documents d'entrée
- **Preuve de paiement TVA** : Preuve de paiement TVA
- **Facture** : Facture fournisseur

### Note de conformité Luxembourg

**Exigences critiques :**
- **Numéros TVA valides** : Vérifier les numéros TVA clients UE
- **Preuve d'exportation** : Maintenir la preuve d'exportation pour les ventes non-UE
- **TVA d'importation** : Payer la TVA d'importation aux douanes
- **Liste des ventes EC** : Déposer si requis
- **Documentation** : Conserver tous les documents de transactions transfrontalières

**Problèmes courants :**
- **Numéros TVA invalides** : Ne peut pas appliquer taux zéro sans numéro TVA valide
- **Preuve d'exportation manquante** : Ne peut pas appliquer taux zéro sans preuve
- **Taux incorrects** : Utiliser le mauvais taux TVA pour transactions transfrontalières
- **Reporting tardif** : Manquer les délais de liste des ventes EC

### Réfléchir

La boulangerie de Sophie reçoit une commande d'une entreprise française pour €2 000 de pain spécial. L'entreprise française fournit un numéro TVA. Comment Sophie devrait-elle gérer cette transaction ? Quel taux TVA devrait-elle facturer ? Quelle documentation a-t-elle besoin ?

### Exemple pratique

**Transaction transfrontalière**

Commande reçue par *Artisan Boulangerie* d'un restaurant français :

**Détails de la transaction :**
- Client : Restaurant français (numéro TVA : FR12345678901)
- Commande : €2 000 de pain spécial
- Livraison : Vers la France

**Traitement TVA :**
- **Fourniture intra-UE B2B** : Taux zéro (0% TVA)
- La facture montre : "Fourniture intra-UE à FR12345678901 - TVA : 0%"
- **Aucune TVA luxembourgeoise** facturée

**Enregistrement PCN :**
- Débit 4011 (Clients) : €2 000
- Crédit 702 (Ventes de produits) : €2 000
- **Aucune TVA enregistrée** (taux zéro)

**Reporting :**
- Inclure dans la liste des ventes EC (si seuil dépassé)
- Déclarer dans la déclaration TVA comme fourniture à taux zéro
