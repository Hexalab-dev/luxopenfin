# Chapitre 27 – Solutions

## Solutions questions à choix multiples

1. **b)** Le taux TVA standard du Luxembourg est 17%.

2. **a)** Le vin servi dans les restaurants est soumis à 17% de TVA (seuls certains vins vendus au détail sont à 14%).

3. **c)** L'inscription TVA est obligatoire lorsque le chiffre d'affaires annuel dépasse €50 000 (depuis le 1er janvier 2025 ; €35 000 auparavant).

4. **b)** Le compte 461411 représente la TVA sur ventes (TVA collectée).

5. **c)** Le compte 421611 est utilisé pour la TVA déductible.

6. **b)** Le dépôt eCDF est obligatoire pour toutes les déclarations TVA.

7. **b)** Les fournitures intra-UE B2B sont à taux zéro lorsque le client fournit un numéro TVA UE valide.

8. **b)** Si la TVA déductible dépasse la TVA collectée, vous avez droit à un remboursement.

9. **b)** Le régime TVA PME est disponible pour les entreprises avec chiffre d'affaires jusqu'à €50 000.

10. **d)** Les denrées alimentaires de base sont soumises à 3% de TVA (taux super-réduit).
