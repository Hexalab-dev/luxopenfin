# 27.7 Système de dépôt électronique eCDF

### Qu'est-ce que eCDF ?

**eCDF** (eCDF - Déclaration et Dépôt Électroniques) est la plateforme électronique obligatoire du Luxembourg pour le dépôt des déclarations TVA et autres déclarations fiscales. Toutes les entreprises inscrites à la TVA doivent déposer leurs déclarations TVA via le système eCDF.

### Inscription eCDF

#### Étape 1 : Obtenir l'accès

- **Enregistrement d'entreprise** : Doit être enregistré auprès du RCS
- **Inscription TVA** : Doit avoir un numéro TVA
- **Demande d'accès** : Demander l'accès eCDF auprès des autorités fiscales

#### Étape 2 : Recevoir les identifiants

- **Nom d'utilisateur** : Fourni par les autorités fiscales
- **Mot de passe** : Mot de passe initial fourni, doit être changé à la première connexion
- **Sécurité** : Authentification à deux facteurs peut être requise

#### Étape 3 : Première connexion

- Se connecter au portail eCDF
- Changer le mot de passe
- Compléter la configuration du profil
- Vérifier les informations de l'entreprise

### Fonctionnalités eCDF

#### 1. Dépôt de déclaration TVA

- **Formulaires en ligne** : Compléter les formulaires de déclaration TVA en ligne
- **Calculs** : Le système effectue des calculs automatiques
- **Validation** : Vérifications de validation intégrées
- **Soumission** : Soumission électronique et confirmation

#### 2. Intégration de paiement

- **Options de paiement** : Payer la TVA directement via eCDF
- **Virement bancaire** : Lier au compte bancaire pour les paiements
- **Confirmation de paiement** : Recevoir confirmation de paiement
- **Historique des paiements** : Voir l'historique des paiements

#### 3. Gestion de documents

- **Télécharger des documents** : Télécharger des documents de support
- **Voir les déclarations** : Accéder aux déclarations TVA précédentes
- **Télécharger des copies** : Télécharger des copies des déclarations déposées
- **Stockage de documents** : Stockage sécurisé des documents

#### 4. Notifications

- **Rappels de dépôt** : Recevoir des rappels pour les délais de dépôt
- **Rappels de paiement** : Recevoir des rappels de paiement
- **Mises à jour de statut** : Recevoir des mises à jour sur le traitement des déclarations
- **Notifications de remboursement** : Notifié lorsque les remboursements sont traités

### Dépôt de déclaration TVA via eCDF

#### Étape 1 : Se connecter

- Accéder au portail eCDF
- Entrer nom d'utilisateur et mot de passe
- Compléter l'authentification à deux facteurs (si requise)

#### Étape 2 : Sélectionner le type de déclaration

- Choisir "Déclaration TVA" (Déclaration TVA)
- Sélectionner la période de déclaration (mois, trimestre ou année)
- Vérifier les dates de période

#### Étape 3 : Saisir les données

- **TVA collectée** : Entrer la TVA collectée sur les ventes
- **TVA déductible** : Entrer la TVA payée sur les achats
- **Ajustements** : Entrer tout ajustement
- **Calculs** : Le système calcule la TVA nette automatiquement

#### Étape 4 : Réviser et valider

- Réviser toutes les entrées
- Vérifier les calculs
- Vérifier les totaux
- Le système valide les données automatiquement

#### Étape 5 : Soumettre

- Soumettre la déclaration électroniquement
- Recevoir le numéro de confirmation
- Imprimer ou sauvegarder la confirmation
- La déclaration est déposée

### Exigences de données eCDF

#### Section TVA collectée

- **Ventes totales** : Ventes totales hors TVA
- **TVA par taux** : TVA à chaque taux (17%, 14%, 8%, 3%)
- **TVA collectée totale** : Somme de toute la TVA collectée

#### Section TVA déductible

- **Achats totaux** : Achats totaux hors TVA
- **TVA par taux** : TVA déductible à chaque taux
- **TVA déductible totale** : Somme de toute la TVA déductible

#### Calcul TVA nette

- **TVA collectée** : TVA collectée totale
- **TVA déductible** : TVA déductible totale
- **TVA nette** : TVA collectée - TVA déductible
- **À payer ou remboursable** : Montant à payer ou recevoir

### Processus de paiement eCDF

#### Méthodes de paiement

1. **Virement bancaire** : Virement bancaire direct depuis eCDF
2. **Banque en ligne** : Lien vers la banque en ligne
3. **Carte de crédit** : Paiement par carte de crédit (frais peuvent s'appliquer)
4. **Prélèvement SEPA** : Autorisation de débit automatique

#### Délais de paiement

- **Même que délai de dépôt** : Paiement dû au délai de dépôt
- **Paiement tardif** : Intérêts et pénalités s'appliquent
- **Confirmation de paiement** : Recevoir confirmation après paiement

### Sécurité eCDF

#### Sécurité d'accès

- **Nom d'utilisateur/Mot de passe** : Identifiants de connexion sécurisés
- **Authentification à deux facteurs** : Couche de sécurité supplémentaire
- **Déconnexion automatique** : Déconnexion automatique après inactivité
- **Restrictions IP** : Peut restreindre l'accès depuis certains emplacements

#### Sécurité des données

- **Chiffrement** : Toutes les données chiffrées en transit
- **Stockage sécurisé** : Données stockées de manière sécurisée
- **Journaux d'accès** : Tous les accès enregistrés et surveillés
- **Conformité** : Répond aux exigences de protection des données de l'UE

### Problèmes eCDF courants

#### Problèmes de connexion

- **Mot de passe oublié** : Utiliser la fonction de réinitialisation de mot de passe
- **Compte verrouillé** : Contacter les autorités fiscales pour déverrouiller
- **Accès refusé** : Vérifier le statut d'enregistrement

#### Problèmes de dépôt

- **Erreurs de validation** : Vérifier les entrées de données
- **Erreurs de calcul** : Vérifier les calculs
- **Échec de soumission** : Réessayer la soumission ou contacter le support

#### Problèmes de paiement

- **Paiement échoué** : Vérifier les détails du compte bancaire
- **Paiement non traité** : Contacter les autorités fiscales
- **Remboursement retardé** : Vérifier le statut du remboursement dans eCDF

### Note de conformité Luxembourg

**Exigences obligatoires :**
- **Dépôt électronique** : Toutes les déclarations TVA doivent être déposées via eCDF
- **Pas de déclarations papier** : Les déclarations papier ne sont pas acceptées
- **Dépôt à temps** : Déposer avant le délai via eCDF
- **Données précises** : Assurer la précision des données avant soumission

**Pénalités :**
- **Dépôt tardif** : Pénalités s'appliquent même si déposé tard via eCDF
- **Données incorrectes** : Les erreurs peuvent entraîner des pénalités
- **Non-dépôt** : L'échec de dépôt entraîne des pénalités significatives

### Exemple pratique

**Premier dépôt eCDF**

Premier dépôt eCDF de *Le Petit Bistro* :

**Préparation :**
1. Rassemblé toutes les factures et reçus
2. Calculé TVA collectée : €4 100
3. Calculé TVA déductible : €3 060
4. TVA nette : €1 040

**Processus eCDF :**
1. Connecté au portail eCDF
2. Sélectionné "Déclaration TVA" pour T2
3. Entré TVA collectée : €4 100
4. Entré TVA déductible : €3 060
5. Système calculé TVA nette : €1 040
6. Révisé et validé
7. Soumis la déclaration
8. Reçu numéro de confirmation
9. Payé €1 040 via système de paiement eCDF

**Résultat :** Déclaration déposée avec succès, paiement traité, confirmation reçue.
