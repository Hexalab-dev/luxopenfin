# Termes clés

- **Système de point de vente (POS)** : Système pour enregistrer les transactions de vente au point de vente
- **Cetrel** : Système de paiement du Luxembourg pour paiements par carte
- **Pourboire** : Gratuité donnée au personnel de service (pourboires en espèces vs. pourboires par carte/frais de service)
- **FIFO (First-In-First-Out)** : Méthode de valorisation de l'inventaire supposant que l'inventaire le plus ancien est vendu en premier
- **Moyenne pondérée** : Méthode de valorisation de l'inventaire utilisant le coût moyen
- **Retours clients** : Produits retournés par les clients, réduisant les ventes
- **Remises clients** : Réductions de prix pour biens endommagés ou remises
- **Facturation basée sur le temps** : Méthode de facturation basée sur les heures travaillées
- **Comptabilité de projet** : Système comptable suivant les coûts et revenus par projet
- **Reconnaissance des revenus** : Processus d'enregistrement des revenus lorsqu'ils sont gagnés
- **Paiements anticipés (Revenus non gagnés)** : Paiements reçus avant la prestation de service
- **Retenue** : Accord de service prépayé, reconnu lorsque services fournis
- **Passerelle de paiement** : Service traitant les paiements en ligne
- **TVA transfrontalière** : Règles TVA pour ventes à travers frontières UE
- **Biens numériques** : Produits électroniques (logiciels, livres électroniques, musique, vidéos)
- **One-Stop Shop (OSS)** : Système UE pour déclaration TVA simplifiée
- **Matériaux directs** : Matières premières directement utilisées dans la production
- **Main-d'œuvre directe** : Main-d'œuvre directement liée à la production
- **Calcul des coûts par commande** : Méthode de comptabilité des coûts suivant les coûts par commande/ordre
- **Commande personnalisée** : Commande de produit unique pour client spécifique
