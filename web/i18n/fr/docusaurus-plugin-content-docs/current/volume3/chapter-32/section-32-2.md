# 32.2 Comptabilité du commerce de détail

## Vue d'ensemble

La **comptabilité du commerce de détail** se concentre sur la gestion de l'inventaire, les transactions de vente, les retours clients et les variations saisonnières. Les entreprises de commerce de détail doivent suivre précisément l'inventaire, appliquer les taux de TVA corrects, gérer les retours et remises, et gérer les flux de trésorerie à travers les cycles saisonniers.

## Méthodes de valorisation de l'inventaire

### Méthodes disponibles

**Méthodes de valorisation de l'inventaire :**
- **FIFO (First-In-First-Out)** : Suppose que l'inventaire le plus ancien est vendu en premier
- **Moyenne pondérée** : Coût moyen de tout l'inventaire
- **Identification spécifique** : Pour articles uniques ou de grande valeur

### Sélection de méthode

**Considérations :**
- **FIFO** : Bon pour les périssables, reflète les coûts actuels
- **Moyenne pondérée** : Plus simple, lisse les fluctuations de coûts
- **Identification spécifique** : Pour articles uniques (bijoux, art)

### Comptabilité PCN

**Comptes PCN :**
- **Classe 3** : Comptes d'inventaire
- **361** : Marchandises (stocks destinés à la revente)
- **321** : Produits finis (si le commerce fabrique ses propres produits)
- **6061** : Achats de marchandises
- **607** : Variation des stocks (utilisé dans ce manuel pour le coût des marchandises vendues)
- **7061** : Ventes de marchandises

## Taxe de vente vs. TVA

### Système TVA du Luxembourg

**Le Luxembourg utilise la TVA (pas la taxe de vente) :**
- La TVA est une taxe à la consommation
- Collectée sur les ventes (TVA collectée)
- Payée sur les achats (TVA récupérable)
- TVA nette payée aux autorités
- Différents taux s'appliquent (3%, 8%, 14%, 17%)

### TVA sur les ventes au détail

**Taux de TVA :**
- **Taux standard** : 17% (la plupart des biens)
- **Taux réduit** : 14% (certains biens)
- **Taux super-réduit** : 8% (certains biens)
- **Taux spécial** : 3% (certains biens, ex. aliments)

### Comptabilité TVA

**Comptes PCN :**
- **4614114** : TVA en aval (3%), sous-compte de 461411
- **4614113** : TVA en aval (8%), sous-compte de 461411
- **4614112** : TVA en aval (14%), sous-compte de 461411
- **4614111** : TVA en aval (17%), sous-compte de 461411
- **421611** : TVA en amont (récupérable)

## Retours clients et remises

### Retours

**Retours clients :**
- Produits retournés par les clients
- Doivent être enregistrés comme réduction de vente
- L'inventaire doit être ajusté
- La TVA doit être ajustée
- Remboursement traité

### Comptabilisation des retours

**Écriture comptable :**
- **Débit** : Compte 709 (Rabais, remises et ristournes accordés) - Montant du retour
- **Débit** : Compte 461411 (TVA en aval) - Montant TVA
- **Crédit** : Compte 4011 (Clients) ou 5131 (Banque) - Montant du remboursement
- **Débit** : Compte 361 (Stock de marchandises) - Coût des biens retournés
- **Crédit** : Compte 607 (Variation des stocks / coût des marchandises vendues) - Montant du coût

### Remises

**Remises clients :**
- Réductions de prix pour biens endommagés
- Remises pour paiement anticipé
- Remises promotionnelles
- Enregistrées comme réduction de vente

## Variations saisonnières

### Cycles commerciaux saisonniers

**Les entreprises de commerce de détail ont souvent :**
- **Saisons de pointe** : Périodes de ventes élevées (vacances, été)
- **Saisons creuses** : Périodes de ventes faibles
- **Accumulation d'inventaire** : Avant les saisons de pointe
- **Réduction d'inventaire** : Après les saisons de pointe

### Gestion des flux de trésorerie

**Gestion des variations saisonnières :**
- Planifier les achats d'inventaire
- Gérer les flux de trésorerie
- Ajuster les niveaux de personnel
- Planifier les campagnes marketing
- Surveiller les niveaux d'inventaire

### Considérations comptables

**Comptabilité saisonnière :**
- Comptabilité d'exercice pour la reconnaissance des revenus
- Gestion de l'inventaire
- Allocation des coûts
- Planification budgétaire
- Analyse des écarts

## Gestion de l'inventaire

### Contrôle de l'inventaire

**Méthodes de contrôle de l'inventaire :**
- **Inventaire permanent** : Suivi continu
- **Inventaire périodique** : Comptages périodiques
- **Analyse ABC** : Se concentrer sur articles de grande valeur
- **Juste-à-temps** : Minimiser les niveaux d'inventaire

### Comptages d'inventaire

**Inventaire physique :**
- Comptages réguliers (mensuels, trimestriels, annuels)
- Comparer aux registres
- Ajuster pour les écarts
- Enquêter sur les différences
- Mettre à jour les registres

## Note de conformité Luxembourg

**Exigences importantes :**
- **Caisse enregistreuse fiscale** : Obligatoire pour le commerce de détail (voir Chapitre 31)
- **Conformité TVA** : Les taux de TVA corrects doivent être appliqués
- **Registres d'inventaire** : Doit maintenir des registres d'inventaire précis
- **Gestion des retours** : Les retours doivent être correctement enregistrés
- **Planification saisonnière** : Planifier pour les variations saisonnières

**Problèmes courants :**
- **Erreurs TVA** : Taux de TVA incorrects appliqués
- **Écarts d'inventaire** : Comptages physiques ne correspondant pas aux registres
- **Erreurs de retours** : Retours non correctement enregistrés
- **Flux de trésorerie saisonnier** : Problèmes de flux de trésorerie pendant les saisons creuses
- **Valorisation de l'inventaire** : Méthodes de valorisation d'inventaire incorrectes
