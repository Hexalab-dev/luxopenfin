# 16.8 Présentation des flux de trésorerie PCN au Luxembourg

### Format PCN

**Structure PCN :**
- Activités d'exploitation
- Activités d'investissement
- Activités de financement
- Doit suivre les classifications PCN
- Doit utiliser le format approprié

### Note de conformité luxembourgeoise

Présentation PCN au Luxembourg :
- Doit suivre la structure PCN
- Doit utiliser les classifications appropriées
- Doit se conformer au format
- Doit être précis
