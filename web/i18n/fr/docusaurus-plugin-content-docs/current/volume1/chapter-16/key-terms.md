# Termes clés

- **Méthode directe** : Montre les encaissements et paiements réels de trésorerie
- **Activités de financement** : Trésorerie provenant de l'emprunt, des capitaux propres, des dividendes
- **Méthode indirecte** : Commence avec le résultat net et ajuste
- **Activités d'investissement** : Trésorerie provenant de l'achat/vente d'actifs
- **Activités d'exploitation** : Trésorerie provenant des opérations quotidiennes
- **État des flux de trésorerie** : Montre les encaissements et paiements de trésorerie
