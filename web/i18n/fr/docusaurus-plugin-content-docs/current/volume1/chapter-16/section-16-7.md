# 16.7 Exigences de l'état des flux de trésorerie au Luxembourg

### Exigences

**Qui doit préparer :**
- Grandes entreprises (basées sur des seuils de taille)
- Peut être requis pour le dépôt RCS
- Utile pour toutes les entreprises

**Format :**
- Doit suivre le format PCN
- Doit inclure toutes les sections
- Doit être précis
- Doit se conformer aux normes

### Note de conformité luxembourgeoise

Exigences au Luxembourg :
- Exigences basées sur la taille
- Doit suivre le format PCN
- Doit être déposé au RCS si requis
- Doit se conformer aux normes

### Réfléchir

Pourquoi les petites entreprises pourraient-elles encore vouloir préparer un état des flux de trésorerie même si ce n'est pas requis ?
