# Résumé du chapitre

### Section 16.1 : Objectif
- Montre les flux de trésorerie
- Explique les variations de trésorerie
- Complète les autres états

### Section 16.2 : Classification des activités
- Exploitation, investissement, financement
- Classification appropriée importante

### Section 16.3 : Méthode indirecte
- Commence avec le résultat net
- Ajuste pour les éléments non monétaires
- Ajuste pour les variations

### Section 16.4 : État complet
- Toutes les trois sections
- Variation nette de la trésorerie
- Soldes de début et de fin

### Section 16.5 : Ratios
- Ratio de flux de trésorerie d'exploitation
- Flux de trésorerie libre
- Flux de trésorerie par rapport à la dette

### Section 16.6 : Méthode directe
- Encaissements/paiements réels de trésorerie
- Plus détaillée
- Moins courante

### Section 16.7 : Exigences
- Exigences basées sur la taille
- Format PCN
- Dépôt RCS

### Section 16.8 : Format PCN
- Structure PCN
- Classifications appropriées
- Compliance
