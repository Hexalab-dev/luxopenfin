# 16.4 Préparer l'état des flux de trésorerie complet en utilisant la méthode indirecte

### État complet

**Format :**
```
État des Flux de Trésorerie
[Nom de l'Entreprise]
[Période]

ACTIVITÉS D'EXPLOITATION
Résultat Net                          €XX,XXX
Ajustements :
  Amortissements                        X,XXX
  [Autres ajustements]                 X,XXX
Variations des Actifs/Passifs Courants :
  [Variations]                           X,XXX
Trésorerie provenant des activités d'exploitation       €XX,XXX

ACTIVITÉS D'INVESTISSEMENT
Achat d'Équipement               (€XX,XXX)
Vente d'Équipement                      X,XXX
Trésorerie provenant de (utilisée dans) l'investissement        (€XX,XXX)

ACTIVITÉS DE FINANCEMENT
Emprunt                              X,XXX
Remboursement de Prêt                    (X,XXX)
Paiement de Dividendes                 (X,XXX)
Trésorerie provenant de (utilisée dans) le financement         €XX,XXX

Variation Nette de la Trésorerie                    €XX,XXX
Trésorerie de Début                         XX,XXX
Trésorerie de Fin                           €XX,XXX
```

### Format PCN Luxembourg

**Exigences PCN :**
- Doit suivre la structure PCN
- Doit utiliser les classifications appropriées
- Doit montrer toutes les activités
- Doit se conformer aux normes

### Note de conformité luxembourgeoise

État complet au Luxembourg :
- Doit suivre le format PCN
- Doit inclure toutes les sections
- Doit être précis
- Doit être déposé si requis
