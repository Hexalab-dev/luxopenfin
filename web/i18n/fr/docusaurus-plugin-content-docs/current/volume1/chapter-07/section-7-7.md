# 7.7 Exigences eCDF et FAIA du Luxembourg

### eCDF (Collecte électronique de données financières)

**Qu'est-ce que l'eCDF ?**

**eCDF** (Collecte électronique de données financières) est la plateforme du Luxembourg pour le dépôt électronique de :
- Déclarations de TVA
- Comptes annuels
- Autres documents fiscaux et financiers

**Objectif :**
- Rationaliser le processus de dépôt
- Réduire les erreurs
- Améliorer l'efficacité
- Assurer la conformité

### Exigences eCDF

**Qui doit utiliser l'eCDF :**
- Toutes les entreprises déposant des déclarations de TVA
- Toutes les entreprises déposant des comptes annuels
- Obligatoire pour le dépôt électronique

**Exigences de dépôt :**
- **Déclarations de TVA** : Mensuelles, trimestrielles ou annuelles (selon l'entreprise)
- **Comptes annuels** : Dans les 7 mois de la fin de l'exercice fiscal
- **Électronique uniquement** : Les déclarations papier ne sont plus acceptées

**Accès :**
- Portail en ligne : https://ecdf.public.lu
- Nécessite une authentification (LuxTrust, eID, etc.)
- Accès sécurisé requis

### Processus de dépôt eCDF

**Étapes :**
1. **Préparer les données** : S'assurer que les registres comptables sont complets
2. **Accéder au portail** : Se connecter à la plateforme eCDF
3. **Sélectionner le formulaire** : Choisir le formulaire approprié (TVA, comptes annuels, etc.)
4. **Saisir les données** : Entrer les informations requises
5. **Valider** : Le système valide les données
6. **Soumettre** : Soumettre électroniquement
7. **Confirmation** : Recevoir la confirmation de dépôt

**Dépôt de déclaration de TVA :**
- Extraire les données TVA du système comptable
- Entrer dans le formulaire de déclaration de TVA eCDF
- Le système calcule la TVA nette
- Soumettre et recevoir la confirmation

**Dépôt de comptes annuels :**
- Préparer les états financiers
- Convertir au format requis (PDF, XML)
- Télécharger sur eCDF
- Soumettre au RCS

### Intégration du système comptable

**Intégration logicielle :**
- De nombreux systèmes comptables s'intègrent avec eCDF
- Sage BOB : Intégration eCDF intégrée
- Odoo : Module eCDF disponible
- Autres systèmes : Peuvent nécessiter une saisie manuelle des données

**Export de données :**
- Les systèmes doivent exporter les données au format compatible eCDF
- Peut nécessiter de formater les données pour eCDF
- Format XML souvent requis

### FAIA (Fichier d'Audit Informatisé AED)

**Qu'est-ce que le FAIA ?**

**FAIA** (Fichier d'Audit Informatisé AED) est un fichier d'audit informatisé que les autorités fiscales peuvent demander à des fins d'audit.

**Objectif :**
- Fournir aux autorités fiscales des données d'audit standardisées
- Basé sur la norme OECD SAF-T (Standard Audit File for Tax)
- Format XML
- Contient des données comptables complètes

### Exigences FAIA

**Qui doit fournir le FAIA :**
- Entités corporatives (SA, SARL, etc.)
- Entreprises individuelles avec chiffre d'affaires supérieur à €100,000 (hors TVA)
- Filiales d'entreprises étrangères
- Lorsqu'il est demandé par les autorités fiscales

**Quand demandé :**
- Lors des audits fiscaux
- Pour la vérification de conformité
- Audits aléatoires
- Sélection basée sur les risques

**Format :**
- Format XML
- Basé sur la norme OECD SAF-T
- Doit inclure toutes les données comptables
- Doit être complet et précis

### Contenu FAIA

**Ce qui est inclus :**
- Grand livre général
- Plan comptable
- Écritures de journal
- Comptes clients et fournisseurs
- Registres d'inventaire
- Immobilisations
- Toutes les transactions pour la période

**Structure :**
- Informations d'en-tête
- Données maîtres (comptes, clients, fournisseurs)
- Données de transaction
- Soldes de clôture

### Exigences du système comptable

**Capacité d'export FAIA :**
- Les systèmes doivent pouvoir exporter au format FAIA
- Sage BOB : Export FAIA intégré
- Odoo : Module FAIA disponible
- Autres systèmes : Peuvent nécessiter des compléments ou une conversion manuelle

**Exigences de données :**
- Registres comptables complets
- Classifications PCN appropriées
- Toutes les transactions incluses
- Précises et vérifiables

### Note de conformité Luxembourg

**Exigences eCDF :**
- Obligatoire pour les déclarations de TVA et les comptes annuels
- Doit déposer électroniquement
- Doit utiliser la plateforme eCDF
- Doit respecter les délais de dépôt
- Pénalités pour non-conformité

**Exigences FAIA :**
- Doit pouvoir fournir lorsqu'il est demandé
- Doit être au format correct (XML, OECD SAF-T)
- Doit être complet et précis
- Doit être fourni dans le délai requis
- Le défaut de fournir peut entraîner des pénalités

### Meilleures pratiques

**Pour eCDF :**
- Maintenir les registres comptables à jour
- Tester l'intégration eCDF avant le dépôt
- Déposer avant les délais
- Conserver les reçus de confirmation
- Vérifier la précision des données

**Pour FAIA :**
- S'assurer que le système peut exporter FAIA
- Tester régulièrement l'export FAIA
- Maintenir les données complètes et précises
- Documenter le processus d'export FAIA
- Être préparé aux demandes d'audit
