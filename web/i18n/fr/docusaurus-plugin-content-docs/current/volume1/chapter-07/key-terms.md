# Termes clés

- **Système d'information comptable (SIC)** : Système qui collecte, traite, stocke et rapporte des informations financières
- **Journal des décaissements** : Journal spécial enregistrant toutes les espèces payées
- **Journal des encaissements** : Journal spécial enregistrant toutes les espèces reçues
- **eCDF** : Collecte électronique de données financières - Plateforme de dépôt électronique du Luxembourg
- **FAIA** : Fichier d'Audit Informatisé AED - Fichier d'audit informatisé (XML, OECD SAF-T)
- **Caisse enregistreuse fiscale** : Caisse enregistreuse certifiée répondant aux exigences légales
- **Journal général** : Journal pour les transactions qui ne correspondent pas aux journaux spéciaux
- **Journal des achats** : Journal spécial enregistrant les achats à crédit
- **Journal des ventes** : Journal spécial enregistrant les ventes à crédit
- **Grand livre auxiliaire** : Grand livre détaillé pour les éléments individuels (clients, fournisseurs) qui soutiennent un compte de contrôle du grand livre général
