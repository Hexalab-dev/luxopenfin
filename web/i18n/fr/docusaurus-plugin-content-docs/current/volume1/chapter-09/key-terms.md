# Termes clés

- **Créances clients** : Montants dus à l'entreprise par des clients qui ont acheté à crédit
- **Rotation des créances clients** : Ratio mesurant combien de fois les créances sont recouvrées
- **Provision pour créances douteuses** : Compte contre-actif estimant les créances irrécouvrables
- **Méthode de provision** : Méthode de comptabilisation des créances douteuses utilisant des estimations
- **Période moyenne de recouvrement** : Nombre moyen de jours pour recouvrer les créances
- **Charges de créances douteuses** : Charge pour les comptes irrécouvrables
- **Méthode de radiation directe** : Radier les créances douteuses lorsqu'elles se produisent (non préférée)
- **Effets à recevoir** : Promesse écrite formelle de paiement avec intérêts
- **Principe de comptabilisation des revenus** : Revenus comptabilisés lorsqu'ils sont gagnés, pas lorsque la trésorerie est reçue
- **Comptes irrécouvrables** : Créances clients qui ne peuvent pas être recouvrées (créances douteuses)
