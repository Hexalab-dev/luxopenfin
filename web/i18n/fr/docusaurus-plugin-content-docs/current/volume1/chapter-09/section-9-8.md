# 9.8 Gestion des comptes clients au Luxembourg (PCN Classe 4 - Tiers)

### PCN Classe 4 : Tiers

La **Classe 4** du PCN contient tous les comptes liés aux tiers (clients, fournisseurs, employés, gouvernement, etc.).

**Plages de comptes :**
- 44 : Fournisseurs
- 40 : Clients
- 42 / 47 : Autres Tiers
- 4216 / 4614 : Comptes TVA
- 462 : Charges Sociales
- 461 : Comptes d'Impôts
- 47 : Autres Dettes
- 48 : Produits Différés
- 18 : Provisions
- 4019 (value adjustments on customers) : Dépréciations et Provisions

### Comptes Clients (40)

**Comptes principaux :**
- **4011** : Créances clients - Clients
- **4012** : Effets à recevoir
- **4012** : Lettres de change à recevoir
- **4012** : Chèques à recevoir
- **4311** : Acomptes reçus sur commandes
- **4013** : Clients douteux

**Sous-comptes :**
- Peut créer des sous-comptes pour des clients individuels
- Exemple : 40111 (Client A), 40112 (Client B)

### Comptes Fournisseurs (44)

**Comptes principaux :**
- **44111** : Dettes fournisseurs - Fournisseurs
- **4421** : Effets à payer
- **4421** : Lettres de change à payer
- **4421** : Chèques à payer
- **44113** : Acomptes versés sur commandes

### Comptes TVA (4216 / 4614)

**Comptes principaux :**
- **461411** : TVA à payer
- **421611** : TVA récupérable
- **461412** : TVA due
- **421612** : Crédit de TVA

### Provision pour créances douteuses

**Compte PCN :**
- **4019** : Provision pour créances douteuses (Dépréciation des Créances Clients)

**Présentation :**
- Compte contre-actif
- Soustrait des Créances clients
- Montre la valeur réalisable nette

### Gestion des comptes clients

**Meilleures pratiques :**

1. **Configuration des comptes**
   - Créer un sous-compte pour chaque client
   - Inclure les informations client
   - Fixer des limites de crédit
   - Définir les conditions de paiement

2. **Enregistrement des transactions**
   - Enregistrer toutes les ventes rapidement
   - Enregistrer tous les paiements rapidement
   - Faire correspondre les paiements aux factures
   - Mettre à jour les soldes régulièrement

3. **Surveillance**
   - Rapports d'échéancier réguliers
   - Surveiller les limites de crédit
   - Suivre l'historique des paiements
   - Identifier les comptes problématiques

4. **Recouvrement**
   - Suivre les comptes en souffrance
   - Envoyer des rappels
   - Escalader si nécessaire
   - Documenter les efforts de recouvrement

### Note de conformité luxembourgeoise

La gestion des comptes clients au Luxembourg doit :
- Utiliser les comptes PCN appropriés (Classe 4)
- Maintenir des registres précis
- Soutenir la conformité TVA
- Permettre l'estimation des créances douteuses
- Soutenir les exigences d'audit
- Maintenir une documentation appropriée
