# 9.6 Identifier et comptabiliser les autres types de créances

### Types de créances

Outre les créances clients, les entreprises peuvent avoir d'autres types de créances :

1. **Effets à recevoir** (couvert dans la section suivante)
2. **Autres créances**
3. **Avances aux employés**
4. **Remboursements d'impôts à recevoir**
5. **Intérêts à recevoir**

### Autres créances

Les **autres créances** comprennent divers montants dus à l'entreprise qui ne sont pas des créances commerciales.

**Exemples :**
- Réclamations d'assurance
- Remboursements d'impôts
- Dépôts auprès des fournisseurs
- Avances aux employés
- Créances diverses

**Compte PCN :**
- 4218 : Autres créances (Classe 4)

**Exemple : Réclamation d'assurance :**
```
4218   Autres créances          €2,000
[Compte approprié]                          €2,000
Pour enregistrer la réclamation d'assurance à recevoir
```

### Avances aux employés

**Avances aux employés :**
- Argent avancé aux employés
- Généralement remboursé par déduction de paie
- Actif courant

**Compte PCN :**
- 42111 : Avances aux employés (Classe 4)

**Exemple :**
- Avance de €500 à un employé

**Écriture de journal :**
```
42111  Avances aux employés      €500
5131   Trésorerie                                    €500
Pour enregistrer l'avance à l'employé
```

**Remboursement :**
```
6211   Charges de salaires           €2,000
42111  Avances aux employés                   €500
5131   Trésorerie (ou 4714   Salaires à payer)      €1,500
Pour enregistrer le paiement du salaire avec déduction de l'avance
```

### Remboursements d'impôts à recevoir

**Remboursements d'impôts :**
- Paiement excessif d'impôts
- Remboursement attendu des autorités fiscales
- Actif courant

**Compte PCN :**
- 4214 : Remboursements d'impôts à recevoir (Classe 4)

**Exemple :**
- Remboursement de TVA de €1,000 attendu

**Écriture de journal :**
```
4214   Remboursements d'impôts à recevoir     €1,000
421611 TVA récupérable (ou 461411 TVA à payer) €1,000
Pour enregistrer le remboursement de TVA attendu
```

**Lors de la réception :**
```
5131   Trésorerie                        €1,000
4214   Remboursements d'impôts à recevoir                  €1,000
Pour enregistrer la réception du remboursement d'impôt
```

### Intérêts à recevoir

**Intérêts à recevoir :**
- Intérêts gagnés mais pas encore reçus
- Généralement sur les effets à recevoir ou les investissements
- Actif courant

**Compte PCN :**
- 4218 : Intérêts à recevoir (Classe 4)

**Exemple :**
- Intérêts de €100 gagnés mais pas reçus

**Écriture de journal :**
```
4218   Intérêts à recevoir        €100
7552   Revenus d'intérêts                        €100
Pour comptabiliser les revenus d'intérêts
```

**Lors de la réception :**
```
5131   Trésorerie                        €100
4218   Intérêts à recevoir                                €100
Pour enregistrer la réception des intérêts
```

### Note de conformité luxembourgeoise

Les autres créances au Luxembourg doivent :
- Être correctement classées (PCN Classe 4)
- Être évaluées de manière appropriée
- Être recouvrables
- Maintenir une documentation appropriée
- Peuvent affecter les calculs fiscaux
