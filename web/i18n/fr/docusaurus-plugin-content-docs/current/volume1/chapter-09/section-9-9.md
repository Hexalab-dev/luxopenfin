# 9.9 TVA luxembourgeoise sur les créances et provisions pour créances douteuses

### TVA sur les ventes à crédit

**Comptabilisation de la TVA :**
- La TVA est due lorsque la vente est effectuée (revenus comptabilisés)
- Pas lorsque la trésorerie est reçue
- TVA à payer créée au moment de la vente

**Exemple :**
- Vente à crédit : €1,000 (hors TVA), TVA 17%
- Revenus : €1,000
- TVA à payer : €170
- Créances clients : €1,170

**Écriture de journal :**
```
4011   Créances clients        €1,170
7061   Chiffre d'affaires                          €1,000
461411 TVA à payer                                  €170
Pour enregistrer la vente à crédit avec TVA
```

### TVA lorsque le compte devient irrécouvrable

**Récupération de la TVA :**
- Si le compte devient irrécouvrable, la TVA peut être récupérable
- Doit suivre les règles de TVA du Luxembourg
- Documentation appropriée requise
- Peut nécessiter d'ajuster la TVA à payer

**Conditions pour la récupération de la TVA :**
- Le compte doit être définitivement irrécouvrable
- Documentation appropriée (procédures légales, faillite, etc.)
- Doit avoir payé la TVA à l'origine
- Doit suivre les procédures de TVA du Luxembourg

**Exemple :**
- Compte de €1,170 (€1,000 + €170 TVA) devient irrécouvrable
- La TVA est récupérable

**Écriture de journal (Radiation) :**
```
4019   Provision pour créances douteuses €1,000
4011   Créances clients                                €1,000
Pour radier le montant net par imputation sur la provision
```

**Écriture de journal (Récupération de TVA) :**
```
461411 TVA à payer                  €170
4011   Créances clients                                  €170
Pour régulariser la TVA collectée sur le compte irrécouvrable
```

Contrôle : le compte 4011 est crédité de €1,000 + €170 = €1,170, ce qui solde la créance. Les deux écritures peuvent être regroupées (Débit 4019 €1,000, Débit 461411 €170, Crédit 4011 €1,170). La provision ne couvre que le montant net ; la TVA collectée initialement déclarée est régularisée lorsque la créance devient définitivement irrécouvrable. Sans provision (radiation directe), on débite 6451 Pertes sur créances irrécouvrables €1,000 au lieu de 4019.

### Provisions pour créances douteuses et impôts

**Traitement fiscal :**
- Les provisions pour créances douteuses peuvent être déductibles fiscalement
- Doit suivre les règles fiscales du Luxembourg
- Doit être raisonnable et justifiable
- Peut nécessiter un ajustement à des fins fiscales

**Règles luxembourgeoises :**
- Les provisions doivent être basées sur des estimations raisonnables
- Doivent être documentées
- Peuvent être ajustées à des fins fiscales
- Des règles spécifiques s'appliquent

### Implications sur la déclaration de TVA

**TVA sur les ventes :**
- Déclarée dans la période où la vente est effectuée
- Pas lorsque la trésorerie est reçue
- Doit suivre la TVA par taux

**Récupération de la TVA :**
- Déclarée lorsque le compte est radié
- Doit avoir une documentation appropriée
- Peut nécessiter de déposer un ajustement

### Note de conformité luxembourgeoise

La TVA sur les créances au Luxembourg :
- TVA due lorsque la vente est effectuée
- La TVA peut être récupérable sur les créances douteuses
- Doit suivre les procédures appropriées
- Doit maintenir la documentation
- Doit déclarer correctement sur la déclaration de TVA
- Doit se conformer aux règles de TVA du Luxembourg

### Exigences de documentation

**Documentation requise :**
- Factures originales
- Preuve des efforts de recouvrement
- Procédures légales (si applicable)
- Documents de faillite (si applicable)
- Documentation de récupération de TVA
- Calculs de provision pour créances douteuses
