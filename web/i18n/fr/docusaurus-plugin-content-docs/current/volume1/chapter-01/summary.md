# Résumé du chapitre

### Section 1.1 – Importance de la comptabilité
- La comptabilité identifie, mesure, enregistre et communique l’information financière.  
- L’équation **Actif = Passif + Capitaux propres** reste la base.  
- La comptabilité financière s’adresse aux utilisateurs externes (PCN).  
- La comptabilité de gestion soutient les décisions internes.  
- Les deux approches sont nécessaires aux PME luxembourgeoises.

### Section 1.2 – Utilisateurs de l’information
- Utilisateurs externes : investisseurs, créanciers, ACD, RCS/CNC.  
- Utilisateurs internes : propriétaires, managers, employés.  
- Chaque groupe recherche des données différentes (rentabilité, flux de trésorerie, conformité, etc.).

### Section 1.3 – Cycle comptable et rôles
- Étapes : identifier → enregistrer → reporter → balance → ajustements → états → clôture.  
- Acteurs clés : fiduciaires, experts-comptables, comptables internes.  
- Exigence constante : documentation complète et conformité au PCN.

### Section 1.4 – Parties prenantes
- La comptabilité crée la confiance, éclaire les décisions, garantit la conformité légale et soutient la croissance.  
- Le non-respect entraîne amendes, poursuites, perte de licence.

### Section 1.5 – Parcours professionnels
- Domaines : fiduciaires, audit, comptabilité d’entreprise, secteur public, enseignement, entrepreneuriat.  
- Compétences attendues : technique (PCN, fiscalité, outils) + soft skills (rigueur, communication multilingue).  
- L’OEC et les associations de fiduciaires accompagnent les professionnels.

### Section 1.6 – Cadre luxembourgeois
- L’OEC régule la profession; les fiduciaires sont agréées.  
- Cadre légal : Code de commerce, PCN 2020, TVA/impôts.  
- Autorités (CNC, RCS, CSSF) surveillent la conformité.
