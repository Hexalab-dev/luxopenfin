# 1.4 Expliquer pourquoi la comptabilité est cruciale pour les parties prenantes

### Créer la confiance

- **Investisseurs** : exigent des données fiables avant d’injecter du capital.  
- **Créanciers** : accordent des lignes de crédit aux entreprises bien tenues.  
- **Clients** : privilégient les fournisseurs financièrement solides.  
- **Employés** : se sentent en sécurité dans une structure saine.

### Aider la prise de décision

- **Dirigeants** : expansion, investissement, politique tarifaire.  
- **Managers** : produits les plus rentables, respect du budget, économies potentielles.  
- **Investisseurs** : rentabilité, rendement attendu, exposition aux risques.

### Respecter la loi

Au Luxembourg :  
- Code de commerce → obligation de tenue comptable, archivage 10 ans.  
- PCN 2020 → plan de comptes obligatoire.  
- Déclarations TVA via eCDF, comptes annuels au RCS, déclarations fiscales exactes et ponctuelles.  
- Risques en cas de manquement : amendes, actions en justice, retrait d’agrément, voire poursuites pénales.

### Soutenir la croissance

- **Financement** : banques et investisseurs demandent des états financiers.  
- **Planification** : les données guident la stratégie.  
- **Mesure de performance** : comparer objectifs et résultats.  
- **Gestion des risques** : repérer rapidement les dérives.
