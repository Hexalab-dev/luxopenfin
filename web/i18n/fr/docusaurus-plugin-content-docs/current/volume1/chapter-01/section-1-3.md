# 1.3 Décrire les principales activités comptables et le rôle des professionnels

### Le cycle comptable

Au Luxembourg, le cycle comptable doit respecter le PCN et les obligations légales.

1. **Identifier les opérations** : ventes, achats, salaires, emprunts, loyers, etc. Chaque transaction doit être justifiée (factures, extraits bancaires) et conservée dix ans.  
2. **Enregistrer dans le journal** selon la méthode de la partie double.  

   ```
   Date : 2024-11-19
   Débit : 5131   Banque (Cetrel)    103,00 €
   Crédit : 7061   Ventes            100,00 €
   Crédit : 461411 TVA due (3 %)       3,00 €
   Libellé : Vente sur place réglée par carte
   ```

3. **Reporter au grand livre** : ventilation dans chaque compte PCN.  
4. **Établir la balance** pour vérifier l’égalité débits/crédits.  
5. **Passer les écritures d’inventaire** : charges à payer, charges constatées d’avance, amortissements, TVA à solder, etc.  

   ```
   Débit : 461411 TVA due          1 500,00 €
   Crédit : 421611 TVA déductible  1 200,00 €
   Crédit : 5131   Banque            300,00 €
   Libellé : Règlement TVA novembre
   ```

6. **Produire les états financiers** : compte de résultat, bilan, tableau des flux, annexe.  
7. **Clôturer** : transférer les soldes des comptes de résultat vers les capitaux propres.

### Rôles des professionnels au Luxembourg

- **Fiduciaires** (cabinets agréés) : tenue comptable, déclarations TVA/impôt, élaboration des comptes annuels, conseil. Autorisation d'établissement du ministère de l'Économie (et adhésion à l'Ordre des Experts-Comptables pour les experts-comptables), assurance RC pro obligatoire.  
- **Experts-comptables (OEC)** : certification, audit, fiscalité, conseil stratégique. Formation, stage, examen et formation continue requis.  
- **Comptables internes** : gestion quotidienne, reporting, assistance conformité pour les PME.

### Note conformité

Les entreprises peuvent combiner équipe interne et fiduciaire, mais restent responsables du respect du PCN et des exigences légales, quelle que soit l’organisation retenue.
