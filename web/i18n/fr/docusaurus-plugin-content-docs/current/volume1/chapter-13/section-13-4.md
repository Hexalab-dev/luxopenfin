# 13.4 Annexe : Sujets spéciaux liés aux passifs à long terme

### Sujets spéciaux

**Obligations de location :**
- Locations opérationnelles vs. locations financières
- Les locations financières enregistrées comme passifs
- Doivent se conformer aux normes comptables de location

**Dette convertible :**
- Dette qui peut être convertie en capitaux propres
- Considérations comptables spéciales
- Moins courante pour les PME

**Restructuration de la dette :**
- Modification des conditions de la dette
- Traitement comptable spécial
- Peut impliquer un gain ou une perte

### Note de conformité luxembourgeoise

Sujets spéciaux au Luxembourg :
- Doivent suivre les normes comptables
- Doivent se conformer aux règlements
- Doivent maintenir une documentation appropriée
- Doivent utiliser les comptes PCN appropriés
