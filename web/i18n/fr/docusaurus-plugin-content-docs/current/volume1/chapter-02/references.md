# Références

## Sources officielles

- **Guichet.lu – Comptes annuels** : obligations, procédures de dépôt, PCN.  
- **CNC (Commission des Normes Comptables)** : documentation PCN 2020, formats, avis.  
- **RCS Luxembourg** : dépôt, consultation publique, informations par forme juridique.

## Ressources PCN

- **Guide PCN KPMG** (FR) – plan de comptes complet, exemples.  
- Notes officielles PCN 2020 (classes 1–7).

## Formes juridiques

- **Guichet.lu – Formes d’entreprises** : comparatifs SA/SARL/SNC/SCS, démarches, capital.  
- **Legitech – Précis de droit comptable** : analyse juridique, obligations d’annexe.

## Formation

- **House of Training** – formations PCN, préparation des états, eCDF.  
- **Université du Luxembourg** – programmes comptabilité/finance.

## Lectures complémentaires

- OpenStax *Principles of Financial Accounting* – bases universelles.  
- Publications OEC, CSSF (pour entités régulées) sur les exigences de reporting.
