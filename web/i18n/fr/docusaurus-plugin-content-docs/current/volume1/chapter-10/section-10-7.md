# 10.7 Comptes d'inventaire PCN Classe 3 du Luxembourg

### PCN Classe 3 : Inventaire

La **Classe 3** du PCN contient tous les comptes liés à l'inventaire.

**Plages de comptes :**
- 30 : Matières Premières
- 31 : En Cours de Fabrication
- 32 : Produits Finis
- 361 : Marchandises

### Comptes d'inventaire principaux

#### 301 : Matières Premières

**Utilisation :**
- Matériaux à utiliser dans la production
- Ingrédients pour la fabrication
- Composants à assembler

**Exemple :** Entreprise de fabrication
```
301    Matières Premières              €5,000
```

#### 311 : En Cours de Fabrication

**Utilisation :**
- Produits partiellement complétés
- Fabrication en cours
- Construction en cours

**Exemple :** Entreprise de fabrication
```
311    En Cours de Fabrication           €3,000
```

#### 321 : Produits Finis

**Utilisation :**
- Produits complétés prêts à la vente
- Entreprises de fabrication
- Produits en attente de vente

**Exemple :** Entreprise de fabrication
```
321    Produits Finis             €8,000
```

#### 361 : Marchandises

**Utilisation :**
- Biens achetés pour la revente
- Entreprises de détail
- Entreprises de gros
- Restaurants (articles de détail)

**Exemple :** Magasin de détail
```
361    Marchandises                €15,000
```

### Sous-comptes d'inventaire

**Peut créer des sous-comptes :**
- 3611 : Marchandises - Catégorie A
- 3612 : Marchandises - Catégorie B
- 3011 : Matières Premières - Type X
- 3012 : Matières Premières - Type Y

**Objectif :**
- Meilleur suivi
- Plusieurs types de produits
- Différents taux de TVA
- Meilleure gestion

### Comptes de coût des marchandises vendues

**Comptes PCN :**
- **607** : Coût des Marchandises Vendues
- **601** : Consommation de Matières
- **607** : Coût des Produits Vendus

**Pour les entreprises de détail :**
- Utiliser 607 : Coût des Marchandises Vendues

**Pour la fabrication :**
- Utiliser 601 : Consommation de Matières
- Utiliser 607 : Coût des Produits Vendus

### Comptes d'évaluation d'inventaire

**Comptes de provision :**
- **3619** : Dépréciation des Stocks

**Utilisation :**
- Lorsque la valeur de l'inventaire est inférieure au coût
- Dépréciations à la valeur réalisable nette
- Inventaire obsolète

### Note de conformité luxembourgeoise

Les comptes d'inventaire PCN Classe 3 doivent :
- Être correctement classés
- Utiliser les numéros de comptes corrects
- Soutenir les valeurs d'inventaire
- Permettre le calcul correct du coût des marchandises vendues
- Soutenir la présentation des états financiers
- Se conformer aux exigences PCN
