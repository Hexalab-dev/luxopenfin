# Termes clés

- **Hypothèse de flux de coûts** : Méthode pour attribuer les coûts aux biens vendus et à l'inventaire final
- **FIFO (Premier Entré, Premier Sorti)** : Méthode d'inventaire supposant que les premiers articles achetés sont les premiers vendus
- **Rotation des stocks** : Ratio mesurant combien de fois l'inventaire est vendu et remplacé
- **Système d'inventaire périodique** : Système où l'inventaire est mis à jour uniquement en fin de période
- **Système d'inventaire perpétuel** : Système où l'inventaire est mis à jour en continu
- **Identification spécifique** : Méthode d'inventaire suivant le coût spécifique de chaque article
- **Moyenne pondérée** : Méthode d'inventaire utilisant le coût moyen pour toutes les unités
- **Jours de ventes en inventaire** : Nombre moyen de jours pendant lesquels l'inventaire est détenu avant la vente
