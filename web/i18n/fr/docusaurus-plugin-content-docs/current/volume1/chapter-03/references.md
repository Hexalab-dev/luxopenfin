# Références et lectures complémentaires

## Sources officielles luxembourgeoises

- **Guichet.lu - Obligations comptables** : https://guichet.public.lu/en/entreprises/gestion-juridique-comptabilite/comptable/enregistrement/obligations-comptables.html
  - Exigences de comptabilité en partie double
  - Obligations de tenue de registres
  - Exigences de conservation

- **Commission des Normes Comptables (CNC)** : https://cnc.lu
  - Classifications de comptes PCN
  - Normes comptables
  - Lignes directrices pour l'enregistrement des transactions

- **Code de Commerce** :
  - Exigences légales pour la comptabilité
  - Mandat de comptabilité en partie double
  - Exigences de conservation des registres
