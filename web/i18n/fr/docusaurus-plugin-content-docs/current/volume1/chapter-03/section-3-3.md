# 3.3 Définir et décrire les étapes initiales du cycle comptable

### Vue d'ensemble du cycle comptable

Le **cycle comptable** est le processus d'enregistrement, de classification et de synthèse des transactions commerciales pour produire les états financiers. Au Luxembourg, ce cycle doit suivre les normes PCN et les exigences légales.

Le cycle comptable complet comprend :
1. Identifier les transactions
2. Enregistrer les transactions dans le journal
3. Reporter aux comptes du grand livre
4. Préparer une balance
5. Passer les écritures d'ajustement
6. Préparer la balance ajustée
7. Préparer les états financiers
8. Clôturer les comptes temporaires
9. Préparer la balance après clôture

Dans ce chapitre, nous nous concentrons sur les étapes 1-4. Les étapes 5-9 sont couvertes dans les chapitres 4 et 5.

### Étape 1 : Identifier les transactions

**Objectif :** Déterminer quels événements économiques doivent être enregistrés dans le système comptable.

**Critères d'enregistrement :**
- Doit être une transaction commerciale (affecte l'entité commerciale)
- Doit être mesurable en termes monétaires (euros)
- Doit affecter les actifs, passifs ou capitaux propres

**Exemples de transactions à enregistrer :**
- Ventes aux clients
- Achats aux fournisseurs
- Paiement de charges
- Réception d'espèces
- Emprunt d'argent
- Investissements du propriétaire

**Exemples d'événements NON enregistrés :**
- Embaucher un employé (pas encore de transaction monétaire)
- Recevoir un devis (pas encore d'engagement)
- Changements de valeur marchande (jusqu'à réalisation)

**Exigence luxembourgeoise :** Toutes les transactions commerciales doivent être justifiées par des documents sources (factures, reçus, relevés bancaires) et conservées pendant 10 ans.

### Étape 2 : Analyser les transactions

**Objectif :** Déterminer quels comptes sont affectés et comment (débit ou crédit).

**Processus :**
1. Identifier les comptes affectés
2. Déterminer le type de compte (actif, passif, capitaux propres, produit, charge)
3. Déterminer si le compte augmente ou diminue
4. Appliquer les règles débit/crédit
5. Vérifier que l'équation est équilibrée

**Exemple d'analyse :**

**Transaction :** Le restaurant vend 500 € de nourriture contre espèces.

**Analyse :**
1. Comptes affectés : Trésorerie, Chiffre d'affaires
2. Trésorerie = Actif (augmente = débit)
3. Chiffre d'affaires = Produit (augmente = crédit)
4. Débit Trésorerie 500 €, Crédit Chiffre d'affaires 500 €
5. Équation : Actifs augmentent, Capitaux Propres (via produits) augmentent ✓

**Comptes PCN :**
- Débit : 5131 Trésorerie (Classe 5)
- Crédit : 7061 Chiffre d'affaires (Classe 7)

### Étape 3 : Enregistrer les transactions dans le journal

**Objectif :** Enregistrer les transactions chronologiquement dans un journal (livre d'entrée original).

**Format du journal :**
- Date
- Noms et numéros de comptes
- Montants débit
- Montants crédit
- Description/explication

**Exemple d'écriture comptable :**

```
Date : 2024-11-19

Compte                          Débit      Crédit
─────────────────────────────────────────────────
5131   Trésorerie                €500
7061   Chiffre d'affaires                         €500
Pour enregistrer la vente au comptant de nourriture
```

**Pratique luxembourgeoise :** Les écritures comptables doivent inclure les numéros de comptes PCN pour une classification et une conformité appropriées.

### Étape 4 : Reporter aux comptes du grand livre

**Objectif :** Transférer les écritures comptables vers les comptes individuels du grand livre (livre d'entrée final).

**Format du compte du grand livre (Compte en T) :**

```
Nom du compte (Numéro de compte)
─────────────────────────────
        Débit        Crédit
─────────────────────────────
```

**Processus de report :**
1. Trouver le compte dans le grand livre
2. Entrer la date
3. Entrer le montant du côté approprié (débit ou crédit)
4. Entrer la référence (numéro de page du journal)
5. Calculer le nouveau solde

**Exemple de report :**

**Écriture comptable :**
```
5131   Trésorerie                €500
7061   Chiffre d'affaires                €500
```

**Reporté au grand livre :**

```
Trésorerie (5131)
─────────────────────────────
19 nov  J1    €500    │
─────────────────────────────
Solde  €500
```

```
Chiffre d'affaires (7061)
─────────────────────────────
        │  19 nov  J1    €500
─────────────────────────────
        │  Solde  €500
```

### Note de conformité Luxembourg

Au Luxembourg, les entreprises doivent maintenir :
- **Journal (Journal) :** Enregistrement chronologique de toutes les transactions
- **Grand Livre (Grand Livre) :** Tous les comptes avec leurs soldes
- **Sous-Livres (Sous-Livres) :** Comptes détaillés (par exemple, comptes clients individuels)

Tous doivent suivre les classifications PCN et être maintenus pendant 10 ans.
