# Résumé du chapitre

### Section 3.1 : Principes, hypothèses et concepts comptables
- Principes comptables : Coût, Reconnaissance des revenus, Correspondance, Divulgation complète
- Hypothèses comptables : Entité économique, Continuité d'exploitation, Période, Unité monétaire
- Comptabilité d'exercice requise au Luxembourg
- Tous les principes intégrés dans les normes PCN

### Section 3.2 : Équation comptable élargie
- Équation de base : Actifs = Passifs + Capitaux Propres
- Équation élargie inclut : Capital Social, Bénéfices Reportés, Produits, Charges, Prélèvements
- Chaque transaction affecte l'équation
- Débits et crédits maintiennent l'équilibre
- Aide-mémoire DEAD CLIC pour les règles débit/crédit

### Section 3.3 : Étapes initiales du cycle comptable
- Étape 1 : Identifier les transactions
- Étape 2 : Analyser les transactions
- Étape 3 : Enregistrer dans le journal
- Étape 4 : Reporter au grand livre
- Toutes les étapes doivent suivre les exigences PCN

### Section 3.4 : Analyser les transactions avec l'équation comptable
- Approche systématique de l'analyse des transactions
- Chaque transaction affecte au moins deux comptes
- Doit vérifier que l'équation reste toujours équilibrée
- Considérer la TVA dans les transactions luxembourgeoises
- Montrer l'impact sur les états financiers

### Section 3.5 : Utiliser les écritures comptables et reporter aux comptes en T
- Écritures comptables : Date, comptes, débits, crédits, description
- Comptes en T : Représentation visuelle des comptes du grand livre
- Soldes normaux : Actifs/Charges (débit), Passifs/Capitaux Propres/Produits (crédit)
- Doit inclure les numéros de comptes PCN
- Le report transfère les écritures du journal au grand livre

### Section 3.6 : Préparer une balance
- Liste tous les comptes et leurs soldes
- Vérifie que débits = crédits
- Prouve l'exactitude mathématique
- Ne prouve pas que toutes les transactions sont enregistrées correctement
- Étape requise avant les états financiers

### Section 3.7 : Système de numérotation PCN du Luxembourg
- Numérotation hiérarchique : classe (1 chiffre) → groupe (2 chiffres) → comptes de plus en plus détaillés (ex. 4 → 40 → 401 → 4011)
- 7 classes (1-7) par premier chiffre
- Sous-comptes pour suivi détaillé
- Doit utiliser les numéros PCN pour toutes les transactions
- Garantit la cohérence et la conformité

### Section 3.8 : Exigences de partie double du Luxembourg
- La comptabilité en partie double est une exigence légale
- Chaque transaction affecte au moins deux comptes
- Doit maintenir journaux, grands livres, documents sources
- Exigence de conservation de 10 ans
- Pénalités importantes pour non-conformité
