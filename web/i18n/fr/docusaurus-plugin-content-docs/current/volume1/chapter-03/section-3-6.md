# 3.6 Préparer une balance

### Qu'est-ce qu'une balance ?

Une **balance** est une liste de tous les comptes et leurs soldes à un moment donné. Elle vérifie que le total des débits égale le total des crédits.

**Objectif :**
- Vérifier l'exactitude mathématique
- Identifier les erreurs de report
- Préparer les états financiers
- Étape requise dans le cycle comptable

### Format de la balance

**Format standard :**
```
Nom de l'entreprise
Balance
Date

Compte                          Débit      Crédit
─────────────────────────────────────────────────
[Nom du compte (Numéro)]        €X,XXX
[Nom du compte (Numéro)]                    €X,XXX
...
─────────────────────────────────────────────────
Totaux                          €XX,XXX    €XX,XXX
```

### Préparation d'une balance

**Étapes :**
1. Lister tous les comptes qui ont des soldes
2. Entrer les soldes débiteurs dans la colonne Débit
3. Entrer les soldes créditeurs dans la colonne Crédit
4. Totaliser les deux colonnes
5. Vérifier que les totaux sont égaux

### Ce qu'une balance prouve et ne prouve pas

**Une balance prouve :**
- L'exactitude mathématique (débits = crédits)
- Toutes les transactions ont été reportées
- Aucune erreur d'écriture unique

**Une balance ne prouve PAS :**
- Toutes les transactions ont été enregistrées
- Les transactions ont été enregistrées correctement
- Les transactions ont été enregistrées dans les bons comptes
- Aucune erreur compensatoire (erreurs qui s'annulent mutuellement)

### Erreurs courantes non détectées par la balance

1. **Transactions omises** : Transaction non enregistrée du tout
2. **Mauvais compte** : Transaction enregistrée dans le mauvais compte
3. **Erreurs compensatoires** : Deux erreurs qui s'annulent mutuellement
4. **Erreurs d'entrée originale** : Montant incorrect dans l'écriture comptable (mais les débits égalent toujours les crédits)

### Correction des erreurs

Si la balance n'est pas équilibrée :

1. **Vérifier l'addition** des colonnes de la balance
2. **Vérifier les soldes des comptes** dans le grand livre
3. **Vérifier le report** du journal au grand livre
4. **Vérifier les écritures comptables** (débits = crédits)
5. **Examiner les documents sources**

### Note de conformité Luxembourg

Au Luxembourg, les entreprises doivent préparer des balances :
- Au moins mensuellement (pour la gestion)
- En fin de période (pour les états financiers)
- Avant le dépôt des comptes annuels
- À des fins d'audit

Les balances doivent :
- Utiliser les classifications de comptes PCN
- Inclure les numéros de comptes
- Être conservées pendant 10 ans
- Soutenir la préparation des états financiers
