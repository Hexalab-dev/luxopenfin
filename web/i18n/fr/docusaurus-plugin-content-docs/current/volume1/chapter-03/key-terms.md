# Termes clés

- **Cycle comptable** : Processus d'enregistrement, de classification et de synthèse des transactions
- **Équation comptable** : Actifs = Passifs + Capitaux Propres
- **Comptabilité d'exercice** : Enregistrement des transactions lorsqu'elles se produisent, pas lorsque l'argent change de mains
- **Crédit** : Côté droit d'un compte ; augmente les passifs, capitaux propres, produits ; diminue les actifs, charges
- **Débit** : Côté gauche d'un compte ; augmente les actifs, charges ; diminue les passifs, capitaux propres, produits
- **Comptabilité en partie double** : Système où chaque transaction affecte au moins deux comptes
- **Équation comptable élargie** : Actifs = Passifs + Capital Social + Bénéfices Reportés + Produits - Charges - Prélèvements
- **Journal** : Enregistrement chronologique de toutes les transactions
- **Écriture comptable** : Enregistrement formel d'une transaction
- **Grand Livre** : Collection de tous les comptes montrant les soldes
- **Principe de correspondance** : Les charges enregistrées dans la même période que les produits associés
- **Solde normal** : Côté du compte où les augmentations sont enregistrées
- **Report** : Transfert des écritures comptables vers les comptes du grand livre
- **Principe de reconnaissance des revenus** : Les revenus enregistrés lorsqu'ils sont gagnés, pas lorsque l'argent est reçu
- **Document source** : Document original justifiant une transaction (facture, reçu, etc.)
- **Compte en T** : Représentation visuelle d'un compte du grand livre
- **Balance** : Liste de tous les comptes et leurs soldes pour vérifier que les débits égalent les crédits
