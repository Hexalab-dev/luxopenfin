# 3.4 Analyser les transactions commerciales en utilisant l'équation comptable et montrer l'impact sur les états financiers

### Cadre d'analyse des transactions

Pour analyser correctement les transactions, suivez cette approche systématique :

1. **Identifier la transaction** et le document source
2. **Déterminer les comptes affectés** (au moins deux)
3. **Classifier chaque compte** (actif, passif, capitaux propres, produit, charge)
4. **Déterminer l'augmentation ou la diminution** pour chaque compte
5. **Appliquer les règles débit/crédit**
6. **Vérifier que l'équation est équilibrée**
7. **Identifier les comptes PCN**

### Exemples complets de transactions

Analysons une série de transactions pour le restaurant de Marie, montrant l'impact sur l'équation comptable et les états financiers.

#### Position de départ

**Bilan, 1er novembre 2024 :**
```
Actifs = Passifs + Capitaux Propres
€10,000 = €0 + €10,000
(Trésorerie)              (Capital Social)
```

#### Transaction 1 : Achat d'équipement

**Transaction :** Le restaurant achète 15 000 € d'équipement de cuisine, payant 5 000 € en espèces et signant un billet pour 10 000 €.

**Analyse :**
- Équipement (Actif) augmente : +€15,000
- Trésorerie (Actif) diminue : -€5,000
- Billets à payer (Passif) augmente : +€10,000

**Impact sur l'équation :**
```
Avant :  €10,000 = €0 + €10,000
Après :  €20,000 = €10,000 + €10,000
        (€15,000 équipement + €5,000 trésorerie)
```

**Comptes PCN :**
- Débit : 222 Équipement (Classe 2) €15,000
- Crédit : 5131 Trésorerie (Classe 5) €5,000
- Crédit : 4421 Billets à payer (Classe 4) €10,000

**Impact sur les états financiers :**
- **Bilan :** Actifs augmentent (équipement), Trésorerie diminue, Passifs augmentent
- **Compte de résultat :** Aucun impact (pas de produit ou charge)

#### Transaction 2 : Achat de stocks à crédit

**Transaction :** Le restaurant achète 2 000 € de stocks alimentaires à crédit auprès d'un fournisseur.

**Analyse :**
- Stocks (Actif) augmentent : +€2,000
- Fournisseurs (Passif) augmentent : +€2,000

**Impact sur l'équation :**
```
Avant :  €20,000 = €10,000 + €10,000
Après :  €22,000 = €12,000 + €10,000
```

**Comptes PCN :**
- Débit : 361 Stocks (Classe 3) €2,000
- Crédit : 44111 Fournisseurs (Classe 4) €2,000

**Impact sur les états financiers :**
- **Bilan :** Actifs augmentent, Passifs augmentent
- **Compte de résultat :** Aucun impact (les stocks sont un actif, pas une charge jusqu'à la vente)

#### Transaction 3 : Fournir des services contre espèces (avec TVA)

**Transaction :** Le restaurant organise un événement privé pour un client (décoration, musique et personnel de service, sans nourriture ni boissons) pour 1 000 €, reçus par virement. Ces services sont soumis au taux normal de TVA de 17 % (les repas et boissons non alcoolisées seraient à 3 %).

**Analyse :**
- Trésorerie (Actif) augmente : +€1,170 (€1,000 + €170 TVA)
- Produits de services (Produit, augmente Capitaux Propres) augmente : +€1,000
- TVA à payer (Passif) augmente : +€170

**Impact sur l'équation :**
```
Avant :  €22,000 = €12,000 + €10,000
Après :  €23,170 = €12,170 + €11,000
        (Les produits augmentent les capitaux propres)
```

**Comptes PCN :**
- Débit : 5131 Trésorerie (Classe 5) €1,170
- Crédit : 703 Produits de services (Classe 7) €1,000
- Crédit : 461411 TVA à payer (Classe 4) €170

**Impact sur les états financiers :**
- **Bilan :** Actifs augmentent, Passifs (TVA) augmentent, Capitaux Propres augmentent
- **Compte de résultat :** Produits augmentent (affecte le résultat net)

#### Transaction 4 : Payer les salaires

**Transaction :** Le restaurant paie 3 000 € de salaires aux employés.

**Analyse :**
- Trésorerie (Actif) diminue : -€3,000
- Charges de salaires (Charge, diminue Capitaux Propres) augmente : +€3,000

**Impact sur l'équation :**
```
Avant :  €23,170 = €12,170 + €11,000
Après :  €20,170 = €12,170 + €8,000
        (Les charges diminuent les capitaux propres)
```

**Comptes PCN :**
- Débit : 6211 Charges de salaires (Classe 6) €3,000
- Crédit : 5131 Trésorerie (Classe 5) €3,000

**Impact sur les états financiers :**
- **Bilan :** Actifs diminuent, Capitaux Propres diminuent
- **Compte de résultat :** Charges augmentent (diminuent le résultat net)

#### Transaction 5 : Payer les fournisseurs

**Transaction :** Le restaurant paie 1 500 € au fournisseur pour l'achat de stocks précédent.

**Analyse :**
- Trésorerie (Actif) diminue : -€1,500
- Fournisseurs (Passif) diminue : -€1,500

**Impact sur l'équation :**
```
Avant :  €20,170 = €12,170 + €8,000
Après :  €18,670 = €10,670 + €8,000
```

**Comptes PCN :**
- Débit : 44111 Fournisseurs (Classe 4) €1,500
- Crédit : 5131 Trésorerie (Classe 5) €1,500

**Impact sur les états financiers :**
- **Bilan :** Actifs diminuent, Passifs diminuent
- **Compte de résultat :** Aucun impact (paiement d'un passif, pas une charge)

### Résumé des impacts des transactions

| Transaction | Actifs | Passifs | Capitaux Propres | Produits | Charges |
|------------|--------|---------|------------------|----------|---------|
| 1. Achat d'équipement | +€10,000 | +€10,000 | - | - | - |
| 2. Achat de stocks | +€2,000 | +€2,000 | - | - | - |
| 3. Fournir des services | +€1,170 | +€170 | +€1,000 | +€1,000 | - |
| 4. Payer les salaires | -€3,000 | - | -€3,000 | - | +€3,000 |
| 5. Payer les fournisseurs | -€1,500 | -€1,500 | - | - | - |
| **Changement net** | **+€8,670** | **+€670** | **-€2,000** | **+€1,000** | **+€3,000** |

**Équation finale :**
```
€18,670 = €10,670 + €8,000
Actifs = Passifs + Capitaux Propres ✓
```

### Considérations TVA Luxembourg

Lors de l'analyse des transactions au Luxembourg, toujours considérer la TVA :

**Transactions de vente :**
- Enregistrer les produits (hors TVA)
- Enregistrer la TVA à payer (461411)
- Le total espèces/créances inclut la TVA

**Transactions d'achat :**
- Enregistrer la charge/actif (hors TVA si récupérable)
- Enregistrer la TVA récupérable (421611) si l'entreprise peut récupérer la TVA
- Le total espèces/payables inclut la TVA
