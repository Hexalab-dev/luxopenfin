# 11.6 Comptabilité des actifs fixes luxembourgeois (PCN Classe 2 - Immobilisations)

### PCN Classe 2 : Immobilisations (Actifs fixes)

La **Classe 2** du PCN contient tous les actifs à long terme.

**Plages de comptes :**
- 20–21 : Actifs incorporels (Immobilisations Incorporelles)
- 21 : Actifs incorporels (suite)
- 22 : Actifs corporels (Immobilisations Corporelles)
- 23 : Actifs corporels (suite)
- …9 sub-accounts : Amortissement cumulé (Amortissements)
- …9 sub-accounts : Amortissement cumulé (Amortissements Incorporels)
- 23 : Actifs financiers (Immobilisations Financières)

### Actifs incorporels (21)

**Comptes principaux :**
- **211** : Coûts de recherche et développement
- **212** : Concessions, Brevets, Licences
- **213** : Fonds de commerce
- **21** : Autres actifs incorporels

**Exemple :**
```
212    Brevets                     €50,000
```

### Actifs corporels (22)

**Comptes principaux :**
- **2211** : Terrain (Terrains)
- **2213** : Bâtiments (Constructions)
- **2221** : Installations techniques
- **222** : Équipement et machines (Matériel et Outillage)
- **2232** : Véhicules (Matériel de Transport)
- **2234** : Mobilier et agencements (Mobilier)
- **2235** : Matériel informatique (Matériel Informatique)
- **2238** : Autres actifs corporels

**Exemple : Équipement de restaurant :**
```
222    Équipement                   €25,000
```

**Exemple : Véhicule :**
```
2232   Véhicules                    €30,000
```

### Amortissement cumulé (…9 sub-accounts)

**Comptes principaux :**
- **22139** : Amortissement cumulé - Bâtiments
- **2229** : Amortissement cumulé - Équipement
- **22329** : Amortissement cumulé - Véhicules
- **22389** : Amortissement cumulé - Autres

**Exemple :**
```
2229   Amortissement cumulé - Équipement €10,000
```

### Actifs financiers (23)

**Comptes principaux :**
- **231** : Participations dans des filiales
- **235** : Autres investissements financiers
- **236** : Prêts accordés

### Note de conformité luxembourgeoise

Exigences PCN Classe 2 :
- Doit utiliser les classifications de comptes appropriées
- Doit maintenir des comptes séparés pour différents types d'actifs
- Doit suivre l'amortissement cumulé séparément
- Doit se conformer à la structure PCN
- Doit soutenir les valeurs des actifs
- Doit permettre une présentation appropriée des états financiers
