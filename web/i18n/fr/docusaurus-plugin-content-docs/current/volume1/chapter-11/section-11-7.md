# 11.7 Règles d'amortissement luxembourgeoises et implications fiscales

### Amortissement fiscal luxembourgeois

**Amortissement fiscal :**
- Différent de l'amortissement comptable
- Doit suivre les règles fiscales
- Affecte le revenu imposable
- Taux différents pour différents actifs

### Taux d'amortissement fiscal courants

**Bâtiments :**
- Nouveaux bâtiments : 2-4% par an
- Bâtiments d'occasion : Varie
- Méthode linéaire

**Équipement :**
- Équipement général : 10-20% par an
- Solde dégressif ou linéaire
- Méthodes accélérées autorisées

**Véhicules :**
- Voitures : 20-25% par an
- Camions : 15-20% par an
- Solde dégressif courant

**Matériel informatique :**
- 33% par an (accéléré)
- Souvent entièrement amorti en 3 ans

### Amortissement comptable vs. fiscal

**Différences :**
- Comptable : Suivre les normes comptables
- Fiscal : Suivre les règles fiscales
- Peut utiliser des méthodes différentes
- Crée des différences temporaires

**Exemple :**
- Équipement : €10,000
- Comptable : Linéaire, 5 ans = €2,000/an
- Fiscal : Solde dégressif, 20% = €2,000 année 1, €1,600 année 2, etc.

**Résultat :** Différence temporaire dans le revenu imposable

### Note de conformité luxembourgeoise

Amortissement au Luxembourg :
- Doit suivre les règles fiscales à des fins fiscales
- Peut utiliser une méthode différente pour les livres
- Doit maintenir des registres pour les deux
- Doit réconcilier les différences
- Affecte les calculs fiscaux
- Doit être correctement documenté

Pourquoi une entreprise pourrait-elle utiliser des méthodes d'amortissement différentes pour les livres et les fins fiscales ? Quelles sont les implications ?
