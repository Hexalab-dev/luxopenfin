# Résumé du chapitre

### Section 11.1 : Actifs corporels vs. incorporels
- Corporels : Actifs physiques (équipement, bâtiments)
- Incorporels : Actifs non physiques (brevets, fonds de commerce)
- Traitement comptable différent
- PCN Classe 2 pour les deux

### Section 11.2 : Coûts capitalisés vs. Charges
- Capitaliser : Avantages à long terme, coûts significatifs
- Charger : Avantage immédiat, coûts non significatifs
- Inclure tous les coûts directs dans le coût de l'actif
- Exclure la TVA (si récupérable)

### Section 11.3 : Méthodes d'amortissement
- Linéaire : Montant constant chaque année
- Solde dégressif : Méthode accélérée
- Unités de production : Basé sur l'utilisation
- Doit utiliser une méthode cohérente

### Section 11.4 : Actifs incorporels
- Durée limitée : Amortir
- Durée indéfinie : Tester pour dépréciation
- Fonds de commerce : Non amorti
- Brevets : Amortis

### Section 11.5 : Problèmes spéciaux
- Dépréciation : Réduire si valeur baisse
- Cession : Retirer l'actif, enregistrer gain/perte
- Réparations vs. Améliorations : Charger vs. capitaliser

### Section 11.6 : Luxembourg PCN Classe 2
- 21 : Actifs incorporels
- 22 : Actifs corporels
- …9 sub-accounts : Amortissement cumulé
- Doit utiliser les classifications appropriées

### Section 11.7 : Règles d'amortissement luxembourgeoises
- Taux fiscaux diffèrent par type d'actif
- Peut différer de l'amortissement comptable
- Doit suivre les règles fiscales pour fiscal
- Affecte le revenu imposable

### Section 11.8 : Actifs incorporels luxembourgeois
- Fonds de commerce : Non amorti
- Brevets : Amortis
- Marques de commerce : Peuvent être indéfinies
- Doit se conformer aux normes
