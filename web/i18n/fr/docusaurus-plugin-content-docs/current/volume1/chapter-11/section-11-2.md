# 11.2 Analyser et classer les coûts capitalisés par rapport aux charges

### Coûts capitalisés vs. Charges

**Coûts capitalisés :**
- Enregistrés comme actifs
- Amortis sur la durée d'utilité
- Faire correspondre le coût aux périodes qui bénéficient

**Charges :**
- Enregistrées immédiatement
- Réduisent le revenu dans la période actuelle
- Pas d'avantage futur

### Quand capitaliser

**Capitaliser si :**
- L'actif a une durée d'utilité supérieure à 1 an
- L'actif fournit des avantages économiques futurs
- Le coût est significatif
- L'actif est utilisé dans les opérations commerciales

**Charger si :**
- L'avantage est consommé immédiatement
- Le coût est non significatif
- Maintenance ou réparation (ne prolonge pas la durée de vie)
- Charge d'exploitation courante

### Exemples : Capitaliser

**Achat d'équipement :**
- Prix d'achat : €10,000
- Livraison : €500
- Installation : €1,000
- **Total capitalisé : €11,500**

**Écriture de journal :**
```
222    Équipement                   €11,500
5131   Trésorerie (ou 44111  Dettes fournisseurs)                €11,500
Pour enregistrer l'achat d'équipement
```

**Améliorations de bâtiment :**
- Rénovation qui prolonge la durée d'utilité : €50,000
- **Capitaliser : €50,000**

### Exemples : Charger

**Réparations :**
- Maintenance courante : €500
- **Charge : €500**

**Écriture de journal :**
```
6122   Réparations et entretien    €500
5131   Trésorerie                                    €500
Pour enregistrer la maintenance courante
```

**Petits achats :**
- Fournitures de bureau : €100
- **Charge : €100** (non significatif, consommé immédiatement)

### Composantes du coût

**Ce qu'il faut inclure dans le coût de l'actif :**

1. **Prix d'achat** : Montant de la facture
2. **Coûts de livraison** : Expédition, fret
3. **Coûts d'installation** : Configuration, assemblage
4. **Frais juridiques** : Titre, enregistrement
5. **Coûts de test** : Tests initiaux
6. **Autres coûts directs** : Nécessaires pour rendre l'actif prêt

**Ce qu'il ne faut PAS inclure :**

1. **Coûts de financement** : Intérêts (comptabilisés séparément)
2. **Coûts de formation** : Formation des employés (chargée)
3. **Coûts d'exploitation** : Maintenance continue (chargée)

### Considérations luxembourgeoises

**Traitement de la TVA :**
- La TVA sur les achats d'actifs est généralement récupérable
- Enregistrée séparément (TVA Récupérable)
- Non incluse dans le coût de l'actif

**Exemple :**
- Équipement : €10,000 (hors TVA)
- TVA 17% : €1,700
- Total : €11,700

**Écriture de journal :**
```
222    Équipement                   €10,000
421611 TVA Récupérable              1,700
5131   Trésorerie (ou 44111  Dettes fournisseurs)                €11,700
Pour enregistrer l'achat d'équipement avec TVA
```

### Note de conformité luxembourgeoise

Pour les coûts capitalisés au Luxembourg :
- Doit suivre les exigences PCN Classe 2
- Doit inclure tous les coûts directs
- Doit exclure la TVA (si récupérable)
- Doit être correctement documenté
- Doit se conformer aux règles fiscales
- Doit soutenir les valeurs des actifs

### Réfléchir

Une entreprise achète un équipement pour €5,000 et dépense €500 pour la livraison et €1,000 pour l'installation. Tous ces coûts devraient-ils être capitalisés ? Pourquoi ou pourquoi pas ?
