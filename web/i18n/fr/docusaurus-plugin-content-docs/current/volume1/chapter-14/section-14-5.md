# 14.5 Discuter de l'applicabilité du bénéfice par action comme méthode pour mesurer la performance

### Bénéfice par action (BPA)

**Formule BPA :**
**BPA = Résultat Net ÷ Nombre Moyen Pondéré d'Actions en Circulation**

**Objectif :**
- Mesurer la rentabilité par action
- Comparer entre entreprises
- Important pour les investisseurs

**Exemple :**
- Résultat Net : €50,000
- Actions en Circulation : 10,000
- BPA : €50,000 ÷ 10,000 = €5.00 par action

### Considérations luxembourgeoises

**BPA au Luxembourg :**
- Requis pour les sociétés publiques
- Optionnel pour les sociétés privées
- Utile pour la mesure de la performance
- Peut être calculé pour toute société

### Note de conformité luxembourgeoise

BPA au Luxembourg :
- Divulgation requise pour certaines entreprises
- Doit être calculé correctement
- Doit être divulgué s'il est significatif
- Utile pour l'analyse

### Réfléchir

Pourquoi le bénéfice par action est-il utile ? Comment aide-t-il les investisseurs à évaluer une entreprise ?
