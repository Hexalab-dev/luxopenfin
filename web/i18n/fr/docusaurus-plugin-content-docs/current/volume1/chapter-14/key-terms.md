# Termes clés

- **Dividendes** : Distributions aux actionnaires
- **Bénéfice par action (BPA)** : Résultat net par action
- **Bénéfices non distribués** : Profits accumulés non distribués
- **Capital social** : Montant investi par les propriétaires
- **Dividende en actions** : Distribution d'actions supplémentaires
- **Fractionnement d'actions** : Augmenter les actions, diminuer la valeur nominale proportionnellement
- **Actions propres** : Actions propres de l'entreprise rachetées
