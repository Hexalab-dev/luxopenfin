# 12.4 Passifs courants luxembourgeois (PCN Classe 4 - Fournisseurs)

### PCN Classe 4 : Tiers

La **Classe 4** contient toutes les obligations envers des tiers.

**Plages de comptes :**
- 44 : Fournisseurs (Fournisseurs)
- 40 : Clients (Clients)
- 42 / 47 : Autres tiers
- 4216 / 4614 : Comptes TVA (TVA)
- 462 : Charges sociales (Charges Sociales)
- 461 : Comptes fiscaux (Impôts)
- 47 : Autres passifs (Autres Dettes)
- 48 : Revenus différés (Produits Différés)

### Comptes fournisseurs (44)

**Comptes principaux :**
- **44111** : Dettes fournisseurs - Fournisseurs
- **4421** : Effets à payer aux fournisseurs
- **4421** : Lettres de change à payer
- **44113** : Avances aux fournisseurs

### Comptes TVA (4216 / 4614)

**Comptes principaux :**
- **461411** : TVA à payer
- **421611** : TVA récupérable
- **461412** : TVA due
- **421612** : Crédit TVA

### Charges sociales (462)

**Comptes principaux :**
- **4714** : Salaires à payer
- **4621** : Charges sociales à payer
- **4621** : Charges sociales employé à payer
- **4621** : Charges sociales employeur à payer

### Comptes fiscaux (47)

**Comptes principaux :**
- **46121** : Impôt sur le revenu à payer
- **46122** : Impôt commercial communal à payer
- **461** : Autres impôts à payer

### Note de conformité luxembourgeoise

Exigences PCN Classe 4 :
- Doit utiliser les classifications de comptes appropriées
- Doit maintenir des registres précis
- Doit soutenir tous les soldes
- Doit se conformer à la structure PCN
- Doit permettre une comptabilité appropriée
