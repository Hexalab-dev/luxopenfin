# Résumé du chapitre

### Section 12.1 : Passifs courants
- Obligations dues dans un délai d'un an
- Incluent les dettes fournisseurs, la TVA à payer, les salaires à payer
- Doivent être correctement classés
- PCN Classe 4

### Section 12.2 : Congés payés
- Doivent être comptabilisés
- Enregistrer le passif pour les CP non utilisés
- Se conformer au droit du travail
- Suivre avec précision

### Section 12.3 : Dette à court terme
- Effets à payer dus dans un délai d'un an
- Doit comptabiliser les intérêts
- Partie courante de la dette à long terme
- Classification appropriée

### Section 12.4 : Luxembourg PCN Classe 4
- 44 : Fournisseurs
- 4216 / 4614 : TVA
- 462 : Charges sociales
- 461 : Impôts
- Doit utiliser les comptes appropriés

### Section 12.5 : TVA à payer
- Collecter la TVA sur les ventes
- Payer la TVA sur les achats
- TVA nette aux autorités
- Déposer via eCDF
- Suivre par taux

### Section 12.6 : Charges sociales
- Parties employé et employeur
- Coût important
- Doivent être payées à temps
- Comptabilité appropriée requise
