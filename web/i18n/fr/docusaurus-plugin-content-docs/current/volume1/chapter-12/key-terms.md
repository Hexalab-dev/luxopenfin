# Termes clés

- **Dettes fournisseurs** : Montants dus aux fournisseurs
- **Passifs courants** : Obligations dues dans un délai d'un an
- **Charges sociales** : Cotisations de sécurité sociale
- **TVA à payer** : TVA due aux autorités fiscales
- **Salaires à payer** : Salaires dus aux employés
- **Effets à payer à court terme** : Effets dus dans un délai d'un an
- **Revenus non gagnés** : Paiements reçus à l'avance
