# 15.5 Discuter et enregistrer les écritures liées à la dissolution d'une société de personnes

### Dissolution d'une société de personnes

**La dissolution se produit lorsque :**
- L'accord de société expire
- Les associés décident de dissoudre
- Un associé se retire (si pas de continuation)
- Autres événements selon l'accord

### Processus de liquidation

**Étapes :**
1. Vendre tous les actifs
2. Payer toutes les dettes
3. Distribuer la trésorerie restante aux associés
4. Fermer les comptes de capital

**Exemple :**
- Actifs vendus : €200,000
- Dettes payées : €50,000
- Trésorerie disponible : €150,000
- Associé A (60%) : €90,000
- Associé B (40%) : €60,000

**Écritures de journal :**
```
5131   Trésorerie                       €200,000
[Comptes d'Actifs]                               €[montants]
744    Gain sur Liquidation                     €[gain]
Pour enregistrer la vente d'actifs

[Comptes de Dettes]              €50,000
5131   Trésorerie                                   €50,000
Pour payer les dettes

1041   Associé A, Capital         €90,000
1042   Associé B, Capital         60,000
5131   Trésorerie                                  €150,000
Pour distribuer la trésorerie aux associés
```

### Note de conformité luxembourgeoise

Dissolution au Luxembourg :
- Doit suivre le droit des sociétés de personnes
- Doit déposer au RCS
- Doit régler tous les comptes
- Doit se conformer aux procédures
