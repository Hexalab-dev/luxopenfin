# Termes clés

- **Écritures de clôture** : Écritures de journal qui transfèrent les soldes des comptes temporaires vers les comptes permanents
- **Ratio de liquidité** : Actifs courants ÷ Passifs courants ; mesure la liquidité
- **Résultat** : Compte temporaire utilisé dans le processus de clôture pour résumer les revenus et les charges
- **Liquidité** : Capacité à honorer les obligations à court terme en utilisant les actifs courants
- **Comptes permanents** : Comptes qui reportent les soldes (actifs, passifs, capitaux propres)
- **Balance après clôture** : Balance préparée après les écritures de clôture, contient uniquement les comptes permanents
- **Comptes temporaires** : Comptes clôturés en fin de période (revenus, charges)
- **Fonds de roulement** : Actifs courants - Passifs courants ; excédent des actifs courants sur les passifs courants
