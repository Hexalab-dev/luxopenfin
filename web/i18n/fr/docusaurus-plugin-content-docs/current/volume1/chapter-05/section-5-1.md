# 5.1 Décrire et préparer les écritures de clôture pour une entreprise

### Qu'est-ce que les écritures de clôture ?

Les **écritures de clôture** sont des écritures de journal effectuées à la fin d'une période comptable pour transférer les soldes des comptes temporaires (revenus et charges) vers les comptes permanents (capitaux propres/bénéfices non distribués).

**Pourquoi clôturer les comptes ?**

1. **Réinitialiser les comptes temporaires** : Les comptes de revenus et de charges sont réinitialisés à zéro pour la période suivante
2. **Mettre à jour les bénéfices non distribués** : Le résultat net ou la perte est transféré aux bénéfices non distribués
3. **Préparer pour la période suivante** : Les comptes sont prêts à accumuler les transactions de la nouvelle période
4. **Compléter le cycle comptable** : La clôture est la dernière étape avant de commencer une nouvelle période

### Comptes temporaires vs. comptes permanents

**Comptes temporaires** (Clôturés en fin de période) :
- **Comptes de revenus** (Classe 7) : Réinitialisés à zéro
- **Comptes de charges** (Classe 6) : Réinitialisés à zéro
- **Résultat** (compte temporaire utilisé dans le processus de clôture)

**Comptes permanents** (Non clôturés) :
- **Comptes d'actifs** (Classes 2, 3, 4, 5) : Les soldes sont reportés
- **Comptes de passifs** (Classes 1, 4) : Les soldes sont reportés
- **Comptes de capitaux propres** (Classe 1) : Mis à jour mais non réinitialisés

### Le processus de clôture

Le processus de clôture comprend quatre étapes :

1. **Clôturer les comptes de revenus** → Résultat
2. **Clôturer les comptes de charges** → Résultat
3. **Clôturer le Résultat** → Bénéfices non distribués
4. **Clôturer les prélèvements/distributions** → Bénéfices non distribués (si applicable)

### Étape 1 : Clôturer les comptes de revenus

**Objectif :** Transférer tous les soldes des comptes de revenus vers le Résultat

**Processus :**
- Débiter chaque compte de revenus de son solde
- Créditer le Résultat du total des revenus

**Exemple :**

De la balance ajustée :
- Revenus de services (703) : solde créditeur de 13 000 €

**Écriture de clôture :**
```
Date : 2024-11-30

703    Revenus de services              €13,000
142    Résultat                                       €13,000
Pour clôturer les comptes de revenus vers le Résultat
```

**Note PCN :** Le Résultat est généralement le compte 142 ou un compte temporaire. Certaines entreprises utilisent une méthode de clôture directe.

**Après clôture :**
- Revenus de services : 0 €
- Résultat : solde créditeur de 13 000 €

### Étape 2 : Clôturer les comptes de charges

**Objectif :** Transférer tous les soldes des comptes de charges vers le Résultat

**Processus :**
- Créditer chaque compte de charges de son solde
- Débiter le Résultat du total des charges

**Exemple :**

De la balance ajustée :
- Charges de salaires (6211) : solde débiteur de 9 500 €
- Charges de loyer (6111) : solde débiteur de 2 400 €
- Charges de services publics (6184) : solde débiteur de 1 500 €
- Charges d'assurance (614) : solde débiteur de 100 €
- Charges d'amortissement (633) : solde débiteur de 500 €
- Charges d'intérêts (6552) : solde débiteur de 100 €
- Charges de fournitures (6185) : solde débiteur de 1 000 €

**Total des charges :** 15 100 €

**Écriture de clôture :**
```
Date : 2024-11-30

142    Résultat                        €15,100
6211   Charges de salaires                         €9,500
6111   Charges de loyer                             2,400
6184   Charges de services publics                  1,500
6185   Charges de fournitures                       1,000
614    Charges d'assurance                            100
633    Charges d'amortissement                        500
6552   Charges d'intérêts                             100
Pour clôturer les comptes de charges vers le Résultat
```

**Après clôture :**
- Tous les comptes de charges : 0 €
- Résultat : 15 100 € débit, 13 000 € crédit = solde débiteur de 2 100 € (Perte nette)

### Étape 3 : Clôturer le Résultat

**Objectif :** Transférer le résultat net ou la perte nette aux Bénéfices non distribués

**Processus :**
- Si Résultat net : Débiter le Résultat, Créditer les Bénéfices non distribués
- Si Perte nette : Créditer le Résultat, Débiter les Bénéfices non distribués

**Exemple (Perte nette) :**

Le Résultat a un solde débiteur de 2 100 € (Perte nette)

**Écriture de clôture :**
```
Date : 2024-11-30

141    Bénéfices non distribués            €2,100
142    Résultat                                       €2,100
Pour clôturer le Résultat (perte nette) aux Bénéfices non distribués
```

**Après clôture :**
- Résultat : 0 €
- Bénéfices non distribués : Diminués de 2 100 € (perte nette)

**Si Résultat net (Exemple alternatif) :**

Si le Résultat avait un solde créditeur de 2 000 € (Résultat net) :

**Écriture de clôture :**
```
Date : 2024-11-30

142    Résultat                        €2,000
141    Bénéfices non distribués                      €2,000
Pour clôturer le Résultat (résultat net) aux Bénéfices non distribués
```

### Étape 4 : Clôturer les prélèvements/distributions (Si applicable)

**Objectif :** Transférer les prélèvements du propriétaire ou les distributions aux Bénéfices non distribués

**Note :** Cette étape s'applique si l'entreprise a un compte de prélèvements (commun dans les entreprises individuelles) ou effectue des distributions (dans les sociétés).

**Exemple (Prélèvements) :**

Si le propriétaire a prélevé 500 € pendant la période :

**Écriture de clôture :**
```
Date : 2024-11-30

141    Bénéfices non distribués            €500
10611  Prélèvements du propriétaire                      €500
Pour clôturer les prélèvements aux Bénéfices non distribués
```

**Note PCN :** Les prélèvements sont généralement dans la Classe 3 ou gérés via les comptes de capitaux propres, selon le type d'entité.

### Alternative : Méthode de clôture directe

Certaines entreprises clôturent directement vers les Bénéfices non distribués sans utiliser le Résultat :

**Étape 1 : Clôturer les revenus**
```
703    Revenus de services              €13,000
141    Bénéfices non distribués                      €13,000
```

**Étape 2 : Clôturer les charges**
```
141    Bénéfices non distribués            €15,100
6211   Charges de salaires                         €9,500
6111   Charges de loyer                             2,400
[Autres charges...]
```

**Résultat :** Identique à l'utilisation du Résultat, mais avec moins d'écritures.

### Note de conformité Luxembourg

Au Luxembourg, les écritures de clôture doivent :
- Être effectuées en fin de période (mensuelle, trimestrielle ou annuelle)
- Utiliser les classifications de comptes PCN appropriées
- Être documentées et conservées pendant 10 ans
- Être complétées avant le dépôt des états financiers
- Suivre les normes PCN pour le traitement des comptes
