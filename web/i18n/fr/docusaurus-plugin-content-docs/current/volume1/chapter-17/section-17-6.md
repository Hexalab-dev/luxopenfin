# 17.6 Annexe : Décrire d'autres mesures utilisées pour analyser une entreprise

### Autres mesures

**Valeur économique ajoutée (EVA) :**
- Mesure la création de valeur
- Considère le coût du capital
- Mesure avancée

**Ratios de marché :**
- Prix/bénéfice (P/E)
- Marché/valeur comptable
- Pour les entreprises publiques

### Considérations luxembourgeoises

**Pour les PME :**
- Se concentrer sur les ratios de base
- Comparer aux références
- Utiliser pour la prise de décision
- Moins d'attention aux ratios de marché

### Note de conformité luxembourgeoise

Autres mesures au Luxembourg :
- Certaines mesures avancées disponibles
- Se concentrer sur les ratios pratiques pour les PME
- Utiliser pour l'analyse
- Soutenir les décisions
