# 17.1 Décrire le besoin et l'objectif de l'analyse des états financiers

### Besoin d'analyse

**Les chiffres bruts ne racontent pas toute l'histoire :**
- Besoin de calculer des ratios
- Besoin de comparer les périodes
- Besoin de comparer aux références
- Besoin d'identifier les tendances

### Objectif


**Figure 17.1:** Financial Statement Analysis Framework

```
                    Financial Statements
                           │
        ┌──────────────────┼──────────────────┐
        │                  │                  │
   Horizontal          Vertical          Ratio
   Analysis            Analysis          Analysis
        │                  │                  │
Compare periods    Compare to total    Calculate ratios
over time          (common-size)        │
        │                  │        ┌────┴────┐
        │                  │        │         │
    Trends            Percentages  Liquidity Profitability
        │                  │        │         │
    Growth            Structure   Current  Gross
    Patterns          Analysis    Ratio    Margin
                                           │
                                      Return on
                                      Actif
```

*Texte alternatif : Diagram showing the financial statement analysis framework with three main approaches: Horizontal Analysis (comparing periods over time to identify trends and growth patterns), Vertical Analysis (comparing to total using common-size statements to analyze structure), and Ratio Analysis (calculating liquidity ratios like current ratio and profitability ratios like gross margin and return on assets), demonstrating the different methods of analyzing financial statements.*

**L'analyse aide à :**
- Évaluer la performance
- Identifier les forces et faiblesses
- Prendre des décisions
- Communiquer avec les parties prenantes
- Planifier l'avenir

### Utilisateurs de l'analyse

**Utilisateurs internes :**
- Direction
- Propriétaires
- Employés

**Utilisateurs externes :**
- Investisseurs
- Créanciers
- Fournisseurs
- Gouvernement

### Note de conformité luxembourgeoise

Analyse financière au Luxembourg :
- Importante pour toutes les entreprises
- Aide à la prise de décision
- Soutient la conformité
- Utile pour les parties prenantes
