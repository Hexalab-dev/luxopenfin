# 17.2 Préparer des états financiers comparatifs

### États comparatifs

**États financiers comparatifs :**
- Montrent plusieurs périodes côte à côte
- Permettent la comparaison période par période
- Montrent les changements en montants et pourcentages
- Identifient les tendances

### Format

**Compte de résultat :**
```
                   2024        2023      Changement      % Changement
Revenus          €100,000   €90,000    €10,000      11.1%
Dépenses           70,000     65,000      5,000       7.7%
Résultat Net       € 30,000   €25,000     €5,000      20.0%
```

### Analyse

**Les changements montrent :**
- Croissance ou déclin
- Tendances
- Domaines nécessitant une attention

### Note de conformité luxembourgeoise

États comparatifs au Luxembourg :
- Utiles pour l'analyse
- Aident à identifier les tendances
- Soutiennent la prise de décision
- Peuvent être requis pour certains dépôts
