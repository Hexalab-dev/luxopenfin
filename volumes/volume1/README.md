# Volume 1: Financial Accounting for Luxembourg SMEs

## Overview

Volume 1 covers the fundamentals of financial accounting with specific application to Luxembourg SMEs. Each chapter integrates universal accounting principles with Luxembourg-specific regulations, PCN requirements, and practical examples.
